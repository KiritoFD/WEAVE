## 2. 本轮补齐的 8 个单因素消融

基准 = `D1_c1_gentle` 精确复现（`base_dim=48` → 1,881,792 参数）：

```
--mode direct --canon-mode c1_gentle --base-dim 48 --steps 800 --microbatch 80
--accum 3 --lr 3e-4 --coherence-beta 0.0 --w-rec 1.0 --w-style-dist 0.25
--w-cross 0.35 --w-canon-inv 1.5 --seed 42
```

| ID | 变更 | 状态 |
|---|---|---|
| **A0_ref** | 无（复现验证） | ✅ **与 D1_c1_gentle 逐项完全一致**（ΔT +0.0323 / DINO 0.9167 / LPIPS 0.3658 / 分目标全同） |
| **A1_no_content** | 去掉每层内容注入（内容仍在 stem 里） | 🔄 训练中 |
| **A2_no_style** | Style-ID 固定为 0 | ⏳ 排队 |
| **A3_canon_none** | 内容 = 原始 latent，不做规范化 | ⏳ 排队 |
| **A4_dim24** | base_dim 24（0.48M） | ⏳ 排队 |
| **A5_dim32** | base_dim 32（0.85M） | ⏳ 排队 |
| **A6_dim40** | base_dim 40（1.31M） | ⏳ 排队 |
| **A7_steps400** | 训练步数减半 | ⏳ 排队 |
| **A1b_content_none** | 内容完全移除（连 stem 也置零）→ 纯风格生成 | ⏳ 排队 |

> **A1 与 A1b 的区别很重要。** direct 模式下调用是 `model(c_in, 0.0, c_in, y)`，
> 所以 stem 输入 `[z_in, c, z_in-c] = [c, c, 0]`。
> `--no-content` 只把 `c` 置零 → stem 仍看到 `[c, 0, c]`，**内容并未移除**，
> 测的是那 0.6% 参数的内容注入路径。
> `--content-mode none` 把 `z_in` 与 `c` 都置零 → 真正的纯风格生成对照。
> （已用随机化输出头验证：`none` 对内容完全不变，`no_inject` 仍依赖内容。）

**ETA**：每臂约 42 分钟（训练 19 分 + 评测 22 分），8 臂约 5.6 小时。

## 3. 已知的负面/警示信号（不需要新实验就能看出）

1. **Ukiyo-e 在每一个变体里都是负的**（−0.0014 ~ −0.1306）。
   V6 报告里"5/5 风格改善、Ukiyo-e +0.0049"来自**推理强度标定**（α=0.70），
   不是原始模型。**原始模型是 4/5。**
2. **ΔT 与 DINO-C 是竞争关系**：D1_T1_strong 的 ΔT 最高（+0.0404）但 DINO-C 掉到 0.8859；
   D1_c1_gentle 折中（+0.0323 / 0.9167）。**没有单一最优，必须先声明目标。**
3. **w_canon_inv=0 会崩**（+0.0017）：内容不变性项不是可选项。
4. **flow 模式在同样预算下更差**，且多 8 步推理。没有理由保留。

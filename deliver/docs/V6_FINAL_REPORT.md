## 1. 结果：最小可用模型缩小到 A0 的 11.6%

| | A0（基准） | **L11（最终）** | 变化 |
|---|---:|---:|---:|
| **参数** | 1,881,792 | **217,824** | **−88.4%** |
| 训练时间 | 19.0 min | **12.0 min** | −37% |
| CSD ΔT | +0.0323 | **+0.0421** | **+0.0098** |
| DINO-C | 0.9167 | **0.9216** | +0.0049 |
| LPIPS | 0.3658 | **0.3403** | **−0.0255（−7.0%）** |
| 风格改善 | 4/5 | **5/5** | +1 |
| 自一致 ΔS | −0.0084 | **+0.0066** | 转为正 |

**配置**：`C3UNet(mode="direct", base_dim=16)` + **1024/风格参考统计** + `c1_gentle` + 800 步。

**七项指标无一项变差。**

### 1.1 三件事让模型变小反而变好

| 改动 | 效果 |
|---|---|
| **参考统计 64 → 1024/风格** | LPIPS −0.0253、DINO-C +0.0057（统计噪声降低约 4 倍） |
| **宽度 48 → 16** | 参数 −88.4%，ΔT 反而上升（抑制实例记忆，被迫学风格层统计） |
| **删除 Core64 采样课程 / B1 编码器** | 零损失（前者 ΔT −0.0002，后者只贡献 0.048%） |

## 3. 核心问题：模型不改变风格身份

### 3.1 指标是好的（决定性对照）

| 层级 | 要求 | **Top-1** |
|---|---|---:|
| **Same150**（目标 = 源风格） | "别改风格" | **0.980 – 0.987** |
| **Heldout400**（目标 ≠ 源风格） | "改成目标风格" | **0.025 – 0.072** |

**同一批模型、同一分类器、同一解码链路。五种风格在"不要求改变"时全部被正确识别（96.7%–100%）。**

> **所以问题不在指标，在变换本身。**

### 3.2 变换"改了很多但瞄不准"

| 量 | 值 |
|---|---:|
| 潜空间变换幅度 | 71.66 |
| 跨目标差异 | 66.39 |
| **比值** | **0.982** |
| **CSD 空间朝目标位移 ΔT** | **仅 +0.03** |
| CSD 空间离源位移 ΔS | −0.11 |
| **方向纯度 \|ΔT\|/\|ΔS\|** | **0.30** |

**模型在潜空间里做了很大改变（换目标风格的改变 ≈ 整个变换的 98%），
但只有 30% 的 CSD 空间位移朝目标 —— 70% 是"去掉了源风格却没换成目标风格"。**

**因此输出仍有 91.4% 被识别为源风格，目标风格仅 3.1%。**

### 3.3 加大幅度能小幅改善，但代价不可接受

M0 的 α 扫描（α=0 → 2.0）：

| α | ΔT | **Top-1** | LPIPS |
|---:|---:|---:|---:|
| 0.00 | −0.0005 | 0.015 | 0.078 |
| 1.00 | **+0.0354** | 0.035 | 0.366 |
| 1.25 | +0.0365（峰值） | 0.075 | 0.454 |
| 2.00 | +0.0074 | **0.130** | **0.655** |

**Top-1 确实随幅度上升，但即使 α=2.0（训练幅度的 2 倍）也只有 0.130，仍低于随机 0.20，
而 LPIPS 从 0.366 涨到 0.655。**

**外推：达到 0.20 需要 α≈3.0，此时图像基本被破坏。**

## 4. 两个必须承认的边界

### 4.1 Val200 的绝对数字乐观约 40%

| 模型 | Val200 ΔT | Heldout400 ΔT | 保留 |
|---|---:|---:|---:|
| L8 | +0.0386 | +0.0226 | 59% |
| L10 | +0.0380 | +0.0218 | 57% |

**在 100 个源图与 Val200 完全不相交的源上，ΔT 只有 Val200 的约 58%。**
**排序保持（L8 > L9 > L10 > L2），但绝对值不能当泛化性能。**

**原因**：CSD 原型与评测参考集都来自训练池（仅排除 300 张源图）。

### 4.2 Minimalism 与 Ukiyo 在未见源图上无改善

| 目标 | Heldout400 上四个模型的 ΔT |
|---|---:|
| **Minimalism** | **−0.014 ~ −0.004（全负）** |
| **Ukiyo_e** | **−0.035 ~ −0.018（全负）** |

**Val200 上 Minimalism +0.026、Ukiyo +0.0006 的改善不能泛化。**

**根因**：DWT 统计空间里 Ukiyo 与 ER 只差 **0.60**，这个空间没有可用的判别方向。
**这是特征空间的天花板，不是调参问题。**

## 5. 结构性解释

> **V6 在 DWT 子带统计空间监督风格，而"是否画成目标风格"在 CSD 语义空间度量。
> 两空间弱耦合 → DWT 空间优化饱和，CSD 空间可识别性保持平坦。**

**四条汇聚证据**：
1. S5：DWT 空间里 Ukiyo 与 ER 只差 0.60；HF 特征与现有 DWT 矩冗余 0.921
2. L4：DWT 统计精度提升带来 LPIPS −0.0253，但 Top-1 毫无变化
3. 24 臂：ΔT 变化 2.6 倍，Top-1 恒定 0.02–0.05，秩相关仅 0.214
4. V11 d2：直接在 CSD 空间监督，L_dist 降 65% 但 CSD-SWD 仍平坦

## 6. 下一步（按推荐度）

### 路径 A（推荐）：提高方向纯度

**理由**：幅度已经很大（比值 0.98），但方向纯度只有 0.30。
**继续放大幅度只会同时放大错误分量。**

**具体做法**：
1. **人工盲评**（计划 §1 要求，唯一未做项）—— 网格图已就绪：
   `runs/v6_24h/grid/grid_*.png`，每张含源图 / VAE 往返 / 五个目标输出，附 `manifest.json`
2. **在损失中显式约束方向**：例如要求 ΔT ≥ κ·|ΔS|，惩罚"只降 ΔS 不升 ΔT"的位移
3. 若确认需要换机制，再考虑在 CSD 空间直接监督可识别性（须先解决 V11 d2 的传导失败）

### 路径 B：换特征空间（针对 Minimalism / Ukiyo 天花板）

DWT 统计空间无法区分这两个目标，**必须换空间**。
但 V11 的教训是 latent 与 CSD 空间失配，需先解决传导问题。

### 明确不该做的事

| 不该做 | 原因 |
|---|---|
| 继续调 λ_s / λ_c | λ_c 已饱和；2×2 因子设计完整，交互项已量化 |
| 继续调 base_dim | 16 已测，48→16 无一致退化 |
| 加 DWT 统计类损失 | S5 预实验证明该空间无法区分困难目标 |
| 用 ΔT 单指标排名 | 秩相关仅 0.214；α>1 后两者方向相反 |
| 把 ΔT +0.008 当显著进展 | 小于 VAE 往返漂移 0.0113 |
| 宣称"5/5 风格改善" | 依赖 Ukiyo 的 +0.0006（噪声内），且 Heldout400 上为负 |
| 单层消融推断"该层不重要" | 三层内容注入是冗余通路（单层 ≤0.0018，全关 +0.0151） |
| 单点正面结果直接推广 | style keys 在 dim32 是 +0.0022，dim48 只有 +0.0011 |

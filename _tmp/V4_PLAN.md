# V4 执行要点（用户 2026-11-06 下发《WEAVE V4｜12小时核心实验＋2小时缓冲》摘要，逐条硬约束）

> 本文件是执行时逐项对照的检查清单，不是交付文档。原文全文曾随对话下发；此处保留全部硬阈值与矩阵。

## 一、前置三项检查（P0 四项审计不重做）

### P1 Pattern 可行性三态 + 实测覆盖率分层
- 三态记录：`match_found`（找到内容相似供体）/ `layout_feasible`（该 Pattern 全部 Patch 匹配通过）/ `partial_feasible`（部分 Patch 可用、实测覆盖率低于名义值）。
- 128px 名义 25% 实测 0.2340：**不要因少一个 patch 整张丢弃**，按实测覆盖率分层：
  - ≥22% → 进 25% 训练池
  - 18–22% → 低覆盖候选，**不混入主实验**
  - <18% → 不训练
  - 22% 是工程分组阈值，不是风格质量阈值。
- 同时记录：某 Pattern 在固定配对上的通过率 / 重新检索供体后的通过率 / 单布局与全布局共同可行样本数 / 实测覆盖率。
- `effective_coverage`：二值硬掩码记真实覆盖面积；羽化另记"非零覆盖面积"和"权重积分覆盖率"，两者不许混用。
- **A_P5 / E7 / E3 必须用同一基础配对集合**（不能因各方案匹配通过率不同吃不同数据分布）。

### P2 FM 可达性 + 数据流
- `z1_reachable = IDWT(LL1, LH1, HL1, HH0)`，与真实伪 GT 比：CSD 目标增益 / 内容变化 / HH 残余能量。若风格改善主要靠不可预测 HH，别指望三头网络复现。
- `z_tau = (1-tau) z0 + tau z1` 必须直接用缓存配对；关闭 SAT 二次改写目标、训练时 AdaIN、未明确需要的桥噪声。

### P3 条件不泄漏
- `target_style_id` 指向真正训练目标风格。
- 正向 A：真实源图 → 拼贴伪 GT，标签 = 供体风格。
- 反向 E：拼贴输入 → 原始真实图，标签 = 原图风格。
- 参考图条件不得把本次配对的真实 GT 当参考；VAE 统一 posterior mean（所有方案相同）。

P1/P2/P3 通过后进入训练，**不再扩大数据筛选实验**。

## 二、训练矩阵（四条新路线 + 一个条件控制）

| 实验 | 训练配对 | Patch 配置 | 步数 | 优先级 |
|---|---|---|---|---|
| S0 | 既有 FM 基线 | 原始训练目标 | 复用 ckpt | 对照 |
| S1 | 正向 A | 4×128, 25%, Hard | 600→2000 | 必做 |
| S2 | 反向 E7 | **与 S1 完全相同的混合图** | 600→2000 | 必做 |
| S3 | 反向 E3 | 4×128, 25%, Feather | 600→2000 | 必做 |
| S4 | 反向 E，新构造 | 24×64, 37.5%, Feather | 600→2000 | 通过数据检查后启动 |
| S4a | 反向 E1 | 16×64, 25%, Feather | 300–600 | S4 覆盖率对照 |
| S5 | 正反向 1:1 混合 | 选出的两种有效配对 | 1200–2000 | 前四组有效才启动 |

- S1–S4 统一 **600 步初筛** → 仅晋级两组延长到 **2000 步总计**（不是额外 +2000）。
- **LR schedule 必须按统一 2000 步设计**，600 只是中途筛选点；晋级时恢复完整 optimizer+scheduler 状态继续，不许重置 LR、不许各实验各一条余弦。先核对仓库训练器按 epoch 构造调度的实际周期。
- paired-latent 模式：`v* = z1 - z0`，**不许**走 `_build_training_target()` 重新随机目标。
- 固定：seed 42 从头、有效 batch 256、microbatch 32×8（显存紧改 16×16）、AdamW 2e-4 cosine、权重 0.3/1.0/1.0、HH 关闭、CKPT 200/400/600/1000/1500/2000、训练时**不加载** VAE/CSD/DINO、FM 时间采样 Uniform、推理 8 步 ODE + AdaIN=0。
- **防修补捷径**：每个 ckpt 在固定留出伪配对上算 `L_correct`（正确 Style-ID）与 `L_wrong`（错换 Style-ID），并测真实推理 Style-ID 交换敏感度。若 `L_wrong ≈ L_correct` 且换 ID 几乎不改输出 → 只是修补，损失再低也不晋级。
- S4 先造 300 组验覆盖率+局部对应+CSD 恢复方向，不行退到 E1。
- S1/S2 若已有严格符合 b256/缓存/标签协议的 ckpt 可直接复用补评估，省下算力给 S5 与第二 seed。

## 三、两级评估

- 一级：训练池独立留出验证图里固定 **50 张源图（每风格 10 张）→ 200 跨风格请求**，看 200/400/600 步。验证图不得作伪 GT 端点或检索供体。
- 二级：仅晋级模型做完整 **600 跨风格 + 150 同风格**，并与**同协议**重算的旧基线比（同测试图与缓存 latent、同 CSD 原型与预处理、512px、8 步 ODE、AdaIN=0）。旧 WEAVE 若原本 AdaIN=2，另存历史分，不与无 AdaIN 新结果混称"训练增益"。
- 晋级条件：ΔT 明显提高且配对 95% CI 支持；ΔS 不许靠源风格崩塌换 ΔM；DINO-C 掉 ≤0.01；LPIPS 升 ≤0.01；Style-ID 正确条件优于错误；至少 3/5 类改善（重点 Rococo、Ukiyo-e）；真实图不能只复原拼贴位置或出伪影。
- 挑战目标：600 跨风格 CSD ΔT **≥ +0.04**（工程目标）。旧完整 WEAVE +0.0203 须在新确定性协议下重测基线后再比。

## 四、工程硬约束（宿主已重启过一次）

- 单卡 12GB 峰值 ≤10GB；WSL 15GB 留余量；**任何时刻只跑一个 GPU 任务**。
- DINO/CSD/VAE 离线依次执行，不与训练同时驻留；训练只读缓存 fp16 latent；DataLoader 0–2 workers；禁止多份大缓存副本；`torch.compile` 关闭；checkpoint 独立目录；缓存分片/mmap，不许一次性灌入候选图+特征+latent。
- 每实验记录：实测 step 耗时、峰值 VRAM、RSS、样本数、真实有效覆盖率；内存吃紧优先减 microbatch 加累积，**不改有效 batch**。
- 一个 tmux 单驱动串行；起任务前 `pgrep` + `free -g` 确认无残留；每阶段往 `runs/gt/PROGRESS.md` 追加一行。

## 六、Pattern 结果决策规则

| Pattern 结果 | 训练策略 |
|---|---|
| 大部分 Pattern 通过率很低 | 只用匹配约束下可行的 Random，放弃固定几何 |
| ≥2 种 Pattern 有足够样本且质量差异明显 | 选两个进额外小规模对照 |
| 多种质量相近 | 混合 Pattern，但保证目标覆盖率分布一致 |
| Spiral 仅极少数可行 | 不训练 Spiral，保留为数据质量观察 |

小样本不足时，**不能用训练失败推断空间布局无效**（更可能是数据筛选引入的分布偏差）。

## 七、12h 结束判定（§8）

| 结果 | 下一步 |

| S1 显著优于 S2 | 正向伪 GT 监督更有价值，扩大高质量 Patch 目标构造 |

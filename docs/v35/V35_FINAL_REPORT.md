## 一、核心结论与定型系统总览（Executive Summary）

CLEAVE（**Zero-DINO** 双流风格迁移系统：**11.13M `E-Core` 1-NFE 风格路由草稿** + **$L_{\rm low}+P_C$ `A3` 解析起点** + **44.54M Stiefel `Q32` `P-Core` 流匹配微调器** + **10.66M `S10B` 轻量解码器**）经 `P0–P8` 严格因果归因与零泄露超参校准后最终定型：

1. **为什么有效，系统边界是什么？**
   - **`E-Core` 决定“去哪种目标画派”**（`P1`）：用随机噪声替代只对齐色度的 `z_src`（`A2 vs A1`）后，`Cross600 CSD Top-1` 从 `4.50% / 17.17%` 跃升至 **`51.67% / 66.17%`**（`+47.17pp / +49.00pp`），源画派锁定从 `88.17% / 65.50%` 骤降至 `40.00% / 24.17%`。没有 `E-Core` 的 `P-only` 退化系统最高仅 `33.50%` Top-1（`P7`），而单靠 1-NFE `E-only` 也只能在 `s=1.00` 拿到 `S=0.5077`、`Top-1=66.83%`。
   - **`A3` ($L_{\rm low}+P_C$) 唯一负责高质量前沿迁移**：在冻结 44M 主干上零训练引入 `A3=(1.0, 1.0)`（`P0/P1`），在 `s085/s100` 同时抬升 `DINO-S` **`+0.0089 / +0.0086`**（CI 均严格排除 0）并把 matched-C `DINO-S` 推高至 **`+0.0154`**（对比 V32），且无需保留旧局部风格适配/参考 Value 模块。
   - **Stiefel 极分解正交商 `Q32` + `15% Pool C` 消除二阶泄漏并保护高强度特异性**（`P3/P4`）：线性探针证实 `Whiten-32` 与 `PCA-32` 残留 **`95.67% / 95.00%`** 二阶 Gram 风格泄漏，Stiefel 压降至 **`20.67%`**（接近 5 选 1 随机基准）；在两个独立随机种子上（`Q0 vs Q1/Q2` 与 `R0 vs R1`），Stiefel 在 `s085/s100/s125` 的 `Top-1`（`+1.83pp..+6.67pp`）和 `DINO-S`（`+0.0054..+0.0159`）均严格显著优于对角白化与 PCA-32；`15% Pool C` 在高强度 `s125/s150` 显著提升目标判别（`s125 +2.67pp CI [0.50, 4.83]`, `s150 +3.00pp`, `Same150 98.0% vs 94.0%`）。
   - **`S10B` (`D2`) 在下游清晰胜过标准 `SD-VAE (D0)` 与过度光滑微调 `D1`**（`P2`）：在完全相同的生成 latent 上，`D2 (10.66M, 21.82 ms)` 比 `D0 (49.49M, 74.84 ms)` 解码快 **`3.43×`**，`pcore_s150` `Top-1` 高 **`+10.00pp` (`92.00% vs 82.00%`)**、`ecore_s100` 高 **`+9.83pp`**；`D1` 因将 Haar HH 高频压垮 **`-73%`** 导致 `DINO-S` 与 `LPIPS` 明显恶化。
   - **训练时长 bell curve 在 `3500 EMA` 见顶**（`P5`）：继续训至 `4500 → 7000` 步尽管训练 `pHuber` loss 下降（`0.7999 → 0.7735`），但 `Cross600 s100 Top-1` 从 **`69.00%`** 单调滑落至 **`64.00% / 63.50%`**，锁定 **`step=3500, EMA`**。
   - **超参无泄露校准（`P6`）**：在 `train_calib_300` 上确定 `ws_mul=1.0, wc_mul=1.2, dtau0=-0.05, steps=6, alpha=(1.0, 1.0)`，最终在完整 `test750` 上达到 **`mean ΔDINO-S vs V32 = +0.0182`**（在 `C=0.70` 高保真区间高达 **`+0.0293`**）。

2. **诚实边界与未完美之处（第九节详述）**：
   - 在极高强度/低保真切片 **`C=0.50` / `C=0.70` 的 matched-C 比较中**，`Stiefel` 在 `C=0.50` 仍稳步占优（`+0.0048 S vs Whiten32`, `+0.0115 vs PCA32`），但在极高内容端 `C=0.70`（`0.5010 vs 0.5013`）各变体接近持平；
   - 同 `s=0.85` 旋钮下，`V35 Final` 相比旧 `V32 (22M)` 显著提升了内容保真（`DINO-C 0.6514 vs 0.6010, +0.0504`），因工作点偏向更高内容端，同旋钮 `Top-1` 为 `57.83% vs 62.33%`，`s=1.00` 则同时高于 V32 并保持 `C=0.5502, Top-1=69.67%`；
   - `Early_Renaissance`（`s085: 25.8%`）与 `Ukiyo_e`（`s085: 26.7%`）在低强度区间仍明显弱于 `Impressionism`（`93.3%`）和 `Minimalism`（`92.5%`），`s150` 下二者恢复至 `90.8%` / `79.2%`；
   - `C2_44m_q32_final.pt` 未保存优化器状态（`P0/P5` 已记录，续训先热身 100 步 AdamW）；`Holdout-750` 虽做到了 **0 画作/0 pid 重叠**，但按文件名提取的 `artist` 前缀与训练集 / src-ref 间存在 **5 个重合画师**。

## 二、τ 截断修正的实测核验（修正 C1 落地）

`tau_records`（17 条）显示：当前所有 solver 配置下 **`frac_at_cap = 0.00`**（实测 τ_max ≤ 0.775，未触及 0.78 clamp）——即初版方案担心的"tau_hi=0.80/0.86/0.90 被截断为同一档"在本文配置下不会发生；曲线 B 按修订版改为 **τ_min ∈ {0.50, 0.58, 0.66} 起点上移 + tau_hi 固定 0.78**，三条臂的实测 τ 分布（mean 0.695/0.720/0.744）确认是三个真正不同的强度档位。fixed Gate 臂的 τ 为恒定值（0.470/0.630），与非自适应门的语义一致。

## 三、四个判定点读数（点估计 + 插值，CI 待补）

### P0-1：单模型 vs Hybrid —— **曲线 B 在两个内容水位均不劣于甚至反超 C**
线性插值到共同 DINO-C 水位（B 曲线内插 / C 曲线内插）：

| 内容水位 | A (PRISM-1) | B (D6 τ-shift) | C (Hybrid) | B − C | 初步读法 |
|---:|---:|---:|---:|---:|---|
| D-C ≈ 0.70 | 0.4504 (`l130` 直击) | **0.5028** (`t066` 直击) | ≈0.4949 (g70/g85 插值) | **+0.0079** | B 风格更高 → 支持删除 Hybrid |
| D-C ≈ 0.73 | ≈0.447 (外推) | ≈0.490 (外推) | ≈0.4766 (g55/g70 插值) | **+0.013** | 同上（外推需 CI 验证） |

- 曲线 A 全场弱于 B/C（同水位差 ≥ 0.04 D-S）→ PRISM-1 单模型不能覆盖中高风格区间（其角色收敛为"极速高内容基座"）。
- **延迟结构性占优**：C 需要 PRISM-1 (17 ms) + D6 8 步流（~40–60 ms）串行；B 只需 D6 一次。若 CI 确认 B ≳ C，**双模型 Hybrid 整条管线可删**，`M1_lin` 降级为历史参考上限。
- `B_dswd_t058` 提示 DualSWD 是风格更强（`0.5156 @ 0.677`，vs B_d6 同水位插值 ≈0.5090）但 Top-1 −3.8pp 的备选单模型，暂列第二候选。
- ⚠️ 注意：Round 2 训练矩阵与机制 B 的教师目标仍按原计划（z* 混合曲线）；若 CI 最终确认 B ≳ C，机制 B 的**对照线从 C 曲线改为 B 曲线**（见 02 文档校准注记）。

### P0-2：CFG 分支 —— **cs_j (20 NFE) 与 full (40 NFE) 等效带内，sc_only 损 Top-1**
- D6h 档：`Δ(cs_j − full) = (−0.0038 D-C, +0.0048 D-S, +0.0035 LPIPS)`，三项全部落入容忍带，且 Top-1 持平（55.00 vs 55.17）→ **主配置 CFG 从 full 降为 cs_j（NFE 40→20）**。
- sc_only（10 NFE）内容略优但 `Top-1 −3.0pp`（55.17→52.17），触最差类守卫边界 → 不采用。
- D5 档方向一致（cs_j 两项均优于 full）。`ws5.5` 与 `ws4.2` 差异极小（+0.0027 D-S），保留 ws4.2 默认。

### P1-3：锚点 —— **PRISM-1 锚 ≈ T4 锚（差在容忍带边缘），z_src 锚判负**
- `Anc_PRISM1@t040` vs `Anc_T4@D6h`：`(−0.0091 D-C, −0.0058 D-S, +0.0116 LPIPS)`——D-S 与 LPIPS **略超**容忍带（−0.005/+0.010），但两臂 τ 配置不同（0.40 vs 0.48 起点），属未严格对齐的初比；等内容对齐后重判。若 CI 后仍略超：T4 锚保留为默认，PRISM-1 锚作为"免 T4 快速档"（省 ~225 ms 锚点准备）。
- **`Anc_Source` 明确判负**：风格完全坍缩（D-S 0.437，Top-1 7.2%，LPIPS 0.2245 ≈ 输出≈源图）——源图锚使模型退化为近恒等映射，从候选中删除。

### P1-4：Gate —— **fixed_g=0.5 与 original 等效带内，密度门控可删**
- D6h 档插值到 D-C 0.6633：fixed `0.5202` vs original `≈0.5178`（**+0.0024 D-S**），LPIPS +0.0037，均在容忍带内 → **sigmoid((dsd−mid)·550) 密度门控可删**，推理少一次 dsd 匹配统计，配置更简。
- D5 档 fixed 臂 τ 分布整体下移（0.470 vs 0.545）导致内容水位不对齐，不作直接判据；最终以 D6h 档 CI 为准。

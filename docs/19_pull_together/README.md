## 铁律（继承 V24 交接 + 本轮新增修正）

- 一律 `S10` 解码 × `test750` × 进程隔离四裁判；评测决策用完整 test750（读数 cross600）。
- **删除组件 = 非劣性判定**：简化版的源图聚类配对 95% CI 必须整体落入预注册容忍带（非"CI 跨零即等效"）。
- **τ 分布必须如实记录**：`exp/v22/core.py:353` 将 `tau_v` clamp 至 `≤0.78`，`tau_hi>0.78` 的臂会被截断，不得视为独立强度档。
- **训练配方 ↔ CFG 有效分支必须对应**：未训过无内容分支（`drop_c=0`）的权重不得参与四分支 `full` CFG 对照。
- 新机制最终候选 ≥2 独立训练种子；种子方向相反则追加第三次；所有最终候选完整 750 评测。
- 前序机制失败不阻断后续实验；失败即记录归因，不反复重训同类小网络（M5/M6 铁律）。

## 机制 A：空间自适应风格混合（优先 1，4090，窗口 2–4h，可深化 7–9h）

### A.1 假设与数学形态

V24 已证双模型全局插值 $z_{\text{out}} = z_{\text{P1}} + \gamma (z_{\text{D6}} - z_{\text{P1}})$ 有效，但全图共用一个 γ。假设：**不同语义区域对风格化的容忍度不同**（人脸结构需稳定，背景色块/纹理可承受更大风格增量），让空间门控分配增量可在同等内容水平下换取更强风格：

$$z_{\text{out}} = z_{\text{P1}} + \gamma \, M_\phi(x_c, s) \odot (z_{\text{D6}} - z_{\text{P1}})$$

- $M_\phi$：16×16 单通道空间门控，**内部均值归一** $M \leftarrow M / \overline{M}$（约束空间均值 ≈ 1，防止模型偷偷改总强度）；逐元素 clamp 至 $[0, 2.5]$。
- **用户仍只有一个参数 γ**；门控由网络预测，不暴露新旋钮。
- **与 S32Zero 的区别**（防重复踩坑）：不增加生成网络的内容条件容量，只决定**已有两种输出在各区域各取多少**——研究风格变化的空间分配，不是再学一遍风格生成（AdaAttN 的局部自适应统计思想支持该方向，但 latent 门控收益需独立验证）。

### A.2 四臂设计

| 臂 | 方法 | 说明 |
|---|---|---|
| `A0_global` | 全局线性混合基线 | 直接复用 Round 1 曲线 C（零成本） |
| `A1_heuristic` | 固定启发式门控：$M = 1 + \kappa (1 - \bar e)$，$\bar e$ 为 `c_64` 梯度密度归一（低细节区给更大 γ），$\kappa \in \{0.5, 1.0\}$ | 零训练，验证"空间分配有没有价值" |
| `A2_learned` | 轻量门控网 `GateNet`（~0.25M：输入 `c_16` ⊕ `Δz` 下采样 16×16 ⊕ 风格弦 tile → ch64 ×3 ResBlock → 1×16×16；末层零初始化 → 初始 $M \equiv 1$，即 A0 恒等热启动） | 学习更优分配 |
| `A3_smooth` | `A2` + 平滑/结构约束：`TV(M)`（系数 0.05）+ 高内容边缘两侧门控连续性惩罚 | 抑制区域边界伪影 |

### A.3 训练与判定

- **训练信号**（ConvNeXt = 训练特征，非评测裁判，遵守"不直接优化裁判"铁律）：冻结一切，只训 `GateNet`。对 micro-batch 走可微 `S10` 解码：
  $\mathcal L = \mathcal L_{\text{cnx-style}}(\text{dec}(z_{\text{out}}), \text{dec}(z_{\text{D6}}^{tr})) + \lambda_c \mathcal L_{\text{cnx-mid}}(\text{dec}(z_{\text{out}}), \text{dec}(z_{\text{src}}^{tr}))$，$\lambda_c$ 校准到 `DINO-C ≈ 0.73` 水位（先 300 updates 标定）。
- **预算**：1500–2500 updates，micro=16；增量参数 0.1–0.5M；单臂 ~10–14 min。
- **通过标准（预注册）**：在 `DINO-C ≈ 0.73` 处 vs 同 γ 的 `A0`：
  ① $\Delta_{\text{DINO-S}} \ge +0.008$ 且 CI 下界超等效带；**或** ② 风格基本不变（$|\Delta_{\text{DINO-S}}| \le 0.005$）时 $\Delta_{\text{LPIPS}} \le -0.010$；
  且通过视觉审计（区域边界无伪影拼图）+ 最差类不坍缩。达标 → 独立种子复验。
- **判负出口**：A2/A3 均未达标 → 记录"空间分配在该预算下无增量"，时间转投 B 深化（不重训第三种门控变体）。

## 机制 B：把双模型 Pareto 曲线蒸馏进一个模型（优先 2，4090，窗口 4–7h，改进 7–9h）

### B.1 假设与目标

M1-Lin 有效但推理需双模型（PRISM-1 17ms + D6 22M 8步）。目标：单模型 + 单强度参数覆盖 Hybrid 在 `DINO-C 0.70–0.75` 的主要工作点。学生：

$$z_{\text{student}} = F_\theta(z_c, u_s, \gamma), \qquad z^*(\gamma) = (1-\gamma)\, z_{\text{P1}}^{tr} + \gamma\, z_{\text{D6}}^{tr}$$

### B.2 与 M5/M6 失败条件的纠正（三点全做，缺一即重蹈覆辙）

1. **热启动 PRISM-1 权重**（`s2_prism1_v2.pt` 绝不从零）：γ 经 Fourier 编码（32 维）拼入风格弦通路，末层对 γ 分支零初始化 → γ=0 时严格还原 PRISM-1。
2. **真实 `z0_tr` 输入定义一致**（共享前置缓存），教师/学生输入无分布 gap。
3. **保留自参考恒等性质**：same-task bypass（输出 = `z_src`）保持在网络之外，与 PRISM-1 推理一致。

### B.3 训练配置

- **损失**：$\mathcal L = \mathcal L_{\text{latent}}(\text{MSE to } z^*(\gamma)) + \lambda_{\text{struct}} \mathcal L_{\text{cnx-mid}}(\text{dec}(z_{\text{student}}), \text{dec}(z^*(\gamma)))$，$\lambda_{\text{struct}}=0.3$（decode 子样本走可微 S10）。**不加** SWD / 动态拉格朗日 / 复杂 CFG。
- **γ 采样**：$\{0, 0.25, 0.40, 0.55, 0.70\}$ 均匀抽取；γ=0 样本权重 ×2（显式锁 PRISM-1 恒等锚）。
- **两个学生规模**：`B0` = 原 PRISM-1 宽度（1.5M），3000 updates；`B1` = 宽度 ×1.7（约 3–5M），6000 updates。先比 B0/B1，胜者换独立种子复验（方向相反则第三种子仲裁）。

### B.4 判定与出口

- **成功**：学生 γ 扫描曲线在 `DINO-C 0.70–0.75` 全程对 Hybrid A0 曲线通过非劣性判定（§01 §2 容忍带），延迟 < 25 ms/img → 冻结为 `PRISMCore` 单模型主接口，Hybrid 退役为参考上限。
- **失败**：B0/B1 均达不到 → 结论"两模型混合捕获了 1 步学生难拟合的非线性变换"，**保留 Hybrid，不再开发新的 1M 学生**（M5/M6 铁律延伸）；时间转投机制 A 深化。

## 机制 C：One-Shot 的监督强度校准与参考对比（3060 主线，窗口 2–9h）

### C.1 诊断事实

`O3_label_free` 风格偏弱的直接原因是教师目标：`L_teacher = L_style + 2.2·L_content + 0.15·L_reg`，`mid_cos=0.965` 几乎贴原图 → 学生学到"少改即安全"。**先改监督信号，不加模型容量**。

### C.2 C1：教师编辑强度校准（窗口 2–4h）

- 同一批训练内部内容–参考配对、同初始化、同 24 步 AdamW，仅改内容权重：

| 教师 | `w_c` | 预期 `mid_cos` 带 | 角色 |
|---|---:|---|---|
| `T-conservative` | 2.2 | ~0.96 | 现状对照 |
| `T-medium` | 1.2 | 0.86–0.90 | 适度纹理变化 |
| `T-expressive` | 0.7 | 0.80–0.86 | 明显参考风格 |

- **流程**：先在 **600 对诊断子集**（3060 可承受）上做教师诊断——内容稳定性（DINO-C vs 源）、外观迁移量（ConvNeXt 风格相似 vs 参考）、伪影（LPIPS + 视觉拼图）；按质量筛选训练对（`mid_cos ∈ [0.80, 0.90]` 且无伪影）。
- **正式产物**：胜出权重生成完整 2000 对教师包 `ref_teacher_pairs_v2_<T>.pt`；正式模型选择只看完整 `test750` + 独立 SG-25 OOD。
- **顺带完成 §01 §4.1 的严格归因**：`O3`（标签对）vs `O3_lf_matched`（无标签对、**教师幅度匹配**）——剩余差距才归因于标签配对本身。

### C.3 C2：参考替换一致性（窗口 7–9h）

对固定内容图 $x_c$ 与两个参考 $r_a, r_b$，要求内容保持与参考无关、风格各自跟随：

- $\mathcal L_{\text{swap}} = w_1 \big| C(G(x_c,r_a), x_c) - C(G(x_c,r_b), x_c) \big|$（内容保持的参考不变性）
- $+\; w_2 \big(S(G_a, r_a) + S(G_b, r_b)\big)$（各自风格跟随；可区分性由逐参考目标自然产生）
- 特征用 **VGG/ConvNeXt 训练专用**空间特征，不直接优化评测裁判；结构项防内容漂移。

### C.4 消融矩阵与判定

| 臂 | 教师 | 训练 | 回答 |
|---|---|---|---|
| `C0` | 原 2.2 教师 | 原 O3（已有） | 基线 |
| `C1` | 校准教师（胜出档） | 原 O3 配方 | 监督强度是否是保守主因 |
| `C2` | 同 C1 | ＋参考替换对比 | 参考条件是否被充分利用 |
| `C3` | 同 C2 | 连续教师强度混合（$\gamma_t \in \{0.4, 0.7, 1.0\}$ 配对混合） | 单模型连续 strength 是否可行 |

- 训练臂均为 `O3_rgb_cnx_gated` 结构 1200 updates（~20 min/臂），评测 `t45/t55` + `swap_dist`；C2 不依赖 C1 成功（若校准无收益仍验证参考替换监督）；最终胜者完整 750 + SG-25 OOD + 多参考敏感性。
- **成功判据**：`t55` 档 `DINO-S` 相对 `C0` 提升 ≥ +0.02 且 `DINO-C` 不低于 0.66；SG-25 `ΔS` 不退化；`swap_dist` 无恶化。

## 判负与排队铁律（继承用户审查意见）

1. 前序机制失败不得阻断后续：A 失败 → B 照常（研究问题不同）；B 失败 → 时间投 A 深化，**不**重训 M5/M6 式小网络。
2. C2 不依赖 C1 必须成功。
3. 最终候选 ≥2 独立种子；种子方向相反 → 第三种子仲裁。
4. 所有最终候选完整 `test750`（读数 cross600），不允许小样本筛选定论。
5. 不把 12h 主要用于重扫 CFG、重复 SWD 或新增生成 U-Net。

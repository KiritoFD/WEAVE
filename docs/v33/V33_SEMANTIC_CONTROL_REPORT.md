## 一、总览与核心结论

V33 以 **V32 ConvNeXt Zero-DINO**（`s085_c10`: `DINO-C = 0.6010, DINO-S = 0.5266, CSD Top-1 = 62.33%, LPIPS = 0.5511`）为唯一生产基线，严格按门控依次执行 **P0（路由与亮度解耦）→ P1（`Q64+` 与部分白化）→ P2（`16×16 + 32×32` 语义控制分支）→ P2 CFG 重平衡探针 → P3 门控裁决**（全流程实测总耗时约 `3.8 GPU·h`，远低于 `14 GPU·h` 上限，无 NaN/OOM）。

**最终科学定论：V33 四项假设全部给出了干净、可复现的否定/边界定位结论，明确排除了四条假瓶颈，并将限制 CLEAVE 突破 StyleGallery 前沿（`0.6113 C / 0.5604 S`）的真正根因收缩至“冻结 22M P-Core 主干容量 + `417-D K=8` 离散中心风格表征 + `E-Core` 起点 `P_Y` 明暗锁定”：**

1. **P0.1（K=8 路由）**：仅用 `train_4400` 跨画派近邻计算 CSLS 密度修正（`2cos - r_k`），成功消解 `s=1.50` 下 Rococo `c7` Hubness 坍缩（`c7` 占比 `45.8% → 30.0%`，归一化熵 `0.7102 → 0.8125`），将 `Rococo DINO-S` 从 `0.5388` 提至 `0.5617`（**`+0.0229`**），但未达到 `+0.03` 放行线（`Min S` 略降至 `0.5260`，整体 `S = 0.6053 vs 0.6054`）；在主工作点 `s=0.85_c10` 下中性（`0.6003 C / 0.5265 S / 62.00% Top-1`）。
2. **P0.2（`Y16/LCN` 亮度锁定）**：即使将 `16×16` 瓶颈的 `Y16/LCN` 条件完全关闭（`Y2_off`）或用 $E_{\rm src}/E_{\rm tgt}$ 连续门控（`Y3a/Y3b`），`Minimalism` 的输出饱和度几乎一动不动（`sat_hsv = 0.0749–0.0758` vs 基线 `0.0750`，`gray_std = 0.1930–0.1945`，`Min S = 0.3335–0.3468`）。这证伪了“`Y16` 通道导致极简主义灰阶锁死”——**真正的亮度/明暗锁死来自中段起点 `z_tau0 = (1-tau0)*eps + tau0*z_E` 中 `E-Core` 携带的 `P_Y` 源亮度包络**。
3. **P1（`Q64+` 正交补空间）**：`Q64+` 在数学上严格保持原 `Q32` 不变性、`(1/256) Q64+ Q64+^T ≈ I_64`（最大误差 `5.56e-4`）以及 **20.00% 随机水平零风格泄漏**（而部分白化 `Q2` 泄漏高达 **`95.33%`**）。但在冻结主干上加 `2.13M` `16×16` Adapter 后，`Q1` 相对 `Q0` 仅得 `ΔC = +0.0007, ΔS = +0.0003`（`excludes_zero=False`），未过门控（`Gate = False`），排除了“`16×16` 商空间维度（32→64）不足”的瓶颈假设。
4. **P2（`SemanticControlAdapter`, `6.98M`, `16×16 + 32×32`）与 P3 门控**：
   - 真 `512px 32×32` 商空间（`S1`）+ `30% T_style` 风格扰动训练（`S2`）**显著重建了低保留率起点的空间构图**：在 `tau0=0.35` 下 `DINO-C` 从 `0.4249` 跃升至 **`0.5019`（`+0.0770`）**，在 `tau0=0.50` 下从 `0.4654` 跃升至 **`0.5423`（`+0.0769`）**，在 `tau0=0.00` 下从 `0.3033` 升至 **`0.3505`（`+0.0472`）**；`6/8/12` 步 ODE 积分差异 `< 0.002`，排除了数值积分误差瓶颈。
   - 但在**相同 `DINO-C`** 曲线对比下，`P2_S2` 无论在默认 CFG（`max ΔS = +0.0007` at `tau0=0.00`，在 `C=0.50–0.64` 区间 `ΔS = -0.0152 ~ -0.0018`）还是经过 5 组大幅提升 `ws`/压低 `wc, lscale` 的 **CFG 重平衡探针**（`max ΔS = -0.0001` at `C=0.6127`）下，均贴着或略低于 V32 原有前沿滑移。
   - 按第 5 节原则：**`P3` 联合训练（2h）已自动跳过（`SKIPPED_NO_FRONTIER_PUSH`）**，节省算力并直指下一代架构改向。

## 五、P3 门控裁决与下一阶段研究启示

1. **为什么按规则跳过 P3 联合训练？**  
   无论默认 CFG（`max ΔS = +0.0007`）还是经过 5 组大幅偏置风格的 CFG 重平衡（`max ΔS = -0.0001`），在**冻结 V32 22M P-Core 主干**上叠加 `32×32` 语义控制均未能在相同 `DINO-C` 下超越 V32 原有前沿——额外内容信号主要在**既定风格—内容权衡曲线上右移工作点**（用风格分与 `Top-1` 换取内容分），而未将整条 Pareto 曲线向右上角抬升。因此按第 5 节门控停止规则跳过 `P3` 联合训练（`SKIPPED_NO_FRONTIER_PUSH`）。
2. **V33 对下一轮（数据 / 表征 / 容量）的精确诊断价值**：
   - 已排除的假瓶颈：`K=8` 路由单点改进（P0.1）、`16×16` `Y16/LCN` 条件（P0.2）、`16×16` 商空间维度（P1）、`6` 步 ODE 积分精度（P2）、冻结 22M 主干上的 `32×32` 语义补充（P2）。
   - 真正的突破口已锁定在三件事的协同改造：**（1）打破 `E-Core` 起点 `P_Y` 明暗包络锁定**（使中段具备像 `Minimalism` 色块抽象那样的低频明暗重分布自由度）；**（2）解除 `417-D K=8` 离散质心条件瓶颈**（转向连续多尺度局部风格统计/条件生成，而非压扁至 8 个全局均值）；**（3）联合放开并适度扩容生成主干容量（`>22M` 端到端共训，而非冻结 22M 主干外挂分支）**。

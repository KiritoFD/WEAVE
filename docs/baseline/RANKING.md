## 五、怎么读这张表

1. **Top-1 才是"风格是否成立"的主判据**。CSD ΔT 高但 Top-1 低，说明只是把图推离源风格，
   并没有真正落到目标风格（例如 SaMAM ΔT +0.10 但 Top-1 只有 2.5%）。
2. **Margin 衡量目标风格的绝对优势**。只有 StyleShot (+0.218) 与 StyleID (+0.153) 为正；
   其余全部为负，说明大多数方法的目标风格仍未压倒竞争类别。
3. **DINO-C 与 LPIPS 只用于排除崩溃**。StyleShot 的 DINO-C 仅 0.357、LPIPS 0.770，
   是"重绘式"风格化；V6 ScoreDiff 的 DINO-C 0.902 / LPIPS 0.237 是"保真式"，两者不在同一取舍点。
4. **不要跨数据集比较**。本表只覆盖 D5-512；P2A-256 与 R5-WikiArt 尚未用 Evaluator V2 重算。

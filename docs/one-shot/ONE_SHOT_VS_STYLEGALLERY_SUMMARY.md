# One-shot 与 StyleGallery 差距专项总结报告

> **2026-11-28 结论边界更正**：下文保留历史数值与比较。已测差距不能证明轻量/Zero-DINO体系存在不可突破的“固有结构性代差”；DINO-S不是纯笔触测量。历史速度标签不足以证明process cold，238×/427×不作为严格同口径加速结论。后续引用以[阶段结论](../system/paper-audit/POST_12H_CONCLUSIONS.md)的限定为准。

**日期**：2026-11-28  
**组件归属**：One-shot（开放域单参考无标签风格迁移独立研究线）  
**核心基线**：正式 One-shot 基线保持 **`V36 P-Core + Reference-A3`**（Zero-DINO、Core-5 严格未见）；`V37 E0/E1` 为实验性 Reference E-Core 分支；`V35 CLEAVE Final`（闭集双核）与 `V36 D1 Oracle`（闭集 Core-5 草稿注入冻结 P-Core）仅作诊断参照，不计入正式 One-shot 成绩。  
**统一评测协议**：完整 `test750`（`Cross600 + Same150`）、**S10 Decoder**（10.66M）；外部 `StyleGallery` 按其原生管线在同批 `test750` 任务上实测（见 [metrics.csv](../performance/metrics.csv)）。

## 1. 一句话核心结论

在严格 **Zero-DINO + Core-5 未见** 的单图参考（One-shot）协议下，于 `StyleGallery` 的内容保留工作点（**`DINO-C = 0.61134`**）做同内容线性插值对齐：

- **正式 One-shot 基线 `V36 P+A3`**：
  - **风格分类差距已收窄至 `-4.61 pp`**（`CSD Top-1`：`47.89%` vs `52.50%`），且调强编辑权重至 `t35`（`DINO-C = 0.5624`）时即可达到 `54.83%`（绝对值反超 `+2.33 pp`）。
  - **真正的硬差距在视觉风格表征 `DINO-S`（`-0.0690`）与感知结构偏离 `LPIPS`（`+0.0389`）**：全曲线任意工作点在 `C ~ 0.61` 处均未接近 `StyleGallery` 的 `0.5604`。
  - **工程推理速度领先 `238× – 427×`**：4090 冷启动 `RGB -> RGB`（含 S10 解码）`B=1` 仅 `127.51 ms/图`（`7.84 img/s`）、`B=8` 仅 `71.17 ms/图`（`14.05 img/s`），对比 `StyleGallery` 的 `30.4 s/图`（`0.0329 img/s`）。
- **V37 开放域 Reference E-Core（`E0 / E1`，12,902 步同曝光对照）**：均**未**缩小与 `StyleGallery` 或 `V36 P+A3` 的差距——`E0+P` 因保源不足未能覆盖 `C ∈ [0.60, 0.75]` 区间；`E1+P` 在 `C=0.6113` 处 `CSD Top-1` 仅 `36.03%`（落后 `StyleGallery` `-16.47 pp`），`P4` 续训门槛未通过，不替换 `P+A3`。
- **闭集与 Oracle 诊断揭示的代差上限**：即使切到闭集双核 `V35` 或注入闭集 Core-5 草稿的 `D1 Oracle`，同内容点 `CSD Top-1` 已大幅反超 `StyleGallery`（`62.52% ~ 64.56%`，**`+10.02 ~ +12.06 pp`**），但 **`DINO-S` 依然落后 `-0.0210 ~ -0.0424`**。这意味着主要差距来源并非单纯“分类对错”或“训练时长”，而是**轻量 Zero-DINO 隐空间流编辑与重型扩散重绘范式在笔触纹理重绘（`DINO-S`）上的结构性代差**。

## 5. V37（Reference E-Core）收官实测为何未能缩小与 StyleGallery 差距？

完整 12 小时固定预算实验（[V37 计划与审计](V37_PLAN_AND_AUDIT.md)、[V37 结果](V37_RESULTS.md)）已给出闭环判负证据：

1. **`E0`（原跨参考统计+SWD配方续训至 12,902 步）**：
   - Seen-Dev32 VGG 跟随从 `71.88%` 升至 `93.75%`，但灰度内容 L1 从 `0.03617` 恶化到 `0.05942`；
   - 双核 `E0+P` 在完整 `Cross600` 上仅分布于 `DINO-C ∈ [0.4688, 0.5645]`，过冲偏离内容，固定笔触图显示极简与浮世绘样本出现明显泛白、网格涂抹与色块伪影；在仅存的 `C ∈ [0.53, 0.56]` 低内容事后交叠区，虽 `C=0.53` 处 `DINO-S` 微升 `+0.0155`（CI `[+0.0006, +0.0262]`），但 `CSD Top-1` 同时暴跌 **`-7.80 ~ -12.27 pp`**。
2. **`E1`（10,000 组 `P1 42k` 反向代理→原画配对同曝光至 12,902 步）**：
   - 仅学回 `P1` 教师已具备的平滑与调色保守修复，在固定 `Seen-Dev300` 内容对齐点（`C=0.70/0.75`）上 `E1+P` 落后 `P+A3` `-0.0064 / -0.0087`（未达 `+.005` 的 `P4` 续训门槛，因此正确跳过 `P4`）；
   - 在正式 `test750` 上于 `C ∈ [0.60, 0.75]` 稳定落后 `V36 P+A3`：**`ΔDINO-S = -0.0054 ~ -0.0065`**（95% CI 全负）且 **`ΔTop-1 = -7.66 ~ -12.96 pp`**。
3. **`Artist-OOD 1000` / `Movement-OOD 500` 的实例跟随假象边界**：
   - 在 `tau=0.35` 下 `E0` 取得 `97.50% / 97.20%` 的 `CSD 2-way`，但这仅反映二选一实例拉偏能力；同一 `E0` 在严格 5 分类 `Cross600` 的同内容工作点上并不占优且在同等内容约束（`Artist-OOD C=0.70`, `Movement-OOD C=0.70/0.75`）下，`E0 / E1` 的 `ΔDINO-S` 与 `Δ2-way` 置信区间均显著劣于 `P+A3`。

## 6. 核心瓶颈与下一步判断

1. **当前真瓶颈已定位**：不是“继续加长 Reference E-Core 训练步数”，也不是“只换风格 Encoder”：
   - 即使由强于现有 One-shot 的闭集 `E-Core` + 冻结 `V36 P2` 构成 `D1 Oracle` 诊断上界（`C=0.6117`），`CSD Top-1` 已达 `64.50%`（反超 `StyleGallery` `+12.00 pp`），但 `DINO-S` 仍是 `0.5179`（仍落后 `StyleGallery` `-0.0425`）。
   - 这证明两重结构差距：(a) **现有 `E-Core` 无法无标签建立接近闭集原型的结构化流派草稿**（差距体现在 `V36 P+A3` vs `D1 Oracle` 的 `~16.7 pp` Top-1 差和 `~0.027` DINO-S 差）；(b) **即使拥有理想草稿，`Zero-DINO + S10 + 44M` 轻量前馈编解码体系在局部高级语义笔触与几何重绘（`Impressionism` / `Ukiyo_e` / `Minimalism` `DINO-S`）上与重型扩散 `StyleGallery` 仍存在 `-0.021 ~ -0.042` 的固有 `DINO-S` 代差**。
2. **明确决策边界**：
   - 保持 **`V36 P-Core + Reference-A3`** 为当前唯一正式 One-shot 基线；
   - 不在无新机制突破前继续堆砌现有 Reference E-Core（E0/E1）或盲改 P-Core 架构；
   - 后续若要追近 `StyleGallery`（目标 `DINO-C ≈ 0.61, DINO-S ≥ 0.56, Top-1 ≥ 52.5%`），核心突破口在于解决**开放域细粒度结构重绘监督信号**（例如不依赖闭集标签、能直接约束局部笔触/边缘结构而非仅全局色彩与像素平滑的无坍缩反向编辑目标）以及提升 **`Ukiyo_e` / `Impressionism` 笔触轮廓迁移表征**。

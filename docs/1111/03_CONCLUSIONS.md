## 2. 多条WEAVE路线为什么没有成为最终答案

**伪GT/端点路线**：目标有可达性、残余源风格和低频占比限制；margin的改善可能大部分来自抹源。直接监督比复杂流更容易优化，但不能自动纠正不合适的目标。

**去噪/DMD路线**：有些强风格点严重破坏内容，稳定化后又趋近恒等；先后存在符号/梯度实现错误，需以修正版本为阴性依据。MSE更低不是迁移更好。

**OT/桥接/分布路线**：局部子集、低维统计或混合分布能改善，不保证五个条件分布均衡。OT时间成本高；加容量或采样步数没有在测试预算内形成稳定全任务优势。V11的learned SWD梯度比仅0.0249，不能用它否定分布监督；fixed raw latent分支梯度比0.8020仍未改进CSD分布，暴露代理空间问题。未实现的路径一致性和未实测d3/d4不能记入失败。

**R1/蒸馏路线**：Oracle确实能改变判别与独立相似度，但同时损害内容。强蒸馏优于弱蒸馏，说明目标权重/方向重要；仍存在相当拟合误差，不能说“学生已完美拟合、容量完全排除”。

**R2**：内容切向投影几乎不改变当前教师方向；LL筛选或小RMS主要提供保守编辑。新教师学生在独立DINO-S上不如B3，845K历史教师学生略接近但未过门槛。`teacher_failure`是这轮决策树输出，不是关于所有未来教师的定理。

## 3. VAE几何路线为什么没转成编辑收益

SWD类内/类间几乎一起缩，困难AUROC近随机，距离尺度捷径明显；CSD更有判别力，但style/content双头高度接近，教师也有题材偏好。
直接蒸馏首轮发生表示坍塌；REPA现有证据不完整；线性/可逆Flow等能提高拟合或检索，困难内容控制下仍弱。
联合ABC的读出探针微升、训练edit loss下降，没有对应独立跨内容编辑改善。可读性、跨画家稳定方向、最终可编辑性是不同层级。
ArtEncoder Stage A与DeepSets/CNN增加了新的有限阴性：数值没有整体崩坏，小型读出改善了部分gap，但还没通过困难AUROC/检索。
因此当前可说**这些具体目标、读出、数据与预算没有造出经验证的通用风格latent**；不能说latent不含风格信息或所有几何学习都不可能。

## 4. 回答“是Decoder蒸馏后果吗”

最终S10并不是教师KD，而是剪枝继承+真实RGB的L1/LPIPS恢复；WEAVE B3/B4的算子蒸馏是另一件事。
剪枝恢复后独立重建仍有损失，弱梯度对齐与边缘变化支持Decoder函数确实改变。B4的全因子结果按CSD也显示Decoder替换负效应比Encoder更明确。
但纯Decoder A0→S10下，有的生成器CSD反而显著提高；ScoreDiff在DINO/CLIP与margin上提高。这使“Decoder导致所有风格变差”的说法与实测不符。

当前更合理的解释是三个因素共同作用：压缩/重建目标改变图像细节偏好；固定旧WEAVE输出与新E/D存在兼容性问题；不同判官响应不同。每个因素的独立比例尚未全面识别。
要证明“某种训练损失导致了退化”，需要同结构、同初始化、同预算的损失消融；目前没有完整对应设计，不能从结果相关性倒推唯一损失根因。

## 5. 当前可使用的工作点与选择理由

| 使用目的 | 候选 | 采用依据与代价 |
|---|---|---|
| 轻量、单步、内容较稳 | B3 + SD0 | R2 DINO-C0.8325；DINO-S0.4183；风格弱于Oracle |
| 单步更强判别迁移 | B4 + SD0或S10 | SD0跨CSD约21%；S10有纯Decoder收益但CLIP/content有取舍 |
| 测逐图R1方向上限 | Oracle1 + SD0/S10 | CSD约34.8/36.3%，内容约0.731/0.735；需critic与梯度 |
| 快速Decoder选项 | S10 | 段级2.86×；必须验真实端到端收益和具体生成器指标 |
| 艺术重建基座 | Art-A0 | 重建好于SD0；固定WEAVE直接替换并非更好 |
| 通用风格表征/可编辑VAE | 尚无已过门槛方案 | StageA/Reader/ABC不足以作为正式成功模型 |

推荐是按目的选择，不是新的统一冠军；不能由点估计差异宣布显著优胜。

## 6. 如果继续，优先补哪个证据

1. 固定主评测链路、参考hash与版本化结果目录；把剩余外部baseline覆盖和旧表版本对齐，避免继续在变动标尺上优化。
2. 若继续Decoder，先测真正整链路延迟、同Encoder少数上榜候选、多指标与代表性视觉盲比；不必重做大批量生成。
3. 若继续VAE适配，最有判别力的是新latent下重编码/重训的小对照，与“旧WEAVE直接替换”区分；只有这能检验兼容性是否主瓶颈。
4. 若继续通用风格几何，先解决内容匹配困难负样本下的表征验收；明确判官/读取器上限与跨画家划分，再考虑扩大Encoder训练。
5. 对任何重启路线写清假设、改变项、最小对照与停止门槛；本次文档没有自动启动这些实验。

# 4套VAE × 5个上榜WEAVE：完整20格结果

## 实验设计

冻结既有WEAVE权重，仅替换配套Encoder/Decoder。SD0=原始SD-VAE，A0=艺术重建后训练全VAE，S10=A0 Encoder+压缩Decoder，C_edit=联合编辑训练全VAE。
每配置固定750任务=600cross+150same；同150源图与参考图；VAE输入[-1,1]，PyTorch BF16解码，评分相对原始RGB。
本轮新增图片文件0，不是生成一万张图。20×750是评分行数，不等于15000个新PNG；DINO/CLIP补评与2×2控制有必要的内存推理，未拓宽生成器候选。


**证据来源：** [deliver/vae_ranked_eval/results.json](../../../deliver/vae_ranked_eval/results.json)；[deliver/vae_ranked_eval/style_comparison.json](../../../deliver/vae_ranked_eval/style_comparison.json)；[tools/vae_swap_eval/run.py](../../../tools/vae_swap_eval/run.py)。

## 这张矩阵支持的判断

Art-A0独立重建更好，但跨风格CSD Top1五项都低于SD0；A0对Direct/Oracle的DINO-S也小幅下降。
S10对三种Direct/Oracle类点估计上升，对ScoreDiff CSD下降，却提高ScoreDiff DINO/CLIP相似度；不存在跨生成器、跨指标的一致胜者。
C_edit在固定旧WEAVE时CSD五项显著下降；ScoreDiff的DINO/CLIP原始相似度却上升。C_edit+N12的DINO margin显著下降，不能把原始相似度上升等同于更会区分目标。
这些都是兼容性结果，**未在新latent空间重新训练WEAVE**，不能当该VAE适配后的性能上限。

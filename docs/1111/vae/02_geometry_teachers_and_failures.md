# 风格几何路线：SWD、教师对齐、显式子空间与可逆变换

这一阶段的核心分歧是：latent 中存在一些画风相关信息，与原始欧氏/SWD 距离可直接充当画风距离，是两个命题。
诊断表明后者很弱；它没有证明前者不存在，也没有证明所有非线性读取器都不可能成功。

### SWD 诊断中的修正

- 全 Encoder 的 style/rec 梯度余弦是 −0.074；旧报告突出 quant_conv 单层 −0.61，不能代表全网冲突。
- `torch.sort` 在多数位置分段可微；有限差分误差 67.4% 仍有数值/尺度/实现疑问，不能一句“排序不可导”略过。
- 1556/1632 bank 数量、17 个单画家风格与尾部类别影响了采样审计，不能把所有类别当作同等有效。
- 早期训练池过滤存在 `in_train=False` 混入问题，后面的全量 clean 训练池才显式收紧到 78,661。
- 原报告“2.548→1.073 下降 10.8 倍”与端点算术不符，本复盘不继承该倍数。

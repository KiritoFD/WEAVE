# Art-VAE：重建后训练、类别监督与对比监督

## 研究目标与命名

4090 线先问“艺术数据后训练是否能改善 VAE”，再问“能否把可判别、可编辑的画风几何写进 latent”。这两个目标必须分别验收。
本系列 **B0=原始 SD-VAE（本复盘简称 SD0）**；**A0=艺术数据上 rec+KL 后训练**，不是同一模型。
下面的 2,048 图表仅在本表内比较。它不是后面的 150 图兼容性重建集，也不是 Decoder 256 图测试集。

## V01 · A0：艺术数据 rec+KL 后训练

| 项 | 记录 |
|---|---|
| 执行侧 / 状态 | 4090 / **完成** |
| 要回答的问题 | 不额外组织风格几何，艺术域重建能否改善？ |
| 实际改动 | 以 SD-VAE 为起点，重建与 KL 后训练；530 updates、50,880 图像曝光，单臂约 3.45 小时。 |
| 任务与评测 | 同一 2,048 张真实艺术验证图、136 个有效风格。 |
| 主要结果 | LPIPS 0.0822→0.0762，PSNR 24.57→25.37，SSIM 0.7484→0.7739；CSD Keep 0.9322→0.9136。 |
| 本次复盘判断 | 明确有重建收益，CSD 特征保真略降；没有证明风格几何或迁移收益。 |


**证据来源：** [docs/v6/VAE_A0_A1_A2_FULL_REPORT.md](../../v6/VAE_A0_A1_A2_FULL_REPORT.md)。

## V02 · A1：类别交叉熵监督

| 项 | 记录 |
|---|---|
| 执行侧 / 状态 | 4090 / **完成 / 未形成总体几何收益** |
| 要回答的问题 | latent 加风格分类能否改善泛化风格表示？ |
| 实际改动 | 在重建后训练上增加 137-label 类别目标。 |
| 任务与评测 | 同上；额外比较浅层 CNN、留画家及线性统计探针。 |
| 主要结果 | LPIPS 0.0766；浅 CNN 15.69%（SD0 17.52%）；留画家 14.29%（SD0 14.49%）；某线性统计未见画家探针 14.91%（SD0 12.42%）。 |
| 本次复盘判断 | 有局部探针正结果，但不能从一个探针推广成整个 latent 风格空间改善。 |

## V03 · A2：MoCo / SupCon

| 项 | 记录 |
|---|---|
| 执行侧 / 状态 | 4090 / **完成 / 未形成总体几何收益** |

## 三条路线共同说明什么

重建可以在原来的 latent 空间中变好，同时类别几何几乎不变。A0 因而是有用的艺术重建基座，不能作为“已经训练出风格 latent”的依据。
训练类别数、评测有效类别数、留画家划分不同，不能把 136 类探针与后来 20 类或 D5 五类准确率直接排榜。

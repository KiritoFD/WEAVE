## 2026-11-05 · 00:20 · batch / 显存定档（只改 batch，不改模型）

配置：`V4UNet` 8.45M（`channels=(64,128,192,256)`），bf16，AdamW，单次前向+反传+优化器一次，无梯度累积。
命令：`python3 -m v4.train --bench --bench-mbs 32,64,96,128,192,256,320`
日志：`runs/v4/diag/bench_mb.log`

| microbatch | step (ms) | img/s | peak alloc (GiB) | peak reserved (GiB) |
|---|---|---|---|---|
| 32 | 432.5 | 74.0 | 1.43 | 1.52 |
| 64 | 175.4 | 364.8 | 2.40 | 2.55 |
| 96 | 246.8 | 388.9 | 3.38 | 3.61 |
| 128 | 309.7 | 413.4 | 4.36 | 4.81 |
| 192 | 447.1 | 429.4 | 6.32 | 6.70 |
| **256** | **560.7** | **456.6** | **8.28** | **9.04** |
| 320 | 914.1 | 350.1 | 10.24 | 11.14 |

判定：
- **定档 batch_size=256、grad_accum=1**，一次前向一次反传，未 OOM（峰值 8.28 GiB / 保留 9.04 GiB）。
- 320 档保留 11.14 GiB，已越过 10 GiB 目标线且吞吐下降（350 img/s），不采用。
- LR 处理（两个变量只说一个）：原 `1e-4` 是按有效 batch 32 定的；按 sqrt 缩放 `1e-4*sqrt(256/32)=2.83e-4`，取 **2.8e-4**。warmup 仍 500 step，weight decay / EMA / CFG dropout 不变。因此本轮 batch 变化与 LR 变化是**一个绑定改动**，后续 A/B/C 全部沿用，不再单独动 batch 或 LR。
- 实测吞吐 456 img/s，比旧 mb16/accum2 的 ~286 img/s 提升 1.6×。

## 2026-11-05 · 00:40 · FiLM 调制幅度与梯度（是否"注入通路失效"）

同一 z、同一 t=500，比较 true(style0) / null / wrong(style1) 三种条件（16 个 FiLM 层）。
产物：`runs/v4/diag/best.json`（`film`、`grad`）

| 指标 | 数值 |
|---|---|
| 调制项 / 主干激活 RMS（true / null / wrong） | 0.869 / 0.871 / 0.896 |
| 逐层调制 RMS（true，stage0→up1_res） | 0.883 / 0.825 / 0.745 / 0.766 / 0.815 / 0.723 / 0.680 / 1.511 |
| 换 Style-ID 后调制变化（vs wrong，逐层均值） | stage0 7.2% · stage1 10.0% · stage2 9.8% · stage3 10.3% · mid 13.6% · up3 11.4% · up2 7.4% · up1 3.0% |
| 换到 null 的调制变化（逐层） | 1.0% / 1.3% / 2.1% / 4.2% / 5.6% / 3.5% / 1.9% / 0.4% |
| cond 向量：真 vs null 相对距离 / 风格两两相对距离（均值/最小） | 6.4% / 20.96% / 10.28% |
| 梯度：style_embed vs time_embed | 1.77e-4 vs 1.14e-3（**6.4× 差距**） |
| 梯度：film proj（16 层均值/最大）、input_conv、out_conv | 1.83e-3 / 8.30e-3、5.35e-3、2.14e-2 |
| 参数模：style_embed / null_style / film proj 均值 | 0.742 / 0.0385 / 1.017 |

判定：
- **注入通路没有失效**：调制项是主干激活的 68%–151% RMS（强），Style-ID 在 16 层上都产生 3%–14% 的调制变化，FiLM 投影梯度非零（最大 8.3e-3）。"零初始化 + 无梯度"的假设被排除。
- 但**风格方向被压制**：cond 向量风格两两差异 21%，传到调制层只剩 ~10%；真条件与 null 在调制上仅差 2%。
- 关键不对称：`style_embed` 梯度比 `time_embed` 小 6.4×，`null_style` 模仅 0.0385（几乎没学动）。说明监督信号对"风格"这一维的需求本来就弱，而不是通路传递问题。

## 2026-11-05 · 00:45 · 按噪声区间比较 L_true / L_null / L_wrong

同一批 512 张验证集 latent，4 组独立噪声与时间步（固定 seed=99），配对比较。95% CI 按配对差值计算。
产物：`runs/v4/diag/best.json`（`cond_loss`）

|---|---|---|---|---|---|---|---|
| 0–165 | 78 | 0.27686 | 0.27703 | 0.27732 | +0.00017 ± 0.00005 | +0.00047 ± 0.00008 | +0.06% / +0.17% |
| 166–332 | 79 | 0.16383 | 0.16396 | 0.16422 | +0.00013 ± 0.00004 | +0.00039 ± 0.00007 | +0.08% / +0.24% |

| **500–665** | 79 | 0.09164 | 0.09173 | 0.09187 | **+0.00009 ± 0.00003** | **+0.00023 ± 0.00005** | +0.10% / +0.25% |
| 666–832 | 85 | 0.08806 | 0.08817 | 0.08831 | +0.00011 ± 0.00004 | +0.00024 ± 0.00006 | +0.12% / +0.27% |
| 833–999 | 99 | 0.12372 | 0.12381 | 0.12393 | +0.00009 ± 0.00003 | +0.00021 ± 0.00005 | +0.07% / +0.17% |
| 全局 | 2048 | 0.14431 | — | — | +0.00011 | +0.00030 | +0.08% / +0.20% |

判定：
- 排序**在所有噪声区间都稳定为 L_true < L_null < L_wrong**，且 Δ 全部显著（CI 不跨 0，4 次重复一致）。因此"Style-ID 完全无效"不成立。
- 但幅度极小：中 SNR（333–665）内 Δ_null 仅 +0.07%~+0.10%，Δ_wrong 仅 +0.20%~+0.25%。这就是 750 全量评测中 null/true 只差 dino_s 0.002 的根源——**条件学到了一点点，但远不足以驱动可见的风格变化**。
- 低噪声段（0–165）Δ_wrong 反而最大（+0.17%），与"输入自带风格信息"的预期相符，因此不能只看低噪声段就判断条件有用。

## 2026-11-05 · 01:05 · 五类小样本过拟合（区分网络问题 vs 数据问题）

40 张（8/风格），AdamW，bf16，batch 40，lr 1e-3，2500 step，`cfg_dropout=0`，FiLM 零初始化（与臂 A 同结构）。
产物：`runs/v4/diag/overfit_synth_lr1e3.json`、`runs/v4/diag/overfit_real_lr1e3.json`

| 数据集 | 最终 L_true | Δ_null | Δ_wrong | 中 SNR Δ_null | 最终 train loss | style_embed 模 | film proj 模 |
|---|---|---|---|---|---|---|---|
| 人工可区分（每类 2σ 固定均值方向 + 类内噪声） | 0.0809 | **+4.09%** | **+12.05%** | +3.98% | 0.0675 | 0.613 | 3.09 |
| 真实 8 图/风格（可记忆） | 0.0566 | **+57.3%** | **+166.7%** | +52.8% | 0.0471 | 0.842 | 3.21 |

对照（同样设置只跑 800 step、lr 2e-4、film 零初始化）：synth 与 real 的 Δ_null 均为 ~0.00%，模型尚未拟合（loss 仍 0.22–0.24）——说明此前的"零增益"部分是**训练不足**，不能单独作为判据。

判定：
- **网络与条件注入可以承载强 Style-ID 依赖**（人工数据 +4.09% / +12.05%，真实 40 图 +57% / +167%）。
- 真实 40 图上的巨大增益是**记忆效应**（风格标签唯一确定样本），不能外推到 4394 张全量，但足以证明"改写标签会显著改变预测"，即实现正确。
- 因此全量下 Δ_null≈0.08% 的原因是**数据侧信息量**：在 5 风格重叠的 latent 上，`E[eps|z_t,s]` 与 `E[eps|z_t]` 差别本来就小，而不是网络学不到。下一步要靠臂 A/B/C 判断"容量/曝光/条件强度"能否把这点差别放大到可用水平。

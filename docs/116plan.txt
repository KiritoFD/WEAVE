# WEAVE V5：24小时连续分支突破实验

这轮不再围绕伪GT做局部改良，而是直接裁决三种可能的正确路线：

1. 确定性风格算子：直接学习内容保持的风格分布变换。
2. 无配对终点监督Flow：保留ODE，但不再使用人工配对速度标签。
3. 真实艺术分布生成先验：从18K真实画作训练风格条件生成模型，再利用输入图像进行编辑。

第三条尤其重要。艺术风格迁移是欠定问题，确定性Style-ID映射未必能表达目标风格的多种合理结果；已有多样化风格迁移研究明确讨论过这一限制。

## 三、P0：修复真实的信息流问题（0–1.5h）

首先处理V4发现的训练－推理条件不一致。

现有paired-latent路径会在没有独立风格latent时，把监督终点`z1`作为风格条件，而推理使用独立参考图。

V5统一采用：

\\[ v\_\theta(z,\tau,t) \quad\text{或}\quad G\_\theta(z,t) \\]

首轮只依赖Style-ID，不依赖当前样本GT。

同时固定VAE posterior mean、验证集、随机种子及输入latent。将真实风格样本的多尺度latent描述符预先缓存。

交付： 条件交换测试、风格指标基线、可复现的数据流。无论条件泄漏影响大小，都继续P1。

## 四、P1：Latent Oracle，判断问题是否可解（1.5–4.5h）

不训练生成器，直接优化源图latent。

\\[ z'=z+\delta \\]

目标为：

\\[ \mathcal L= D\_{\rm style}(\Phi(z'),P_t) +\lambda D\_{\rm structure}(\Psi(z'),\Psi(z)) \\]

\\(\Phi\\)使用真实画作多尺度latent统计与patch分布；\\(\Psi\\)使用归一化空间自相似和结构特征，不强制源图LL统计保持不变。

### 测试矩阵

| Oracle | 允许修改        | 内容约束 |
| ------ | ----------- | ---- |
| O1     | LL          | 弱、强  |
| O2     | LL＋LH＋HL    | 弱、强  |
| O3     | LL＋LH＋HL＋HH | 弱、强  |

先测100个固定跨风格任务，每组64次latent优化迭代。

另外保留一个无内容约束的小样本诊断，区分“风格目标无效”和“内容约束过强”。

### 分支G1

A：Oracle成功。

判据：在独立CSD评估中，目标风格显著靠近，且DINO-C、LPIPS满足内容约束。

立即进入M1/M2训练。

B：Oracle失败。

不停止，进入监督目标修复。

| 失败现象           | 直接执行的实验                 |
| -------------- | ----------------------- |
| 无约束也无法提高CSD ΔT | 训练一个D5内部风格表征器，替换无效的风格统计 |
| 无约束有效，加结构约束就失效 | 更换内容结构约束，解除过强的LL空间锁定    |
| O3有效，O2失败      | 下一模型允许HH输出              |
| 目标风格改善但内容崩塌    | 调整结构损失，寻找Pareto前沿       |

新风格表征器只使用真实D5训练作品，采用同风格对比与类别监督，并检查留画家、内容困难负样本表现。

修正后再次做小规模Oracle。成功就进入M1；仍失败就进入真实分布生成先验路线C。

因此Oracle失败也不会造成实验链条中断。

## 五、路线A：真正比较两种模型范式（4.5–12h）

这是Oracle成功后的主线。

### M1：直接风格算子

\\[ \boxed{z'=z+R\_\theta(z,t)} \\]

设计：

- 1M–2M参数。
- 4个残差块，采用FiLM/AdaLN风格条件。
- LL与HF分别输出残差。
- 输出零初始化，初始严格等于输入。
- HH是否可训练由Oracle决定。

监督直接作用于最终latent：

\\[ \mathcal L\_{\rm M1} = \mathcal L\_{\rm style} +\lambda_c\mathcal L\_{\rm structure} +\lambda_i\mathcal L\_{\rm identity} \\]

训练时每个batch固定或分组目标风格，从真实目标风格latent库采样统计目标。SWD按样本集合计算，不把随机目标图当成逐像素GT。

这是真正不依赖伪GT、不需要ODE的模型。

### M2：无配对终点监督Flow

保持现有WEAVE约1M规模，输出：

\\[ z'=ODE\_\theta(z,t) \\]

训练不使用人工速度标签：

\\[ \boxed{ \mathcal L\_{\rm M2} = \mathcal L\_{\rm style}(z',P_t) +\lambda_c\mathcal L\_{\rm structure} +\lambda_i\mathcal L\_{\rm identity} } \\]

首轮使用2步可微ODE，随后比较4步训练与8步推理。

它与M1使用完全相同的风格和内容目标。

这样能够直接回答：真正有效的是监督目标，还是ODE提供了必要的模型能力？

## 六、路线B：Oracle失败后，如何继续（4.5–12h）

这条路线要明确区分两种根因。

### B1：原风格描述符失效

若latent统计SWD下降，但CSD和视觉效果不改善，说明原风格目标可能不够表达真实画风。

立即建立一个轻量Style Encoder：

\\[ E_s:z\rightarrow h_s \\]

使用18K真实画作训练，学习五类风格的分布表征。

先验证其在留画家和内容相似负样本上的风格区分能力。达标后冻结编码器，以其特征分布重新运行Oracle。

若成功： 用新监督训练M1。

若仍失败： 不再反复调整统计量，直接切换路线C。

### B2：内容约束过强

若无约束时可以明显靠近目标风格，但内容损坏，说明当前内容保持定义不合理。

对比两种约束：

\\[ L\_{\rm local\ selfsim} \\]

与

\\[ L\_{\rm coarse\ geometry} \\]

并检查LL外观变化是否仍然被结构损失过度抑制。

若存在有效Pareto点： 使用对应目标训练M1。

若仍不存在： 进入路线C，用真实生成先验重新建立风格－内容权衡。

这保证P1失败后，仍然有明确的模型训练工作，而不是仅仅得到一份诊断报告。

## 七、路线C：训练真正的艺术风格生成先验（7–17h）

这是整轮最重要的备用方向，也可能反而是真正正确的模型。

不再让网络学习“源图应该去往哪张图”。

直接学习：

\\[ p(z\mid t) \\]

其中 \\(z\\) 是真实艺术作品latent，\\(t\\) 是五种风格类别。

采用Style-Conditional Rectified Flow：

\\[ z\_\tau=(1-\tau)\epsilon+\tau z\_{\rm real} \\]

\\[ \boxed{ v^\*=z\_{\rm real}-\epsilon } \\]

这一次FM监督是合法且明确的生成建模目标：从噪声分布学习到真实目标风格作品分布，而不是拟合人为拼贴的目标图。

模型约2M参数，单卡3060训练约2000–4000步，依据实测吞吐调整。

### 如何实现风格迁移？

借鉴SDEdit的部分加噪编辑思想：把真实源图映射到中间噪声水平，再利用目标风格生成先验恢复。原始SDEdit依赖预训练生成先验；这里需要自行训练D5小模型，不能假设能够获得相同质量。

[image](https://www.google.com/s2/favicons?domain=https://arxiv.org\&sz=32)

arxiv.org



设：

\\[ z\_{\tau_0}=\tau_0z\_{\rm source}+(1-\tau_0)\epsilon \\]

从\\(\tau_0\\)积分至1，目标条件为\\(t\\)。

固定测试：

| 输入保留比例 \\(\tau_0\\) | 预计取舍          |
| ------------------- | ------------- |
| 0.35                | 风格自由度较高，内容风险大 |
| 0.55                | 平衡档           |
| 0.75                | 内容保留较多，风格改变较弱 |

另测试一种结构引导：保留源图归一化的粗尺度空间布局，但允许LL颜色统计变化。

### 路线C的后续也不能中断

| 结果                  | 继续执行                     |
| ------------------- | ------------------------ |
| 能生成合理目标风格，但内容差      | 扫描部分加噪强度与结构引导            |
| 内容很好，但目标风格弱         | 降低输入保留比例，增加目标风格生成自由度     |
| 从纯噪声都不能生成可信艺术latent | 改成低/中噪声去噪训练，测试局部生成先验能否成立 |
| 生成质量与内容都达标          | 测试两个随机种子的风格多样性及泛化        |

这条路线的意义是验证：我们是否真正需要一个会生成艺术画风的模型，而不是仅会修改输入的确定性网络。

如果低噪声去噪也失败，则可进一步将失败定位到模型容量、数据规模或训练表示，而不再归咎于伪GT。

## 八、模型训练失败后的第三层分支（12–17h）

即使Oracle成功，M1和M2也可能都失败。这种情况同样有预定后续。

| 结果                 | 后续实验                  |
| ------------------ | --------------------- |
| M1成功，M2失败          | M1延长训练＋第二seed；不再投入ODE |
| M2成功，M1失败          | M2扩展到4步可微训练，检查ODE实际价值 |
| M1/M2都成功           | 比较同质量下的计算量和风格多样性，选择主线 |
| Oracle成功，但M1/M2都失败 | 进行Oracle解蒸馏实验         |
| Oracle修复失败         | 直接运行路线C               |

### Oracle解蒸馏

如果单张latent可以优化到正确风格，但网络不能一步预测到那里，问题就是优化结果无法被有效摊销到模型参数中。

从已经成功的Oracle生成约1000个经过内容约束与独立风格评估的解：

\\[ (z,\hat z\_{\rm oracle},t) \\]

用M1学习：

\\[ R\_\theta(z,t)\approx \hat z\_{\rm oracle}-z \\]

这里的终点不是Patch拼贴伪GT，而是已经实际验证风格和内容都合格的优化解。

训练后检查：

- 是否能拟合这些可行变换。
- 是否能泛化到未参与Oracle优化的源图。
- 是否只需要增加模型容量，还是需要迭代式优化。

若蒸馏有效： 后续采用Oracle指导的迭代训练。

若蒸馏失败： 在剩余预算内运行路线C的小规模生成先验试验，判断问题是否来自确定性变换。

## 九、24小时固定时间表

所有分支共享同一时间窗口，不会因为前面某一项失败导致后面无事可做。

| 时间       | 主线成功时                 | 主线失败时                    |
| -------- | --------------------- | ------------------------ |
| 0–1.5h   | 条件泄漏修复、评测冻结           | 相同                       |
| 1.5–4.5h | Latent Oracle         | 相同                       |
| 4.5–7h   | 构建M1/M2，开始训练          | 修复风格表征或内容约束，重做Oracle     |
| 7–12h    | M1/M2训练及200验证         | 训练修正目标M1；若仍失败，启动真实风格RF先验 |
| 12–17h   | 成功则扩训/复验；失败则Oracle解蒸馏 | 继续RF先验、部分加噪与结构引导实验       |
| 17–21h   | 最优模型完整600/150评测       | RF或补救模型完整600/150评测       |
| 21–24h   | 第二seed、失败案例分析、模型定型    | 低噪声补救/结构约束复核、完整失败归因      |
| 总计       | 24h                   | 24h                      |

这次每个时间窗口固定资源预算，未使用的时间立即转给当前最优路线，不再增开新研究主题。

工程上维持单GPU任务、串行评估、FP16 latent缓存、单独加载CSD，以及已实测的batch/渲染档位。

## 十、统一成功标准

所有路线，包括Oracle、M1、M2和生成先验，都使用相同的独立风格与内容评价。

| 指标            | 要求                  |
| ------------- | ------------------- |
| 600跨风格CSD ΔT  | 挑战目标≥+0.04          |
| 相比同协议旧WEAVE   | 配对95% CI支持正向改善      |
| DINO-C        | 不低于旧基线超过0.01        |
| LPIPS         | 不高于旧基线超过0.01        |
| 目标风格覆盖        | 至少4/5风格改善           |
| Ukiyo-e       | ΔT必须转正              |
| Style-ID条件选择性 | 显著高于错误ID            |
| 150同风格保持      | 不出现明显额外风格损伤         |
| 可视化           | 不允许明显纹理作弊、语义改变或结构崩塌 |

对于随机生成路线，两个随机种子都要报告，采用平均性能，不允许只选最好的一张。

如果某模型风格有突破但内容未达标，保留它作为风格能力证据，并进入内容引导分支；不能直接宣布成功。

## 十一、24小时结束时必须交付的结果

| 必须回答的问题                | 对应证据                |
| ---------------------- | ------------------- |
| 现有VAE latent能否表达强风格迁移？ | O1/O2/O3与Oracle补救实验 |
| 原监督是否根本错误？             | 修正条件后的FM、M1/M2结果    |
| 直接算子是否比ODE合理？          | M1与M2同监督、同评估对照      |
| 主要瓶颈是否为模型不能摊销优化解？      | Oracle解蒸馏           |
| 是否真正需要生成先验和随机性？        | 路线C噪声－真实作品Flow与编辑实验 |
| 该使用什么模型继续研究？           | 600跨风格主表＋内容Pareto前沿 |

最后的裁决只有三类：

A. 确定性直接算子成功： WEAVE过去主要错在监督目标，ODE可以退出主线。

B. 无配对Flow或真实艺术先验成功： 需要保留生成过程，但必须使用真正的分布建模，而不是随机画作伪配对。

C. 所有模型都未成功： 通过Oracle与补救实验明确区分是风格目标、内容约束、表示能力，还是小模型生成容量限制，并据此确定下一轮唯一优先方向。

本轮不以“找出哪个超参数更好”为目标，而是要在24小时内决定下一代WEAVE究竟应该是一种风格变换算子，还是一种内容约束的艺术生成模型。

# WEAVE伪GT：A–E五种方法的具体实现

统一原则：所有方法都从现有18K五风格数据中取图，使用同一批内容匹配结果和Patch位置。只改变伪GT构造算法，不改变原始数据、不训练额外模型。

五种方法实际上分为两类：

| 方法            | 训练输入 \\(z_0\\) | 训练目标 \\(z_1\\) | 核心区别         |
| ------------- | -------------- | -------------- | ------------ |
| A RGB硬替换      | 真实源图           | RGB拼贴伪GT       | 直接复制目标画作局部   |
| B RGB软融合      | 真实源图           | RGB融合伪GT       | A的接缝处理对照     |
| C Latent HF替换 | 真实源图           | 高频拼贴伪GT        | 只移植局部高频信息    |
| D Latent局部统计  | 真实源图           | 统计迁移伪GT        | 不复制目标画作的具体内容 |
| E 反向Patch污染   | 人工污染的目标图       | 真实目标画作         | 反向构造真实GT配对   |

其中，A/B检验RGB真实纹理移植，C/D检验是否需要复制真实纹理，E检验真实GT恢复是否优于人工伪GT。

## 一、五种方法共享的Patch匹配

这一部分必须完全相同，否则实验结果无法归因于构造方法。

### 1. 数据表示

使用两张不同风格、内容相似的真实画作：

- \\(x\\)：源风格作品，例如Impressionism。
- \\(y\\)：目标风格作品，例如Ukiyo-e。
- \\(t\\)：目标风格ID。

图像均使用仓库现有的512px预处理。

VAE编码：

\\[ z_x=E(x),\qquad z_y=E(y) \\]

均为 \\(4\times64\times64\\)。

使用 `latent_dist.mean`，而非随机采样，固定VAE scaling factor。

### 2. Patch对应关系

从DINOv2内容检索得到的候选图像中，建立匹配：

\\[ \mathcal P_i=(R_i^x,R_i^y,q_i) \\]

其中：

- \\(R_i^x\\)：源图中的矩形区域。
- \\(R_i^y\\)：目标图中语义对应的矩形区域。
- \\(q_i\\)：匹配置信度。

两块区域在第一轮要求尺寸相同，不进行复杂形变。

例如：

```
源图 x（Impressionism）             目标图 y（Ukiyo-e）

┌──────────────────┐                ┌──────────────────┐
│                  │                │                  │
│      ┌─────┐     │                │  ┌─────┐         │
│      │房屋 │     │     匹配       │  │房屋 │         │
│      └─────┘     │  ─────────►    │  └─────┘         │
│                  │                │                  │
└──────────────────┘                └──────────────────┘
       Rx                                   Ry
```

需要注意：两个patch位置可以不同，但应描述相近的内容。

第一轮不要使用随机位置替换作为正式方案。 随机匹配只保留为负对照。

### 3. 生成Patch掩码

令 \\(M\in[0,1]^{512\times512}\\)。

固定九种配置：

| ID | Patch尺寸     | 数量 | 覆盖率   |
| -- | ----------- | -- | ----- |
| P1 | 64          | 8  | 12.5% |
| P2 | 64          | 16 | 25%   |
| P3 | 64          | 32 | 50%   |
| P4 | 128         | 2  | 12.5% |
| P5 | 128         | 4  | 25%   |
| P6 | 128         | 8  | 50%   |
| P7 | 256         | 1  | 25%   |
| P8 | 256         | 2  | 50%   |
| P9 | 128×1＋64×12 | 13 | 25%   |

Patch不允许重叠。

若匹配图像中找不到足够多的可靠区域，标记该样本构造失败，而不是用低质量匹配凑数量。

## 二、A：RGB硬Patch替换

目标：测试直接复制真实目标风格局部像素，能否产生有效伪GT。

### 具体算法

对于每个匹配区域 \\((R_i^x,R_i^y)\\)：

1. 从目标画作 \\(y\\) 中裁剪区域 \\(R_i^y\\)。
2. 将其复制到源图 \\(x\\) 的对应区域 \\(R_i^x\\)。
3. 不改变patch内部的颜色、对比度、笔触或纹理。
4. 完成所有非重叠patch替换。
5. 将生成的RGB图像编码为VAE latent。

公式：

\\[ \boxed{ \hat y_A=(1-M)x+M W(y) } \\]

其中 \\(W(y)\\) 表示根据匹配坐标拼接到源图位置的目标patch。

### 实现要点

RGB使用float32 `[0,1]`，拼贴完成后直接转为VAE输入范围`[-1,1]`并编码。

不要中间保存PNG再读回来，也不要进行二次量化。

伪GT：

\\[ z_A=E(\hat y_A) \\]

缓存训练配对：

\\[ \boxed{(z_x,z_A,t)} \\]

### 实验变量

A完整测试P1–P9，九组。

预期问题： 256px大patch可能带入其他画作的物体结构；64px小patch则可能只形成局部异质纹理。

A是最重要的朴素基线，不能因为有接缝就提前排除。

## 三、B：RGB软边界融合

目标：在与A完全相同的patch内容和位置下，判断接缝是否是主要问题。

### 具体算法

前四步与A完全一致，但不直接使用二值掩码。

对每个patch生成羽化权重：

\\[ \alpha_i(u,v)\in[0,1] \\]

设patch边长为 \\(p\\)，边界过渡宽度：

\\[ w=p/8 \\]

距离边界超过 \\(w\\) 的内部区域权重为1；靠近边界逐渐降至0。

采用Smoothstep：

\\[ h(r)=3r^2-2r^3 \\]

\\[ \alpha_i(u,v)= h\left( \min\left(1,\frac{d(u,v)}{w}\right) \right) \\]

其中 \\(d(u,v)\\) 为像素到该patch最近边界的距离。

最终：

\\[ \boxed{ \hat y_B=(1-\alpha)x+\alpha W(y) } \\]

其中 \\(\alpha\\) 是所有非重叠patch的融合权重。

### 实现要点

B只测试P2、P5、P7、P9。

必须与A使用相同的：

- 源图和目标图。
- Patch对应坐标。
- Patch数量和位置。
- 随机种子。

只有边缘融合不同。

需要同时记录名义覆盖率与实际权重覆盖率：

\\[ a\_{\rm effective} = \frac{\sum\_{u,v}\alpha(u,v)}{512^2} \\]

因为羽化后实际注入强度低于硬替换的25%。

训练配对：

\\[ \boxed{(z_x,E(\hat y_B),t)} \\]

A与B的差异可以判断：直接复制纹理带来的收益，是否被人工拼贴边界抵消。

## 四、C：Latent高频Patch替换

目标：只移植目标作品的局部纹理频带，避免直接复制颜色与大尺度内容。

这个方案不在RGB空间操作。

### 1. 对两张图的latent做Haar分解

\\[ (LL_x,LH_x,HL_x,HH_x)=DWT(z_x) \\]

\\[ (LL_y,LH_y,HL_y,HH_y)=DWT(z_y) \\]

各子带大小为 \\(4\times32\times32\\)。

### 2. 将RGB匹配坐标映射到子带

图像分辨率512，latent分辨率64，一级Haar子带分辨率32。

因此：

\\[ p\_{\rm subband}=p\_{\rm image}/16 \\]

| 图像Patch | Latent区域 | Haar子带区域 |
| ------- | -------- | -------- |
| 64×64   | 8×8      | 4×4      |
| 128×128 | 16×16    | 8×8      |
| 256×256 | 32×32    | 16×16    |

为避免坐标误差，Patch位置需对齐到16像素网格。匹配坐标需要取整到该网格并重新确认有效性。

### 3. 只替换LH、HL

\\[ \widehat{LH} = (1-M_h)LH_x+M_hW(LH_y) \\]

\\[ \widehat{HL} = (1-M_h)HL_x+M_hW(HL_y) \\]

同时：

\\[ \widehat{LL}=LL_x \\]

\\[ \widehat{HH}=HH_x \\]

其中 \\(M_h\\) 是32×32的子带掩码。

### 4. 逆DWT

\\[ \boxed{ z_C=IDWT( LL_x,\widehat{LH},\widehat{HL},HH_x ) } \\]

训练配对：

\\[ \boxed{(z_x,z_C,t)} \\]

与A/B的重要区别： 不经过第二次VAE编码；只需要将构造好的latent转成FP16缓存。

### 特别注意

当前WEAVE主要预测LL、LH、HL，HH头关闭。

所以本轮C先不替换HH，避免目标变化大部分落在模型不能预测的频带。

C也不要额外进行全图AdaIN，否则会混入一个新的风格变换变量。

测试P2、P5、P7、P9，共四组。

这组的核心价值不是一定获得最高CSD，而是验证局部笔触频带本身能提供多少风格监督。

## 五、D：Latent局部统计迁移

目标：迁移目标作品的局部风格统计，但完全不复制目标patch的空间纹理。

它与C形成最重要的一组对照。

### 1. 同样进行Haar分解

取LL、LH、HL三个子带。

### 2. 对匹配patch计算局部统计

对于某个子带 \\(b\\)：

源patch：

\\[ P_x^b \\]

目标patch：

\\[ P_y^b \\]

分别计算每个latent通道的均值和标准差：

\\[ (\mu_x^b,\sigma_x^b) \\]

\\[ (\mu_y^b,\sigma_y^b) \\]

注意：64px图像patch对应子带仅4×4，直接使用16个空间位置估计标准差可能不稳定。

建议统计量使用以patch为中心、边长约2p的上下文窗口，变换只应用于原patch内部。 上下文不足时截断到图像边界，并记录实际统计窗口大小。

### 3. 变换源patch

使用局部AdaIN：

\\[ \boxed{ \widetilde P_x^b= \frac{P_x^b-\mu_x^b} {\sigma_x^b+\epsilon} \sigma_y^b+\mu_y^b } \\]

第一轮建议对方差放大比例进行限制：

\\[ r=\operatorname{clip} \left( \frac{\sigma_y^b}{\sigma_x^b+\epsilon}, 0.5,2.0 \right) \\]

实际上计算：

\\[ \widetilde P_x^b = (P_x^b-\mu_x^b)r+\mu_y^b \\]

并记录发生裁剪的比例，防止极小方差patch导致数值爆炸。

### 4. 将变换后的patch放回源子带

\\[ \widehat H^b= (1-M_h)H_x^b+M_h\widetilde H_x^b \\]

这里 \\(b\in\\{LL,LH,HL\\}\\)。

HH保持原样。

然后：

\\[ \boxed{ z_D=IDWT( \widehat{LL},\widehat{LH},\widehat{HL},HH_x ) } \\]

训练配对：

\\[ \boxed{(z_x,z_D,t)} \\]

### D与C究竟有什么区别？

| 属性            | C         | D          |
| ------------- | --------- | ---------- |
| 复制目标patch像素   | 否         | 否          |
| 复制目标patch高频系数 | 是         | 否          |
| 迁移局部统计        | 隐式        | 显式         |
| 改变LL          | 否         | 是          |
| 源图局部结构保留      | 可能被目标HF扰动 | 通常更容易保留    |
| 主要风险          | 局部高频错配    | 只能表达简单统计变化 |

D测试P2、P5、P7、P9。

这里需要特别注意：C与D当前不只是“复制纹理”和“复制统计”的区别，LL是否参与也不同。

因此，建议D额外输出一份`D-HF`诊断结果，仅改变LH/HL、不改变LL。这样可以拆出LL统计迁移的贡献，而不增加一套完整训练实验。

## 六、E：反向Patch污染，真实画作为GT

这是与A–D本质不同的方法，也是最值得优先研究的一种。

A–D：

\\[ \text{真实源图}\rightarrow\text{人工伪GT} \\]

E：

\\[ \text{人工污染图}\rightarrow\text{真实目标图} \\]

### 1. 选择真实目标画作

设真实Ukiyo-e画作为 \\(y\\)。

这张画原封不动就是GT。

### 2. 找到内容对应的其他风格作品

例如一幅Impressionism画作 \\(x\\)，其中某些建筑、人物或背景区域与 \\(y\\) 相近。

匹配规则与A–D一致，但这次掩码定义在目标画作 \\(y\\) 上。

### 3. 把异风格Patch反向贴入真实目标画作

从 \\(x\\) 裁剪匹配patch，将它们写入 \\(y\\) 的相应区域。

\\[ \boxed{ \tilde x_E=(1-\alpha)y+\alpha W(x) } \\]

此时：

- \\(y\\)：完整真实目标风格。
- \\(\tilde x_E\\)：部分区域被其他风格污染的图像。

例如：

```
真实 Ukiyo-e 作品 y          注入 Impressionism Patch

┌──────────────────┐         ┌──────────────────┐
│                  │         │                  │
│  浮世绘房屋      │         │  油画风格房屋    │
│                  │   →     │                  │
│  浮世绘背景      │         │  浮世绘背景      │
│                  │         │                  │
└──────────────────┘         └──────────────────┘
       GT y                         输入 x~
```

### 4. 构造训练配对

\\[ z_0=E(\tilde x_E) \\]

\\[ z_1=E(y) \\]

\\[ \boxed{(z_0,z_1,t)} \\]

GT来自原图latent缓存，不需要重新编码。

仅需编码污染后的输入。

### 5. 七种实验配置

| 实验 | Patch | 覆盖率 | 融合      |
| -- | ----- | --- | ------- |
| E1 | 16×64 | 25% | Feather |
| E2 | 32×64 | 50% | Feather |
| E3 | 4×128 | 25% | Feather |
| E4 | 8×128 | 50% | Feather |
| E5 | 1×256 | 25% | Feather |
| E6 | 混合尺度  | 25% | Feather |
| E7 | 4×128 | 25% | Hard    |

这里的`16×64`表示16个64×64 patch，不是16像素×64像素。

### 为什么需要50%覆盖率？

25%的替换意味着75%的图仍然是完整目标风格。

模型可能学到：

> 把少量异物抹掉，恢复原图。

而不是学到：

> 输入属于其他画风，应当转成指定目标风格。

50%污染能够降低这种捷径的强度。

但覆盖率越高，语义损伤风险也越大，所以必须与25%比较。

### 为什么要E7硬替换？

它用于判断网络是不是只利用明显的拼贴边界定位污染区域。

如果E7训练集恢复很好，但真实跨风格迁移完全失败，就说明模型可能主要学会了图像修补。

另一个重要要求是：训练时不得把真实GT \\(y\\) 当作Style Reference输入网络。 若模型需要目标参考图，必须选择同风格、不同作品的第三张图，否则构成目标泄漏。

## 七、统一缓存接口

A–E都直接输出训练需要的两个latent，而不是使用原有“仅替换终点”的缓存接口。

建议使用统一数据结构：

```
# 伪代码：每一条训练记录record = {    "sample_id": "...",    "method": "A",          # A/B/C/D/E    "patch_spec": "P5",    "source_image_id": "...",    "donor_image_id": "...",    "target_style_id": 3,    "patch_match_id": "...",    "seed": 42,    # 真正训练用的配对    "z0_index": 1234,    "z1_index": 5678,    # 其中一端通常引用原图latent    "z0_is_original": True,    "z1_is_original": False,    "nominal_coverage": 0.25,    "effective_coverage": 0.25,    "match_confidence": 0.91,}
```

数据加载器统一返回：

```
z0, z1, target_style_id
```

两个latent均为`4×64×64`，存储格式FP16，加载后按照训练精度使用。

具体缓存规则：

| 方法 | 原图缓存      | 新增缓存                |
| -- | --------- | ------------------- |
| A  | \\(z_x\\) | \\(z_A\\)           |
| B  | \\(z_x\\) | \\(z_B\\)           |
| C  | \\(z_x\\) | \\(z_C\\)           |
| D  | \\(z_x\\) | \\(z_D\\)           |
| E  | \\(z_y\\) | \\(E(\tilde x_E)\\) |

单张新增latent仅32KiB。

现有`pseudo_targets.py`可以复用shard存储逻辑，但它的索引主要是`(content_key, style_id)`，不足以区分同一图像的多个patch版本。新实验应使用唯一`sample_id`，否则版本之间可能覆盖。

工程上还要处理一个已核实的问题：当前[`flow.py`](https://github.com/KiritoFD/WEAVE/blob/main/flow.py?utm_source=chatgpt.com)的`_build_training_target()`可能再次对输入目标执行SAT、LL匹配或训练AdaIN。

本轮必须设置独立的`paired_latent`训练分支，直接使用缓存的 \\(z_0,z_1\\)。

训练目标固定为：

\\[ z\_\tau=(1-\tau)z_0+\tau z_1 \\]

\\[ u=z_1-z_0 \\]

不得对 \\(z_1\\) 再执行任何风格化处理。

## 八、每种构造必须通过的正确性测试

| 方法 | 必须验证                                    |
| -- | --------------------------------------- |
| A  | 掩码外RGB严格等于源图；patch内严格等于目标对应区域           |
| B  | Patch内部等于A；边缘连续；同一匹配位置下比较               |
| C  | LL、HH与源图一致；修改仅来自指定LH/HL区域               |
| D  | 目标统计与源统计相同且无裁剪时，输出应恢复源latent；无NaN、无极端增益 |
| E  | GT严格等于真实作品latent；污染图没有直接作为参考输入模型        |
| 全部 | 相同seed逐位可重现；原数据目录哈希不变；不会混入test图         |

另需保存少量临时解码图用于检查，不能只看latent数值。尤其A/B/E经过VAE编码后，局部变化会扩散至邻近区域，掩码外RGB的严格相等只适用于编码前。

## 九、最重要的实验判断

这五种方法不是简单比较谁的CSD得分最高。

| 对照                  | 可以回答什么             |
| ------------------- | ------------------ |
| A vs B              | 接缝处理是否决定伪GT质量      |
| A vs C              | 复制RGB内容是否必要        |
| C vs D-HF           | 真实高频纹理复制是否优于统计迁移   |
| D-HF vs D           | LL风格统计是否带来额外收益     |
| A/B vs E            | 人工伪GT与真实GT恢复，哪个更有效 |
| E25% vs E50%        | 模型是否依赖大量原目标风格区域    |
| E-Feather vs E-Hard | 模型是否在利用接缝捷径        |

执行优先级仍是E＞C≈D＞B＞A，但数据质量评估必须五种全部完成。

最终只选择正向、反向各一个方案进入相同预算的短训练。A–D的伪GT风格增益与E的污染强度需要分别定义和报告，不能混成一个排行榜。

最关键的是：A–D研究如何构造可靠的目标风格变化；E研究能否从真实艺术作品获得严格对齐的训练监督。两条路线解决的是不同问题，必须保留这一区分。

## 机理结论（为什么判负）

1. **处方式检索（按 q）是错误形态**：把当前 patch 的笔触特征拉向**另一幅画作**的
   patch——那组特征值混合了 donor 的内容外观，对本 patch 不是"更真实"的方向。
   退化恢复要的是 undo 当前点的参数化退化，不是搬别人的特征值。
2. **软密度核（KDE）才是对的形态**：exp(−‖v−v_j‖²/2σ²−…) 的权重由 **v 相似度主导**，
   score = 拉向条件分布中离当前点最近的真值区域——这正是"密度梯度"与"处方"的本质区别。
3. **内容条件化本身有边际收益**（M1 −.25 > M0 −.53，逐画派一致）——v11 文档 P1 的
   问题"内容匹配是否有收益"答案为**是**，但它救不了处方式这个机制。
4. **硬选择（Top-1/Top-K）不优于软核**（M1v/M2v ≈ 0 vs KDE .30）：软核的平滑加权
   已经是更好的"选择器"，硬目标只增加噪声——v11 文档担心的"平均不兼容笔触"在
   KDE 形态下并未发生（因为核宽 σ=1.0 限制了平均范围）。

## 对 v11（延期方案）的含义

- **不要**把"检索目标 + 距离损失"作为 v11 的监督/推理形态——已证伪。
- v11 的真正缺口是 v11 文档自己指出的："WEAVE 必须从真实画作中**学习**可执行的
  局部笔触表示"——即一个能把内容结构映射到合理笔触模式的**学习式编码器**
  （其 P3 的 32×32 Attention 分支）。在它存在之前，任何"免训练处方目标"都缺合法目的地。
- 若重启 v11：以 V10 KDE 方向为推理期基线，学习式分支的目标函数建议直接用
  **密度提升**（让生成的 v 落入条件分布高密度区）而非**距离回归**。

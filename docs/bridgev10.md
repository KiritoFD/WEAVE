# WEAVE：五风格 Schrödinger Flow 重构与 40 组实验计划

**目标：一个共享模型实现 5 种风格、20 个有向转换；12 小时完成机制探索，确定下一代主线。**

代码继续使用现有 `sbflow/`，实验通过 Git commit、配置文件和运行目录管理，不创建新的 V10/V11 代码树。

## 一、先完成五风格迁移

### 1.1 统一任务定义

五个风格：

`Early_Renaissance / Impressionism / Minimalism / Rococo / Ukiyo_e`

训练包含 10 个无序风格对，推理覆盖 20 个有向转换。所有实验必须使用**一个共享网络**，不能分别训练十个模型。

对任意两个风格，规定规范顺序：

\[
a=\min(i,j),\qquad b=\max(i,j)
\]

训练桥：

\[
z_0\sim p_a,\quad z_1\sim p_b
\]

\[
z_t=(1-t)z_0+tz_1+\sqrt{\varepsilon t(1-t)}\,\xi
\]

两个监督目标保持博客定义：

\[
b^*_{+}=\frac{z_1-z_t}{1-t},\qquad
b^*_{-}=\frac{z_0-z_t}{t}
\]

概率流：

\[
\boxed{v_{ab}(z,t)=\frac{b_{+}(z,t,a,b)-b_{-}(z,t,a,b)}2}
\]

推理时，`a→b` 从 0 积分到 1，`b→a` 从 1 积分到 0。

同一风格转换直接走 Identity，不训练额外的恒等网络。

### 1.2 修改网络条件

当前 `sbflow/network.py` 只有时间和方向条件。扩展为：

```python
model(x, local_t, style_a, style_b, direction)
```

使用规范排序后的 `style_a < style_b`。

第一版条件：

\[
c=e_t(\tau)+W[e_a,e_b]+e_d
\]

其中：

- `e_a,e_b`：五风格共享 embedding。
- `e_d`：正向/反向漂移 embedding。
- `τ`：正向使用 `t`，反向使用 `1-t`。
- 主干：继续使用 `width256/depth6/heads4/patch2`。

**默认采用分解式风格 embedding，不直接使用十个彼此独立的 pair embedding。** 后者只作为一组对照。

这样模型既知道具体的源、目标风格，也能共享不同风格对之间的知识。

### 1.3 数据和 EDM 必须同时修改

当前 `sbflow/train.py` 的两个缓存参数改为五域缓存列表。

所有五域 latent 使用**同一个全局 mean/std**：

\[
z'=\frac{z-\mu_{\rm global}}{\sigma_{\rm global}}
\]

禁止按风格单独标准化，否则会抹掉真实的跨域统计差异。

但 EDM 的端点统计需要按风格对保存：

```text
global_mean/std: [32]

domain_stats: [5, 32]
pair_moments: [10, 5, 32]
```

对无 OT 的独立端点：

\[
\operatorname{Cov}(z_a,z_b)=0
\]

因此可以直接使用五域真实统计构造十对 EDM 系数，不必继续通过大量随机配对估计交叉协方差。

在线 α-DSBM 会改变端点耦合，需要另行处理动态交叉协方差。

**原有双域 checkpoint 不能直接当作五域模型使用。** 主干参数可作为迁移初始化的独立实验，但本轮主对照应从零训练，以免旧标准化和旧风格对产生混杂因素。

### 1.4 训练采样器

每 10 个 update 覆盖全部十个风格对，顺序随机打乱。

每次 update 只使用一个风格对，保证该批量有足够的同目标分布样本。

```python
pairs = all_unordered_pairs(num_styles=5)

for step in range(total_steps):
    a, b = balanced_pair_schedule(pairs, step)

    z0 = sample_domain(a, batch)
    z1 = sample_domain(b, batch)

    loss = bridge_objective(
        model, z0, z1, a, b
    )

    optimizer_step(loss)
```

默认 `batch=1024`，但首先实测显存和吞吐。

每域只有约 1000 张图。建议采用独立随机排列、循环取样；Batch 1024 时最多补少量重复样本，避免有放回采样造成约 38% 的重复位置。

数据索引、桥噪声、时间采样、OT 和初始化必须使用独立 RNG。

### 1.5 评测接口直接改成完整五风格

原 `eval_test600.py` 只筛一个风格对，需要改为统一处理全部 600 个跨风格任务。

输出：

- 20 个有向转换的独立指标；
- 5 个目标风格的宏平均；
- 全部 600 的总指标；
- 150 个同风格 Identity 的单独结果。

保持原有 CSD/DINO/CLIP/LPIPS 协议，不重新定义测试集。

修复旧诊断中的 DCAE 风格域读取错误，以及不同目标域混合计算总体 MMD 的问题。

**第一阶段交付标准：一个从零训练的五风格模型，可以完整生成 600 张跨风格结果。未达到这一步，不启动后续机制实验。**

## 二、先明确此前已经发现的瓶颈

目前已有证据支持以下判断。

| 已知结果 | 对后续设计的意义 |
|---|---|
| 1.89M→7.45M 有明显收益，继续扩大到 32M 收益有限 | 容量暂时固定 |
| Bridge MSE 继续下降，但风格指标后期下降 | 局部回归和终点质量存在目标错位 |
| 双向迁移显著不对称 | 需要研究双向动力学与目标分布，而非只优化统一 Top-1 |
| Ukiyo→Imp 有明显发白等异常 | 必须区分真实风格生成与源风格擦除 |
| DCAE 的纹理保真尚未得到充分证明 | 先测表征上限，不急于更换 VAE |
| OT 的收益不稳定，且有额外计算成本 | 降为最低优先级 |
| 单速度与双漂移在理想条件期望下等价 | 可通过参数化消融寻找更容易优化的实现 |

这次主要探索四个根本问题：

**桥本身是否正确、桥是否足够优化、生成分布是否被正确监督、五风格是否需要共享中间坐标。**

## 三、40 组实验矩阵

所有编号均为**五风格共享模型训练实验**。五风格对比编码器的预训练、数学单测、推理诊断不占这 40 个名额。

### A：五风格基线与大 Batch（4 组）

目标：先建立可靠的计算与优化基线。

| ID | 改动 | 核心问题 |
|---|---|---|
| **01** | B256，3200 updates | 小 Batch 参考 |
| **02** | B512，1600 updates | 吞吐与梯度方差 |
| **03** | B1024，800 updates，有放回采样 | 超大 Batch 是否提升单位曝光量收敛 |
| **04** | B1024，800 updates，均衡无放回采样 | 重复样本是否浪费有效 Batch |

四组名义样本曝光量相同。

**04 为后续默认对照；如果 1024 的单位曝光量收敛明显劣于 512，则使用 02 作为对照。** 不机械追求显存占用率。

基线统一为：

`5-style / bidirectional / EDM / ε=.04 / noOT`

04 额外继续训练到 1200 步，保存后续在线微调所需的 800-step 起点及同更新数继续训练对照。

### B：概率流参数化（6 组）

这一组优先级最高。

| ID | 相对对照的唯一核心改变 | 验证假设 |
|---|---|---|
| **05** | 双漂移→直接单速度，使用重新推导的 EDM | 双漂移是否造成不必要的优化难度 |
| **06** | 05 去掉 EDM | EDM 对直接速度是否仍必要 |
| **07** | 双漂移共享主干，但使用独立输出头 | 正反向输出层是否发生冲突 |
| **08** | 每个桥样本同时监督两个方向，而非半 Batch 各监督一个方向 | 双向联合监督是否降低估计方差 |
| **09** | 五风格分解 embedding→十个 pair-ID embedding | 跨风格参数共享是否真正有益 |
| **10** | 将双漂移重参数化为 `current velocity + score` 双头 | 是否能更好分离运输与密度估计 |

05 的直接速度目标：

\[
v^*=(z_1-z_0)+
\frac{\sqrt{\varepsilon}(1-2t)}
{2\sqrt{t(1-t)}}\xi
\]

必须对这个目标重新计算 EDM 的输入、skip 和输出系数。

10 使用：

\[
v^*=\frac{b^*_+-b^*_-}{2}
\]

\[
s^*=\frac{b^*_++b^*_-}{\varepsilon}
\]

模型预测 `v` 和 `s`，再构造：

\[
b_+=v+\frac{\varepsilon}{2}s
\]

\[
b_-=-v+\frac{\varepsilon}{2}s
\]

这是一种有明确数学意义的参数化：**直接区分概率流运输速度与扩散边缘密度的 score。**

对两个输出头分别使用合适的标准化和损失权重，避免 score 的数值尺度主导训练。

主要比较：

- 收敛所需样本曝光量；
- 真实目标分布匹配；
- 正反向不对称；
- 网络计算开销。

### C：布朗桥与 EDM 的本质机制（5 组）

不再进行密集 ε 扫描，只保留结构性对照。

| ID | 改动 | 要回答的问题 |
|---|---|---|
| **11** | 单速度确定性 CFM，ε=0 | 布朗随机性本身是否必要 |
| **12** | 双漂移，ε=.16 | 更宽随机路径是否改善学习和分布覆盖 |
| **13** | 将逐通道 EDM 升级为 32×32 通道协方差 EDM | 只使用对角统计是否损失重要的风格相关性 |
| **14** | 预测端点条件期望，再解析转换成漂移 | 直接预测奇异速度是否是不必要的困难 |
| **15** | 分层时间采样，并使用重要性权重保持原目标 | 是否存在训练时刻覆盖不足 |

13 要使用联合协方差、交叉协方差推导矩阵预条件器，而不是简单增加一个可学习线性层。矩阵分解在 FP32 中计算，确保协方差正定；加入小对角正则。

14 的思想是让网络预测：

\[
\hat z_1=E[z_1\mid z_t,t]
\]

再转换：

\[
b_+=\frac{\hat z_1-z_t}{1-t}
\]

反向同理。

理论最优条件期望不变，但网络学习的目标不再直接具有端点奇异尺度。这项实验检验的是**监督参数化是否降低优化难度**。

15 的采样分布必须记录，并通过重要性权重保持数学目标不变，否则无法区分改变损失定义与改善采样效率。

### D：直接目标风格分布监督（8 组）

这是第二条突破主线。

先用五种真实绘画，训练一个内部小型风格表征网络：

\[
\Phi_\psi(z)
\]

训练采用同风格不同画作的 supervised contrastive learning，同时保留局部 patch 特征。

五类均衡 Batch 1024，冻结后供生成器训练。

**这里的对比学习只负责建立风格表征，真正推动生成器的是目标分布损失。**

令：

\[
\hat z=T_\theta(z_i,i,j)
\]

采用：

\[
\mathcal L_{\rm dist}
=
\operatorname{SWD}^2
\left(\Phi(\hat z),\Phi(z_j)\right)
\]

并按目标风格分别计算，不混合不同目标域。

| ID | 网络 | 新增监督 |
|---|---|---|
| **16** | 双漂移 | 学习表征的 Global-SWD |
| **17** | 单速度 | 学习表征的 Global-SWD |
| **18** | 双漂移 | 固定 latent 统计的 Global-SWD |
| **19** | 单速度 | 固定 latent 统计的 Global-SWD |
| **20** | 双漂移 | 学习表征的 Local-Patch SWD |
| **21** | 单速度 | 学习表征的 Local-Patch SWD |
| **22** | 双漂移 | Global + Local SWD |
| **23** | 单速度 | Global + Local SWD |

这样可以比较三个相互独立的因素：

- 双漂移还是单速度；
- 学习表征还是固定统计；
- 全局风格还是局部笔触。

全部使用：

\[
\mathcal L=\mathcal L_{\rm bridge}
+\lambda\mathcal L_{\rm dist}
\]

第一次对照前测量两种损失对生成器的梯度范数，然后固定 \(\lambda\)，不逐组寻找有利权重。

**重要实现：** SWD 必须作用于从真实源图出发、沿模型自由 ODE 得到的终点，不能作用于教师强制的布朗桥中间样本。

为节约显存，实现固定大批量排序、分块重新计算前向的两遍 SWD 梯度算法。对小 Batch 验证其梯度与完整反传一致后才能使用。

训练中使用短 ODE 展开，最终统一用 Heun4 评测，避免只对训练求解器过拟合。

### E：真正的在线 α-DSBM（8 组）

**这是本次最接近原论文、同时最值得突破的部分。**

原论文不是只用固定的独立端点做布朗桥训练，而是在预训练后使用当前模型采样新端点，在线更新桥耦合。

对每个风格对 \((i,j)\)：

\[
x_0\sim p_i,\qquad x_1\sim p_j
\]

先用当前模型生成：

\[
\hat x_1\sim P_\theta^{\rightarrow}(\cdot\mid x_0)
\]

\[
\hat x_0\sim P_\theta^{\leftarrow}(\cdot\mid x_1)
\]

这里必须是带扩散噪声的 **SDE**，而不是确定性 ODE。

再建立两个桥：

\[
(\hat x_0,x_1),\qquad(x_0,\hat x_1)
\]

分别进行正向和反向桥匹配：

\[
\boxed{
\mathcal L_{\rm online}
=
\frac12
\left[
\mathcal L_+(\hat x_0,x_1)
+
\mathcal L_-(x_0,\hat x_1)
\right]
}
\]

所有生成端点使用 `stop_gradient`，不反向传播穿过教师 SDE。

这对应原论文 Algorithm 1 的核心在线更新方式。

| ID | 在线更新方式 | 核心问题 |
|---|---|---|
| **24** | 正反向 SDE，EMA 教师，4 步 | 原论文在线方法的基础复现 |
| **25** | 24 改成 8 步 SDE | 在线生成端点的积分精度是否重要 |
| **26** | 24 改用 Raw 教师 | EMA 是否过度平滑风格动力学 |
| **27** | 仅使用单方向生成端点的非对称更新 | 双向更新是否确实能防止误差积累 |
| **28** | 50% 原始独立端点 + 50% 在线端点 | 在线训练是否需要原始分布锚定 |
| **29** | 用确定性 ODE 生成端点替代 SDE | 普通 Reflow 与真正 α-DSBM 有何差异 |
| **30** | 用旧端点 Replay Buffer 替代完全在线生成 | 新鲜耦合是否比缓存更有价值 |
| **31** | 在线更新时动态估计 EDM 交叉协方差 | 固定独立端点统计是否限制后训练 |

24 是原论文路线；28–31 是明确标注的扩展或消融，不冒称原算法。

**关键数学约束：**

原始桥的端点协方差在无 OT 时为零，但在线 SDE 生成的端点不再独立。因此 31 需要重新估计真实耦合的 cross-covariance。

动态 EDM 的统计更新不得让梯度反传进采样器。

另外，原论文中的 \(\alpha\) 是路径测度迭代的步长概念；使用 Adam 时不能简单把某个损失权重命名为 `alpha`，再宣称实现了不同 \(\alpha\)-DSBM。

所有 E 组都从**同一个五风格预训练 checkpoint** 初始化，完成相同的追加更新数，并和继续普通 Bridge 训练的对照比较。

对于在线 SDE，必须同时测试：

- 生成端点是否仍接近正确的目标域；
- 两方向的生成分布误差；
- 在线训练是否减少而非放大分布偏差；
- SDE 数值收敛是否足够；
- 是否出现生成端点逐轮漂移。

### F：共享高斯中间域（4 组）

这一组不再要求直接连接不同风格的真实端点。

训练五风格共享生成流：

\[
F_s:\mathcal N(0,I)\rightarrow p_s
\]

任意转换：

\[
T_{i\to j}=F_j\circ F_i^{-1}
\]

一个模型、五个条件生成过程、20 个转换方向。

| ID | 训练方式 | 判别目标 |
|---|---|---|
| **32** | 五风格共享 Gaussian→Art，确定性 CFM | 普通高斯流的基准能力 |
| **33** | Gaussian→Art，博客式双向布朗桥 + EDM | 博客方法能否增强单域生成 |
| **34** | 33 + 目标风格分布监督 | 直接分布监督是否继续有效 |
| **35** | 33 + 在线 α-DSBM | 真正 SB 优化能否改善共享生成流 |

这四组均为五风格条件模型，不能训练五个独立网络。

首先评估每种风格的单域生成，再评估 20 个组合转换。

如果高斯→真实风格本身失败，不能继续把跨域失败归因于共享坐标。

如果单域生成很好，但跨域组合效果差，主要问题是不同风格流在高斯空间的坐标对齐。

**特别注意：** Gaussian Pivot 的循环一致性在数值精确、映射可逆的理想条件下自动成立，但不代表语义内容得到保留。

### G：五风格共享结构与路径一致性（3 组）

| ID | 改动 | 理论动机 |
|---|---|---|
| **36** | 加入三风格路径组合一致性 | 不同转换路径是否应该共享一致坐标 |
| **37** | 共享风格 embedding + 小型 pair-specific 低秩适配器 | 全共享是否限制了风格对的特殊变化 |
| **38** | DiT 加局部深度卷积残差 | 64 tokens 的全局注意力是否缺少局部笔触建模能力 |

36 使用：

\[
T_{j\to k}(T_{i\to j}(z))
\approx T_{i\to k}(z)
\]

这不是一般两域 Schrödinger Bridge 必然满足的性质，而是针对**五风格共享转换系统**提出的新结构约束。

要单独标注其归纳偏置，不能把它解释为原论文的定理。

37 采用低秩适配器而不是为每个风格对复制完整网络，保持共享主干。

38 不直接把 patch2 改为 patch1，以免 token 数从 64 增至 256，令计算量成为混杂因素。先测试较廉价的局部卷积增强。

### H：OT 最小验证（2 组）

| ID | 改动 | 判断 |
|---|---|---|
| **39** | 五风格 Bridge + RGB Mini-batch OT | 博客 OT 是否有独立收益 |
| **40** | 五风格 Bridge + DINO 语义 OT | 语义配对是否优于 RGB 配对 |

两组均与无 OT 五风格基线使用相同的非配对随机数流、曝光量和网络结构。

OT 默认比例 0.5，使用已验证的提前收敛 Sinkhorn。

不同代价函数的尺度需要归一化，不能直接使用同一个绝对正则系数。

**若 OT 仅降低配对成本，而未改善目标分布与风格指标，直接删除整个 OT 分支。**

## 四、40 组的实验正交性

上面的 40 组不是 40 个随意组合。

它们分为：

| 实验轴 | 组数 | 主要干预对象 |
|---|---:|---|
| A：Batch/采样 | 4 | 优化统计与计算效率 |
| B：参数化 | 6 | 网络预测什么 |

## 五、统一训练与数值要求

### 5.1 模型配置

默认：

```text
DiT:
    width: 256
    depth: 6
    heads: 4
    patch: 2

data:
    styles: 5
    unordered_pairs: 10
    latent_shape: [32, 16, 16]
    normalization: shared_global

training:
    batch: 1024
    lr: 2e-4
    warmup: 100
    eps: 0.04
    ot_ratio: 0
    ema_decay: 0.999

inference:
    solver: heun
    steps: 4
    t_floor: 0.002
```

以上为起始实验配置；实际 Batch 和可微 ODE microbatch 由 P0 显存/吞吐测试确定。

训练目标改变时，允许使用相同的起始学习率，但必须检查梯度 RMS、梯度非有限值和优化器稳定性。

### 5.2 梯度与 ODE

普通 Bridge 使用完整 Batch 更新。

分布监督需要穿过推理终点的梯度，采用：

- 完整目标分布 Batch 512–1024；
- 可微 ODE microbatch 32–128；
- 固定排序的双遍 SWD 梯度计算；
- 不更新参数直到完整大 Batch 梯度累积完毕。

如果使用梯度重计算，必须保证两遍使用完全相同的输入、时间、随机数和模型状态。

在线 α-DSBM 的教师 SDE 在 `no_grad` 中运行。它产生新的端点，但不是生成器损失的可微计算图。

### 5.3 SDE/ODE 必须严格区分

概率流 ODE：

\[
dz=v(z,t)\,dt
\]

正向 SDE：

\[
dz=b_+(z,t)\,dt+\sqrt{\varepsilon}\,dW_t
\]

反向 SDE 需要使用反向时间坐标和正确的反向漂移及噪声增量。

**禁止以 ODE 加一点终点噪声冒充 SDE，也禁止把确定性 Reflow 记录为 α-DSBM。**

所有随机桥采样和反向时间实现必须通过 Gaussian 及 Gaussian Mixture 的边缘分布测试。

## 六、12 小时执行预算

### 6.1 不应假定每组都完成长训练

当前已知五风格评测成本会显著高于原来的 60 图评测。因此：

**40 组表示 40 个独立训练实验臂；第一轮全部快筛，只有高价值组进入完整训练。**

建议快筛预算：

- 常规实验：先跑到约 400–800 updates；
- 在线 SDE 实验：先跑 200–400 次额外更新；
- 优胜模型：继续训练至足够覆盖十个风格对的完整曝光量；
- 每组固定保存中间 checkpoint，不能只看终点。

完整对照以样本曝光量为准。

对五风格十对，每对达到原 V9 双域约 256k 的曝光量，在 Batch 1024 下约需：

\[
10\times\frac{256000}{1024}=2500\text{ updates}
\]

因此 **2500 updates 是完整训练的初始参考预算**，而不是所有 40 组都必须跑完的步数。

### 6.2 评测分两级

**Quick200：**

从原冻结 Test600 中固定取每个有向风格对 10 张，共 200 张。

用于 40 组快速筛选，输出连续 Margin、ΔT、ΔS 及五目标域 SWD/MMD。

这不是新建训练集或声称独立测试集，只是现有协议的固定计算子集。

**Full600：**

对所有进入最终复验的模型运行完整 600 跨风格评测，并输出 20 个方向的独立结果。

正式结论只能基于 Full600；反复用其选模型后，也不能宣称它是完全未参与选择的独立测试集。

### 6.3 具体时间分配

| 工作 | 预算 |
|---|---:|
| 五风格改造、数学单测、评测缓存与新机制基础实现 | 140 min |
| 常规 32 组快筛，每组上限 5 min | 160 min |
| 在线 SDE 8 组快筛，每组上限 12 min | 96 min |
| 40 组 Quick200，含评分及写入 | 80 min |
| 最多 8 个候选延长训练 | 80 min |
| Full600、视觉核查与报告 | 50 min |
| **预计预算占用** | **606 min** |
| **预留调试与性能波动** | **114 min** |
| **总计** | **720 min** |

这是一套**硬预算上限**，不是未经实测的完成时间保证。

此前 Mid B256 的 83ms/update 不能直接用于推算 B1024，也不能用于估计在线 SDE 或可微 ODE 的成本。

因此必须在五风格迁移完成后，用真实完整 update 测速。若单组运行超出预算，先缩短快筛更新数，不能降低五风格覆盖范围，也不能跳过数学测试。

若 12 小时实际无法完成全部长训练，优先保证 40 组可解释的快筛和最重要机制的完整复验，而不是生成 40 份缺乏训练充分性的终点结果。

## 八、最终判断规则

### 第一优先级：算法是否真正改善目标分布？

不能继续只看 CSD Top-1。

主指标为：

- 20 个方向的 Target Margin；
- 5 个目标风格的 SWD/MMD；
- Target ΔT 和 Source ΔS；
- 真实目标域的生成多样性；
- 视觉上的风格可信度和严重异常率。

如果源风格被擦除，但没有建立足够的目标风格，不能算成功。

### 第二优先级：机制本身是否必要？

| 结果 | 决策 |
|---|---|
| 05 优于 04 | 采用直接速度流，删除不必要的双漂移 |
| 10 优于 04/05 | 保留 current+score 分解 |
| 16/17 明显优于 Bridge | 将直接分布监督作为主训练目标 |
| 18/19 与 16/17 相当 | 删除额外对比编码器 |
| 24–31 显著改善目标分布 | 在线 α-DSBM 成为主线 |
| 29 与 24 相当 | 进一步验证是否需要随机 SDE refinement |
| 33/35 优于直接风格桥 | 改用五风格共享 Gaussian Pivot |
| 39/40 无明显收益 | 正式删除 OT |
| 36 有效 | 多域组合一致性可能是五风格任务的关键新约束 |

### 第三优先级：必须能复现

最终保留至多三个独立机制的优胜方案。

分别完成：

- 第二随机种子；
- 完整 Test600；
- 每风格/每方向报告；
- 原始桥模型同计算预算对照；
- 同一批输入图片的视觉对照。

失败实验保留原始结果，不因表现不佳而删除。对所有主要负结果必须给出实际干预已生效的证据。

## 九、研究路线的最终优先级

**第一梯队：**

直接速度 D3、Current+Score、五风格直接分布监督、真正的在线 α-DSBM。

它们分别改变模型的**预测对象、数学参数化、监督目标、端点耦合更新机制**。

**第二梯队：**

Gaussian Pivot、五风格路径组合一致性、完整协方差 EDM、局部纹理增强。

它们解决五风格任务特有的共享结构或表征能力问题。

**最低优先级：**

OT、普通 ε 扫描、学习率微调、继续扩大 DiT。

本轮不应该把主要计算资源分配给这些已经表现出收益有限的方向。

**最终目标不是在旧 V9 上再增加几个百分点，而是确定一种能够稳定学习五种艺术分布、支持全部 20 个转换方向、并且可以持续训练而不发生风格退化的统一生成方法。**

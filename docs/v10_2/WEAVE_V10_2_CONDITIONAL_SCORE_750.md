# WEAVE V10.2：Conditional Style Score 特异性验证

**预注册计划 · 2026-11-14 · RTX 4070 Laptop · 750 口径**

> 前置：v10（KDE score 路线，恢复方向 +.302）→ v10.1（检索目标判负，
> `docs/v10_1/V10_1_RESULTS.md`）。用户决定：**v10.1 正式收尾，v11 继续延期，
> 本阶段回答一个核心问题——条件密度 Score 的正向收益究竟有多少来自真实画派特征，
> 多少只是通用纹理恢复。** 核心公式：
> `Reference Retrieval ≠ Style Distribution Gradient`（v10.1 结论）。

**口径**：任务级一律 750 全量（读数 cross600；merged-750 LD 基线）。Dev200 预览步
省略——E 臂实测 750 全量 ~2 min/臂 + ~2.5 min 评测，直接全量更快且无口径歧义。
Score 级实验沿用 v10 实验 A 协议（holdout 40 幅/画派 × 7 退化算子）以便与 +.302 直接对比。

## 实验 A：风格 Score 的目标特异性（6 控制变体，恢复代理）

| # | 变体 | 回答的问题 | 预期 |
|---|---|---|---|
| A1 | 目标画派 KDE（复现） | 基线 | ≈+.30 |
| A2 | **错误画派 KDE**（固定错派 t' = (t+1)%5） | 画派特异性 | 显著 < A1 |
| A3 | **五画派混合 KDE**（bank = 全画派 concat） | 收益是否仅通用去噪 | 若 ≈A1 → 判"通用纹理恢复" |
| A4 | **q 打乱**（同图内 patch 的 q 随机互换） | 内容条件是否有效 | < A1 |
| A5 | **去除 v 相似权重**（σ→∞，仅 q 核） | 当前状态选择的重要性 | < A1 |
| A6 | **多尺度联合**（8×8 + 16×16 KDE 各 0.5） | 尺度互补 | ≥ A1 则采纳 |

混合 bank：细尺度 577,792 patches concat（~156MB fp16）；错派/q打乱不新增 bank。
q 打乱实现：同一样本内 patch 的 k 行随机置换（保持逐图 q 边际分布）。
**A 组判据**：A1 − A3 的差 = 画派特异分量；A1 − A2 = 画派身份分量；A1 − A4 = 内容
条件分量；A1 − A5 = 状态选择分量。若 A3 ≥ 0.9×A1 → **score 的收益主要不是画派的**，
实验 B/C 降级为诊断，v11 重启门槛相应上调。

## 实验 B：风格差异 Score（SMS 思想 + 绝对密度约束）

```
g_style = ∇_v log p_t(v|q) − β·∇_v log p_mix(v|q)      （β 预注册 {0.5, 1.0}）
```

变体（恢复代理 + 750 任务两处评测）：

| 变体 | 公式 |
|---|---|
| B-T | 纯目标密度（=A1） |
| B-TM β=0.5 / β=1.0 | 目标 − 混合 |
| B-TS | 目标 − 源画派（**仅 750 任务有源画派**；恢复代理跳过） |
| B-T+D | 目标 + 0.3×差异项（弱差异增强） |

**约束（防 R1 式判别捷径）**：任何使用差异项的候选更新，必须**同时提高目标画派
绝对密度**（log p_t(cand) > log p_t(cur)）；只提高密度比的一律拒绝。

**B 组判据（恢复代理）**：最优差异变体 ≥ A1 且其"画派特异分量"（= 该变体 − 对应
混合控制）> A1 的画派特异分量。若差异项只是削弱收益而不增加特异性 → 弃用差异项。

## 实验 C：接入 LD4 机制，750 全量任务

冻结 N2C；**完全保留 LD4 机制**（SPDHead 预条件 r1 + v9 proxy 验收 + mask + 回溯），
仅把 'local' 方向替换为新 Score 方向（v10.1 教训：不做"额外候选"稀释短表）：

| 臂 | 短表 | 说明 |
|---|---|---|
| C-T | {r1, score(T), mix} | 纯目标密度方向替换 local |
| C-TM | {r1, score(T−Mix β=1), mix} | 差异方向替换 local；验收加绝对密度约束 |
| C-TS | {r1, score(T−Source), mix} | 同上，源画派版 |

对照：LD4（原样）、E4（v10 独立优化）。**C 组判据**：最优 C 臂 cross600 上
Top-1 ≥ LD4 且（dino_s 或 affinity）> LD4 → "**方向正确但表达受限**"，v11 重启评估
通过第一关；若所有 C 臂 ≤ LD4 且 ≤ E4 → 方向改进在任务级无效，v11 重启门槛上调。

## v11 重启门槛（沿用用户定义，口径换算说明）

用户表（DINO-S 超 LD4 的 .4461、目标 ≥.452）为 **test580 口径**；merged-750 口径下
LD4 = .4401，等比目标 ≥ .452 保持不变（更严格）。完整门槛：
恢复方向明显 > KDE +.30；特异性（A2/A3 显著差于 A1）；DINO-S ≥ .452 且 DINO-C ≥ .770
（S10、750 口径）；≥3/5 画派改善；Same150 无过度编辑。**只有 A/B 全过才有资格进入
C 的最终确认，只有 C 过才重启 v11。**

## 两类失败的区分（本阶段的额外产出）

- **目标方向错误**（A/B 判负）→ 改进 Style Score 表示，不训生成器；
- **方向正确但输出变化有限**（A/B 过而 C 弱）→ latent 优化表达不足，才考虑 v11 生成分支。

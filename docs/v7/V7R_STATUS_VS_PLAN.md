## 1. 一句话结论

**V7-R 全部跑完，但没有产出一个越过预注册成功门槛（P4.3）的新模型**：
48 个 arm 中 **25 个 NO、23 个 PARTIAL、0 个 PASS**。
不过它给出了三个清晰、可复用的机制结论：

| 问题 | 判定 | 证据 |
|---|---|---|
| **A** 真实局部风格目标是否比 R1 分类边界更自然？ | **YES** | 局部 patch 能量 **E3** 在 P1-C 最优；R3c/R4c 相对 B4 的 ΔDINO-S 显著为正 |
| **B** 显式 source→target 条件能否改善训练？ | **NO** | N2−N1 的 ΔDINO-S = **−0.0008**，95% CI `[−0.0022,+0.0008]` 含 0 |
| **C** 保留 B4 内容映射、只学有限修正是否更稳？ | **YES** | 冻结 predictor + 小修正（R3c/R4c）保持在 B4 内容档；相对重学 M1 坍缩为恒等 |

**研究价值在结构而非分数**：`corrector-on-B4`（冻结主干 + 小修正）是稳定结构，
`E3 局部真实 patch 能量`是唯一稳定有效的风格目标；显式 source 条件与相对重学均无效。

## 3. 核心数据

**读法**：
- **R3c/R4c 是本次真正的右上推进**——相对 B4 **DINO-C 与 DINO-S 同时上升**，且 LPIPS 下降。
- 但它们**仍低于强 R1 编辑 T0/T1 的 DINO-S**（0.4353/0.4361），只是内容保持好得多（0.83 vs 0.74–0.76）。这是两条不同的 Pareto 档位，不是「全面超越」。
- N1/N2 的 DINO-C 只有 0.50、LPIPS 0.71 —— 训练后**丢掉了 B4 的内容映射**，这是 P2 判负的直接原因。
- E2_C 完全坍缩（DINO-C 0.17、LPIPS 0.956）。

### 3.4 模型级 Pareto 前沿（同 600 任务，DINO-C / DINO-S）

前沿 15 个点：`E2_B@1000/2000`（高内容 0.87/0.396）、`E2_C_lr`、`E5@1000`、

以及 4 个 `p1a_*_rand` / `p1a_S1_fwd` 诊断探针。

> 虽进入数值前沿，但不参与结论；`*_rand` 甚至只是随机方向。可视化时已单独画空心环排除。

### 3.5 P0 失效归因（上游病灶）

- `c1_probe`：painter-disjoint 下 `c1_gentle` 上的源风格探针准确率 **0.7043**、R1 同输入 **0.7655** → **「内容不变换」假设不成立**，这是 N1/N2 学不到东西的上游原因。
- `b4_shortcut`：150 源 × 5 目标 pairwise_rms 约 0.55–0.57 → **B4 存在明显捷径**。
- M1 轨迹：第 100 步 `pair_cos` 掉到 0.006 且 target_margin 转负 → 差分方向**不再指向目标**（不是被压成零）。
- M2 轨迹：`pair_cos` 升到 0.237 但 residual_rms 涨到 0.64 → 方向变对、幅度失控。

### 3.6 P4.3 门槛与总体判定

门槛（`final_matrix.json:gates`）：`ΔDINO-S ≥ +0.020 & CI>0`、`DINO-C ≥ 0.8125`、
`LPIPS ≤ 0.4712`、`ΔTop-1 ≥ −0.02`、Same150 不退化。

**48 个 arm：25 NO / 23 PARTIAL / 0 PASS。**
最好的 R4c 相对 B4 只有 +0.0048 DINO-S，远未达到 +0.020 的门槛 →
**没有任何新模型可以宣称「成功」**，但机制结论（A/C YES、B NO）是成立的。

## 4. 与本轮可视化（帕累托图）的关系

`deliver/v7_vs_external_pareto.png`（及 svg/pdf）把 V7/V7-R 的 36 个**真实候选**
与 10 个外部 baseline 放在同一张 DINO-C × DINO-S 图上：

- **前沿只由外部方法构成**；WEAVE published、Q2a+R1 Oracle、B3/B4、新 S10、全部 V7/V7-R 都是 ours，不参与前沿线。
- 所有 V7/V7-R 点继承 **q2a TRT 口径 45.78 ms/img（21.85 img/s）**（`INFERENCE_SPEED_REPORT.md` 的拼接估计）。
- 结论：**36 个真候选里 26 个不被任何外部方法 2-D 支配**；E3/E4 相对 B4 明确往右上。
- 纵轴用 DINO-S 而非 Style Affinity，因为 V7 eval **不含 CLIP-S**，无法补算亲和度；
  DINO-S 是两套评测共享且数值对齐的指标（V7 B4 0.42137 ↔ 外部榜 B4 0.4217）。

这与第 3 节并不矛盾：图里说的是「不被**外部** baseline 支配」，报告里说的是「没越过**预注册 P4.3** 门槛」——前者是横向定位，后者是纵向成功标准。

本次是靠人工修复 + `state/*.done` 跳过已完成的阶段才续上；**建议后续把 FATAL 改为

## 6. 口径限制（如实）

1. **全部是研发集内配对结果**（`tasks_750`，Val200 ⊂ Test750 / 重复用），无盲测主张。
2. **45.78 ms/img 是拼接估计**（论文 enc+WEAVE 18.7 + 实测 TRT S10 decoder 27.08），非端到端重测。
3. V7/V7-R 候选速度**继承共享 q2a 前端**，未对每个 arm 单独 profile。
4. V7 eval 无 CLIP-S → 无法计算 Style Affinity；跨口径比较统一改用 DINO-S。
5. `p1a_*` 诊断探针数值上进入 Pareto，但不是模型，已从结论中排除。
6. 问题 C 的 verdict 文案里出现的 `DINO-C 0.5022` 是 **N1 内容崩坏值**，不是「corrector-on-B4」的内容值；后者保持在 0.82 附近（B4 0.8199、R3c 0.8331、R4c 0.8318）。

# WEAVE V7 P1：纯去噪 MSE ScoreNet (S1) 对照报告

> 目标：验证原 V6 ScoreNet 中的错误类别 margin 损失是否扭曲了真实条件 Score 估计，
> 尤其关注 Ukiyo-e 等弱类的去噪误差、Score 方向可分辨性与噪声尺度敏感性。

## 三、Ukiyo-e 条件 Score 专项诊断

- 原 V6 Ukiyo-e 去噪 MSE：**0.35354**；S1：**0.33018**。

- 原 V6 Ukiyo-e wrong-correct gap：**-0.00442**；S1：**-0.00174**。

- Ukiyo-e 目标方向与其他目标方向平均余弦：原 V6 **0.3766**，S1 **0.3059**（越低越不易与其他画风混淆）。


## 四、结论

S1 使用完全标准的高斯去噪目标，具有明确的统计最优解。若其 Ukiyo-e / 弱类去噪误差与方向分离度明显改善，
则 RDMD 的真实 Score 监督器应优先采用 S1；若改善有限，则 Ukiyo-e 弱类瓶颈更可能来自数据分布或 CSD 原型偏置，
而非 margin 损失本身。

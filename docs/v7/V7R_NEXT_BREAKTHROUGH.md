- **CPT 还没有正式消融结果**：当前完成部分 P0 审计和候选 Patch Bank 构建，C1–C6、T2–T6、蒸馏学生和正式测速未完成。旧总控打印 FINISHED 不等于研究完成。

## 3. CPT P0：已经测得的新证据

目标特异性定义：`G(z,t)=S(z,t)−mean(S(z,k), k≠t)`；每个 S 为对对应风格参考集的最大 DINO 余弦。负值本身不代表错误，比较时应看配对变化。

| 实验 | DINO-S | G |
|---|---:|---:|
| B4 零更新 | 0.42137 | −0.02108 |
| E3 / R3c | 0.42520 | −0.02325 |
| R4c | 0.42619 | −0.02256 |
| 随机方向，5 seed 均值 | 约 0.43624 | 约 −0.01966 |

### 3.1 随机扰动提升不等于目标风格改善

随机方向相对 B4 的平均 ΔDINO-S 为 **+0.01487**，ΔG 仅 **+0.00142**。按定义可推出非目标四风格平均相似度也提高约 **+0.01345**。这说明大部分 DINO-S 增长伴随全风格共性增长。尚未完成该差值的配对显著性，不能断言目标特异性完全为零，也不能仅凭阈值判断“随机增益是目标特异的”。

R3c/R4c 的 G 相对 B4 分别下降约 0.00217/0.00148。因此先前“DINO-S 提升证明真实目标方向有效”的表述需要收回。

### 3.2 Gate 实现有误，不能直接照抄自动 verdict

- 历史单步探针将损失梯度以加号更新，而 R1 的 softplus(-margin) 是要最小化的目标，存在正反标签倒置。受影响方向臂必须修正后完整复评；不能把它扩展认定为 R3c/R4c 所有路径都有相同错误。
- 新增 R1 margin 检查也沿用了加号，因此该项不构成独立验证。
- 同一目标内 5 个随机 seed 的 hash 不同；跨 R1/S1/S2 的同 seed 随机方向输出相同符合目标无关随机对照的定义。要求 15 个 hash 全不同的 Gate 是误报。
- 用 DINO-S 是否上升替代“自身优化损失是否下降”不成立。
- 每批重设随机 seed 尚不满足按 task ID 隔离与排列不变性，需补审计。

### 3.3 重复臂仅确认指标相同，未确认复用根因

R3c_noC/R3c_disp 和 E0/E1 在已比较的 750 逐任务指标上完全一致。**这不是错误复用同一文件的充分证据**。尚需对照解析配置、实际代码分支、逐步约束和最终 latent。旧评测没有保存全部最终 latent，不能伪称已完成该项检查。

## 5. 速度与图的解释边界

历史图可作为探索性图保留，但不作为本轮正式性能结论：

1. 所有候选借用 Q2a 的 45.78 ms/img 是用户此前指定的可视化假设，不是各方法实测速度。
2. 该值来自论文前端与新 S10 decoder 拼接；不能对应到 SD-VAE 质量主表后宣称同配置速度。
3. 外部前沿与 Ours 内部前沿应分别计算；诊断、重复项剔除。不能把相邻前沿点的直线插值直接当作支配检验。
4. 历史“26/36”统计来自早期快照，含重复与不同 checkpoint，不能解释为 26 个独立新方法。
5. 后续正式图必须补 CLIP/Style Affinity 与每种方法真实 batch1/batch8 推理计时。

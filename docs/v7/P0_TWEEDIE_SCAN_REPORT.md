## 三、诊断结论

- **独立验证集上 Calib_Balanced_s16**：Top-1 = **28.5%**，$\Delta T$ = **+0.0762**，DINO-C = **0.6866**，Ukiyo-e Top-1 = **17.5%**。

- **当前最佳 Tweedie 配置**：`sigma0.50_K1_alpha14.790_x1.0`，NFE = **2**（相对 96 NFE 减少 **48.0×** ScoreNet 调用），Top-1 = **20.0%**，$\Delta T$ = **+0.0371**，DINO-C = **0.6349**，Ukiyo-e Top-1 = **5.0%**。

- 若 2~8 NFE 的 Tweedie 已接近 16 步积分，则继续优化 Score Difference 积分器的收益很低；
  若 Tweedie 明显落后，说明多步积分确实提供了超出单步后验均值差的非线性路径，但仍应转向训练 1-NFE 分布传输算子。

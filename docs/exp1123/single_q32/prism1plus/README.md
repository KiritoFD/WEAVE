# PRISM-1+ 单阶段训练

在 RTX 4090 从随机初始化训练 1,500 次更新。编辑器为 6,985,732 参数，每次更新 12 张，微批 3。训练只使用已有 Q32 的 4,400 张训练画作，五类平衡轮转。累计 15% 同画派 λ=0 恒等样本，其余采样跨画派与连续 λ。

16×16 内容瓶颈只收 Q32 和 y16_lcn。64/32 亮度跳连乘以 1−λ，噪声以 λ 注入 64 层。目标 one-hot 和 801 维未做分类压缩的 Oklab、Haar、RGB DINO 统计只进入解码器条件，32/64 两层使用空间 AdaGN。原始 RGB DINO 来自训练池冻结特征缓存。训练图库的场景目标由原始灰度 DINO 重新计算 kNN 核心和场景聚类，产生每画派 8 个场景中心和每中心 4 个参考槽。

训练损失为冻结 S10 的 RGB 分布监督、亮度结构监督和同派 RGB 恒等监督。风格项包含六层 VGG/ConvNeXt 正交切片距离、Oklab 及 Haar。内容项由亮度 LCN、亮度误差和灰度 VGG 自相似组成，回传至 latent 的内容梯度投影到亮度轴。全程未使用教师 latent MSE。模型只保存一份最终 EMA 编辑权重及必要的路由描述子。

完成后自动跑 λ=.2/.4/.6/.8/1.0 的 1-NFE test750，每个档位关闭 Same150 旁路。单独评 λ=0 供恒等机制核验。评测报告 Cross600 CSD Top-1、DINO-C、DINO-S、ER 与 Uki 命中。额外的推理期梯度修正留给独立实验，单步图只含实际一次模型前向。

```bash
python -m exp.v27_single.train_prism1plus --updates 1500
python -m exp.v27_single.train_prism1plus --eval-only
```

4090 日志和权重在 `runs/v27_mainline/prism1plus_v1/`。

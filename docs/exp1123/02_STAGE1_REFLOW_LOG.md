## 二、首轮诊断与精准修复（`v1` → `v2`）

### `v1`（`d1_reflow.pt`, $\alpha=0.30$ + 无 `y32_lcn` + 1D $\gamma$）诊断

首轮训练（`3,500` upd，`phuber=0.3457`, `hf=0.1565`）虽把 `Top-1` 稳在 `55.67%`、`DINO-S` 推高至 `0.5670`、`Imp→Min` 守在 `93.33%`、错标签压到 **`1.33%`**（`Δ_causal = +54.50pp`），但 **`DINO-C` 跌至 `0.4781`（`Uki=0.0%`）且 $\gamma=0.0$ 与 $\gamma=1.0$ 的内容差距未拉开**：

**根因定位**：
1. **起点信噪比过低（$\alpha=0.30 \Rightarrow 70\%$ 纯高斯噪声）**：4 步 Euler 首步从 70% 噪声出发，无锚点预构图导致 `Ear/Roc/Uki` 轮廓大幅漂移。
2. **缺少潜空间亮度结构损失**：仅有 `phuber + hf`，无 `y32_lcn` 保底中低频骨架。
3. **1D $\gamma$ 被 199D 淹没**：单标量输入 `cond_mlp` 导致 $\gamma=0$ 未能准确对齐 `hiC` 档。

### `v2`（`d1_reflow_v2.pt`）三项手术修复
1. **$\alpha = 0.55$**：$\tilde{z}_0 = 0.45\epsilon + 0.55 z_0^\perp$，保留清晰零参数亮度骨架同时保留 45% 噪声重构笔触。
2. **加入 `0.25 * st_loss`**：直接约束 $\hat{z}_1$ 与 $z^*$ 的 `32×32` 潜空间亮度 `LCN_5` 结构一致性。
3. **`16D` Sinusoidal $\gamma$ Embedding**（零初始化列扩维）：显著放大强度控制信号。

*(目前 `d1_reflow_v2` 正在 4090 训练中，`350` 步 `phuber` 已从 `0.378` 降至 `0.242`、`hf` 从 `0.185` 降至 `0.123`，`1050` 步进一步降至 `0.2125 / 0.1058`。)*

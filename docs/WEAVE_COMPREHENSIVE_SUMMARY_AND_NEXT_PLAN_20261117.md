## 0. 核心决断摘要（Executive Summary）

经过 V6→V17 共十余轮、近百个完整 Test750 实验臂的系统排查，WEAVE 当前的全部实验证据已收敛为一个非常清晰的全局图景：

1. **全仓真实帕累托前沿分裂为两条截然不同的技术谱系**：
   - **谱系 A（显式去风格内容条件算子：Q2A / B4 / V8-N2C / V9-LD4 / V10-E4）**：以显式 canonical content $c = C(z_{\text{src}})$ 为输入锚点，**已实现强跨画派迁移**——`Q2a + R1 Oracle + S10` 达 **CSD Top-1 36.3%（配对集 37.7%）**，`V9 LD4 + S10` 达 **Top-1 35.17% / DINO-C 0.7718 / LPIPS 0.4872 / Affinity 0.5615**，纯前馈单步蒸馏 `P1_B4_distill50 (218K) + S10` 达 **Top-1 22.20% / DINO-C 0.8152 / LPIPS 0.4396**（在 DINO-C×DINO-S 二维上严格支配 StyTr2 与 Seedream 4.5）。短板是局部笔触锐度与高感知保真区（LPIPS < 0.35）覆盖不足。
   - **谱系 B（自配对画派生成 Flow + SDEdit 部分加噪编辑：V15 / V16 / V17，底座 `W_dim96_conv_base` @ $\tau_0=0.7$）**：画面自然度与感知保真极高（**LPIPS 0.22–0.28，DINO-S 0.461–0.467**），**但跨画派分类率死锁在 10.5%–12.33% 的结构性天花板下**，其中 **Early Renaissance 与 Ukiyo-e 在全部变体中 Top-1 恒为 0.0%**。
2. **V15–V17 彻底查明了谱系 B 卡在 ~12% 的三大物理根因**：
   - **根因 ① SDEdit $\tau_0$ 结构性两难（源画派锁定 vs 空间布局坍塌）**：`V15` 训练仅见自配对样本（$s = s_{\text{real}}$），无独立内容通道 $c_{\text{src}}$。在 $\tau_0=0.7$（信噪比 $\text{SNR}=5.44$）时，$z_{0.7}$ 携带 70% 源画派统计量，网络后验直接忽略离散标签 $s$ 而重建源画风——**57.5%–59.7% 的 Cross600 输出被 CSD 判回源画派**；把 U-Net 容量扩 11 倍（`dim96→384`, 34.2M）反而使源锁定更强（DINO-C `.751→.808`，**Top-1 从 `10.67%` 跌至 `6.67%`**）。反之降到 $\tau_0=0.4$ 虽能松动源锁定，却因缺乏 $c_{\text{src}}$ 导致空间结构坍塌（DINO-C 跌至 `0.44`）。
   - **根因 ② 底座先验坍缩（57.8% Impressionism 类不平衡）**：V17 `P0_swap_t0`（$\tau_0=0$ 纯噪声生成）实锤证明，即便完全没有源图干扰，`W_dim96_conv_base` 在指定 `ER` 或 `Ukiyo-e` 标签时生成目标画派的比例也是 **0.0%**（分别有 **93.5%** 和 **97.3%** 塌缩为 Impressionism）！这意味着 Cross600 中 `240/600 = 40%` 的任务在底座速度场里根本没有目标吸引子。
   - **根因 ③ 局部残差信任域过窄**：同一套 LD4 算子在 `V9 (N2C 起点)` 上拿到 **35.17%** Top-1，而重锚定到 `V16 B_teacher (V15@0.7 起点)` 上仅得 **11.83%**——因为 `N2C` 前馈本身已抹除源画风并到达 `32.83%`，LD4 只需微调 `+2.34pp`；而 `V15@0.7` 锁在源画派内，$\text{RMS}(\Delta z)\approx 0.075$ 的局部信任球不足以跨越画派边界。
3. **V15–V17 中真正成立的正向积木（下一步必须保留）**：
   - **积木 A — DINOv2 Patch 上下文 + 充分步数蒸馏可 100% 摊销局部教师（V17 `P2_S2`）**：将学生训练从 1.5k 步扩至 12k 步并注入冻结 DINO 16×16 patch 上下文后，单步 Adapter 的 Cross600 Top-1 从 `10.67%`（V16 `B_adapter`）升至 **`12.33%`**（反超 `B_teacher` 的 `11.83%`，Margin 升至 `-0.2161`，且 `dT = +0.0080` 首次转正；`S0` 正确标签 `11.67%` > 错标签 `10.67%` 验证了真实标签特异性）。**证明了“学生学不会教师”只是上下文与步数问题，现已解决。**
   - **积木 B — 跨风格合成桥接监督（V15 `PT2_P2` Style-Bridge FM）**：零推理额外开销，将 `W96` 的 $\tau_0=0$ Top-1 从 `36.33%` 推至 **`45.67%`**（+9.3pp，双 seed 复现），$\tau_0=0.4$ 从 `15.33%` 推至 **`17.83%`**（+2.5pp），证明“带外派统计污染的起点 → 干净目标画作终点”的桥接流能直接打通条件注入盲区。
   - **积木 C — 纯 Conv U-Net 绘画先验 + S10 解码器**：在 $\tau_0=0$ 纯生成下 `S6_dim384` 达到 **49.33% CSD Top-1 / 0.591 DINO-S / Margin −0.0009**，证明轻量 Conv Flow 完全具备生成高质量多画派纹理的表达能力，缺的只是**与源风格解耦的空间结构条件输入**。

> **核心战略转向建议**：立即停止在 `V15 SDEdit (τ0=0.7)` 局部邻域内做修补式叠床架屋（尤其停止当前 3060 上无评测配对的 `R_*` 重复训练池消耗）；用 ~2 小时收尾 V17 已训完但未评分的现成权重后，**启动 V18：将谱系 A 的“显式去风格结构条件 + N2C/LD4 强跨派端点”与谱系 B 的“Conv Flow 强绘画生成先验 + DINO 上下文单步摊销”合流**。

## 2. 六条方法论铁律与 V15–V17 深度归因

在 V10–V13 四条铁律基础上，V15–V17 用严格受控实验补齐了生成端与蒸馏端的两条新定律，至此全链路因果闭合：

### 2.1 六条已验证铁律汇总

1. **Law 1 — Reference Retrieval $\neq$ Style Distribution Gradient（V10.1）**：内容条件近邻检索目标混入供体具体内容，与真实恢复方向反向对齐（$-0.25\sim -0.53$ vs KDE $+0.30$）。
2. **Law 2 — Recovery Alignment $\neq$ Style Specificity（V10.2）**：统计特征空间（DWT 矩/协方差）KDE 的恢复收益中 **95% 是通用“像画”先验，仅 5% 具画派特异性**。
3. **Law 3 — Separation Margin $\neq$ Generative Direction（V11–V12 / V15 PT_C）**：无强信任域保护直接优化判别器奖励必然走“破坏内容刷分”捷径（`PT_C_guided` DINO-C `.75→.26` 坍塌）；线性 logit 常数偏置对固定类别差分的梯度精确为零。
4. **Law 4 — Local DWT Token $\neq$ Semantic Style Carrier（V13–V14）**：小感受野小波统计无法承载语义画派判别（DWT 对比学习 NCM 仅 `0.425–0.544`，而 224px DINOv2 16×16 patch 达 **`0.793`**）。
5. **Law 5 — Self-Paired Generative Capacity $\neq$ Cross-Style Editing（V15 Group A + Scaling + V16 A_strict + V17 P0/P4，新增）**：
   - 容量从 `0.13M` 扩至 `34.19M`（260×）：严格留出 FM MSE 从 `1.0155` 單调降至 `0.9083`，$\tau_0=0$ 纯生成 CSD Top-1 从 `36.3%` 升至 **`49.3%`**；**但在 $\tau_0=0.7$ 跨派编辑点上，CSD Top-1 从 `10.67%` 单调退化至 `6.67%`**。
   - Attention、Where 自监督、免训练 CFG（`w=2,4,early,late`）、甚至五画派 1:1:1:1:1 均衡的冻结底座速度残差（`P4_F0/F1/F3`），在自配对 FM 目标下对 $\tau_0=0.7$ Top-1 的提升全部 $\le +0.67\text{pp}$。
6. **Law 6 — Residual Distillation Succeeds With Context, But Remains Bounded by Anchor Basin（V16 B + V17 P2，新增）**：
   - V16 学生拟合不足（relMSE `0.935`，幅度仅教师 `28%`，Top-1 `+0.0pp`）并非架构死局：V17 将训练预算提至 12k updates（`P2_S0` 幅度达教师 `74%`，Top-1 `+1.00pp`，且 `S0` 正确标签 `11.67% > S0_wrong 10.67%`），再加入冻结 DINOv2 patch 上下文（`P2_S2` 幅度达教师 `98%`，**Top-1 `12.33%` 反超教师 `11.83%`**），证明**轻量单步 Adapter + DINO 语义上下文完全能摊销局部教师**。
   - 但只要教师本身被绑在 `V15@0.7` 的 $\text{RMS}\approx 0.075$ 信任球内，学生最高也只能到 `12.3%`，无法凭空跨越未解锁的 `ER / Ukiyo-e` 边界。

### 2.2 V17 揭示的两个决定性诊断证据

#### 证据 A：为什么所有 V16/V17 臂在 `Early Renaissance` 和 `Ukiyo-e` 上都是 `0.0%`？
查看 V17 `P0_swap_t0`（$\tau_0=0.0$ 纯高斯噪声起步，将全量 750 任务强制设为单一目标标签 `label ∈ {0..4}`）的 CSD 预测分布：

|---|---:|---:|---:|---:|---:|---:|
| `label=0` (Early Renaissance) | **0.0%** | **93.5%** | 0.0% | 6.5% | 0.0% | **0.0%** |
| `label=1` (Impressionism) | 0.0% | **98.7%** | 0.0% | 1.3% | 0.0% | **98.7%** |
| `label=2` (Minimalism) | 0.0% | 41.2% | **54.7%** | 4.1% | 0.0% | **54.7%** |
| `label=3` (Rococo) | 0.0% | 72.5% | 0.7% | **28.0%** | 0.0% | **28.0%** |
| `label=4` (Ukiyo-e) | 0.0% | **97.3%** | 2.7% | 0.0% | **0.0%** | **0.0%** |

这张表一锤定音：**由于 `orig_mean_fp16` 训练池中 Impressionism 占 57.8%，4000 步训练的 `W_dim96_conv_base` 发生了严重的条件模式坍缩——`ER` 与 `Ukiyo-e` 两个类别先验已被 Impressionism 完全吞噬**。而在 $\tau_0=0.7$（`P0_swap_t07`）下，五个强制标签的 Cross600 Top-1 全部落在 `10.33%–10.50%`，且 **58.3%–59.2% 的输出恒定等于源画派**（`pred == src`）。

#### 证据 B：为什么 `V8 N2C` 纯前馈就能拿 `32.83%` Top-1，而 `V15@0.7` 只有 `10.67%`？
对比两者的信息瓶颈结构：
- `V15` 依赖 $z_{0.7} = 0.7 z_{\text{src}} + 0.3\varepsilon$ 同时传递“空间构图”与“起点状态”，没有任何去风格瓶颈过滤 $z_{\text{src}}$ 中的源画派色彩与笔触统计。
- `Q2A / B4 / N2C` 先通过 `canonicalizer`（低频/去统计归一化）剥离源画派先验，再将结构条件显式喂给网络。因此它不需要靠保留 70% 的原始 $z_{\text{src}}$ 来维持构图，从而在同一工作点上同时拿到 **`DINO-C = 0.7715` 与 `CSD Top-1 = 32.83%`**（叠加 2 步 LD4 后达 **`35.17%`**）。

### 3.2 代码审计发现的实现缺陷（不得误读为科学结论）
1. **`P0_tcurve` (`exp/v17/probe.py:35`)**：循环中写了 `lab = sid if s < 5 else sid`，导致 5 个标签分支均传入真实 `sid`，`mse_corr == mse_wrong` 恒成立。该臂仅 `R_style(t)`（`0.197 → 0.0325`）与监督对齐余弦有效；`wrong − correct FM MSE` 请以 `V16 A_strict`（`+0.000961`）为准。
2. **`P0_cfg_early` 在 $\tau_0=0.7$ 下退化为恒等基线**：调度定义为 `t <= 0.35` 时 `w=3` 否则 `w=1`，在 `[0.7, 1.0]` 积分区间内全程 `w=1`（因此读数精确等于 `V15_base`）。
3. **`P1_T2 / P1_T4` 步长归一化尺度错配 (`exp/v17/teacher.py:70`)**：`DirectionComputer` 标准使用 RMS 归一化（$\|d\|_2 = \sqrt{16384}=128$），而 `T2/T4` 手写成了 L2 范数归一化（缩小了 128 倍），导致 `delta_rms_cross = 0.00059`（近零操作）；`T1` 的 `CalibratedDirectionComputer` 未将 `bias` 接入 `target_margin` 分支。因此 `T1/T2/T4` 并未有效测出教师改进。
4. **`P2_S5 / S6 / S8` 死分支 `amplitude` 头污染推理 (`train_student.py` vs `run.py:200`)**：训练时 `student_loss` 直接对 `delta` 施加 `rel_norm` 约束，从未乘上 `self.amplitude(ctx)`，导致 `amplitude` 线性层全程零梯度、保持随机初始化；而推理时 `run.py:200` 执行了 `delta * scale.clamp(0, 2)`，用未训练的随机标量截断了输出（直接解释了为何 `P2_S8_eval` 退回 `10.50%` 基线水平）。**好消息是：`S3/S4` 无此头（完全干净），`S5/S6/S8` 的主干 `delta` 本身也是完整训好的，只需在评测时忽略未训练的 `amplitude` 头（`scale=None`）即可测得真实性能！**
5. **现成权重未评完的 3 个轻量配置笔误**：
   - `P2_S3/S4/S5/S6_eval` 因早期内联 `measure` 显存叠加 OOM 中断，尚未用修复后的分进程 `measure_only` 跑完（仅需纯评测 ~6 分钟/臂）；
   - `P3_H3/H4_*_eval` 因 `build_manifest.py` 写键 `'H3_dir'/'H4_dir'` 而 `arm_h2_eval` 读 `'head_dir'` 秒级报错（`h2_head.pt` 已训好在盘）；
   - `P4_F2_train` 因 CPU 张量索引用了 CUDA `idx` 报错；`P5` 组合臂因 `build_manifest.py` 路径双前缀 `'runs/v17/P2_runs/v17/...'` 报错；
   - 当前队列进入的 `R_S5_s1` 重复池在 `build_manifest.py` 中只生成了 `student` 训练任务而未配对 `student_eval` 任务，继续空跑 16 小时不会产出新的 Test750 指标。

### V18 方向一（最高性价比、最快刷新可交付前沿）：在 `N2C` 上用 DINO-Context 学生摊销 `LD4`（`V18-A: N2C + DINO Distilled Corrector`）

- **核心逻辑（直接兑现 V9 + V17 两项已验证正结果）**：
  - V17 `P2_S2` 已经证明：**0.3M 参数的 `ContextAdapter`（冻结 DINOv2 16×16 patch 上下文 + 12k updates）能够 100% 吸收局部 LD4 教师的 Top-1 增益并略微反超（`12.33%` vs `11.83%`）**。
  - V17 之所以绝对值只有 `12.33%`，唯一原因是它挂在了源锁定的 `V15@0.7`（`10.67%`）上；而在 **`V8 N2C`（`LD0`，纯前馈已达 `32.83%` Top-1、`0.7715` DINO-C）** 上，同一套 **`V9 LD4` 教师已经实测拿到 `35.17%` Top-1 / `0.4872` LPIPS / `0.5615` Affinity**（若适度放宽预算至 $\varepsilon \in \{0.10, 0.16\}$ 并修正 `T2` 的 RMS 归一化 Target−Source 方向，教师上限还可进一步测试）！
- **具体设计**：
  1. 在严格去重且排除 Test750 源/参考的 clean pool（≥2,000 源 × 5 目标，五派 1:1:1:1:1 均衡）上，运行 `N2C` + `LD4`（对照 `ε=0.10` 标准预算与 `ε=0.16` 强风格预算）生成 `n2c_ld4_pairs.pt`；
  2. 训练 `V17 P2_S2/S4` 同款 **DINO-Context Residual Adapter**（输入 `[z_N2C, c_canon]` + 源图 DINO patch tokens + `u_tgt - u_src` 同派严格归零参数化，12k updates）；
  3. 全量 Test750 + S10 + `correct/wrong` 控制 + 端到端延迟计时。
- **预期收益与判据**：
  - **零测试期 R1 反向传播、零多步搜索回溯**，单次纯前馈推理（`N2C + 0.3M Adapter + S10`，3060 端到端毫秒级），冲击 **CSD Top-1 ~34%–36%、DINO-C ~0.77、LPIPS ~0.48**——直接成为全仓最快且超越 Seedream 4.5 / StyTr2 的主力可交付部署模型！
  - 耗时预算：单卡 3060 仅需 **~3–4 小时**即可见分晓。

### V18 方向二（核心架构破局）：显式去风格结构条件 Flow（`V18-B: Style-Bottlenecked Structural-Content Flow, CCF`）

- **核心逻辑（正面解决谱系 B 的两大病根，融合 V15 强画质与 N2C 强控制）**：
  - 为什么 `V15` 在 $\tau_0=0.0$ 纯噪声下能生成极漂亮的画质与高指标（`S6` 达 `49.3% Top-1 / 0.591 DINO-S`；`PT2_P2` 达 `45.7% Top-1`），一到跨派编辑就哑火？因为没有显式结构通道 $c_{\text{struct}}$，被迫走 $\tau_0=0.7$ SDEdit 把源画风漏进去！
  - 为什么 `V15 PT2_P3`（直接加 Content Adapter）会坍缩成复制源图（`DINO-C 0.88, Top-1 1.8%`）？因为传入的内容特征仍保留源画派色彩/纹理信息，自配对训练时网络直接走恒等捷径！
- **具体设计（三道硬闸门缺一不可）**：
  1. **闸门 1 — 严格去风格化的空间结构表征 $c_{\text{struct}}(x)$（训练前必须过线性泄漏审计）**：
     - 由两部分拼接构成 $64\times 64$ 空间条件：① **Patch-wise Instance-Normalized DINOv2 tokens**（对 $16\times 16\times 384$ 每个通道在空间维做 $\mu=0,\sigma=1$ 归一化，彻底抹除全图色彩与全局笔触均值/方差统计，仅保留语义部件空间排布，经轻量 $1\times 1$ 瓶颈压至 16 维后上采样）；② **亮度多尺度边缘/结构图**（源图转灰度亮度 $Y$，提取归一化多尺度梯度幅值与低通平滑几何轮廓）。
     - **强制预检门（Pre-Training Leakage Gate）**：在进入 Flow 训练前，在冻结 $c_{\text{struct}}$ 上训练一个线性 + 2 层 MLP 五画派分类器；**必须验证 5-way 画派预测准确率 $\le 30\%$**（远低于原始 latent/DINO 的 ~80%），且提取 $c_{\text{struct}}$ 前对训练源图施加色彩抖动 + V6 DWT 随机跨派统计扰动，从源头切断自配对恒等捷径！
  2. **闸门 2 — 五画派严格 1:1:1:1:1 均衡采样 + 混合跨派桥接监督**：
     - 彻底废除 `DataLoader(shuffle=True)` 的 57.8% Impressionism 偏置，强制每 batch 五派均衡采样，修复 `ER = 0%` 与 `Ukiyo-e = 0%` 的底座先验坍缩。
     - 80% 步数使用去风格结构条件下的真实画作 FM（从 **$\tau_0 = 0.0$ 纯高斯噪声**积分至 $z_{\text{real}}$）；20% 步数混入 `N2C+LD4` 预生成的真实跨派配对端点 $(c_{\text{struct}}(z_{\text{src}}), s_{\text{tgt}} \to z_{\text{LD4}})$ 作跨派对齐锚定。
  3. **闸门 3 — 推理从 $\tau_0 = 0.0$（或极低 $\tau_0 = 0.15$）起步**：
     - 推理时不再把 70% 的源图原始 latent 塞进 $z_{\tau_0}$！完全依靠 $c_{\text{struct}}(x_{\text{src}})$ 锁定人物/景物几何构图，依靠纯噪声起步的 20 步 Conv Flow（`dim96` 或 `dim128`，3.2M–4.5M）自由生成指定目标画派（含 ER 蛋彩画质感、Ukiyo-e 木版平涂轮廓、Minimalism 纯净色块）！
- **预期收益与判据**：
  - 同时打破 `ER/Uki = 0%` 死锁与 SDEdit 保源锁，冲击 **Cross600 CSD Top-1 > 40%、五画派每派 Top-1 均 > 20%、DINO-S > 0.48、DINO-C > 0.72**，真正越过外部分析帕累托前沿（AesPA / StyTr2 / Seedream）！
  - 耗时预算：单卡 3060 约 **8–12 小时**（含泄漏预检 + 8k 步训练 + 全套 750/错标签/切换响应 $I$ 评测）。

---

### V18 方向三（消除类内多模态均值模糊）：原型/参考特征条件化（`V18-C: Continuous Style-Prototype / Sub-Mode Conditioning`）

- **问题诊断**：即便五派均衡，`Early Renaissance` 或 `Rococo` 内部仍包含肖像、宗教祭坛画、风景等多种色调与构图子模态。单一 `one-hot` 标签在 MSE 速度场损失下迫使模型预测类内条件期望，导致色调灰暗或退向 Impressionism 均值。
- **具体设计**：
  - 训练期：对每幅训练画作 $i$（画派 $s$），不喂单一类别 ID，而是从**训练集同一画派的其他画作**（或类内 $K=4$ 聚类子中心）抽取 L2 归一化的风格条件向量 $e_{\text{style}}$（带 15% CFG drop 与类内随机配对，防止自重建泄漏）。
  - 推理期（严格遵守零测试泄漏）：每个目标画派使用**训练集**计算的 $K=4$ 子模态原型中与源图内容最兼容的子中心（或在明确声明为 Reference-Guided 赛道时使用冻结参考库原型），无需触碰任何测试集信息。
- **定位**：作为 `V18-B` 的条件器升级消融臂（2–4 小时增量实验），专门解决难画派（ER / Rococo / Ukiyo-e）的类内多模态塌缩。

## 5. 评测与研发纪律升级（防过拟合与防伪增益守则）

总结过去十余轮踩过的所有度量与工程陷阱，后续所有实验强制执行以下五条硬纪律：

1. **禁止汇报无错标签对照的指标微增**：任何声称风格提升的模型，必须同轮输出固定起点/固定噪声下的 **`correct_label` vs `wrong_label` 配对差**及**同源四目标切换响应 $I$**；若 `correct ≈ wrong`（如 V16 `C_h2_strong`），一律定性为通用纹理扰动而非风格控制。
2. **强制汇报逐目标五画派分解表（ER / Imp / Min / Roc / Uki 各 120 Cross 任务）**：禁止用单一总均值掩盖“Impressionism 刷到 60%、ER 与 Ukiyo-e 仍是 0%”的偏科退化。
3. **生成与裁判严格分进程串行（单卡 12GB 铁律）**：生成阶段完整落盘 `raw/<arm>/batch_*.pt` 并退出释放显存后，再由独立进程运行 `measure_only.py`；严禁父进程持模型权重派生裁判子进程，严禁无配对 `_eval` 的盲目多 seed 训练空转。
4. **训练前必过单步数值与梯度单测**：任何自定义方向/门控模块（如归一化尺度、辅助头乘法链路、时间轴探针标签循环）必须有独立断言验证“非零梯度 + 预期幅度量级（RMS）”，杜绝静默零梯度死头或 128× 尺度缩水进入长队列。
5. **建立独立盲测集（Blind Holdout Set）**：鉴于 `Test750` 已被 V6–V17 反复用于路线筛选，在确定最终论文交付模型时，必须从 `datasets/wikiart_new_512` 的非训练留出池中新建一份一次性冻结盲测集（如 `Blind500`）做最终定稿核验。

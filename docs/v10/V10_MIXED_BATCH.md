# V10 混合 Batch 基线结果（04M）

> 对照：04L = 单风格对/update（旧工程约束）；04M = 十对 + 双向混合在一个 Batch 内。
> 两者均为 6000 updates、batch 512、patch 8、eps=0.04、noOT、SD-VAE。
> 04M 额外启用**等权全局标准化**。

---

## 一、审计结论先摆正（我此前的两个判断是错的）

`sbflow/audit_v10.py` 对 04L 的四项审计：

| 检查 | 结果 |
|---|---|
| 20 方向采样分布 | 每个方向 **5.00%**，每个目标 **20.00%**，max/min = **1.000** |
| 目标风格条件响应 | 固定 z、t=0.5，切换目标：速度两两余弦 **0.2408**（min -0.056，max 0.644），相对变化 1.25 |
| 规范序/反向/EDM | 正反重建恒等式成立、`reversed` 正确交换、恒等精确、循环误差 0.93 vs 随机 11.3 |
| 全局标准化 | 频数加权 vs 等权 均值 L1 差 **0.046**，Impressionism 占 57.8% 确实拉偏中心 |

**所以：采样不存在类别失衡，模型也确实在使用目标条件。**
我此前"57.8% 多数类导致失败"和"忽略目标条件"两个诊断都不成立，已撤回。

同时纠正曝光量对比：04L 每对 `600×1024 = 614,400` 次曝光，
V9-Mid 最好 checkpoint 是 `1000×256 = 256,000`，**04L 反而是 2.4 倍**。
"欠训练"也不成立。

## 二、混合 Batch 改动

- `preconditioning.py`：新增逐样本版本 `moment_coefficients_batch` /
  `precondition_input_batch` / `reconstruct_drift_batch` / `normalized_target_batch`，
  接受 (B,C) 端点统计；与标量路径逐项一致（最大误差 2.4e-7）。
- `train5.py`：`objective_bidir_mixed` 让**每个样本**携带自己的规范对、方向与 EDM 系数；
  `_mixed_pair_ids` 保证一个 Batch 内 20 个 (pair, direction) 单元**完全均分**
  （测试断言 20 个单元各 2 个样本）。
- `--mixed-batch` 设为默认，`--single-pair` 保留旧路径。
- 等权全局 mean/std 设为默认（`--frequency-stats` 保留旧行为）。

## 四、如何解读

混合 Batch 是**正确**的工程修正，也确实带来改善（Top-1 +2pp，Impressionism
从 0.300 提到 0.350，Minimalism 从 0.150 提到 0.225，正向方向 7→8）。

但它**没有解决核心问题**：Rococo 作为目标完全为 0，Early_Renaissance 和 Ukiyo_e
仍然 ΔT 为负，整体 ΔT 仍为 -0.031。

结合审计结果，可以排除的解释：

- ❌ 采样类别失衡（实测 1.000 均衡）
- ❌ 忽略目标风格条件（速度余弦 0.24，响应明确）
- ❌ 方向/EDM 统计错误（恒等式与循环一致性都通过）
- ❌ 曝光量不足（已是 V9 单对预算的 2.4 倍）

剩下的候选解释（尚未验证）：

1. **表征上限**：SD-VAE `4×64×64` 可能不足以表达 Rococo 的装饰性细节与
   Early_Renaissance 的写实结构。LPIPS 0.696 / DINO-C 0.680 说明内容被大量破坏，
   这与"编码器丢掉细节"一致。V9 双域时 Ukiyo→Imp 的发白现象同源。
2. **共享容量的条件分离度**：`c = time + W[e_a;e_b] + dir` 是**加性**条件，
   零初始化起步。8M 模型要在一个加性偏置里区分 10 对，可能不够。
   审计显示条件**有**响应（余弦 0.24），但响应强度是否足够支撑 10 个不同场，未测。
3. **目标分布的难度差异**：Impressionism（8,989 张、类内变化大）与 Minimalism
   容易逼近；Rococo/ER 的类内分布可能更"薄"，SWD 最小化更容易退化成平均化。

## 五、建议的下一步（按判别力排序）

1. **测表征上限**：把真实 Rococo / Early_Renaissance 图像过一遍 SD-VAE 编解码，
   再算 CSD Top-1 与 MMD（C1 实验）。若真实图像往返后都无法被识别为本风格，
   则问题在编码器，不在生成器。
2. **测条件分离度**：固定 z，在 10 个 pair 上测速度的成对余弦矩阵。
   若同类目标的不同源对余弦接近 1，说明加性条件无法区分源。
3. **测目标分布的"厚度"**：对每个目标风格，用真实 latent 之间两两 SWD 看类内离散度，
   与生成 latent 的 SWD 对比，判断是否只是被平均化。
4. 只有以上定位清楚后，再决定是换表征、加强条件（如 pair 专用 FiLM 或低秩适配），
   还是引入 D 组的直接分布监督。

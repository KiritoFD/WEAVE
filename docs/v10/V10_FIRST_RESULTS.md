## 三、结论：问题不是预算，是类别不均衡

三个证据同时指向同一件事：

1. **只有目标为 Impressionism 的方向成功**，而它占训练集 **57.8%**。
2. **ΔS 在所有方向都约 -0.39**：源风格被普遍擦除，但目标风格只在多数类上建立。
   这是典型的"擦除式迁移"，与 V9 双域时观察到的 Ukiyo→Imp 现象同源。
3. **加 7.5 倍步数只把 Top-1 从 7% 提到 11%**，ΔT 没转正。
   若纯粹是欠拟合，应该看到更明显的改善。

也就是说：**模型学到了一个把任何输入推向"平均/多数艺术风格"的场，
而不是 20 个有方向的运输场。**

`data.md` 早就警告过 8.3× 不均衡（Impressionism 8,989 vs Minimalism 1,084），
现在它在五风格共享模型上直接发作了。

## 四、下一步建议（按优先级）

1. **修正训练分布的类别不平衡**，三种做法可选：
   - a. 按目标风格逆频率加权采样（每个风格在 batch 中出现概率相同）；
   - b. 只用均衡池 `distinct5_512/train`（每类 1,000）训练；
   - c. 每对等量采样但让"目标风格"轮流成为被过采样的那一个。
   建议先做 (a)，改动最小且保留全部数据。
2. 用修正后的分布重跑 04L（6000 步，约 16 分钟），确认 ΔT 是否转正、
   是否还有 3 个风格完全失败。
3. 只有第 2 步成立后，38 组快筛才有意义；否则 38 组会一起测出同一个不均衡伪影。

## 一、结论（TL;DR）

1. **Score 级验证全部通过**：真实画作条件 KDE 的方向质量显著优于 R1/LD3（恢复方向
   余弦 .302 vs .122/.054，5/5 画派）；**不是颜色账**（texture .265 > color .227）；
   密度对退化单调（Spearman −0.98）；内容条件化防捕获（+10.8pp）。
2. **任务级（750）**：最优 V10 臂 E4 相对 LD0 **Top-1 +1.17pp、dino_s +0.0016、
   affinity +0.0011**——预注册判停 3 不触发；但**未超越 LD4**（Top-1 .3400 vs .3517，
   LPIPS .4907 vs .4872）→ §9 验收（全面超 LD4）未达成。
3. **互补性假设被否定**（post-hoc）：把 V10 方向加进 LD4 短表（E2_ld4plus，v9 机制
   与 proxy 原封不动）反而 **Top-1 −1.0pp**；margin+density 混合 proxy（E2_mix）也无收益。
4. **P4：保留闭式 KDE**。DSM（修复两处实现 bug 后）方向质量 .204 < KDE .302。
5. **关键负发现：hψ 残差有害**——残差空间方向一致性掉到 .109（vs raw f .302）。

## 三、Score 级实验（P2）

### 实验 A：方向一致性（40 幅/画派 × 7 退化算子，holdout 画作）

| 方法 | mean cos |
|---|---:|
| **V10-B**（内容条件 KDE，raw f） | **.3022** |
| V10-A_f（无条件 KDE，raw f） | .3016 |
| V6 全局矩匹配 | .2914 |
| V10-A（无条件，残差空间） | .1094 |
| V10-C（条件 + hψ 残差） | .1092 |
| LD3 原型能量 | .1221 |
| **R1 margin 梯度** | **.0537** |

- **门槛过**：V10-B > R1 且 > LD3，5/5 画派同向。
- 条件化在该代理上几乎不改变方向（B≈A_f）；残差空间严重有害。
- R1 与真实恢复方向几乎不相关（.054）——独立复核了 V9 的"margin↔真实错位"结论。
- v6 全局矩是意外强的基线（.291）——恢复代理偏爱简单参数化逆操作；**代理≠任务**，
  任务级读数以 §二 为准。

### 实验 B：颜色捷径审计

texture-only .2648 > color-only .2270；joint .3022 最优；更新能量分解
color 44–51% / texture 49–56%（按画派）→ **判定：非颜色账**（预注册判停 2 不触发）。

### 实验 C：泛化

- holdout 5-way 混淆：V10-B **57.7%**（20% 随机），R1 判别器 93.6%（判别式强于
  生成式密度是预期）；
- 密度对退化梯级 Spearman：B −0.98 / C −1.0（≥0.9 门槛过）；
- 条件化探针（内容相近跨画派 patch）：条件 54.3% vs 无条件 43.5%（**+10.8pp**）。

## 四、P4：DSM 对比（保留闭式 KDE）

- 修复两处实现 bug（s_idx=None；`L=D·f−f²/2` 中 D 未 detach 导致雅可比污染方向，
  修复前 −0.50 伪反向对齐）后：**DSM σ=0.1 → .2045，σ=0.5 → .1918 < KDE .3022**。
- σ=0.1 分支欠拟合（holdout 上 model mse 0.117 vs 恒等预测 0.010）。
- **预注册裁决：keep_kde**（零训练成本是特性；DSM 代码与曲线归档于 `exp/v10/dsm.py`）。

## 五、关键发现与下一步（v10.1 候选，需新预注册）

1. **hψ 残差有害的机理**：r_std 对 hψ 拟合好的维度放大噪声（残差只保留 11.6% 方差）。
   候选修复：不做 per-dim 残差标准化，或按残差能量截断/降权。
2. **组合方向需要新验收函数**：v9 proxy（margin−0.3·L_loc）对 v10 候选不公平
   （E2_ld4plus 稀释效应）；margin+density 线性混合 proxy（E2_mix）也未转化成任务收益
   ——proxy 与任务指标的相关性本身是下一阶段要量化的对象。
3. **方向质量→任务收益的转化率**：A_grad .302 只换来 Top-1 +1.17pp；而 R1 方向
   A_grad .054 却在 LD4 短表里贡献了 +2.3pp——方向余弦不是任务收益的充分预测子。
4. **互补事实**：E4 拿走了 LD4 缺的 DINO-S/affinity（且是全场最高），LD4 拿走
   Top-1/LPIPS；两者优化的是不同指标维度——如果目标是"全维度推进"而非单指标，
   交替/分段使用两种方向（非短表混合）值得测试。

# CLEAVE V35 — RTX 3060 12GB 最终性能评测与 `test750` 质量门控报告

> **结论摘要**：纯 PyTorch（零外部推理引擎）优化版本 **`Optimized`** 在 RTX 3060 12GB 上全面达成所有性能与无损质量门控指标：
> - **`E-only` (`l=0.60`, 严格不加载 `P-Core`)**：Host E2E `B=1` `144.91 → 111.80 ms` (**`1.30×`**, `8.94 img/s`, `1.16 GB` VRAM)；`B=2` 峰值 **`81.21 ms/img`** (**`1.86×`**, `12.31 img/s`, `1.71 GB`)；Hot Cached `B=4` 达 **`33.63 ms/img` (`29.74 img/s`)**。
> - **`E→P` (`s=1.00`, 29 Flow NFE)**：Host E2E `B=1` `372.73 → 221.36 ms` (**`1.68×`**, `4.52 img/s`, `1.42 GB` VRAM)；`B=2` **`182.92 ms/img` (`1.90×`, `5.47 img/s`)**；`B=4` 峰值 **`181.98 ms/img` (`1.77×`, `5.49 img/s`, 单批清洁测 `180.25 ms/img`)**；Hot Cached `B=4` 达 **`133.62 ms/img` (`7.48 img/s`)**。
> - **可选加速档 `Fast` (`Euler 5-step`, 20 NFE)**：`E→P B=4` 达 **`153.55 ms/img` (`2.10×`, `6.51 img/s`)**，且同样通过全量 `test750` 非劣性校验。
> - **完整 `test750` 配对非劣性门控 (`150` 源图聚类 Bootstrap 95% CI)**：`Optimized` 在 `E l050/l060` 与 `P s060/s085/s100/s150` 全部 6 个工作点 **100% PASS**（`|ΔDINO-C| <= 0.0004`、`ΔDINO-S >= -0.0001`、`ΔCSD Top-1` 在 `-0.50pp ~ +0.83pp`）。

## 3. 多进程冷启动与工程权衡说明

1. **`Optimized` (`torch.compile reduce-overhead`)**：常驻服务 / 批量任务首选，稳态 `1.68×–1.90×` 加速；多进程冷启动首次图编译/CUDAGraph 捕获耗时较长（`E-only` ~50.2s、`E→P` ~63.0s，模型加载仅 `2.07–2.57s`）。
2. **`Optimized-Eager` (`compile_mode=""`)**：单次短命 CLI 任务首选，**无任何编译延迟**（总启动仅 `~5.5s`），依然靠轨迹外提与 `SDPA` 取得 `1.17×–1.18×` 端到端提速（`E-only 123.1 ms`、`E→P 305.4 ms`）。
3. **固定视觉对照**：已抽取全部 16 臂固定 6 样本 PNG 至 `runs/v35_3060_opt/visual_samples/`，与数值一致，`Optimized` 肉眼视觉无边界或伪影退化。

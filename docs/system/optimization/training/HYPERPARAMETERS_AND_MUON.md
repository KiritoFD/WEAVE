# CLEAVE 超参数与 Muon 优化器专项评估

日期：2026-11-28。范围：现役闭集 CLEAVE E/P、开放域 CLEAVE-One P，以及实验性的 Reference E-Core。本文依据当前训练源码、本地权重形状和已有评测证据提出建议；候选数值均为**待验证设置**，不是新实验结果。

**已落实的第一阶段方案**：[RTX3060 · 16h训练定型计划](STAGE1_PLAN.md)及[机器配置](stage1_config.json)。第一阶段缩小为监督契约、B画法权重、One-shot P学习率/Q噪声及双EMA；本文更广候选中的Muon与Reference E宽范围LR搜索推迟。本轮仅准备文档和代码，不占用正在补Qwen的显卡。

**结论：有调整空间，但当前不建议把 AdamW 全面换成 Muon。** 最值得处理的是 Reference E 的监督契约与任务梯度平衡，其次是分组学习率、条件扰动和 EMA。Muon 值得作为未来训练效率对照，尚无本项目证据说明它能解决保源锁定、笔触替换不足或推进等内容前沿。

现役权重与部署基线继续冻结。本文不启动训练、不恢复已关闭的蒸馏、不修改当前优化器。3060 测速部署按原任务推进；训练优化器不是推理加速开关。

|---|---|---|

## 2. 已有证据如何限制调参判断

### 2.1 Reference E：先处理目标与梯度，不先换优化器

V37 在相同 4500-step 在线权重上，对12个固定训练批次分别反传、不更新参数，得到：

| 任务 | 平均梯度范数 | 对总梯度平均投影份额 |
|---|---:|---:|
| A：去风格代理→真实画作 | .37618 | 81.14% |
| B：跨作品参考替换 | .16668 | 18.21% |
| C：非零强度自参考恒等 | .02340 | .65% |

投影份额定义为 `g_task·g_total / ||g_total||²`，可能为负，不是参数更新贡献率。A/B 平均梯度余弦约 .0057；这份小样本审计**没有证明严重的整体梯度冲突**，不需要立即引入复杂梯度手术。它支持更简单的判断：该检查点主要受 A 推动，C 梯度较弱。

关键契约是：**A 输入去风格代理 latent，却使用目标原画的 Q32。** V37 E0/E1 都保留此设置；E1 仅在反向配对 B 重算代理 Q32。因此下一轮若重开 Reference E，应先建立“输入代理对应自身 Q32”的干净对照，再讨论优化器。否则 Muon 可能更快拟合原有捷径。

C 在 λ∈[.10,.70] 上有非零梯度，不是数学上无效的任务；只有 λ=0 被结构保证恒等。但它是否值得每步消耗4个样本，需要结合 Same150 与耗时判断，不能因为系数 .30 就认为它主导训练。

证据：[P0 审计与契约](../../../one-shot/V37_PLAN_AND_AUDIT.md)、[原始 audit.json](../../../../runs/v37_editing/audit.json)、[共享目标实现](../../../../exp/v37_editing/training/objectives.py)。81% 是4500步附近的局部测量，不能外推整条训练轨迹。

### 2.2 延长训练已有反例，不能当作默认答案

- 闭集 P：3500→7000 的特定续训使 s100 Top-1 从69%降到64%；最终保留3500 EMA。该续训重建了 AdamW 状态，只能否定这次续训配方，不能证明所有优化路径的绝对最优步数。
- Reference E：V37 E0/E1 都从4500到12902步。E0 以内容破坏换取更强统计对齐；E1 极端保源。两者均未达到预定采用标准，P+A3 仍是正式 One-shot 基线。
- 固定 A3 后打乱 P 的参考，τ=.50 的 Top-1 从43.83%降到19.00%，说明 P 确实使用参考条件。不能把弱笔触表现直接解释成“条件完全没用”。

来源：[闭集 P 总结](../../../p-core/README.md)、[V37 结果](../../../one-shot/V37_RESULTS.md)、[四象限诊断](../../../one-shot/V37_PLAN_AND_AUDIT.md)。这些结果更支持优先调整目标和条件使用方式，而非继续无上限训练。

## 3. 哪些参数值得调：建议优先级

以下是未来有训练预算时的候选顺序；**不是现在全部执行的网格**。每次只改变一个主要因素，进入下一项前先判断是否解决了对应问题。

| 优先级 | 对象/参数 | 初始候选 | 为什么值得 | 保留条件 |
|---|---|---|---|---|
| P0 | Reference E 的 A 任务内容条件 | 目标 Q32 → 从代理输入重提 Q32 | 消除训练/推理内容条件不一致；属于监督契约，不是普通调参 | 输入契约成立，且无明显独立 E/双核前沿退化 |
| P1 | Reference E 的任务/损失相对强度 | 在干净基线中，先试 B 风格子项×1.25，保留 B 内容项；或另试 A 总项×.75，两项不同时改 | A 的局部梯度占优；单纯提高 B 总权重也会放大其保内容项 | 等内容风格改善，灰度笔触有效，Same150 无明显退化 |
| P1 | P 与 Style MLP 分组 LR | 保留现有比例1.5，先比较整体 LR×.5/×1；若参考编码响应持续衰减，再单独试比例1或2 | V36 Style MLP 与 P 同时训练，表征和使用端可能不同步 | Seen-Dev 实例响应与完整曲线改善，不只 FM loss 下降 |
| P1 | Reference E 续训 LR/调度 | 以1e-4为锚，候选 .5×/1×/1.5×；warmup 250 保持 | 比换优化器干预更小；需先固定目标与初始状态 | 无振荡/过曝，独立 E 与 E+P 同时受益 |
| P2 | P 的条件扰动 | 先单测 Q噪声减半，或 style dropout .15→.10；不同时关闭全部增强 | Q噪声、Y丢弃、content dropout、gamma 降级同时存在，可能有重复正则化 | 条件可用性改善，错参考与 CFG 控制仍成立 |
| P2 | EMA | Reference E：β .995 vs .999；One-shot P：.999 vs .9995 | 成本较低，可在线维护两份影子权重 | 按独立校准选择；短训练须计入更长滞后 |
| P2 | batch / micro / 重计算 | 优先固定 effective batch，增 micro、减累积或关闭 checkpointing | 先争取相同统计配方下的吞吐收益 | 实测 samples/s、稳定峰值和质量，而非仅显存更高 |
| P3 | Muon、β2、decay、时间采样 | 先做下述小范围对照，不与上面配方同时变动 | 有潜力，但当前证据链更远 | 达到质量—时间采用标准 |

### 3.1 损失权重应看“加权后的梯度”

Reference E 的 B 包含 ranking、直接参考距离、Gram、Patch-SWD、Oklab、内容、边缘和 latent std；统一提高 B 不等于只强化画法。应分别记录风格项与保内容项的梯度及分层更新，再改一组系数。不要把 `81/18/.65` 强制调成 `1/3,1/3,1/3`，投影相等不是学习目标。

闭集 P 已有主梯度与像素 SWD 梯度校准：每偶数步在高 t 小批量上计算 SWD，像素梯度目标约为主梯度范数 .25 倍，缩放上限2。它不是单纯把所有 loss 相加。若未来调整该 .25，应单独比较 .125/.25，而不是把 Reference E 的经验套过去。见 [闭集 P 梯度合成](../../../../exp/v34_frontier/train_common.py)。

### 3.2 条件扰动与时间采样：值得看，但优先级低于监督

One-shot P 当前：content dropout30%、style dropout15%、Y16 blur/drop40%、Q32噪声σ=.05；gamma 有40%取1，其余采样 [.15,1]，layout 在内容保留时采样 [.25,1]。不要仅看单个 dropout 不大，就认定联合扰动合适。

独立 content/style dropout 对应约59.5%双条件、25.5%仅风格、10.5%仅内容、4.5%全空条件。更改 dropout 会改变 CFG 分支训练覆盖率，推理 guidance 也需重新校准。把 style dropout 降低，未必能改善大 CFG 下的稳定性。

V36 的 t 实际是 `clip(U(0,1), .02, .98)`，边界各约有2%点质量，**不是**均匀采样 U(.02,.98)。若未来测试更偏编辑区间的时间分布，应保留至少一半全区间样本作为初始候选，另半针对目标区间；必须保留纯噪声生成验证。不要改采样同时改速度目标或再次引入除以 `1−τ0` 的短区间放大。

### 3.3 EMA、beta 与 decay：先做低成本、可解释的调整

- Reference E β=.995 的 EMA 半衰期约138次更新；One-shot P β=.999 约693次，.9995约1386次。更平滑不等于更好，短续训中过长半衰期可能主要保留旧模型。改变 effective batch 后还要按样本曝光重新理解该时间尺度。
- 保持同样样本半衰期的近似换算为 `β_new = β_old^(B_new/B_old)`。这里 B 是可比较的有效样本数；Reference E 的 A/B/C 曝光要分开记录，不能草率合并。
- One-shot P 的 β2=.999、Reference E 的 .99 是不同配方；若有明显非平稳梯度，可以单测 P 的 .999→.99。闭集 E 的 β1=.5 与 GAN 配方相关，不建议顺手改成 .9/.95。
- 现有 V36 AdamW 参数组未细分 norm/bias 的 no-decay。未来可先试只对矩阵/卷积权重做 decay，norm/bias/gate 不衰减，再研究量级；这是新配方，不能悄悄改变历史复现。
- 不能从一个已保存 EMA 恢复出另一种 β 的完整历史；双 EMA 需从共同起点在线维护，或有足够密集的在线权重轨迹。

### 3.4 不建议现在调整的东西

base width、Q32维度、prototype 数8、Style MLP维度、是否启用归一化、源门控系数 .85 等会改变容量或信息路径，应视为架构/机制实验。不要因为它们写成一个常数，就和 LR、CFG 一起扫。

Reference E 最后 delta 没有 tanh/硬裁剪，虽然 λ与输入门控有边界；弱编辑不能归因于一个不存在的输出硬幅度上限。修改门控不等于修正监督。

| 参数 | 建议 | 边界 |
|---|---|---|
| τ0 / 强度调度 | 继续作为内容—风格工作点控制 | 降τ通常更重绘，移动曲线不代表推进前沿 |
| 风格/内容 CFG | 若训练条件或优化器改变，再在独立校准上局部校准 | 放大条件响应也可能放大伪影；闭集四分支与 One-shot 三分支含义不同 |

| 步数/积分器 | 优先复用已验证的6步/部署加速档 | 闭集首步 midpoint，6步为7次批量调用；One-shot Euler首步+AB2为6次，不能混算 NFE |

One-shot 已做 I0/I1/I2 与 wj=2.8/3.2/3.8 的 Seen-Dev 校准。后续若确有配方变化，只围绕冻结点做局部比较，不能拿 test750 反复选最优超参数。[One-shot 推理与校准](../../../../exp/v36_art_foundation/eval_v36.py)

## 5. Muon：值得候选，不值得立即全面替换

### 5.1 它提供什么，不提供什么

Muon 先构造动量方向，再通过有限次 Newton–Schulz 迭代作近似矩阵正交化，并按实现约定缩放更新。作者实现支持把4D卷积更新展平成 `[out_channels, in_channels·kh·kw]`；非矩阵参数配合 AdamW。[M1][M2]

因此“Muon只能用于Transformer”不正确。它也不是保证最终质量或单步更快的通用替换：作者列有视觉任务实验，后续已有 diffusion Transformer 研究，但这些架构、任务和预算与本项目的小型卷积 Flow 不同。[M1][M4] 本项目中能否减少达到同等编辑质量的时间，仍是待验证假设。

Muon 改的是训练更新；相同架构、相同推理设置下，它不直接减少卷积量、积分步数或推理内存。若目标是当前3060部署加速，继续处理推理图、后端和已验证步数档，比改训练优化器更直接。

### 5.2 WEAVE 的参数结构决定了它不是一行替换

本轮以本地现役闭集 EMA 统计参数形状；V36 则在 CPU/meta 上按当前构造器统计，不做前向或GPU实验：

| 模型 | 4D卷积参数 | 2D参数 | 1D参数 |
|---|---:|---:|---:|
| 闭集 E | 9,465,344（85.03%） | 1,647,616（14.80%） | 18,308 |
| 闭集 P | 37,819,136（84.91%） | 6,690,816（15.02%） | 30,580 |
| One-shot P | 37,819,136（83.64%） | 7,364,352（16.29%） | 33,652 |
| Reference E | 9,855,744（77.79%） | 2,789,888（22.02%） | 24,109 |

Style MLP 单列为932,608参数，不包含在 One-shot P 的45,217,140中。2D参数也不全是普通主干映射，包含大量 FiLM/AdaGN、条件投影与路由参数。

显存也不是主要采用理由：按AdamW保存两份FP32矩状态、Muon保存一份FP32动量估算，即使45.22M参数全部切换，常驻状态也只理论减少约 .17GiB；混合分组收益更小，还未计入正交化临时缓冲。不能据此预期十几GiB的训练峰值会大幅下降，实际仍要测。[M2]

**PyTorch 2.11 的原生 `torch.optim.Muon` 明确只接受2D参数**，不能直接传 `model.parameters()` 给这些网络。该版本提供 `adjust_lr_fn="match_rms_adamw"`，也不代表已自动实现卷积展平或所有模型上的学习率等价。[M3] 如果采用作者卷积实现，必须锁定代码版本、展平与缩放约定；不能在不同实现之间照搬数值。

### 5.3 建议的首轮混合分组

| 参数类型 | 首轮建议 | 理由 |
|---|---|---|
| 主干 hidden Conv、hidden attention 投影 | 候选 Muon；卷积明确展平为 Cout×(Cin·kh·kw) | 覆盖主要主干，符合作者卷积路径；效果须单独验证 |
| 输入/输出卷积、预测头 | 保留 AdamW | 首轮减少 latent 坐标与残差幅度更新方式的变化 |
| Style MLP、条件 MLP、FiLM/AdaGN、route/gate | 保留 AdamW | 条件幅度和路由是当前关键机制，先避免一起改变 |
| bias、norm、标量 | AdamW，是否 no-decay 按固定白名单定义 | 不交给矩阵正交化 |
| 闭集 E 的判别器 | 保持原 AdamW 与 G/D 时序 | 避免把优化器收益和对抗平衡变化混淆 |

这是本项目的保守试验分组，不是 Muon 原作者的唯一标准。要用模块/参数名称白名单，不只检查 `ndim`。若只给2D参数用 Muon，又把条件投影留在 AdamW，实际改变的主干可能很少，报告必须披露参数覆盖率。

源码中的零初始化层要区分“架构初始状态”和“已训练权重”：现役闭集 EMA 的2D/4D矩阵已非全零。续训时不重新把输出层或调制层归零，也不把 Muon 的更新正交化与条件 Q32 的 Stiefel 正交化混为一件事。

### 5.4 不能照搬的设置

1. **LR**：作者实现的矩阵形状缩放、PyTorch 的 `original` / `match_rms_adamw` 不是相同数值约定。不要把 AdamW 3e-4直接改成 Muon .02，也不要因名字相近便保留同一个 LR。[M2][M3]
2. **Decay**：在作者实现中有 `p *= 1−lr·wd` 的解耦衰减。LR改变时，相同wd也会改变累计收缩；应记录实际使用的LR与decay，而非只说两边wd相同。[M2]
3. **动量与迭代**：首轮固定 momentum=.95、NS steps=5、Nesterov开启，沿用所选实现的标准设置；不同时搜索这些维度。它们是起点，不是已证明适合WEAVE的最优值。[M2][M3]
4. **裁剪**：Muon还会归一化矩阵更新，同一global grad clip阈值不保证相同权重步长。保留数值保护并测 `||ΔW|| / (||W||+ε)`，特别检查调制层与输出头。
5. **状态恢复**：AdamW的一、二阶矩不能当成Muon动量直接加载。优化器、scheduler、EMA和随机数必须分别管理；否则比较的是不同重启条件。

## 6. 如果未来批准试验，最小公平方案是什么

### 6.1 首先选一个问题，不同时改配方和优化器

- **要解决 Reference E 的质量**：先做输入Q32契约与任务平衡对照，仍用AdamW。不能把修监督、换优化器、加token同时组成一个“Muon臂”。
- **要测优化器训练效率**：先选一个已有可恢复状态的P训练配置；固定监督、数据、架构与分组，仅比较AdamW与混合Muon。若只做闭集快速先导，结论也只限闭集，不外推One-shot。
- **要提高现役推理速度**：沿用已批准的3060部署工作，不安排训练优化器实验。

### 6.2 两个主臂足够起步

| 项目 | A：AdamW 控制 | M：Muon + AdamW |
|---|---|---|
| 初始在线权重、EMA、数据顺序、噪声 | 完全相同 | 同左 |
| 优化器状态 | 若切换试验，两边均从相同权重重建状态 | 重建Muon和辅助AdamW状态 |
| 目标/条件/有效batch/精度 | 固定 | 固定 |
| 参数分组 | 同一清单，全部AdamW | 仅白名单主干改Muon |
| LR选择预算 | 小范围校准 | 同等候选/时间预算，按该实现缩放约定校准 |
| 核心比较 | 等更新数/等曝光的质量 | 同左，并另报等wall-clock的质量 |

先让两边实际分层更新RMS处于相近量级，再做完整先导；这只是避免明显尺度失配，不是保证两算法等价。如果保留旧AdamW moments另设 `A_keep`，它是工程续训参照；不能把它与冷启动Muon的差异全归于算法。

**相同更新数与相同运行时间通常不能同时成立。** 必须同时保存质量—曝光、质量—GPU时间两种视角。记录完整step time、optimizer time、吞吐、allocated/reserved显存、裁剪前范数、相对更新量；不能只报Muon step更快或只报训练loss更低。

### 6.3 选择、验收与停机

1. 小规模校准只选有限配置，不作最终质量结论。One-shot用独立Seen-Dev，闭集用独立train-side calibration；不反复拿test750选LR。未来短先导使用预先固定预算，不自动扩成新的12小时训练。
2. 先导若仅FM/reconstruction loss更低，而等内容风格、实例参考遵循或灰度笔触不改善，停止扩展。单种子只能说明可行性；正结果在第二种子复核后再讨论稳定优势。
3. 最终候选完整test750，分别报告Cross600、Same150、画派分项；One-shot另保留Artist-OOD/Movement-OOD，不能用五类Top-1评价131派。固定S10与独立裁判。
4. 质量型采用仍要求至少两个匹配内容点 `ΔDINO-S≥.01`，或 `Top-1 +5pp` 且风格不退化；有源图聚类配对CI与固定笔触样例支持。只在实测交叠区内插，不外推。
5. 效率型采用可预设“达到相同独立校准质量所需GPU时间减少≥15%”作为工程门槛，最终候选还须完整质量非劣；15%是建议的采用线，不是Muon性能预测。
6. 没有可靠优势便保留AdamW。新生成评测完成后才更新统一Pareto、SVG/HTML并展示，不为本文制造新性能点。

## 7. 当前决策

从用户给出12小时计划起，V37续训/配对、后续独立审计与3060部署分别支持哪些结论，已汇总于[阶段结论文档](../../paper-audit/POST_12H_CONCLUSIONS.md)。该总结同时标出未验收项和F1/F6的LPIPS输入错误；不能将研究假设或失败启动写成已完成成果。

**现在保留AdamW、冻结权重，完成测速部署。** 若未来恢复质量研究，Reference E先修监督和任务平衡，One-shot P先查分组LR与条件扰动。Muon排在这些问题之后，作为有明确参数分组、更新尺度和时间收益标准的优化器对照。

已有模型能生成艺术图像，也能响应参考；当前更缺的是正确的编辑约束和稳定的内容—画法取舍。优化器可能提高学习效率，但现有证据不支持把它当作画法转换问题的主要解法。

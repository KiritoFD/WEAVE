## 2. 对最初几个问题，现在如何回答

### 2.1 E-Core究竟是不是只差训练时间？

**可以否定“沿当前配方多训就会自然解决”的假设，不能宣称已经证明E训练完全充分。**

原4500步Reference E确实训练很少。加到12902步后，A任务累计曝光约7.74万次，只相当于有效训练池约一轮，且包含重复作品；这不是“从零12.67M参数已全面收敛”的证明。更有价值的观察是：

- E0训练侧参考2-way跟随从71.88%升到93.75%，灰度内容L1却从.03617增至.05942。训练目标改善伴随内容破坏。
- E1独立λ=1仍有DINO-C=.8990、目标Top-1仅3.67%，表现为强保源，未学到足够的目标画法替换。
- 正式验收而非训练loss决定采用；两条路线都没有通过预定标准。

因此，继续研究应先调整监督/条件契约，而不是默认再追加几万步。这个结论只针对已测配方，不否定所有更长训练或其他配对方式。

### 2.2 当前E0/E1为什么都不能升级正式系统？

E1+P相对正式P+A3，在相邻实测点内做等内容插值，得到：

| DINO-C | ΔDINO-S | 源图聚类95% CI | ΔTop-1 |
|---|---:|---|---:|
| .60 | −.0065 | [−.0115,−.0012] | −11.32pp |
| .65 | −.0058 | [−.0106,−.0005] | −12.96pp |
| .70 | −.0054 | [−.0094,−.0010] | −10.34pp |
| .75 | −.0057 | [−.0103,−.0008] | −7.66pp |

E0+P仅覆盖C=.4688—.5645，不能外推到预定C=.60—.75。它在事后低内容交叠点C=.53有ΔS=+.0155、CI[+.0006,+.0262]，但Top-1下降7.80pp；另两个交叠点S的CI跨0。这是局部指标取舍，不能抹掉，也不足以满足原验收条件。

独立Holdout没有推翻该结论：Artist-OOD上E1在C=.75的ΔS=−.0075，Movement-OOD上C=.70/.75为−.0117/−.0120，CI均低于0。这里是实例参考指标，不是核心五类Top-1。

**决策：正式One-shot继续使用V36 P-Core + Reference-A3。** 闭集V35 E与Oracle不计入正式One-shot。

证据：[等内容配对CI](../../../runs/v37_editing/matched_content_ci.json)、[E0交叠区CI](../../../runs/v37_editing/e0_lowcontent_ci.json)、[Holdout CI](../../../runs/v37_editing/holdout_matched_ci.json)、[完整结果](../../one-shot/V37_RESULTS.md)。插值CI在重采样后只保留仍有实测括区的draw，原JSON保留有效draw数量，不能称所有点都有2000个有效draw。

### 2.3 P-Core是不是完全不会用参考，效果是否都来自A3调色？

**这两种极端解释都被反事实对照否定。** 固定模型、源图和噪声，τ=.50的完整Cross600结果为：

| A3参考 | P参考 | Top-1 |
|---|---|---:|
| 正确 | 正确 | 43.83% |
| 正确 | 错误 | 19.00% |
| 错误 | 正确 | 16.17% |
| 错误 | 错误 | 4.33% |

A3与神经参考条件都参与结果。τ=0的固定24例中，仅改变A3起点，输出最大差为0，符合起点不参与的契约。

闭集E草稿送入冻结V36 P，在τ=.75得到C=.6117、S=.5179、Top-1=64.50%，好于普通开放域草稿的相近内容工作点。它支持“改善草稿可能释放现有P能力”，**不能证明P处处没有瓶颈**。闭集E见过Core-5，它只是一个更强诊断起点，不是完美草稿或数学上界。

后续F3同样显示参考/内容可控：200组三元组的参考交换跟随为87.5%/92%，100对内容交换跟随99%；同色盘全流程64组跟随65.62%。固定A3的另一定义得到78.12%，二者不能混算。跟随说明可区分输入条件，不等于已经完成正确的笔触重绘。

证据：[四象限](../../../runs/v37_editing/diagnostics/core_quadrants.json)、[Oracle](../../../runs/v36_art_foundation/measured/v36_diag_d1_oracle.json)、[F3](../../../runs/paper_audit/f3_summary.json)。

### 2.4 监督问题定位到哪里了？还有哪些没有隔离？

已确认A任务把去风格代理latent与目标原画Q32组合；E0/E1都保留此设置。4500步附近12批审计中，A/B/C对总梯度平均投影为81.14%/18.21%/.65%。**当前数据首先支持检查A的条件捷径与目标占优，不支持先断言优化器不行。**

E1的B确已从proxy图重提Q32，但它同时改变了B的监督目标和样本来源；教师proxy又大多只是有限调色/纹理变化。因此，保源结果与“逆向任务太像修复”这一解释一致，但尚未单独区分教师强度、A捷径、B损失构成和配对多样性的因果作用。不能把失败都归因于Q32重提，也不能宣布“反向真实配对”作为一类方法已经被否定。

## 6. 当前可以用于论文的主张

| 可以写的结论 | 不应升级成的结论 |
|---|---|
| 闭集双核在固定协议下形成有效质量—效率谱；高内容E独立运行 | 所有请求都调用E+P，或44M就是完整系统参数量 |
| One-shot同时使用解析起点与神经参考条件 | 只是A3调色，或已经实现充分、正确的画法转换 |
| 本次原配方续训和固定教师逆向配对未达到采用门槛 | 所有长训、所有真实配对、所有Reference E都不可能成功 |
| 未见源画家上仍存在显著正确/错误条件差 | 跨所有域泛化已解决，或已证明整系统训练从未见过目标画派 |
| A0 TRT在预设质量门下有实际工程收益 | 所有TRT组件组合已验收，或压缩一定能在不损质量下加速 |
| 当前已测One-shot相对StyleGallery仍有等内容风格差距 | 已证明该差距来自Zero-DINO、小模型、S10或某种优化器的固有上限 |

最值得保留的认识是：**训练目标更好拟合、参考更可区分、分类率更高、速度更快，这四件事都不能单独替代“相同内容保持下画法更好”。**

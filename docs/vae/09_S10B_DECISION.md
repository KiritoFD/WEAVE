# 关键决策：旧 S10 无需重训即可配合原版 SD0 Encoder

> 本文是 2026-11-12 适配实验的**决策记录**，解释为什么「用 SD0 Encoder 就要重训 S10」这个前提被推翻。
> 完整 A/B/C/D 数据见 `docs/v6/S10_SD0_ADAPT_REPORT.md` 与 `deliver/s10_sd0_adapt_FINAL.json`。

---

## 1. 问题从哪来

旧 S10（`s10_p5_lowlr/decoder.pt`）是在 **A0 Encoder** 空间训练的。仓库里两处加载代码
（`tools/v6_next/w_vae.py` 思路、`tools/v6_next/vae_swap_compat.py:111`）都明确使用：

```
E_A0 → post_quant_conv_A0 → D_S10
```

而 `docs/baseline/UNIFIED_FULL_RANKING.md` 第 4 名 `Q2a + R1 Oracle + S10`（Affinity 0.5587）
正是这个 A0 配对。因此「旧 S10 在**原版 SD0 Encoder**下是否同样有效」此前没有直接证据。

另一个悬案：历史上有人把 SD0 latent 直接送旧 S10，测得 **DINO-C ≈ 0.22**，而正确 A0 配对是 0.9387。
但实测 A0 与 SD0 原生 latent `cos ≈ 0.992`、RMS 比 ≈ 0.998，两者极接近 —— 所以那次退化更可能是
**缩放 / `post_quant_conv` 接口错误**，而非两种 latent 不可弥合。

## 2. 验证方案（保持 S10 主体 10.658M 参数完全不变）

只考察输入端 4→4 通道映射：

| 档 | Encoder | 输入映射 | Decoder 主体 |
|---|---|---|---|
| A | A0 | A0 原版 PQC | 旧 S10（目标上界 / 参考） |
| **B** | **SD0** | **A0 原版 PQC** | **旧 S10（直接兼容，零训练）** |
| C | SD0 | 最小二乘闭式校准 PQC | 旧 S10 |
| D | SD0 | SD0 原版 PQC | 官方 49.49M D0 |

硬约束（接口审计确认）：**未缩放 posterior-mean latent**、**恰好一次 PQC**、`scaling_factor=0.18215` 不进 Decoder。

闭式校准：`min ‖W z_SD0 + b − P_A(z_A0)‖² + λ‖W − W_A‖²`，2000 张训练图 / 819 万个 4 维样本，λ=1e-3，纯最小二乘，不训练 S10。

## 6. 决策表命中

| 方案条件 | 实测 | 处理 |
|---|---|---|
| **B 已经接近 A** | **是**（P0 DINO-C 0.9678 vs 0.9695；P2 B 0.5616 ≥ A 0.5587） | ✅ **直接使用旧 S10 + SD0 Encoder，零训练、零额外推理开销** |
| C 明显优于 B 且接近 A | 否（5 个主指标显著更差） | 不发布 C |
| 1×1 不足、3×3 有效 | 不需要走到 | 不做 3×3 适配器 |
| 两种适配均无效 | 不适用 | 不重训 Decoder |

## 7. 为什么 C 会失败（重要教训）

闭式最小二乘保证的是 **PQC 输出中间特征**在训练样本上的最优线性拟合；
但 S10 是一个高度非线性的解码函数，中间特征误差最小 ≠ RGB 输出质量最优。
方案自己已预警「不能保证达到 A0 配对下完全相同的图像质量」，实测证实：
MSE 降 8.2% 的同时，Affinity/DINO-S/DINO-C/LPIPS 全部显著变差。

## 8. 与 32 方法榜的定位

`B = Q2a+Oracle + 原版SD0 Encoder + 旧S10` 的 Affinity **0.56159**：
- 高于榜单第 4 名 `Q2a+Oracle+S10`（A0，0.5587）
- 高于本轮新 C0（0.5575）/ C1（0.5576）
- 仅次于 3 个外部 Baseline（StyleShot 0.6949 / StyleID 0.6469 / AesPA 0.5784）

**「目前最好的 Ours 配置」从 A0 配对变成了零成本的 SD0 + 旧S10 直接兼容。**

## 9. 落地：S10B 自包含包

`deliver/checkpoints/s10b_standalone/`：PQC + S10 主体 + 契约 + 零依赖加载器。
独立加载与 B 输出**逐元素一致**（max\|diff\| = 0.0），**彻底去掉 A0 运行时依赖**。

**字节级证明：S10B 就是旧 S10**（`state_dict` sha256 相同、140 张量 `torch.equal`、PQC 相同）。
B 没改模型任何一个参数，只换了喂它的 Encoder；C 的校准被否；主体 10.658M 参数自始至终未动。

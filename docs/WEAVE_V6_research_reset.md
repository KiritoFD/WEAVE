# WEAVE — V6 研究基点与消融复盘

**版本：** 2026-11-09 · Research reset / evidence ledger  
**任务：** 五种艺术风格、20 个有向转换；保留输入图像的语义与空间结构，建立目标艺术风格。  
**主线：** V6 `C3UNet` Direct；V6 Score Difference 仅作为独立的强风格参照。V7–V11 的普通跨域 Bridge 只保留负面证据，不再自动继承其架构或训练决策。

> **证据边界：** V6 代码及历史报告已核对 GitHub `main`（`6d17a785d9`）；最新的九组消融表、A0 精确复现和正在进行的 A1–A7 来自本轮提供的实验记录。最新 `Negative_Results/`、`V6_ABLATION_INVENTORY.md` 等文件当时尚未出现在可读取的远端 `main`，因此不把进行中的实验写成已完成结论。本文严格区分 Val200 与 Test600、不同评测协议，以及单因素证据与多因素对照。

## 0. 一页结论

1. **保留的核心是学习问题，而不是复杂架构：** 同一真实画作提供 `(内容规范化表示 c, 原风格 s, 原画 z)`，先通过自重建学会在给定内容下恢复真实绘画，再用跨风格统计损失及内容一致性学习转换。
2. **目前最稳妥的基点：** `D1_c1_gentle`，Direct、`base_dim=48`、约 **1.88M 参数**、800 updates / 有效 batch 240。Val200：`ΔT=+0.0323 / DINO-C=0.9167 / LPIPS=0.3658`，4/5 目标风格正向；Ukiyo-e `ΔT=-0.0078`。
3. **已知能增加风格的有效组合：** T1 把 Val200 `ΔT` 提升到 `+0.0404`，但 DINO-C 降到 `0.8859`。注意这同时调整了两个有效损失权重，**不能只归因于加大跨风格损失**。
4. **已知负面：** 直接取消内容一致性/自重建的联合配方、强 ZCA、D1 结果的过度线性外推，以及没有内容条件的跨域 Bridge。它们不是“风格优先”的可靠捷径。
5. **结构极简化先做精确等价：** Direct 下折叠重复输入 Stem、常量时间条件、冻结权重的五风格 AdaLN 查表；删掉 `coherence_beta=0` 的空操作。**不能在 A1–A7 完成前声明内容注入、Style-ID 或更窄网络可以删除。**
6. **关键问题：** 现有模型已能做稳定、温和的风格化，却没有建立足够强、足够均衡、具有多样性的目标风格。下一阶段应最大化“给定内容保真约束下的风格改进”，而不是单纯增大图像改动幅度。

## 1. V6 到底训练了什么？

令 `z=E(x)` 为冻结 SD-VAE latent；`s` 为真实风格；`j` 为随机跨域目标风格；`C` 为 V6 的温和内容规范化算子。Direct 网络：

$$
\hat z_s=G_\theta(C(z;\xi),s),\qquad
\hat z_j=G_\theta(C(z;\xi),j).
$$

在 `coherence_beta=0` 时，同风格训练目标就是真实画作 `z`。训练器实际组合为：

$$
\boxed{\mathcal L=w_{\rm rec}L_{\rm self}
+w_{\rm sd}L_{\rm style,same}
+w_{\rm cross}\big(L_{\rm style,cross}
+w_{\rm inv}L_{\rm content,inv}\big)}
$$

其中：

- `L_self`：同一张画作的多频段标准化重建 MSE；确保模型学会给定内容时生成**真实的**本风格绘画。
- `L_style,same/cross`：真实风格训练集的 Haar 多尺度均值/标准差、LL 通道协方差、LL/HF patch-SWD；如 B1 风格编码器 checkpoint 存在，还可加入编码器原型项。
- `L_content,inv`：将跨域输出重新规范化，与输入图像的规范化表示比较（LL/LH/HL 为主），保证转换仍属于同一内容。
- `C(z;ξ)`：gentle 规范化和随机外观扰动，降低仅复制源风格的捷径；**不是已证明完美的内容—风格分离器**。

**机制解释：** 自重建提供可学习的真实图像终点；跨风格统计提供目标外观方向；内容不变性限制它不能任意改变主题。三者合起来，才是 V6 比独立随机画作 Bridge 更适合风格迁移的原因。

也要承认局限：单独的 MSE 部分理论最优为 `E[z | C(z)=c,s]`，倾向于条件平均；跨风格没有逐图 GT，LL/HF 统计也不能唯一确定笔触和局部细节。因此 **V6 的可行性已验证，风格强度不足仍然是训练目标的固有限制之一**。

**最容易误读的一点：T1 不是单因素实验。** 由于源码是 `w_cross*(L_style_cross + w_inv*L_inv)`，真实有效权重为：

| 配方 | 自重建 | Same-style | Cross-style | **内容一致性实际系数** |
|---|---:|---:|---:|---:|
| A0 | 1.00 | .25 | .35 | **.525** |
| T1 | 1.00 | .25 | 1.20 | **.240** |
| T2 | 1.00 | .25 | 2.00 | **0** |
| T3 | .30 | .25 | 2.00 | **0** |

从 A0 到 T1，**跨风格统计权重增加 3.43 倍，同时内容一致性权重降低约 54%**。因此 T1 的 `ΔT +0.0081` 不能说明“只需要增大 `w_cross`”；T2 的失败也不能单独证明“`w_inv=0` 必然失败”。可确定的是：**保留某种内容锚定的风格增强组合，比全面放开图像改写更有效**。

## 3. 哪些改动值得保留？

| 改动或事实 | 证据 | 判定 |
|---|---|---|
| **Direct + 真实画作同图自重建** | A0 两 seed 稳定；相较 F1 精度/速度/参数更优 | **主线保留**；尚不能将全部收益纯归因于 Direct |
| **温和 Canonicalization 与外观增强** | gentle/soft 配方明显好于 pure；激进 C2-ZCA 破坏内容 | **保留 gentle**；Canonicalizer 的独立贡献等 A3 |
| **跨风格 style loss + 内容一致性** | T1 优于 A0；T2/T3 联合修改退化 | **保留两者组合**；单因素权重效应尚未定量分离 |
| **明确 Style-ID 条件** | V6 训练条件有效性：wrong−correct loss +.1128；相同内容的输出存在目标选择性 | **保留**；待 A2 重新验证依赖程度 |
| **多尺度 LL/LH/HL/HH 表示** | V6 真实使用各频段的重建与分布监督；轻量 Palette Head 仅占极少参数 | **暂保留**，未完成独立损失/头消融 |
| **Score Difference 的风格强度旋钮** | Test600 中增强能提高 ΔT / Top-1；保留同风格差分零更新 | **作为独立竞争基线保留**，不并入最小 Direct |
| **按目标风格单独标定** | 能纠正统一强度下 Minimalism 的过度吸引 | **未来控制层保留**，不进入基点训练 |

**额外好消息：** V6 的 Style-ID 并未完全被忽略。但“同一内容切换目标时输出不同”仍然弱于“每个目标都能生成足够强且可信的对应风格”。此前 5×5 条件响应测试不能替代真实跨域 Test600 成功率。

## 4. 哪些尝试已表现出负收益？

| 尝试 | 结果 | 正确解释 |
|---|---|---|
| **C2-ZCA 过强风格剥离** | 裸解码内容 DINO-C≈.478 | 规范化不能以消除风格为唯一目标，必须保住内容的充分信息 |
| **T2/T3 激进放开风格、取消内容锚定** | Val200 ΔT 从 +.0323 降到 +.0017/−.0232 | 只会抹除原图不一定能建立目标画风；但多权重耦合，不能断言单项因果 |
| **直接放大 D1 输出残差** | α 1→2.2，Val200 Top-1 3%→14%，ΔT +.0323→−.0042、LPIPS≈.690 | 排名改善可能来自擦除与失真；线性放大不是可信的风格生成 |
| **统一提高 ScoreDiff 步数与步长** | Test600 Top-1 可达 32.2%，DINO-C 降至 .631；Minimalism 吸引子明显 | 强度旋钮有用，但存在目标域不均衡与内容损失；不可只看宏观 Top-1 |
| **更大/更复杂网络自动更好** | D1_bench/F1 结果均弱于 1.88M A0 | 现有数据下未证实“容量不足”是第一瓶颈；由于配方混杂不能认为大网络必然无效 |
| **无配对完整艺术域 Bridge（V9–V11 主线）** | 五风格 Top-1 主要 4.5–13%，ΔT 负，内容/风格冲突 | 数学任务缺失逐图内容条件；作为负面经验归档，不继续当默认 V6 升级路径 |

### 不能过度使用 CSD 的历史证据

额外的 V6 风格子空间探针发现：沿 CSD 梯度微小移动，可得到 `ΔT≈+.12`，却几乎看不出画面差别（LPIPS vs no-op≈.008）。这说明 **CSD 是有用的方向性评价，但不是“可见风格真实性”的充分代理**。未来应同步报告独立风格特征/人工盲评，并避免把极微小的数值改动当成风格迁移突破。

## 5. 从实验结果能得到什么 Insight？

**I1 — 风格迁移本质是有内容条件的生成，不是无约束的域搬运。** V6 通过真实画作自重建获取了正确的逐图学习信号，跨风格约束负责改变外观；完全独立端点的流没有同等内容对齐信息。

**I2 — 内容约束不仅“压制风格”，也保护风格学习免走捷径。** 删除或削弱它的联合实验使 ΔT 下降而非上升。应寻找给定内容保真预算下更强的风格损失，而非粗暴降低所有内容损失。

**I3 — 风格相似度提升、分类跨过决策边界、视觉风格成立，是三个不同层次。** A0 的 ΔT 为正但 Top-1 仅个位数；加大编辑可提升 Top-1 却损失 ΔT 或视觉可信度。必须同时测绝对目标相似度、Margin、多目标召回与视觉质量。均衡五分类随机参考为 20%；若目标限定为已知源风格之外四类，则不使用目标信息的固定“另一个风格”策略机会水平为 25%。

**I4 — 五种风格不是同样难的“强度”任务。** Minimalism 在 ScoreDiff 上容易成为吸引子，Rococo/Ukiyo-e 难以稳定建立；简单统一推高所有风格的强度会掩盖最差目标。需要按目标报告宏平均与最差风格，而不是让某一类主导收益。

**I5 — 低阶统计可以提供画风倾向，却不足以保证复杂笔触。** V6 的 LL/HF moments/covariance/SWD 能提供廉价监督，但难以逐图唯一确定装饰性纹理。这解释了“内容保留好，风格辨识弱”的可能机制；仍需独立消融区分统计表达不足与网络容量不足。

**I6 — 可能存在训练分布的原型偏置。** V6 每风格约一半训练样本来自 Core64。800 步、有效 batch240 时，每张 Core 图平均被抽到约 **300 次**。它可能强化典型风格，也可能让生成倾向少数原型，导致稀有笔触欠覆盖。**目前只是风险，不是已验证的模式塌缩。**

**I7 — 最小化不等于删掉风格控制。** 输入内容仅占少量额外参数，AdaLN 是较大的条件部分，但它可以在冻结权重后精确折叠成五风格常量查表。先做**等价压缩**，再做**可训练结构消融**；两者不能混称为“无损重训”。

## 6. 最小基点如何冻结？

**M0：实验原点（不可修改）**

```yaml
model: C3UNet
mode: direct
base_dim: 48
params: ~1.88M
vae: SD1.5 frozen
canonicalizer: c1_gentle
coherence_beta: 0.0
steps: 800
effective_batch: 240
seed: 42
loss:
  w_rec: 1.0
  w_style_dist: 0.25
  w_cross: 0.35
  w_canon_inv: 1.5  # effective content term = 0.525
validation: Val200  # A0 reference
```

**M0-fold：精确等价的推理部署版本（不重训）**

- Direct 模式 `z_in=c`，Stem 的 `[z_in,c,z_in-c]=[c,c,0]`，将前两组卷积核相加后使用 4 通道输入。
- `tau=0` 恒定，`time_mlp(0)` 并入条件常量。
- 冻结 checkpoint 后，五个 Style-ID 的 `style_mlp + time_mlp + 每层 AdaLN` 可预计算成五行参数表；保留内容相关卷积与 Palette Head。
- `coherence_beta=0` 时删除不执行实际变换的目标构造逻辑。
- 要求固定输入、所有五类、FP32 下逐层/最终输出满足预定浮点误差阈值，再称为“等价”。**不能把此结论直接迁移到从零训练的查表网络。**

**M1：待消融确认的最小可训练版本。** A1/A3/A4–A7 完成后，选择最小且对 A0 非劣的结构；不能在结果未出时预设 dim32、无内容注入或无规范化一定可行。建议 Val200 配对门槛：`ΔT≥A0−.005`、`DINO-C≥A0−.01`、`LPIPS≤A0+.02`，并要求目标条件有效性与 Ukiyo-e 不显著恶化。通过后用第二 seed + Test600 锁定。

## 7. 进行中的消融：每组究竟能回答什么？

| 实验 | 可回答的问题 | **实现/解释警戒** |
|---|---|---|
| A1_no_content | 64/32/16 多尺度内容注入是否必要？ | Stem 仍输入 `c`，**不是无内容模型** |
| A1b_content_none | 纯 Style-ID 能否达到风格分类，但失去内容？ | 必须连 Stem、输出残差基底及 Palette 输入都隔离；它是负对照而非候选迁移器 |
| A2_no_style | 模型是否真的依赖目标 Style-ID？ | 不能只冻结 `style_emb`：`palette_head(c,style_id)` 也有独立 Style-ID 路径；要全部固定才是正确负对照 |
| A3_canon_none | gentle Canon 是否有必要？ | 若 `C=id`，`L_inv` 会同时变成更强的原像约束；**应将输入规范化与内容一致性参考算子分开**，否则并非纯 Canon 消融 |
| A4/A5/A6 dim24/32/40 | 1.88M 是否过宽？ | 固定数据/损失/有效曝光量；报告 FLOPs、吞吐，不只看参数数目 |
| A7_steps400 | 半步数预算是否够？ | 400 步训练 + 缩短 LR 周期，不等于 800 步 run 的 step400 checkpoint；明确两者口径 |

**只在这些结果完成后补极少数因果实验：**

1. **A8（真正的内容一致性单因素）**：A0 仅将 `w_inv=0`，其余不变；同时记录真实的有效权重。
2. **A9（B1 编码器的真实贡献）**：先记录 A0 是否实际加载 B1 checkpoint，再在相同模型/采样下独立删除对应编码器损失。若 A0 未加载，此项不必重训。
3. **A10（Core64 采样）**：保留相同 style-target 参考统计，只把训练样本从“50% Core64 + 50% 全库”改为普通均衡采样；检验风格强度与生成多样性的影响。

进一步拆解 Style Loss 的 moments、covariance、patch-SWD 可以做，但在确定最小训练基点前不扩大阵列。

## 8. 固定后的研究方向与拒绝项

**第一阶段：** 先固化最小 D1 主干与统一评测，继续保留 Val200 / Test600 两套口径但绝不混排，附加五目标分别的 Top-1 / ΔT / Margin，以及内容保持。

**第二阶段：** 在给定内容阈值下提高目标风格，而不是最大化编辑幅度。推理目标可设为 `DINO-C≥0.75/0.85` 两档，对比 ΔT、Margin、Top-1、真实风格分布距离和视觉盲评。`LPIPS` 是变化量，不能无条件解释为画质坏。

**第三阶段：** 如果 Direct 的强风格上限被证实不足，先比较 V6 自身已验证的 ScoreDiff 与风格专属控制；只有出现清楚的增益缺口时，才考虑在同一内容条件下添加 V9 的小残差修正。**禁止重新采用无内容条件的随机跨域 Bridge 作为主目标。**

**短期拒绝：** 增大 DiT、重训 VAE、GAN、每步 VAE Decoder 的 RGB Loss、Gaussian Pivot、复杂教师蒸馏、未证明有效的随机潜空间风格方向。它们不是永久否决，而是目前没有比确认 V6 基点更高的证据优先级。

### 最终科研命题

> **在冻结、可解码的 SD-VAE latent 中，用最小的内容条件模型学习真实艺术风格：先锁定可复现的内容保持映射，再研究能否提高“单位内容损伤所购买的真实目标画风”，而不是仅提升某个分类器的判别排名。**

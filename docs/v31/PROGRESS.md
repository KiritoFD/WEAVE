## 三、核心根因诊断（已实证闭合）

### 1. 为什么两代 `EditFlow`（`A1` 与 `A1b`）都未打破 Pareto 前沿？
- **`A1` (`anchor = (1-tau0)*eps + tau0*E-Core(tid)`)**：锚点提前泄露了目标画派 `tid`，导致无风格条件分支 `v_0c` 同样能从 `zt` 中读出目标风格并预测相同残差，CFG (`v_sc - v_0c`) 失效（Top-1 跌至 `28.17%`）；且 `(u, tau0)` 拆分使 `tau0=0` 仅占 `22%` 训练步，`ER/Uki` 塌陷（`0.0%–7.5%`）。
- **`A1b` (`v* = (z1 - z_tau0)/(1 - tau0)` 中性桥)**：消除了 `tid` 泄露并恢复 CFG（Top-1 回到 `61.3%–67.0%`），但高 `tau0` 时分母 `(1 - tau0)` 把编辑速度幅度放大至 `~2x`，推理期在固定 `s=0.85` (`tau0=0.71`) 下过度重绘，`DINO-C` 从 `0.6119` 跌至 `0.5069`；在同等 `C ≈ 0.51` 下仍以 `0.5088 S / 61.3%` 严格负于 `A0`（`0.5530 S / 70.8%`）与 `V29_Final`（`0.5605 S / 77.0%`）。
- **`RCSM`（`A2` / `A2b`）**：即便改进为零冷启动余弦路由 + `16×16` 瓶颈 `adagn16` + 区域统计监督，在 `global_avg` 对照下 `DINO-S` 净增益仍仅 `+0.0003`（不显著），局部空间统计注入尚未转化为风格分优势。

### 2. 为什么 `A3_PStar_RegionalCorr (a=0.25)` 与 `V29_Final` 读数几乎完全重合？
- 训练日志显示 `loss_r` 从步 1 的 `0.0129` 降至步 2500 的 `0.0092`，梯度范数仅 `gn = 0.01–0.05`；
- 根因在于 `grad_z` 原始幅值低于 `1e-3`，经过 `.clamp_min(1e-6).sqrt()` (`= 1e-3`) 归一化后 `|g_target|` 仍小（步 1 零输出时 `smooth_l1(0, g_target, beta=0.25) = 0.0129` 对应均值幅值不足 `0.1`），叠加 `RegionalCorrectionNet.out_conv` 零初始化与推理系数 `alpha=0.25`，实际施加到潜变量的速度扰动几乎为零（`a25_s085`：`0.6147 C / 0.5305 S / 66.83%` vs `V29`: `0.6157 C / 0.5307 S / 66.83%`）。

像素级统计进一步揭示两个具体机制：
1. **强度调度与目标复杂度错配**：`StyleGallery` 即使内部在 `Minimalism` 上保持 `C = 0.655–0.889` 时其 `Min S` 也同样只有 `0.169–0.212`；它能够拿到 `Min S = 0.484`，是因为其在 `Minimalism` 上天然退让至 **`C = 0.4536` (`LPIPS = 0.7464`)**，同时在其他 4 类维持 `C = 0.631–0.681`。而 `WEAVE` 统一调度对全部 5 类施加固定 `tau0 / lscale / gamma`。
2. **中高内容档下的色彩枯竭与明暗锁定**：在 40 例交叉 `Minimalism` 像素测量中：
   - `StyleGallery`: `TV_grad=0.0140`, `gray_std=0.0948`, **`sat=0.1438`**（高色域色块 + 扁平亮度）；
   - `V29_s085`: `TV_grad=0.0132`, `gray_std=0.2018`, **`sat=0.0514`**（近似灰阶褪色图，仅去掉色度但保留源图明暗反差）；
   - `V29_s125`: `TV_grad=0.0149`, `gray_std=0.1957`, **`sat=0.0406`**（仍锁死在灰阶模式，即便 `C=0.425` 已低于 `StyleGallery` 的 `0.454`，`Min S` 仍落后 `0.360 vs 0.484`）；
   - `V29_s150`: **`TV_grad=0.0070`**, `gray_std=0.2317`, **`sat=0.1780`**（脱离 `y16` 灰阶锁定后色度跃升 `4×`、内纹梯度减半，`Min S` 跃至 `0.584`）。

## 四、恢复工作后的下一步建议

1. **先做轻量零训练推理探针（1–2 分钟/次）验证“复杂度自适应调度 + 高内容脱灰阶”上限**：
   - 使用 `rcsm_region_bank.pt` 中无类别特判的连续复杂度信号 `m_proto`（梯度/边缘/Haar 高频密度）按输入动态放宽稀疏目标（如平面色块画风）的 `tau0 / lscale / gamma`，避免把高明细画派与低明细画派绑死在同一 `y16` 锁定点上；
   - 核查若不锁死灰阶 `y16`（如只传语义边缘轮廓而非全局亮度反差，或提高高 `t` 色度保持/平滑度），能否把 `Min S` 在 `C ≈ 0.45` 从 `0.360` 直接推到 `≥ 0.48`（同时保持 `ER/Imp/Roc/Uki` 在 `C ≈ 0.63–0.67`）。
2. **若继续修 `A3` 局部梯度蒸馏**：
   - 将 `_regional_energy_and_grad` 中的梯度归一化修正为真正的单位 RMS 标准化（移除 `clamp_min(1e-6)` 截断失衡，按样本 `grad_z / grad_z.std().clamp_min(1e-12)` 标准化）并对 `RegionalCorrectionNet.out_conv` 使用 `std=0.02` 非零小初始化，确保真实梯度注入；
   - 或直接采用 **高阶多步高质轨迹 (`s135–s150` 风格质感) 与高内容构图分离的直接回归/对齐** 解决 `C ≈ 0.45–0.62` 区间灰阶锁死问题。

# CLEAVE V34 实验报告：解析起点重构、连续风格条件、联合扩容与独立留出集复验

> **结论摘要**：保持 **Zero-DINO（全流程禁用 DINOv2）**、**S10 解码** 与完整 **test750** 协议及独立 **holdout-300（150 留出源图 × 5 画派 = 750 盲测任务）** 验证，V34 明确厘清了四阶段边界：
> 1. **Stage A（解析起点 $P_Y z_E = L_{\rm low} + L_{\rm high}$，0.15h 零训练）正收益成立**：在 `P_Y` 主方向 $u_y$ 上联合重分布低频亮度矩 $L_{\rm low}$ 与色度 $P_C$（`A3`）同时提升内容与风格，冻结 V32 上 `s100` 点从 `(0.4896 C / 0.5629 S)` 推至 **`(0.5076 C / 0.5725 S)`**（`DINO-C +0.0180`、`DINO-S +0.0096`），`Minimalism` `DINO-S` 提升 **`+0.0303`**、Oklab 色度 `+20.6%`。
> 2. **Stage B（连续风格条件，~2.1h）响应成立但前沿判负**：实例级 `417-D`（`B1`）与加多尺度纹理 `1101-D`（`B2`）将同内容风格响应度提高 **4.0×～4.8×**（色彩偏移 **9.1×**、中点线性度 `0.5315`），但场景加权凸组合会平均锐度，同内容前沿比 $K=8$ 离散对照 `B0` 低 `-0.0128 DINO-S`（按门控**不并入** Stage D）。
> 3. **Stage C（2×2 联合训练与容量扩容，~3.2h）揭示主因**：`V33 S2` 32×32 控制即使联合训练仍压低前沿（22M 上 `C1-C0 = -0.0137 S` @ `C=0.61`，44M 上 `C3-C2 = -0.0159 S`）；而**仅将主干扩容至 `44.54M + Q32`（`C2_44m_q32`）** 在强风格与匹配内容下取得显著跃升（`C=0.50` 下 `Top-1 +5.11pp`，`s150` 达 **`91.17% Top-1 / 0.5890 S`**，`tau0=0` 无草稿达 **`73.67% Top-1 / 0.5925 S`**）。
> 4. **Stage D 合并对照与独立留出集复验**：`44.54M C2 + A3 解析起点` 在 `test750` 上全面刷新 Zero-DINO Pareto 前沿（在固定 $C \in \{0.50, 0.61, 0.70\}$ 下分别达到 `DINO-S = 0.5709 / 0.5388 / 0.5010`，超越 `V32` **`+0.0111 / +0.0150 / +0.0202`**，`Top-1 = 76.29% / 62.57% / 53.65%`）；在完全未见 **`holdout-750`** 盲测上，相比 `V32` 在 `s085` 显著领先 **`+0.0044 DINO-S`（95% CI `[+0.0016, +0.0073]`）、`+5.00pp Top-1`**，在 `s100` 领先 **`+0.0246 DINO-C`（`[+0.0197, +0.0296]`）、`+6.67pp Top-1`**（`92.7%` Same-150）。同时消融发现：用 $(z_1 - z_{\rm start})/(1-\tau_0)$ 做 `A3` 桥接回归重训（`D_merged_winner`）会因 $\frac{1}{1-\tau_0}$ 放大残差方差（`phuber` `0.82 -> 1.25`）而损失分类锐度（`Top-1` 降 `13~17pp`），应在保持干净流匹配目标的前提下于推理/低方差增强中使用 `A3`。

> **为什么桥接方差重训 `D_merged_winner` 输给纯净 `C2_44m + A3`？**
> 在 `D_merged_winner` 的 35% 样本中，目标速度被替换为 $(z_1 - z_{\rm start}) / (1 - \tau_0)$。由于 $\tau_0 \in [0.60, 0.80]$（$1 - \tau_0$ 最小 `0.20`），跨图 E-Core 草稿与目标 $z_1$ 的残差被放大 **3×～5×**（训练后期 `phuber` 停在 `1.2507`，而干净 `C2_44m_q32` 降至 `0.82` 水平），导致条件速度场在高风格频段变得模糊、判别力下降（`Top-1` 与 `Same150` 同步回退）。相比之下，`C2_44m + A3` 同时在 **`test750` 与独立 `holdout-750`** 上保持全曲线严格占优且零崩塌。

- **`batch = 1`**：`107.56 ms / img`（**`9.3 img/s`**）
- **`batch = 16`**：`68.74 ms / img`（**`14.5 img/s`**）
（注：阶段 A3 在 E-Core 输出后仅对 $4 \times 64 \times 64$ 潜变量做单次可分离 `19×19` 高斯分解与矩仿射变换，额外算力开销 $< 0.3\text{ ms}$。）

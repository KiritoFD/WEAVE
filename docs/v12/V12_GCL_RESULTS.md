## TL;DR

1. **五个 GCL 臂的指标与 LD4 几乎无差异**（Top-1 −1pp 基线 / −2pp 强预算，LPIPS
   ±0.003）；三个不同 Query 闸门（Haar/关系/旧 selfsim）产生**逐位一致**的结果——
   **闸门从未 binding**。
2. 遥测实锤：候选的 Query 成本全部远低于预算（G1 max 0.0053 vs B 0.0274；
   G2 max 0.0011 vs B 0.0021；G2O max 0.092 vs B 0.167），且
   **cos(风格方向, grad L_Q) ≈ +0.09~+0.15**——LD4 的风格编辑与内容 Query 梯度
   **近乎正交**：风格方向本来就不怎么动内容结构。
3. **强预算臂显著变差**（G0S/G2S：Top-1 −2.0pp*，LPIPS +0.0028*）——eps=0.10 已在
   甜点之外，扩预算无风格收益纯添内容损伤。
4. **按计划 §7 决策树第一分支结案**："当前 LD4 内容保护已经足够；若风格仍受限，
   回到风格表示，而不是继续堆内容正则。" —— 与 V10.2/V11 的结论（表示/方向问题）
   完全一致，三角互证。

## 机理：为什么闸门不 binding

**cos(风格方向, ∇L_Q) = +0.085 ~ +0.148（近乎正交）**。LD4 的候选更新（R1 预条件
方向 + 局部能量方向的混合）在内容 Query 空间里的投影极小——一阶近似下，风格编辑
本来就几乎不改变 Haar/关系/自相似结构。

这解释了两个现象：
1. 三个不同 Q 闸门接受完全相同的候选集合（闸门过滤的都是 proxy 已拒绝的候选）；
2. 强预算臂（eps .10→.14）只带来内容损伤（Top-1/LPIPS 恶化），因为 LD4 的
   proxy 验收在更大预算下接受了更多**低质量**候选，而风格方向本身没有更多
   可提取的增益。

**结论：内容保护不是当前风格增益的瓶颈。瓶颈在风格方向本身**
（与 V10.2 特异性为零、V11 密度方向为零的发现三角互证）。

## 与预注册的偏差（全部记录）

1. **B_Q 规则修正**：外观 p90 与几何 p10 相差 78×（关系 Q），按预注册的外观 p90

   已在 `calibrate.py` 注记。修正后闸门依然不 binding——结论不依赖该修正。
2. **Q 闸门锚定修正**：源图锚定的预算低于 B4/N2C 已有的风格化距离 2.2×（
   Q(z_n2, z_src)=.061 vs B=.027），会拒绝一切候选 → 改为 **z_0 锚定**
   （"不新增结构损伤"语义），源图距离进遥测。修正后闸门仍不 binding。

   （计划 §3-G5 已预置保守回退）。

## 决策（按计划 §7）

- **GCL 线关闭**。不再投入 Haar/关系/自相似/学习式内容正则——它们在当前管线中
  均 not binding。
- **eps=0.10 保持**；强预算臂已证明有害。
- **风格增益的瓶颈在风格方向**：剩余可行路线 = (a) V11 已证明的表示问题（学习式
  笔触表示 + 判别式目标）；(b) R1 的 margin↔真实错位问题（判别器域升级）。
  两者都需要新的预注册，且不应再投入"内容正则"方向。

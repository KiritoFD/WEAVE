## 三、V24 P1–P2（4090）：`M3 / M4` 0.99M 双路径残差与动态预算（第 1 版诊断）

从冻结 `PRISM-1` 起步，接入 `0.99M` `PaletteTextureResidualNet`（`Oklab 27D` + `MultiScalePatchSWD` 纹理分布 + `ConvNeXt` 中尺度对齐）：
- 训练过程：`M4` 动态拉格朗日预算顺利自适应将 `lam_c` 从 `1.00 → 0.32` 释放给风格优化（`style: 0.455 → 0.268`）。
- 评测（Cross600）：
  - `M3_res_s075`: `DINO-C=0.7147 / DINO-S=0.4557 / LPIPS=0.5446 / Top1=29.83%`
  - `M4_res_s075`: `DINO-C=0.7055 / DINO-S=0.4621 / LPIPS=0.5432 / Top1=32.67%`（同强度下相比固定 `M3` 风格更强 `+2.84pp Top1, +0.0064 DINO-S`）
- **失败诊断（未达 `≥0.473 @ ≥0.73` 验收线）**：
  直接用 1 步常规卷积去拟合任意单张参考图 `Patch-SWD`（而无洁净目标画派结构引导，且训练期 `z0_c` 采用了高斯模糊替代 `n2c_z.pt`）导致网络往图像中注入高频噪声（LPIPS 从 `0.505` 升至 `0.543`），且弱化了目标画派的辨识力（Top1 `44.3% → 32.7%`）。下一步改用 **无伪影 `V20 D6` 洁净风格增量引导 + 紧致动态内容预算 (`M5`)** 纠正这一噪声问题。

三、真正可以填补的五项空白
空白1：从“整场景精扫”转向“整建筑LR + 原位局部HR”
这是数据采集方式上的区别。

现有ScanNet++可以理解为：
\[
\text{室内场景高精扫描}\rightarrow\text{获得几何GT}
\]

我们希望是：
\[
\boxed{
\text{独立全建筑LR扫描}
+
\text{独立原位HR构件扫描}
}
\]

两套设备不同、工作距离不同、有效分辨率不同，甚至原始坐标系也不同。

例如：
层级	覆盖范围	建议精度目标
全局LR	10–100 m级的整栋建筑	毫米至厘米级
局部HR	10 cm–2 m级的真实构件	0.1–0.5 mm级
跨尺度位姿	构件相对于建筑	单独验收，目标可先设1–5 mm

这些是拟定采集指标，不是现有设备的保证精度。

其价值不只是分辨率跨度，而是保存真实传感器采样、遮挡和噪声差异。

下采样HR得到LR的实验，可以作为受控消融；但不能替代真实LR扫描。
空白2：真正固定在建筑上的高精构件GT
ADT和HILO都采用独立物体扫描，但它们主要面对可移动物体。

我们的雕刻具有不同性质：
- 脊兽固定于屋脊，无法为扫描而任意翻转。
- 木雕、斗拱可能与梁柱连续连接。
- 浮雕根本未必具有可独立分割的闭合表面。
- 扫描存在脚手架、屋檐、邻近结构等真实遮挡。
这会产生一个新问题：

真实HR-GT可能只是开放的、部分可观测的表面，而不是一份闭合、完整的物体Mesh。

所以数据集应同时提供实测有效区域和未观测区域，严格区分实测细节与算法补洞。

这一点对文物真实性特别重要。
空白3：独立HR扫描到整栋建筑的公制位姿GT
这是最有研究价值、也最容易做不扎实的一项。

已有ADT证明物体级6DoF标注并不新；我们的贡献应当是更大空间尺度、跨设备分辨率，以及经过独立测量验收的固定构件位姿。

每个样本需要：
\[
\boxed{
(M_{\mathrm{HR}}^{local},
T_{\mathrm{HR}\rightarrow\mathrm{Global}},
\Sigma_T)
}
\]

其中：
- \(M_{\mathrm{HR}}^{local}\)：独立扫描的HR几何。
- \(T\)：放回建筑的公制刚性变换。
- \(\Sigma_T\)：位姿不确定度，至少应有独立检验误差记录。
尤其需要警惕：扫描仪标称0.1 mm精度，不代表构件在全局建筑中的位置也精确到0.1 mm。

如果GT位姿本身只有3 mm精度，我们就不能对预测模型宣称0.2 mm的全局定位精度。
空白4：面向局部高精重建，而不是NVS或语义分割的Benchmark
现有大型场景数据集的官方评价主要集中于：
数据集	主要原生任务
ScanNet++	NVS、语义分割、实例理解
CULTURE3D	大规模三维重建与Gaussian Splatting
ArCH	文化遗产点云语义分割
ARKitScenes	3D检测、深度上采样
ETH3D	MVS几何准确率与完整率

ScanNet++官方NVS评价仍主要报告PSNR、SSIM、LPIPS；ArCH发布的遗产点云主要用于语义分割，且其公开预处理版本通常已降采样到约1–1.5 cm点距。
scannetpp.mlsg.cit.tum.de+1


而我们的核心任务是：
\[
\boxed{
S_{\mathrm{LR}}^{Global}
+
Range
+
I_{\mathrm{local}}
\longrightarrow
M_{\mathrm{HR}}^{Local}
+
T_{\mathrm{placement}}
}
\]

GT来自独立实测激光扫描，而不是照片渲染结果。

这可以直接测量已有粗建筑几何究竟能使局部3D重建精度提升多少。
空白5：局部回填和非目标区域保持的联合评价
这也是现有纯MVS Benchmark通常没有完整评价的部分。

我们的HR输出不仅需要和GT接近，还要能放回原始建筑。

因此应该形成三张独立榜单：
榜单	评价内容	关键指标
Geometry	局部HR恢复是否准确	Surface RMSE、P95、Normal Error、F-score
Placement	在原建筑中的位置是否准确	平移误差、旋转误差、World-space几何误差
Integration	是否正确接合、破坏其他结构	接缝误差、误删面积、非目标几何保持

Integration中，非目标区域可以通过只读原Mesh和实例化回填实现硬性不修改。但仍须检查错误遮挡、穿插及误删邻近构件。

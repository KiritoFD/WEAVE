# V11 P3：五风格无条件生成能力（结果）

**目的**：回答 V10/V11 一直混在一起的两个问题中的第一个——
**共享模型能否从噪声生成五种风格？**
**设置**：pivot 模式（$F_s:\mathcal N(0,I)\to p_s$，共享网络、仅风格条件不同），
从零训练 4000 等效步，Batch512，`patch8`，SD-VAE `4×64×64`。
每风格无条件采样 100 张，4-step Heun，EMA 权重。
**训练**：704 s（0.176 s/update），峰值 3958 MiB，曝光 4,096,000 端点。
**对照上界**：真实图上的 CSD style Top-1 ≈ **0.98**（见 `V11_METRICS.md`）。

---

## 2. 最重要的发现：失败风格与跨域运输完全一致

**无条件生成失败的三个风格，正是跨域运输失败的三个风格：**

| 风格 | 无条件生成 style Top-1 | 跨域运输 Top-1（P1 四组） |
|---|---:|---:|
| Early_Renaissance | **0.000** | 0.025 – 0.075 |
| **Rococo** | **0.000** | **0.000（四组全部）** |
| **Ukiyo_e** | **0.000** | **0.000（四组全部）** |
| Impressionism | 0.410 | 0.200 – 0.425 |
| Minimalism | 0.670 | 0.000 – 0.200 |

**这不是巧合。** 一个模型如果连"无条件生成 Rococo"都做不到，
那么"把某张图变成 Rococo"自然也不可能成功——后者是前者的子问题。

### Rococo 的 own score 只有 0.0388

`own_score` 是生成图与**其声明风格原型**的余弦相似度。
Rococo 只有 **0.0388**（真实图约 0.2–0.3 量级），Margin **−0.1976**。

**这意味着生成的"Rococo"不是"风格错了"，而是"几乎没有风格"**——
既不像 Rococo，也不像任何一个原型。典型的模糊/平均图像。

### 多样性比 0.30–0.50，比跨域臂严重得多

| | 多样性比 |
|---|---:|
| 真实参考 | 1.000 |
| 跨域臂（P1 四组） | 0.751 – 0.862 |
| **无条件生成（P3）** | **0.297 – 0.501** |

无条件生成出现**严重模式塌缩**：模型只覆盖了每个风格分布的一小片区域。
这解释了为什么 own score 低——塌缩到一个"最安全"的模糊区域。

## 3. 必须承认的两个混淆（不能直接归因于容量）

### 3.1 每个配对的曝光量只有跨域臂的一半

| | 配对数 | 每次更新每对样本 | 4000 步每对曝光 |
|---|---:|---:|---:|
| 跨域臂（P1） | 10 | ~51 | **~409,600** |
| **P3（pivot）** | **5** | **~102** | **~204,000** |

pivot 模式只有 5 个配对（风格↔高斯先验），所以**每个配对的曝光量减半**。
P3 的训练不足有一部分来自这里，不完全是容量。

### 3.2 4000 步对无条件图像生成极少

无条件生成一个图像分布通常需要**十万量级**的更新。
4000 步（B512）对"学会生成 Rococo"来说几乎可以肯定是不够的。

**因此本结果确立的是**：
> 在 4000 等效步预算下，共享模型无法无条件生成 ER / Rococo / Ukiyo_e。

**它没有确立**：
> 模型容量不足 / 潜空间表征不足。

**预算与容量尚未分离。**

---

## 4. 判定与决策

按 `V11_IMPLEMENTATION_PLAN.md` 的 P3 判定分支：

| 分支 | 结果 |
|---|---|
| 五种都能生成 | ❌ |
| 都不能生成 | ❌（Minimalism 67%、Impressionism 42% 部分可生成） |
| **部分可生成，其余失败** | ✅ **命中** |

**结论**：问题**同时**涉及
- 目标分布建模（对 ER / Rococo / Ukiyo_e：完全无法生成）
- 内容条件（对 Imp / Minimalism：能生成，但跨域运输仍拿不到正 ΔT）

### 因此的决策

1. **不能**进入 P4（内容约束运输）——对三个失败风格，运输的上游能力还不存在。
2. **必须先做**：把预算与容量分离。唯一决定性实验是**延长 P3 训练**。
3. 若延长后 ER / Rococo / Ukiyo_e 仍然为 0 → 是容量/表征问题
   （7.58M 共享 DiT 或 `4×64×64` 潜空间），需要换模型或换表征。
4. 若延长后显著上升 → 之前的跨域失败主要是**预算不足**，P4 才有意义。

## 5. 复现

```bash
# 训练（4000 等效步，约 12 分钟）
python3 -m sbflow.train5 --config configs/v11/p3.json --caches <5 个缓存>
# 无条件采样（每风格 100 张）
python3 -m sbflow.gen_uncond --ckpt runs/blog_sbflow/v11/p3/model_equiv4000.pt \
    --out runs/blog_sbflow/v11/p3_gen --per-style 100 --weights ema
# 打分（含多样性守卫与真实上界判读）
python3 -m sbflow.score_uncond --gen runs/blog_sbflow/v11/p3_gen \
    --out runs/blog_sbflow/v11/p3_score
```

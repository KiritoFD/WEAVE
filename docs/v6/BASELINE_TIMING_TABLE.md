**同口径结论**：
- 最快的是 `Latent-WCT 3.67 min`（293.6 ms/img? 不，3.67 min/750 = **293.6 ms/img**——注意 3.67 min 是 750 图总时长，换算后 293.6 ms/img，而 WEAVE 1.22 min = 97.6 ms/img）；

- **主表里已报时间的方法中最快的是 WEAVE 官方（97.6 ms/img）**；本轮新 S10 整条拼接估计 `18.7 + 27.08 = 45.78 ms/img`，约为它的 **2.13×**（不同源，见口径说明）。
- 但这是**拼接估计**（论文 enc+WEAVE 段 18.7 + 本轮 TRT S10 decoder 27.08），不是端到端重测；且论文 baseline 的 Infer 是各自完整方法在 3060 上的总时长，与「只换 Decoder」不完全同类，解读需谨慎。

## 关键口径说明

1. **同口径**：12 个 baseline 与 WEAVE 官方的 Infer 都来自 `paper.tex` 主表同一列、同一硬件（RTX 3060）、同一 750 图输出、单位分钟 —— 彼此严格可比。
2. **本轮新 S10 的时间不同源**：decoder 段是 3060 WSL + TensorRT 11.4 + FP16 b8 + CUDA Event 实测（27.08 ms/img）；整条 45.78 ms/img 是拼接论文 enc+WEAVE 段得来，**不能当作与 baseline 完全同口径的端到端实测**。
3. **论文主表 WEAVE `1.4/1.22`**：1.4 min 训练、1.22 min 推理（750 图）；supplement 的 `73.0 s = 97.3 ms/img` 是同一数字的 audited 复测。
4. **Ours 的 V6/Q2A/ScoreDiff 系列在榜单里没有时间**：`UNIFIED_FULL_RANKING.md` 只有质量指标，没有这些配置的 Infer；主表也只报 WEAVE 一个 Ours 行。所以「把时间维度加到总表」只能加到主表覆盖的 12 个 baseline + WEAVE，其余留空。
5. **TRT decoder 段实测对照**（同 3060 / b8 / fp16）：官方 49.49M = 73.34 ms/img，新 S10 = 27.08 ms/img，**2.71×**（`deliver/s10_trt_b8_bench.json`）。

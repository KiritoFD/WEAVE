# 三项决定性测试报告（A 可读取性 / B 方向一致性 / C 真实编辑）

> 日期：2026-11-09  
> 冻结 B0 / A0 Encoder，无 VAE 重训  
> 训练集 8,944 张（136 类全覆盖）| 独立验证集 2,048 张 | 内容匹配对 1,000 组（DINOv2，gap=0.0014）  
> 产物：`C_editing.json`、`blind_images/`（16 组盲评图）

---

## 一句话结论

**风格方向在原始 latent 中是「可复现」的（B：cos=0.63），但「无编辑功能」的（C：效果不如随机方向）。**
可复现 ≠ 可编辑。这是本轮最重要的发现。

---

## 测试 A：风格可读取性（冻结 Encoder + 线性/CNN Probe）

| 模型 | Probe | 136类 Top-1 | Top-5 | Cross-Artist | Same-Genre Hard | **Content-Matched** |
|---|---|---:|---:|---:|---:|---:|
| B0 | LinearProbe (16384→136) | 2.39% | 10.64% | 53.54 | 49.06 | **50.67** |
| B0 | SmallCNN | **7.86%** | 31.98% | **61.43** | 54.46 | **53.76** |
| A0 | LinearProbe (16384→136) | 4.25% | 13.77% | 53.88 | 49.44 | **51.52** |
| A0 | SmallCNN | **7.37%** | 31.30% | **61.40** | 54.15 | **53.39** |

随机基线 = 1/136 = **0.735%**

### 读数

1. **风格信息确实存在，且需要非线性才能读出**：
   - 线性 Probe 只有 2.4~4.3%（3~6× 随机）→ 线性不可读；
   - SmallCNN 达 7.4~7.9%（**10~11× 随机**）→ 非线性可读。
   - **Cross-Artist AUROC：线性 53.5% → SmallCNN 61.4%（+7.9pp）**，这是目前为止所有 latent 表示中最好的成绩（远超无参数 Pool8×8 的 54.6%）。

2. **但内容匹配后仍只有 53.4~53.8%（≈随机）**：
   - 即便用 SmallCNN 学到的最强非线性表征，一旦控制题材，风格可分性回到随机。
   - 说明 latent 中可读的「风格信号」**主要与题材/画家身份共线**。

3. **A0 vs B0 几乎无差异**（61.40 vs 61.43）→ 重建+KL 后训练没有改变 latent 的风格可读性结构。

---

## 测试 B：风格方向一致性（两组独立、画家不相交的参考集）

对每个风格对 $(s,t)$，用**两组画家互斥的参考图**独立估计：
$$\delta^{(1)}_{s\to t}=\bar z^{(1)}_t-\bar z^{(1)}_s,\qquad \delta^{(2)}_{s\to t}=\bar z^{(2)}_t-\bar z^{(2)}_s$$

| 比较 | B0 | A0 | 含义 |
|---|---:|---:|---|
| **同一转移，两组独立参考** $\cos(\delta^{(1)},\delta^{(2)})$ | **0.6264** | **0.6251** | **高** |
| 　median | 0.6747 | 0.6741 | |
| 　IQR | [0.494, 0.803] | [0.490, 0.803] | |
| 同一目标，不同源 $\cos(\delta_{s_1\to t},\delta_{s_2\to t})$ | 0.3436 | 0.3438 | 中低 |
| 同一源，不同目标 $\cos(\delta_{s\to t_1},\delta_{s\to t_2})$ | 0.3935 | 0.3924 | 中低 |

### 读数

1. **同一转移方向高度可复现（0.626，中位数 0.675）**：
   用完全不同的画家作品独立估计，得到的方向余弦达 0.63。这**排除了「方向纯粹是噪声」的可能**——latent 中确实存在与风格转移对应的稳定位移。

2. **但不能分解为「通用目标向量 + 通用源向量」**：
   - 同目标不同源只有 0.344；
   - 同源不同目标只有 0.394。
   - 二者都远低于完整转移的 0.626，说明 $\delta_{s\to t}$ 是一个**真正的成对向量**，不能拆成「某种风格的绝对坐标」。

3. **B0 与 A0 几乎完全相同**（0.6264 vs 0.6251）→ 后训练未改变这个结构。

## 测试 C：真实编辑能力（用 B 的方向，不是 CSD 图像梯度）

方向定义：$\hat\delta = \dfrac{\bar z_t - \bar z_s}{\lVert \bar z_t-\bar z_s\rVert}$，**源图自身从其风格质心中剔除**（无泄漏）。24 组任务，33 个可用风格。

| 方向 | 扰动 | **ΔT_CSD** | 正增益率 | ΔT_ALADIN | 正增益率 | LPIPS |
|---|---:|---:|---:|---:|---:|---:|
| **数据方向**（质心差） | 0.02 | 0.0005 | 58.3% | 0.0025 | 66.7% | 0.0012 |
| | 0.05 | 0.0015 | 62.5% | 0.0086 | 75.0% | 0.0067 |
| | 0.10 | **0.0034** | 58.3% | 0.0214 | 75.0% | 0.0229 |
| **随机方向** | 0.02 | 0.0012 | 54.2% | 0.0013 | 41.7% | 0.0032 |
| | 0.05 | 0.0069 | 50.0% | 0.0118 | 62.5% | 0.0149 |
| | 0.10 | **0.0159** | 58.3% | 0.0286 | 70.8% | 0.0459 |
| **CSD 图像梯度** | 0.02 | **0.0996** | **100.0%** | 0.0135 | 87.5% | 0.0056 |
| | 0.05 | **0.1479** | **100.0%** | 0.0214 | 79.2% | 0.0256 |
| | 0.10 | **0.1706** | 95.8% | 0.0213 | 75.0% | 0.0688 |

### 决定性读数

1. **数据方向比随机方向还差**：
   - 0.10 档：数据方向 ΔT_CSD = **0.0034**，随机方向 = **0.0159**（随机是它的 **4.7 倍**）；
   - 正增益率 58~63% ≈ 抛硬币。
   - **「质心差方向」不仅无效，还有害。**

2. **只有 CSD 图像梯度有效**：
   - 0.0996 / 0.1479 / 0.1706，正向率 96~100%；
   - 比数据方向强 **30~50 倍**，比随机强 **10~60 倍**。
   - 但这是**循环论证**（用 CSD 梯度优化 CSD 目标），且依赖**逐图、逐目标的梯度计算**，不是可复用的固定向量。

3. **ALADIN 无法区分三种方向**：
   - 0.10 档：数据 0.0214 / 随机 0.0286 / CSD 0.0213 —— **随机最高**；
   - 说明 ALADIN 的增益只随扰动幅度增长，与方向无关。**独立指标不能确认任何方向的特异性。**

4. **盲评视觉确认：四个面板肉眼无法区分**。
   见 `blind_images/blind_00_key_rand-noop-grad-data.jpg`（顺序：随机 / no-op / CSD梯度 / 数据方向）——在 0.05 档，四张图几乎完全一致。

## 三项测试合起来的结论

| 问题 | 答案 | 证据 |
|---|---|---|
| 风格信息在 latent 中吗？ | **在，但弱且被内容污染** | A：SmallCNN 7.9% top1（11× 随机），但内容匹配 53.8% |
| 线性可读吗？ | **不可读** | A：线性 Probe 2.4~4.3% |
| 风格方向稳定吗？ | **可复现（0.63）** | B：独立画家参考集给出 cos=0.626 |
| 可分解为通用风格轴吗？ | **不能** | B：同目标 0.344、同源 0.394，均远低于 0.626 |
| 该方向能真实编辑吗？ | **不能，比随机还差** | C：ΔT_CSD 0.0034 vs 随机 0.0159 |
| Decoder 能响应吗？ | **能，但只对逐图梯度** | C：CSD 梯度 ΔT 0.17，正向率 96~100% |

### 核心矛盾：可复现 ≠ 可编辑

- B 证明：**同一风格对的质心位移方向在不同画家作品上高度一致（0.63）**；
- C 证明：**沿这个一致方向移动，完全不产生目标风格变化，甚至不如随机**。

**解释**：质心差捕获的是两个风格群体之间**均值外观差**（色调、笔触粗细、构图倾向、画家身份），这些量在 latent 中一致但**解码器不把它们映射为「画风」**。真正驱动可见画风变化的方向，只有**逐图、逐目标、依赖当前内容的梯度方向**。

**这意味着：风格迁移不是 latent 空间中的固定平移。** 它要么需要逐图优化（成本高、且目标依赖 CSD 本身），要么需要一个**学习到的条件传输**——即一个真正的下游编辑器。这为「必须训练下游模型（如 ScoreDiff）」提供了直接证据，而不是继续在 VAE latent 里寻找可复用的风格向量。

## 对 Style-REPA 的判断

| 判据 | 结果 |
|---|---|
| latent 是否有风格结构可被蒸馏？ | 有，但非线性、且被内容主导（A） |
| 蒸馏能否产出可复用风格方向？ | 结构上可复现（B），但功能上无效（C） |
| 继续投入 Style-REPA 的理由 | **减弱**。即便蒸馏成功，得到的方向也可能像 C 中的质心差一样——一致但不可用。 |

**建议**：在把更多算力投到「让 latent 对齐教师几何」之前，先接受一个事实——**latent 几何变好（AUROC 上升）不等于可编辑性变好**。C 测试已经给出反例：方向一致性 0.63 却零编辑效果。

如果要继续，必须先确立一个**能同时通过 A（内容匹配后可读）与 C（数据方向真能编辑）的门槛**，否则任何「latent 对齐」都可能只是在优化一个与生成无关的度量。

---

## 限制说明

1. C 只用了 33 个可用风格（验证集中 ≥10 张者）、24 组任务，样本量偏小；但数据方向 vs 随机方向差 4.7 倍的结论方向明确。
2. C 的方向来自验证集质心，虽然剔除了源图本身，仍属「同分布估计」，跨数据集泛化未测。
3. ALADIN 在本数据上同题材 AUROC 仅 53.6%，作为独立裁判的判别力本身有限，其「无差异」结论需谨慎。
4. 盲评图为 16 组，非全部 24 组。

## 三、发现并修正的三个 bug

### 1. `post_quant_conv` 被跳过（影响全部早期训练）

`AutoencoderKL.decode()` = `post_quant_conv(z) → decoder`。早期所有 decoder-only 脚本直接调 `decoder(z)`。用错误路径测 A0 自己：**PSNR 5.34 / SSIM 0.013**（正确路径 29.05 / 0.812）。已加 `StudentDecoder` 包装器，训练/评测/校准三处全部改正。

后续在 `exp_p3_final_eval.py` 与 `exp_l0_latent_direction.py` 中又各出现一次**双重应用**（`vae.decode(pqc(z))` 或对 `StudentDecoder` 再手动 `pqc`），均已修正。

### 2. 训练集与测试集泄漏（影响 P0/P1）

`RawMemmapWikiArtDataset(is_training=True)` 只按 `raw_index not in val_indices` 过滤，**忽略 `in_train` 标志**：

```
total records 102,255 | in_train 78,661 | in_train=False 23,594
dataset(is_training=True) = 100,207  → 泄漏 21,546 张测试图
已有 12,991 缓存中 2,640 张（20.3%）是泄漏测试图
```

**对已有结论的影响**：评测用的 2,048 holdout 全部来自 `in_train=False` 且被 `val_indices` 排除，训练从未见过，所以所有报告的指标都是在真正未见数据上测的。但训练池不干净。

P2 已改用显式过滤的 **78,661** 张，并做完整校验：

```
[Split] 无重复、无 val 重叠
[Shards] problem shards: 0（无全零行、无 NaN/Inf）
[Verify] re-encode cos(cached, fresh): min=0.99998 mean=0.99999
```

### 3. 变量遮蔽导致 P2 崩溃

平台早停块里写 `dl = abs(...)`，把 DataLoader 变量 `dl` 覆盖为 float。第 1 个 epoch 边界（78,661/64 ≈ 1,229 步）触发 `StopIteration` 时崩溃，且阶段末才存盘 → 1200 步权重全丢。已改名 `dlp`，并加每 250 步的 `decoder_partial.pt` 保险。

## 四、P4-L0：latent 风格方向是否可复用

用**内容匹配、不同风格的真实图像对**构造 `Δz = E(x_t) − E(x_s)`（不是质心差），在 A0 解码下测量，排除 decoder 混淆。

### Q1 可复现性：同一风格对不同内容对的 Δz 是否一致

| 风格对 | cos |
|---|---:|
| Impressionism → Rococo | **+0.617** |
| Minimalism → Rococo | +0.414 |
| Impressionism → Minimalism | **+0.036**（≈随机） |

mean +0.356 / median +0.414。**部分可复现，但风格对之间差异极大。**

### Q2 可迁移性：在内容对 #1 上估的 Δz 能否推动另一张同风格源图

`spec = dS(style dir) − dS(随机同范数方向)`

| 风格对 | frac | dS | dS_rand | **spec** |
|---|---:|---:|---:|---:|
| **Minimalism → Rococo** | 0.20 | +0.0308 | −0.0348 | **+0.0656** |
| Minimalism → Rococo | 0.10 | +0.0130 | −0.0154 | +0.0284 |
| Rococo → Minimalism | 0.20 | −0.0053 | −0.0230 | +0.0178 |
| Impressionism → Rococo | 0.20 | −0.0089 | −0.0248 | +0.0160 |
| … | | | | |
| **Rococo → Impressionism** | 0.20 | +0.0594 | **+0.1314** | **−0.0720** |
| Minimalism → Impressionism | 0.20 | +0.0761 | +0.0919 | −0.0158 |

总体：**mean −0.0003 / median +0.0013 / frac>0 = 55.6%**（等同抛硬币）。

### 结论

1. **latent 里确实存在可迁移的风格成分**，但只在部分风格对上有（Minimalism→Rococo 达 +0.066，且方向可复现 cos 0.414）。
2. **系统性失败于 `→Impressionism`**：随机方向推向 Impressionism 的 CSD 增益（+0.131）比真实方向（+0.059）还大。这说明**问题不在方向本身，而在 Impressionism 的 CSD 目标向量不具判别性**——它接近"任何扰动"的共同方向。
3. 因此**不能笼统地说"风格方向无效"**。正确的表述是：**方向在风格对上有选择性，而 CSD 作为风格判官对部分风格（尤其 Impressionism）缺乏判别力。**

这修正了此前"specificity ≈ 0，方向完全无效"的结论——那个结论部分来自被 bug 破坏的扰动幅度（`norm(dim=1)` 返回逐像素范数而非逐样本范数，使扰动小了 400 倍）。

## 四补、CSD 作为风格判官的有效性诊断

L0 中 `→Impressionism` 的 specificity 为负，需要确认是「方向无效」还是「度量被混淆」。

| 风格 | D1 自一致性 cos | **D2 最近质心准确率** | D3 随机扰动增益 @0.05 / 0.10 / 0.20 |
|---|---:|---:|---|
| Impressionism | 0.5435 | 97.5% | **+0.0104 / +0.0359 / +0.0826** |
| Minimalism | 0.6737 | 100.0% | −0.0036 / −0.0134 / −0.0408 |
| Rococo | 0.6019 | 97.5% | −0.0031 / −0.0160 / −0.0643 |

（测试集仅 3 个风格有足够样本；Early_Renaissance / Ukiyo_e 在测试划分中不足 10 张。）

### 结论

1. **CSD 是有效的风格分类器**：最近质心准确率 **98.3%**（随机 33.3%），自一致性 0.54–0.67。
2. **但随机扰动对 Impressionism 的 CSD 增益为正且随幅度增长**（+0.083 @20%），对 Minimalism / Rococo 为负。
   说明 **Impressionism 的 CSD 质心接近"通用/平均"方向**：任何把 CSD 推离 Minimalism/Rococo 的扰动都会顺带推向 Impressionism。
3. **因此 `csd_keep`（自相似度）是有效指标**——它衡量输出是否保持**原图自身**的风格，不受该偏差影响。**S10 的 0.853 vs A0 0.916 是真实差距。**
4. **但"CSD 目标相似度"不能用作风格迁移方向的度量**（至少对 Impressionism）：随机扰动也会让它上升。这解释了 L0 的负 specificity，**不是 latent 方向无效，而是度量被混淆。**

### 对后续工作的要求

任何"是否成功迁移到风格 t"的评测，必须同时报告**同范数随机方向对照**，并对 `t = Impressionism` 这类质心接近通用方向的风格使用**成对判别**（例如在 {t, 随机} 二选一中强制排序），而不是绝对相似度。

## 四补二、L0 的无混淆复核：方向不成立

用**最近质心分类**（真实图上 96–100% 准确）替代绝对目标相似度，做同范数成对判别：

```
pair                                  frac  P(style)  P(rand)    delta
Minimalism->Rococo                    0.10     0.000    0.000   +0.000
Minimalism->Rococo                    0.20     0.000    0.000   +0.000
Impressionism->Rococo                 0.20     0.000    0.000   +0.000
Rococo->Impressionism                 0.20     0.043    0.130   -0.087
overall delta: mean=-0.0036  median=+0.0000  frac>0=8.3%
```

**L0 中 `Minimalism→Rococo` 的 +0.066 绝对 CSD 增益在分类检验下完全不存活**（P(style)=0.000）：它只是 CSD 特征空间里的小位移，没有跨过风格判别边界。

**结论：不存在可迁移的 latent 风格方向。** 这是用无混淆度量得到的稳健负面结果。

## 四补三、风格在 latent 中是否可分离（决定性诊断）

按方案「如果 L0 仍然失败，应先分析跨内容的风格差异能否被稳定分离」，在冻结 latent 上做线性探针（107 个风格、14,859 张、分层 80/20 划分、随机基线 0.93%）：

| 表示 | 维度 | 测试准确率 | 训练准确率 | 相对随机 |
|---|---:|---:|---:|---:|
| **A0 latent 4×64×64** | 16384 | **10.51%** | 100.00% | 11.3× |
| **A0 latent + PCA-256** | 256 | **9.38%** | 29.04% | 10.1× |
| 原始像素 64×64 | 12288 | 7.01% | 88.23% | 7.5× |
| **CSD 图像特征** | 768 | **55.91%** | 77.34% | **60.1×** |
| CSD + PCA-256 | 256 | 53.24% | 67.28% | 57.2× |

原始 16384 维探针训练 100% / 测试 10.5% 是过拟合；**PCA-256 后训练降到 29%、测试仍为 9.38%**，说明 ~10% 不是过拟合假象，而是 latent 中风格信息的**真实线性可达上限**。

### 这是整条调查链的最终答案

**风格在 A0 latent 中只有约 10× 随机基线的可分离度，仅略高于原始降采样像素（7%）；而专用风格编码器 CSD 有 60×。**

- **瓶颈在 Encoder，不在 Decoder，也不在方向构造。** A0 的 VAE encoder 丢弃了大部分风格信息。
- 这解释了此前全部失败：固定 768 维投影、Ranking、风格质心差、可逆流——它们都在一个几乎不含风格信息的表示上做优化。
- 也解释了为什么增强 Decoder（本次工作）无法产生风格迁移：Decoder 忠实地解码了 latent，而 latent 里本来就没有足够的风格。

**因此下一步不应是继续训练 latent 编辑器或增加模型容量，而应是让 encoder 保留风格信息**（例如在 VAE 训练中加入风格保持目标，或改用风格信息更丰富的表示层）。这与方案「不盲目增加模型容量」的指示一致。

## 六、对方案的结论

| 方案预期 | 实际 |
|---|---|
| LPIPS ≤0.10 | ✅ 0.0936 |
| L1 ≤0.075 | ✅ 0.0676 |
| CSD ≥0.90 | ❌ 0.853（A0 的 93%） |
| 保留吞吐优势 | ✅ forward 2.87×、fwd+grad 3.02× |
| 不加 CSD/HF Loss | ✅ 全程未加 |
| 提前收敛即停 | ✅ P0 600 步、P2 1400 步触发平台早停 |

**CSD 0.853 是否属 10M 容量上限？** 证据支持"部分是"：
- LPIPS 已到 A0 的 1.19×，说明感知重建基本追平
- CSD 在 P2 后 1000 步内稳定在 0.865–0.875 不再上升（平台早停触发）
- 加大数据量（13k→78k）只带来 +0.023 CSD

**但不宜断言**：方案明确禁止 CSD Loss，所以"纯重建目标下 CSD 到 0.865 饱和"与"10M 容量上限"是两件事。要区分它们，需要一个 CSD 监督的对照实验（方案已排除）。

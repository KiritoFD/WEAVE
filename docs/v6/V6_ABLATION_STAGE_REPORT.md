## 3. 已确立的结论

### 3.1 `direct` 完胜 `flow`

ΔT +0.0323 vs +0.0152，参数更少（1.88M vs 2.55M），无 ODE 循环，推理 1 次前向。
**没有理由保留 flow。**

### 3.2 内容不变性项 `w_canon_inv` 是必要的

`w_canon_inv=0`（D1_T2_style_first）→ ΔT 从 +0.0323 塌到 **+0.0017**。
这不是可选项。

### 3.3 `w_cross` 有明确最优点

0.35（+0.0323 / 0.9167）优于 0（+0.0166）、0.45（+0.0304）、1.20（+0.0404 / 0.8859）、
2.00（+0.0017）。**1.20 能买到更高 ΔT，代价是 DINO-C 掉 0.031。**

### 3.4 内容注入路径是必要的，但它保的是"内容"不是"风格"（A1）

去掉 0.6% 参数的内容注入后：

| 指标 | A0_ref | A1 | 变化 |
|---|---:|---:|---:|
| ΔT | +0.0323 | **+0.0474** | **+0.0151（更高）** |
| DINO-C | 0.9167 | **0.7920** | **−0.1248** |
| LPIPS | 0.3658 | **0.4751** | **+0.1094** |
| 风格改善 | 4/5 | **3/5** | −1 |
| Early_Renaissance | +0.0378 | **−0.0291** | 翻负 |
| Impressionism | +0.0517 | **+0.1992** | 暴涨（最大类 8,989 张） |
| Ukiyo_e | −0.0078 | **−0.0849** | 更差 |

**这是"用内容换风格"，不是"去掉内容注入更好"。**
内容注入的职责是保住内容与少数类，不是提升 ΔT。

**推论：ΔT 可以靠牺牲内容买到。** 这是 L1 的"内容/风格不相容"在 V6 内部的直接体现。

### 3.5 ΔT 与 DINO-C 是竞争关系，没有单一最优

三个点落在同一条取舍曲线上：

| 配置 | ΔT | DINO-C | 定位 |
|---|---:|---:|---|
| A1_no_content | **+0.0474** | 0.7920 | 风格最强、内容最差、少一个组件 |
| D1_T1_strong | +0.0404 | 0.8859 | 中间 |
| **D1_c1_gentle** | +0.0323 | **0.9167** | 内容最好 |

**"简化"必须先声明目标。** 若要求 DINO-C ≥ 0.90，A1 不可取；若只要 ΔT，A1 更简单且更高。

### 3.6 可证明无损的三项简化（direct 模式）

1. **stem 12ch → 4ch**：direct 模式 `z_in == c`，故 `[z_in, c, z_in−c] = [c, c, 0]`，
   **4 通道恒为零、8 通道重复**。等价于 4 通道卷积。
2. **删除 `time_mlp`**（14,016 参数）：τ 恒为 0，只产生常量偏移。
3. **删除 `make_coherent_real_target`**：`coherence_beta=0` 时原样返回，最优臂正是 0。

合计只省 **0.93% 参数**，但删掉三个在 direct 模式下毫无意义的概念。

### 3.7 参数分布（决定简化杠杆在哪）

| 组件 | 占比 |
|---|---:|
| block conv3×3 | **61.8%** |
| **AdaLN 条件层** | **19.8%** |
| down/up/proj | 14.5% |
| style_mlp + time_mlp | 1.8% |
| 内容注入 | **0.6%** |
| stem64 | 0.3% |
| palette head | 0.004% |

**真正的杠杆是 AdaLN（20%）与 base_dim（决定 80%），不是那些零碎部件。**

```
V6 D1 Direct Operator（C³-Direct, c1_gentle, base_dim=48）
  mode      = direct                # 单步前向，无 ODE、无迭代
  参数      = 1.88M（叠加 §3.6 三项无损简化后结构更干净）
  训练      = 800 步 / 有效 batch 240 / 572 s / 峰值 ~3.9 GB
  推理      = 1 次网络前向（~15 ms/张）
  目标      = 真实 latent（coherence_beta=0，无 target 变换）
  损失      = w_rec 1.0 + w_style_dist 0.25 + w_cross 0.35 + w_canon_inv 1.5
```

所以 1.88M 是"当前已验证"的最小值，不是理论最小值。

# 10. 三个静默失败（本轮最重要的工程发现）

## 10.1 第 7 条：训练图上的 autograd 探针清零梯度

**现象**：`grad(λ_r·L_rank)` 对 113 个参数精确为 0，而 `grad(L_V6)`=1.51、
`grad(L_rank)` 对 `z_cross`=4.04e-03、`z_cross.grad_fn=AddBackward0`、113/113 参数需梯度。

**后果**：G0 与 G1a **权重逐位相同**（`sha=a66a429aacc08470`，`max|dW|=0.000e+00`）。

**定位**：去掉全部探针的 3 步对照 → 113/113 不同。

**结论**：`torch.autograd.grad(..., retain_graph=True)` 作为训练图诊断，
**会让被探测分支在随后的 `backward()` 中静默贡献零梯度。`retain_graph` 不能阻止。**

## 10.2 第 8 条：fp16 让小权重梯度精确下溢

**修掉探针后仍然逐位相同。** λ 扫描定位：

| AMP | λ_r | `max\|dW\|` | 变化张量 |
|---|---:|---:|---:|
| **fp16** | 0.001 | **0.000e+00** | **0/113** |
| **fp16** | 0.010 | **0.000e+00** | **0/113** |
| fp16 | 0.020 | 1.316e-03 | 113/113 |
| **bf16** | 0.001 | **1.465e-03** | **113/113** |

**机制**：ranking 损失对 `z_cross` 的梯度只有 4.04e-03。乘 λ_r 后 4.0e-06，
落入 fp16 次正规区（最小正规数 6.1e-5），经各层连乘下溢为 0。
**bf16 指数范围同 fp32，无此悬崖。**

**为什么最危险**：不报错、损失值确实增加 0.016、梯度张量存在（113 个非 None）、
模型照常在主损失上收敛 —— **唯一可见的证据是一个恰好错误的结论**。

## 10.3 第 9 条：`--seed` 未传

**现象**：`Q1_G0_s43` 与 `P2_G0_bf16` 六位小数完全相同，报告里 `seed=42`。

**后果**：如果没查，会得出"seed 43 复现了 seed 42，Rococo 增益稳定成立"
—— **而实际上只是把同一次运行跑了两遍。**

**已加守卫**：断言报告里的 `seed` 字段等于目标值；
并断言 `seed43 G0 ≠ seed42 G0`（`max|dW|=2.658e-02`），证明种子确实改变了训练。

## 10.4 共同教训

| # | 缺陷 | 静默方式 |
|---|---|---|
| 7 | 训练图 autograd 探针 | 梯度张量存在但全 0 |
| 8 | fp16 小梯度下溢 | 损失值增加但梯度全 0 |
| 9 | `--seed` 未传 | 目录名写 s43，报告里是 42 |

> 不能只看损失值、诊断打印或目录名。**
>
> **本轮加入的守卫：每个新机制臂训练后与对照比较 `max|dW|`，为 0 直接 `exit 1`。**

# 13. 真正的瓶颈

**三条独立证据指向同一结论**：

1. **几何诊断**：`cos_align = 0.127`（夹角 82°），`m_target = −0.32`
2. **机制上限**：所有机制的 ΔT 增益在 +0.004 ~ +0.010 量级
3. **零结果**：ER / Imp / Min / Ukiyo 在两种子上零变化

> **要把 margin 从 −0.32 推到 0 以上，需要的位移量级远超现有机制能提供的 ΔT 增益。
> 这不是"再调一个超参"能解决的 —— 差一个数量级。**

**与 P0.2 的对照**：ScoreDiff 用 24 步多尺度编辑能达到 Top-1 0.367，
但 DINO-C 只有 0.5687。**它跨越边界的方式是大幅破坏内容。**

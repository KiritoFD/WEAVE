# WEAVE W 之后的下一阶段计划（用户 2026-11-11 拍板）

## 结论与方向

W 阶段的负结果成立：W1/W2/W3/W5 均未超过既有 B3/B4 基线，不值得继续微调 R1 特征蒸馏、LossClean 或反吸引子损失。

但 W 阶段也纠正了 R2 的误判：学生对 Oracle 教师的相对拟合误差仍达 53%–60%，不能称为已经充分拟合，更不能据此排除模型容量或优化问题。W1 的失败只说明“仅靠更复杂的 R1 特征监督”不能解决它。

因此，下一阶段不再优先蒸馏 Oracle，而是研究一个更根本的问题：

> 现有模型是否学到了真实的跨风格映射？内容条件是否仍泄漏源风格？

## 优先级路线

| 优先级 | 方向 | 核心问题 | 建议预算 |
| --- | --- | --- | --- |
| P0 | 内容条件的源风格泄漏 | 模型是否具备真正的跨风格可学习条件？ | 1–2h |
| P1 | 真实 latent 密度先验 + R1 引导 | 能否从分类边界编辑转向真实风格分布？ | 4–6h |
| P2 | 空间自适应风格编辑门控 | 能否只修改需要改变的局部结构？ | 3–4h |
| P3 | 真实画作驱动的条件流匹配 | 能否摆脱 Oracle 伪监督，直接学习目标分布？ | 后续独立阶段 |

### P0：先确认训练问题是否可辨识

现有 V6 训练中，同风格重建使用 `y_real`，跨风格训练主要依赖 DWT 分布损失、内容约束和 Oracle 监督。但 `c1_gentle` 没有彻底去掉原始风格，仍保留约 40% 原始 LL、50% LH/HL、70% HH 信息。

因此可能存在捷径：模型在同风格阶段学习复制源图；切换目标 Style-ID 时，缺少足够的真实监督告诉它应怎样改变笔触结构。

先做两个低成本测量：

1. 比较原始 latent 与 `c1_gentle` latent 的五风格分类准确率。
2. 固定同一内容条件，改变五种 Style-ID，测量模型输出的真实风格响应。

若条件仍携带大量源风格、Style-ID 的因果作用很弱，应优先改造内容条件，而不是继续加蒸馏损失。

### P1：真实 latent 密度先验 + R1 引导

理论关系：

```text
∇z log p(z | t) = ∇z log p(z) + ∇z log p(t | z)
```

即目标风格分布 score ≈ 真实数据分布 score + 目标风格后验 score。这是 classifier-guided diffusion 的基础。

现有 R1 可近似提供后者，但缺少可靠的前者。建议复用 V6 的 Score Network 工程，训练一个小型无条件真实画作 latent denoiser，仅使用现有 15,545 张真实画作。然后比较：

1. 单独 R1 梯度；
2. 单独真实数据 score；
3. R1 梯度 + 真实数据 score。

在相同编辑 RMS、相同 DINO-C 档位下判断收益。

注意：R1 的 logit margin 不等于校准后的 `log p(t|z)`；旧 ScoreDiff 的带 margin 训练也不保证学到精确 score。因此这是有理论动机的实验假设，不能直接宣称等价于真实条件采样。它和已失败的 ScoreDiff 的区别在于：新路线额外强调真实数据流形约束。推理阶段多做几步梯度下降可以接受，不必马上蒸馏。

### P2：空间自适应编辑

R2 已证明全局频带裁剪过于粗糙。应让模型对不同空间位置、通道和频带采用不同编辑强度：

```text
z' = z + α M(z,t) ⊙ d(z,t)
```

`M` 决定哪些位置可较大幅度编辑。与 LL-only 不同：有些区域应保留边缘，有些区域需要改变笔触和纹理，不能用全图统一规则处理。

可先做零训练门控实验；有收益后再增加学习模块。PRISM（2026 预印本）研究了类似的目标分布差异局部特征门控与无 GAN Flow Matching，但任务不完全相同，其论文结果不能直接作为 WEAVE 有效性证据。

### P3：真实画作驱动的条件流匹配

若 P1 证明真实数据先验有效，可进一步采用条件 Flow Matching。

但要避免陷阱：只训练 `p(z_real | c(z_real), t_real)` 仍只有同风格监督，模型可能忽略 Style-ID。必须解决跨风格条件训练覆盖问题，例如在真实画作之间建立内容匹配的软耦合，或利用跨风格内容一致性构造有效条件。

不能简单把两张不配准画作做 latent L2，否则会学习改变题材和几何，而不是只迁移风格。V8 桥流负结果也说明：不能只换一个 Flow Matching 名称重跑旧方案。

## 下一轮建议安排

先让正在执行的 VAE-swap 完成，并明确标注其评测范围与 Encoder/Decoder 配对限制。

之后先做 6 小时 P0+P1 验证，而不是直接开展新的 12 小时学生训练：

1. 约 1h：内容条件风格泄漏、真实画作 VAE 往返、困难风格审计。
2. 约 2h：训练或校准真实 latent 密度先验。
3. 约 2h：R1 / score / 联合引导的等预算、等内容保持比较。
4. 约 1h：五风格分项、配对统计、失败样例分析。

继续使用原预设门槛：DINO-S ≥ +0.020 显著提升，基线固定为同协议 B4（DINO-S 0.4214、DINO-C 0.8199）。不得为新路线改变测试口径。

另外，R1 在真实画作 latent 上已有 87.5% 风格分类准确率，ER/Ukiyo-e 召回率分别约 81.4%、93.7%。这说明 SD-VAE latent 中存在可辨识的困难风格信息，不能在没有更直接证据时把迁移失败全部归咎于 VAE。

## 最终建议

1. VAE-swap 作为对照继续完成。
2. 主研究方向转向“真实 latent 分布先验 + 风格引导”。
3. 把内容条件的风格泄漏作为第一道检查。
4. 暂时不再蒸馏 Oracle。

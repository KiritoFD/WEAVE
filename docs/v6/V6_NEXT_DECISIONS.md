## 1. P0 决策：进入 P1/P2

### 1.1 计划规定的规则

> **计划 §3**：若 ScoreDiff 在新同协议任务上依然显著优于 Direct，则继续 P1/P2；
> 若也退化到随机以下，先审计历史 ckpt/manifest/预处理，不应在不可靠基线上蒸馏。

### 1.2 实测

| 模型 | Heldout400 Top-1 | ΔT | DINO-C | LPIPS |
|---|---:|---:|---:|---:|
| ScoreDiff Cand_B（N=24） | **0.367** | +0.0669 | 0.5687 | 0.5439 |
| ScoreDiff Cand_A（N=12） | 0.310 | +0.0641 | 0.6200 | 0.4907 |
| Direct L11 | 0.028 | +0.0244 | 0.8902 | 0.3607 |

**ScoreDiff 不但没有退化到随机以下，反而比 Direct 高 13 倍。**

### 1.3 决策

✅ **继续 P1/P2。**

### 1.4 但这个决策附带一个重要限定

**ScoreDiff 的 0.367 不是五风格均衡的能力。**

| 目标 | Cand_B Top-1 |
|---|---:|
| **Minimalism** | **0.988** |
| Impressionism | 0.400 |
| Early_Renaissance | 0.188 |
| Rococo | 0.150 |
| Ukiyo_e | 0.113 |

**非 Minimalism 四类平均 = 0.213，勉强高于 20% 随机。**
混淆矩阵：Rococo 的 51/80（64%）被判为 Minimalism。

> **因此"进入 P1/P2"不等于"ScoreDiff 是一个好教师"。**
> **若直接蒸馏它，学生会继承单类吸引子。**

**这导致追加一条闸门（见 §3.4）。**

## 3. P2 决策：执行 G1 + G0

### 3.1 计划决策树原文

> **ScoreDiff 复现成功，R1 critic 有效** → G1 ranking vs G4 ScoreDiff 蒸馏，同预算竞争；
> 先解决真正目标风格。

### 3.2 决策

✅ **执行 G1（margin ranking），保留 G0（续训对照）作为保底。**

**G4（ScoreDiff 蒸馏）暂缓**，理由：
- ScoreDiff 的单类吸引子（Min 0.988 / 其余 0.11–0.40）会直接传给 G4
- G1 的 Pareto 已优于 G4 的上界（ScoreDiff 自身）
- 若 G1 失败再回退 G4

### 3.3 按计划 §8 的取消顺序

若时间不足，按 **R3 → G2 → G6 → M2** 取消。
**G0 与至少一条 G1/G4 路线必须保留。**

### 3.4 追加闸门（P0 揭示的风险）

> **P2 每个臂都必须报告 5×5 混淆矩阵的 Minimalism 列。**
> **非对角 Minimalism 计数不得超过 G0 的 1.2 倍。**

理由：P0.2 证明"整体 Top-1 上升"可以完全由 Minimalism 吸引子造成。
不设这条闸门，G1 可能用同样方式刷高 Top-1 而实际没有解决目标风格。

### 3.5 P2 完整闸门清单

| # | 判据 | 阈值 |
|---|---|---|
| 1 | 相对 G0 的 Top-1 提升 | ≥ +5pp，配对聚类 CI 排除 0 |
| 2 | 分目标不退化 | 5 个目标中至少 4 个 ΔT 与 margin 不降 |
| 3 | 内容档位 | DINO-C ≥ 0.85（保真）/ ≥ 0.75（均衡） |
| 4 | **Minimalism 列不膨胀** | 非对角计数 ≤ G0 × 1.2 |
| 5 | 困难目标真实增益 | ER / Rococo / Ukiyo 至少两个显著上升 |
| 6 | 独立复核 | Heldout400 + Same150 |

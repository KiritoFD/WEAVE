## 6. 结论

1. **Q2A+Oracle1 确实是历史 baseline 里 CSD Top-1 最高的 arm**（sdvae 34.83 / s10 36.33），本轮重算 sdae 34.50、old_s10 37.67 与之吻合，出图与打分路径可信。
2. **新 Decoder 的排名**：cross600 Top-1 `old_s10(37.67%) > c0(36.83%) > c1(36.00%) > sdvae(34.50%)` —— 新 C0/C1 都**高于官方 sdvae baseline**，但**略低于旧 S10**。配对 Bootstrap：c0/c1 对 sdvae 的 Top-1 提升 CI 均含 0（+2.33pp / +1.50pp，不显著），只有 old_s10 的 +3.17pp [+0.67,+5.83] 排除 0。
3. **CSD Margin 与 LPIPS 显著改善**：c0 margin +0.0094 [+0.0038,+0.0151]、c1 +0.0073 [+0.0014,+0.0133]，LPIPS c0 −0.0126、c1 −0.0133 均排除 0；CLIP-S 也小幅显著提升（+0.0049 / +0.0056）。**但 DINO 内容保持显著下降**（−0.0083 / −0.0082）。
4. **C1 响应蒸馏未在下游带来收益**：c1 在 Top-1/Margin/dT 上均略低于 c0，只在 LPIPS/CLIP-S 上极微幅更好。按方案「若 C1 没有优于 C0，允许 best_overall 直接选 C0」—— 从下游 Q2A+Oracle1 视角，C0 更合适；但 C1 的响应 Gate 通过，故保留两个 Pareto 候选，不指定单一冠军。
5. **同风格无谓漂移**：same150 Top-1 全部 0.94–0.97、LPIPS 0.385–0.393，四个 Decoder 无显著差异。

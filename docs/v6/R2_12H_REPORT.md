- DINO-S 有效性控制：真实画作 5 类 Top-1 = 83.3% (125/150)（raw RGB），同风格 vs 异风格 DINO-S 有明显区分间隔（约 +0.12），证明 DINO-S 在本测试域具备画风判别力，不是纯内容/题材混淆。

## A. 现有 Oracle 到底提升了什么？

- CSD Top-1：**6.0% → 34.3%**（28.3pp），Target Margin -0.2596 → -0.0546。
- 独立 DINO-S：**0.3988 → 0.4277**（Δ = 0.0289），相对源图增益 0.0355 → 0.0644。
- 内容代价：DINO-C **0.8873 → 0.7303**，LPIPS 0.3759 → 0.5240。
- **结论**：Oracle 的分类器收益（Top-1 +约 28pp）远大于独立画风相似度收益（DINO-S 仅 +约 0.029），且伴随明显内容下降。R1 梯度主要把图推向分类决策边界，而非等幅地提升真实画风相似度——Q1 的两种情形中，更靠近『提高分类准确率』，只是部分同时抬升了 DINO-S。

## B. 内容损失从哪里产生？

强度扫描（Val200，RMS 递增）：

| 变体 | RMS | Top-1 | DINO-S | DINO-C | LPIPS |
|---|---:|---:|---:|---:|---:|
| E0_q2a | 0 | 6.5% | 0.3813 | 0.8893 | 0.3781 |
| E1_rms008 | 0.08 | 11.0% | 0.3926 | 0.8613 | 0.4114 |
| E2_rms015 | 0.15 | 21.5% | 0.4043 | 0.8155 | 0.4556 |
| E3_rms025 | 0.25 | 33.0% | 0.4110 | 0.7293 | 0.5281 |
| LL_rms025 | 0.25 (LL) | 24.0% | 0.4013 | 0.7879 | 0.4894 |
| HF_rms025 | 0.25 (HF) | 30.0% | 0.4029 | 0.7122 | 0.5341 |

- 方向对齐：`cos(g, -∇L_inv) = -0.2306`（R1 梯度与 canonical 内容不变性负梯度显著反向），`cos(g, -∇L_content) = -0.0295`、`cos(g, Q2a Δ) = 0.1354`、`cos(g, ScoreDiff Δ) = 0.1252`。
- 频带：LL-only 在同等 RMS 下 DINO-C 明显更好（约 0.79 vs 全带/HF 约 0.73/0.71），说明内容破坏主要集中在高频子带。

- **结论**：内容损失主要由『编辑幅度』驱动（RMS 从 0→0.25 时 DINO-C 单调下降），且高频分量是主要破坏来源；R1 梯度与内容结构梯度近乎正交（cos≈−0.03），**不是**强烈的方向冲突。这解释了为什么 P2 的切向投影几乎不起作用。

- **内容切向投影 T3 与历史 Oracle T1 几乎逐位相同**（Top-1 33.0% vs 33.0%，DINO-C 0.7295 vs 0.7293）：因为 R1 梯度与内容梯度近乎正交，半空间投影几乎不删除任何分量。这是本轮明确的负结果。
- 在 DINO-C ≥ 0.78 档位中，`T4_projected_ll025`（LL 频带 + 投影）以 Top-1 24.5% / DINO-C 0.788 相对 T1（DINO-C 0.729）扩展了一小块前沿；但该收益来自 **LL 频带筛选**，不是来自投影。
- 残差锚点 `z_new = zs + delta`（零训练）把 DINO-C 提到 0.9195、LPIPS 降到 0.256，但 Top-1 掉到 4.0%（重新引入源风格），故不采纳。

- **结论**：不存在『内容约束更好』的机制性新教师；唯一可用的帕累托改进是降低 RMS 或 LL 频带筛选（等价于保守编辑）。按计划决策树，不扩大投影参数搜索，保留诊断结论，仅以 T4（LL 投影）作为 P3 的新教师输入。

- 218K 与 845K 学生的拟合能力接近（cos≈0.64–0.68，相对误差≈0.53–0.60），**没有出现『845K 明显拟合更好』**——再次排除容量瓶颈。
- 蒸馏项确实对权重产生非零更新（单元测试 12：sum|ΔW|≈1301）。但拟合误差几乎全部集中在 LL 子带（Haar LL MSE 远大于 LH/HL/HH）。

- 下游结果：P2 教师学生 S1/S2/S4 的 DINO-S（0.4067）**未超过**历史 B3（0.4183），Top-1 也更低（14.2% vs 17.8%）；唯一持平/略优的是用历史 Oracle 教师的 845K 学生 S3（Top-1 20.7% ，DINO-S 0.4194）。

- **结论**：学生能拟合教师（非优化/容量问题），但**新教师（LL 投影）目标本身更弱**，学得再好也只是复现一个保守编辑。归因落到『教师目标或泛化』，对应决策表『两者拟合好、DINO-S 均无提升 → 教师目标/泛化问题』。

## P4.3 预先设定的成功标准判定

主门槛（相对 B3）：DINO-S ≥ +0.020 且 CI 下界 > 0；DINO-C 不低于 B3 超过 0.02；LPIPS 不恶化超过 0.03；Top-1 不下降超过 2pp；≥4 类风格 DINO-S 非负；Minimalism 误判不膨胀超过 +5pp。

- 配对聚类 bootstrap（150 簇）：所有新学生 S1/S2/S4 相对 B3 的 ΔDINO-S 均为**负**（约 −0.010 ~ −0.012，CI 全在 0 以下）；S3 相对 B3 的 ΔDINO-S ≈ +0.001 且 CI 含 0。
- **没有任何模型满足 DINO-S +0.020 的主门槛。** 因此 G4 = 否。
- 按计划 G4 分支：『没有 +0.020 独立显著收益，但获得了可靠的机制诊断，仍按完整负结果交付，不通过修改测试协议或选择性展示制造提升』。

## F. 下一阶段应该做什么？（三选一）

**结论：教师失败（Teacher failure）→ 转向更明确的目标分布建模，而非继续蒸馏。**

依据链：
1. G0 通过：统一协议、12 项单测、DINO-S 判别力校准全部成立。
2. G1：R1 编辑能提高 DINO-S，但幅度（约 +0.03）远小于 CSD Top-1（约 +28pp），且伴随内容下降 → 更接近『分类边界捷径 + 部分真实风格收益』的混合，独立风格收益不足以支撑『判别梯度=真实条件风格迁移』。
3. G2：结构约束教师**未扩展**风格–内容 Pareto 前沿——切向投影近乎无效（梯度与内容梯度正交），唯一改进来自 LL 频带筛选（保守编辑）。
4. G3：学生能拟合教师（218K≈845K），排除容量；但教师目标本身更弱。
5. G4：无 +0.020 的独立显著 DINO-S 收益。

后续建议：
- 不再沿『分类器梯度 + 内容投影 + 蒸馏』这条线加参数或换损失；本轮已用受控实验证明其上限。
- 转向显式目标风格分布建模（例如以真实画作特征为条件的生成目标、或基于参考图的分布匹配），因为当前 R1 只提供局部判别方向，不提供『什么是该风格的真实画作』的分布信息。
- Early Renaissance / Ukiyo-e 需要专门的表示或数据，不是通用教师能覆盖。
- 保留 `P1_B3_distill20`（218K）作为高保真档最好单步基线，以及完整负结果与诊断数据，避免重复探索。

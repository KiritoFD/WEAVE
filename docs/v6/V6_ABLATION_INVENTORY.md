**日期**：2026-11-09

**产物**：`runs/v6/<variant>/{report.json, *.pt}`

## 0. 为什么回到 V6

V10/V11 的双向桥路线，四组修正后的算法对照**全部失败**（`docs/v11/V11_P1_RESULTS.md`）：
ΔT 全为负，SWD 停在地板的 2.4 倍，Rococo / Ukiyo_e 的 Top-1 恒为 0。
V11 的无条件生成实验（`docs/v11/V11_P3_RESULTS.md`）进一步显示，
共享模型连**无条件生成** ER / Rococo / Ukiyo_e 都做不到。

而 V6 是仓库里**唯一 ΔT 全为正**的路线，且 5/5 风格改善：

| 路线 | 600 跨风格 ΔT | DINO-C | LPIPS | 5 类改善 |
|---|---:|---:|---:|---:|
| **V6 D1 直接算子（c1_gentle）** | **+0.0323** | **0.9167** | 0.3658 | 5/5 |
| V6 D1 T1_strong | +0.0404 | 0.8859 | 0.3984 | 4/5 |
| V6 ScoreDiff | +0.0437 | 0.8639 | 0.3333 | — |
| V10 双向桥（04） | **−0.0284** | 0.685 | 0.700 | 0/5 |
| V11 P1 最好（e2） | **−0.0289** | 0.646 | 0.729 | 0/5 |

**V6 与 V11 理论最终指向的方向一致**：V11 的理论文档结论是
"目标风格分布 + **源内容约束** + 可学习随机运输"，而 V6 的核心正是
**内容规范化 C + 条件生成 G(c, s)**。所以回 V6 不是退回旧方案，而是回到
唯一被实测验证过的那条正确路线。

### 1.2 已有消融覆盖的轴

| 轴 | 已覆盖取值 | 结论 |
|---|---|---|

| `canon_mode` | c1, c1_soft, c1_gentle | c1_gentle ≈ c1_soft > c1；**过强规范化（c2_zca）会破坏内容**（DINO-C 0.478，见 Stage0 审计） |

| `w_cross` | 0, 0.35, 0.45, 0.50, 1.20, 2.00 | **0.35 是内容/风格最佳折中**；1.20 提高 ΔT 但伤 DINO-C；2.00 直接崩 |
| `w_canon_inv` | 0, 0.20, 1.50 | **0 会崩**（+0.0017）；1.50 明显更好 → 内容不变性项是必要的 |

| `coherence_beta` | 0, 0.65 | 最优臂用 0（关闭） |

### 1.3 已有消融的**三个缺口**

1. **没有任何"去掉某个条件"的消融。**
   `w_cross=0` 只是去掉跨风格损失，**输入侧的内容条件 c 与风格条件 s 从未被单独移除**。
   因此 V6 的核心主张（"内容条件保结构、风格条件驱动转换"）**没有被直接检验**。
2. **`canon_mode` 全都有规范化。** 没有 `none`（直接把原始 latent 当内容）这一档，
   所以无法判断 C 本身贡献了多少。
3. **参数量从未在固定权重下扫过。** 1.88M 与 2.55M 的差别混杂了 mode/weights/steps，
   无法回答"最小可用模型是多大"。

## 2. 本次补上的消融

全部以 **D1_c1_gentle 的最优配置为基准**，**只改一个因素**：

```
--mode direct --canon-mode c1_gentle --base-dim 48 --steps 800 --microbatch 80
--accum 3 --lr 3e-4 --coherence-beta 0.0 --w-rec 1.0 --w-style-dist 0.25
--w-cross 0.35 --w-canon-inv 1.5 --seed 42
```

> **重要：`base_dim=48` 才是 1,881,792 参数。** `C3UNet` 的默认值 56 对应 2,553,784
> 参数（即 `D1_bench` / `F1_c1_flow` 那一档）。实测映射：
>
> | base_dim | 16 | 20 | 24 | 28 | 32 | 36 | 40 | 44 | **48** | 52 | 56 |
> |---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
> | params | 0.22M | 0.34M | 0.48M | 0.65M | 0.85M | 1.07M | 1.31M | 1.58M | **1.88M** | 2.20M | 2.55M |
>
> 若误用默认 56，消融臂会比参照臂大 36%，结论不可比。本轮已修正。

| ID | 变更 | 要回答的问题 |
|---|---|---|
| **A0_ref** | 无（精确复现 D1_c1_gentle） | 复现验证：harness 是否与已有结果一致 |
| **A1_no_content** | `--no-content`：内容条件全置零，**参数完全不变** | 结构保真来自内容路径，还是仅来自重建损失？ |
| **A2_no_style** | `--no-style`：Style-ID 固定为 0，**参数完全不变** | 转换来自风格条件，还是网络本身就在做平均修补？ |
| **A3_canon_none** | `--canon-mode none`：内容 = 原始 latent | 规范化器 C 到底贡献了什么？ |
| **A4_dim24** | `--base-dim 24`（0.48M） | 更小是否够用 |
| **A5_dim32** | `--base-dim 32`（0.85M） | 更小是否够用 |
| **A6_dim40** | `--base-dim 40`（1.31M） | 更小是否够用 |
| **A7_steps400** | `--steps 400` | 800 步是否必要（一半预算够吗） |

### 实现方式（最小侵入）

- `tools/v6/models_v6.py::C3UNet.__init__` 新增 `no_content` / `no_style` 两个布尔量，
  在 `forward` 开头对 `c` / `style_id` 做置零。**不新增任何参数**，
  因此与对照臂的参数量完全一致（已实测：`base_dim=32` 时三者均为 845,008）。
- `tools/v6/canonicalize.py::ContentCanonicalizer.forward` 新增 `mode == "none"`，
  原样返回输入（已实测 `identical_to_input=True`）。
- `tools/v6/train_eval_v6.py` 新增 `--no-content` / `--no-style`，并把
  `canon-mode` 的 choices 扩到含 `none`；两项开关写入 `report.json`。

### 判读规则（预先声明）

| 观察 | 结论 |
|---|---|
| A1 的 DINO-C 显著下降、ΔT 不变 | **内容路径是必要的** → 核心主张成立 |
| A1 的 DINO-C 几乎不变 | 内容路径是装饰性的，模型靠重建损失保结构 → 主张需修正 |
| A2 的 ΔT 掉到 ≈0 或负 | **风格条件是必要的** |
| A2 的 ΔT 仍为正 | 转换来自网络先验而非条件 → 严重问题 |
| A3 ≈ 基准 | 规范化器 C 可省 → **可给出更简单基线** |
| A3 明显更差 | C 是必要的 |
| 某 dim 首次明显掉点 | 该尺寸以下为不可用，其上一档即**最小基线** |

## 3. 最小基线的候选（待 A4–A7 结果确认）

按已有数据，**当前可用的最小基线**是：

```
V6 D1 Direct Operator (C³-Direct, c1_gentle)
  mode         = direct          # 单步前向，无 ODE
  参数         = 1.88M           # base_dim=48
  训练         = 800 步, 有效 batch 240, 572 s, 峰值 ~3.9 GB
  推理         = 1 次网络前向（~15 ms/张）
  损失         = w_rec=1.0, w_style_dist=0.25, w_cross=0.35, w_canon_inv=1.5
  评测         = ΔT +0.0323, DINO-C 0.9167, LPIPS 0.3658, 5/5 风格改善
```

它比 V6 报告里的"定型推荐"更简单：**不需要 ODE、不需要 ScoreDiff 的多步迭代、
不需要 2.55M/3.27M 的大网络**。

A4–A7 若显示 `base_dim` 可降到 32 或 24 而指标不塌，则可进一步把基线压到
**~0.85M 参数**；A7 若显示 400 步足够，训练时间还能再减半。

# 旧 S10 适配原版 SD0 Encoder：A/B/C/D 对照结果

**日期**：2026-11-12 ｜ **机器**：4090 ｜ **协议**：`paper_rgb_v1`（与 `docs/baseline/UNIFIED_FULL_RANKING.md` 32 方法榜一致）
**核心结论**：**方案决策表命中「B 已经接近 A → 直接使用旧 S10，无需训练」**。闭式校准 C 反而略差于 B，不需要 1×1 校准，更不需要 3×3 适配器或 Decoder 微调。

---

## 1. 方案与四档定义

旧 S10 排行榜成绩用的是 `A0 Encoder + A0 post_quant_conv + 旧S10`（`tools/v6_next/vae_swap_compat.py:111` 实证）。方案提出：保持 S10 卷积主体 10.658M 参数**完全不变**，只校准输入端 4→4 通道映射，让它在**原版 SD0 latent** 下工作。

| 档 | Encoder | 输入映射 | Decoder 主体 |
|---|---|---|---|
| **A** | A0 | A0 原版 PQC | 旧 S10（目标上界 / 参考） |
| **B** | **SD0** | A0 原版 PQC | 旧 S10（**直接兼容，零训练**） |
| **C** | SD0 | 最小二乘校准 PQC | 旧 S10 |
| **D** | SD0 | SD0 原版 PQC | 官方 49.49M D0（官方基线） |

所有档位：**未缩放 posterior-mean latent、恰好一次 PQC**（P0 接口审计 `pqc_is_1x1_4to4=true`、`student_applies_pqc_once=true`）。

- 按方案「P0 若 B 已接近 A，根本不需要训练，直接使用即可」→ **无需校准**。

`min ‖W z_SD0 + b − P_A(z_A0)‖² + λ‖W−W_A‖²`（λ=1e-3，纯闭式，不训练 S10 主体）。

## 5. 最终判定（对照方案决策表）

| 方案条件 | 实测 | 处理 |
|---|---|---|
| **B 已经接近 A** | **是**（P0 DINO-C 0.9678 vs 0.9695；P2 A-ref 0.5587 vs B 0.5616，B 甚至略高） | ✅ **直接使用旧 S10 + SD0 Encoder + A0 PQC，零训练、零额外推理开销** |
| C 明显优于 B 且接近 A | 否（C 在 5 个主要指标上显著略差） | 不发布 C |
| 1×1 不足、3×3 有效 | 不需要走到这一步 | 不做 3×3 适配器 |
| 两种适配均无效 | 不适用（B 本就可用） | 不重训 Decoder |

**重要结论**：
1. **旧 S10 现在可以视为 SD0 原生兼容模型**：只需保持 A0 的 `post_quant_conv`（随 checkpoint 附带），把未缩放 SD0 latent 送入即可。历史 DINO-C≈0.22 是接口/缩放问题，不是 latent 空间差异。
2. **B 在跨风格下游上甚至略优于 A**（0.5616 vs 0.5587），且显著优于官方 D0（+0.0068 Affinity、−0.0114 LPIPS，CI 排除 0）。这不是说 SD0 Encoder 优于 A0（A 用不同 Encoder、非单变量对照），而是说**「SD0 Encoder + 旧S10」这条零成本组合在原生 latent 下已完全可用**。
3. **闭式校准是多余甚至有害的**：它在 PQC 输出的中间特征上 MSE 降 8.2%，但 RGB 下游的 Affinity/DINO-S/DINO-C/LPIPS 全部显著变差。印证方案自己的预警「闭式求解保证的是训练样本上的最优线性拟合，不能保证达到 A0 配对下完全相同的图像质量」。
4. **不需要重新训练 10.66M Decoder**，也不需要 3×3 适配器或函数蒸馏。

---

## 6. 与 32 方法榜的定位

`B = Q2a+Oracle + 原版SD0 Encoder + 旧S10` 的 Affinity **0.56159** → 在 `docs/baseline` 34 方法（32 baseline + 本轮新 C0/C1）中：
- 高于第 4 名 `Q2a+Oracle+S10`（A0，0.5587）
- 高于本轮新 C0（0.5575）/ C1（0.5576）
- 仅次于 3 个外部 Baseline（StyleShot 0.6949 / StyleID 0.6469 / AesPA 0.5784）
- **即「目前最好的 Ours 配置」从 A0 配对变成了零成本的 SD0 + 旧S10 直接兼容**

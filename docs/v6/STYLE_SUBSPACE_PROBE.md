## 二、P1：CSD 风格梯度在 768 维子空间内的能量占比

$$r=\frac{\lVert P_sg\rVert^2}{\lVert g\rVert^2},\qquad P_s=Q_s^\top Q_s$$

| 指标 | 实测 |
|---|---:|
| **mean r** | **4.66%** |
| median r | 4.68% |
| std r | 0.19% |
| 随机期望 | 4.69% |
| **ratio vs random** | **1.00×** |

### 结论
**CSD 风格梯度在 16384 维 latent 中是完全各向同性的。** 固定 768 维子空间捕获的梯度能量精确等于随机水平（1.00×），不存在任何「天然集中了风格方向」的固定低维子空间。

这意味着：**若要用 768 维子空间做风格编辑，这个子空间必须是学出来的，不能是随机固定的。**

### 四个关键读数

1. **完整梯度极强且稳定**：ΔT_CSD 从 0.063 到 0.154，**100% 样本正向**。这比之前的四通道协方差传输（0.0153）强 4~10 倍。**Decoder 确实能沿风格梯度方向响应。**

2. **768 维投影仍有实质效果**：ΔT_CSD 0.018 / 0.039 / 0.051，正向率 94~100%，**比随机方向强 25~30 倍**。投影/完整 ≈ 0.28 / 0.32 / 0.33，与梯度范数比 $\sqrt{4.66\%}\approx21.6\%$ 量级一致（近线性响应）。

3. **投影方向更「健康」**：
   - 完整梯度在 0.06 时**源风格被破坏**（srcDrop = **−0.0433**），即主要靠擦除源风格而非真正叠加目标风格；
   - 投影梯度在 0.06 时**源风格几乎不变**（srcDrop = **+0.0007**），且 LPIPS 更低（0.0178 vs 0.0256）。
   - 这是 768 维子空间的一个实质优势：**更接近「风格叠加」而非「风格抹除」**。

4. **随机方向确实无效**：0.0002~0.0015，正向率 56~63%（接近抛硬币）。

## 四、必须记录的严重保留：CSD 增益与视觉可见性脱节

看第 0 号任务的五联图（源图 / no-op / 完整梯度 / 投影梯度 / 随机）：

- 在 0.03 档，**LPIPS vs no-op 仅 0.0084**，五张图**肉眼几乎无法区分**；
- 但同一扰动下 **ΔT_CSD = 0.1204**（CSD 相似度提升了 0.12）。

**CSD 对肉眼不可见的变化极度敏感。** 这意味着：
- ΔT_CSD 的绝对数值不能直接当作「风格迁移效果」；
- 之前用 CSD 作为唯一目标函数的风险被再次确认；
- **必须配合 ALADIN 与人工视觉判断**，不能只看 CSD 数字。

同时注意：ALADIN 的增益在 0.06 档，随机方向（0.0073）已接近投影方向（0.0092），说明**独立指标对子空间优势的确认较弱**。

## 五、三个问题的直接回答

### 1. 完整 latent 能不能沿风格方向编辑？
**能，但代价明确。** 完整梯度在 0.01~0.06 三档均取得 100%/97% 正向的 CSD 增益（0.063→0.154），说明 Decoder 响应能力**不是**瓶颈。但在 0.06 档源风格被破坏（srcDrop −0.043），说明大扰动下是「擦除」而非「转换」。

### 2. 768 维子空间是否能够产生可见的风格变化？
**能产生可测变化，但「可见」二字存疑。** 相对随机方向强 25~30 倍、正向率 94~100%、且**保留源风格**、LPIPS 更低——方向上有可利用的局部响应。但绝对 LPIPS（0.006~0.018）对应的视觉变化极其微弱。

### 3. CSD 改善是否得到独立指标和视觉支持？
**部分支持，视觉支持弱。** ALADIN 增益为正（0.0005~0.0092）但幅度小，且高扰动档随机方向也已追平；32 组五联图肉眼难以分辨差异。

## 六、对 Style-REPA 的影响（重要限制）

按您的明确要求：**这 20 分钟只验证 A0 已有的局部可编辑性，不能证明固定 768 维子空间经训练后一定成功或失败。**

具体地：
- P1 的 $r=4.66\%$（=随机）**不构成对 Style-REPA 的否决**。它恰恰说明：当前 A0 的风格方向没有集中，而这正是 Encoder 训练要改变的东西——训练目标就是让风格方向在某个可学习的低维结构上集中起来。
- 但它确实说明：**不能指望一个随机固定子空间**；子空间必须由训练产生。

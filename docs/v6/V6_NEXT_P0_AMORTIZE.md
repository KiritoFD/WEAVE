## 0. 结论

> **判据 1 成立：A1 把目标风格 Top-1 从 0.067 提到 0.365（+29.8pp，5.4 倍）。**
> **存在有效但未被 Direct 学到的编辑方向。**

> 但 Top-1 从 0.067 升到 0.365。它改善的是 **margin**（−0.2536 → −0.0528），不是余弦相似度。**

## 2. 关于 A1 ≡ A3：这不是结果，是实验设计的必然

**在固定总 RMS 预算下**：

- A1 = `z0 + 0.25 · ĝ(z0)`
- A3 = `z0 + 4 × 0.0625 · ĝ(z0)` = `z0 + 0.25 · ĝ(z0)`

**两者终点在数学上完全相同**，实测 `max|ΔdT| = 0` 验证了实现正确。

> **所以 A1/A3 不是一组独立对照。**
> **计划里的"4 步固定初始梯度"在"固定总预算"约束下与"1 步"等价。**
> **真正有信息量的比较是 A2 对 A1：动态重算 vs 单一方向，等总位移。**

A3 的价值仅在于**验证实现无 bug**（梯度确实被冻结、步长确实相加）。

## 3. 判据逐条判定

### 判据 1：A1 明显优于 A0 → **成立**

| 指标 | A0 | A1 | 变化 |
|---|---:|---:|---:|
| **Top-1** | 0.067 | **0.365** | **+29.8pp（5.4 倍）** |
| **m_target** | −0.2536 | **−0.0528** | **+0.2008（缺口 79%）** |
| ΔT | +0.0487 | +0.0343 | **−0.0144** |
| DINO-C | 0.8786 | 0.7097 | −0.1689 |
| LPIPS | 0.2732 | 0.4152 | +0.1420 |
| Same Top-1 | 0.980 | 0.947 | −3.3pp |
| Same ΔS | +0.0184 | −0.1545 | **退化** |

**存在有效编辑方向 —— 而且它改善的是 margin 而不是 ΔT。**

### 判据 2：A2 明显优于 A3 → **不成立**

| 指标 | A1（=A3） | A2 | 谁更好 |
|---|---:|---:|---|
| **Top-1** | **0.365** | 0.242 | **A1（+12.3pp）** |
| m_target | **−0.0528** | −0.1146 | **A1** |
| ΔT | +0.0343 | **+0.0566** | A2 |
| DINO-C | 0.7097 | **0.7955** | A2 |
| Same ΔS | −0.1545 | **−0.0573** | A2 |

**A2 是 Pareto 上的另一个点，不是支配关系：
A1 识别率更高，A2 内容与自一致更好。**

**但就"动态重计算是否有独立价值"这个问题，答案是没有** ——
在等总位移下，动态重算反而降低了识别率。

**可能机制**：每步都把梯度重新归一化到单位 RMS，
相当于在弯曲的 margin 地形上反复"重新起步"，丢失了初始方向的累积效应。

### 判据 3：A1–A3 均无收益 → 不适用

**A1 有 +29.8pp 收益 → 进入 P1。**

## 6. 机制层面最重要的发现

> **A1 的 ΔT 比 A0 低（+0.0343 vs +0.0487），但 Top-1 高 5.4 倍。**

**这直接证明：**

1. **ΔT（余弦相似度变化）不是正确目标** —— 增加 ΔT 可以不改善识别
2. **真正起作用的是 margin**（目标 logit 减去最强竞争者）：
   −0.2536 → −0.0528，缺口补了 79%
3. **R1 梯度朝"目标原型成为 argmax"的方向走，而不是朝"余弦更大"的方向走**

**这与 P0.3 的几何诊断完全一致**（`cos_align = 0.127`、`m_target = −0.32`）：
**问题从来不是"位移不够大"，而是"位移方向没对准判定边界"。**

**R1 critic 的 margin 梯度恰好提供了这个方向 —— 这正是 V6 的 DWT 统计损失无法提供的。**

# V6 简化分析：可证明无损的部分 vs 需要实测的部分

**目的**：在**保留最优性能**的前提下把 V6 压到最小最简单
**基准**：`D1_c1_gentle`（direct / c1_gentle / base_dim=48 → 1,881,792 参数 /
800 步 / ΔT +0.0323 / DINO-C 0.9167 / LPIPS 0.3658）

---

## 1. 参数量分布（实测，`base_dim=48`, direct）

| 组件 | 参数 | 占比 |
|---|---:|---:|
| block conv3×3（10 个 StyleAdaLNBlock 的 conv1+conv2） | 1,162,752 | **61.8%** |
| **AdaLN 线性层**（style+tau → 5×channels） | **372,480** | **19.8%** |
| down/up/proj 卷积 | 272,352 | 14.5% |
| style_mlp + time_mlp | 33,120 | 1.8% |
| 输出头 | 24,884 | 1.3% |
| 内容注入 1×1（每层） | 10,752 | 0.6% |
| stem64（12ch → c1） | 5,232 | 0.3% |
| StyleChannelPaletteHead | 220 | 0.004% |

**结论：参数几乎全在卷积主干与 AdaLN 条件层里。**
删掉 palette head、stem、内容注入这些"看起来花哨"的部分**省不了什么**。

## 2. 可**证明**无损的简化（不需要实验）

### 2.1 stem 从 12 通道降到 4 通道

direct 模式的调用是

```python
z_pred = model(c_in, 0.0, c_in, y)      # z_in == c
```

于是 stem 输入

```python
x0 = torch.cat([z_in, c, z_in - c], dim=1)   # = [c, c, 0]
```

**12 个通道里有 4 个恒为 0，另外 8 个是重复的。**
`Conv2d(12, c1, 3)` 作用在 `[c, c, 0]` 上等价于 `Conv2d(4, c1, 3)` 且权重为
`W[:, 0:4] + W[:, 4:8]`。

- 省参数：5,232 → 1,776（**−3,456**）
- 更重要的收益：**去掉一个恒为零的输入和一份重复输入**，模型不再"看起来"用了三路输入
- 风险：无（数学上等价）

### 2.2 删除 `time_mlp`

direct 模式恒传 `tau=0.0`，所以

```python
t_emb = self.time_mlp(sinusoidal_embedding(0.0))   # 常量向量
cond  = s_emb + t_emb                              # 等价于 s_emb + 常数偏置
```

**τ 在 direct 模式下不携带任何信息**，`time_mlp` 只产生一个常量偏移。

- 省参数：**14,016**（`time_mlp` 全部）
- 风险：低。常量偏移可以被 AdaLN 的 bias 吸收，函数类不变
- 注意：**flow 模式仍需要它**，所以这是 direct 专用简化

### 2.3 删除 `make_coherent_real_target`

```python
if coherence_beta <= 0.0:
    return z_real        # ← 最优臂用 coherence_beta=0.0
```

最优臂的 `--coherence-beta 0.0`，该函数**原样返回**。整个 coherent-target 逻辑
在该配置下是死代码。

- 省参数：0（无参数）
- 收益：**删掉一整段训练目标变换逻辑**，训练目标就是真实 latent
- 风险：无（在 beta=0 时）

### 2.4 三者合计

| 项 | 省参数 |
|---|---:|
| 12ch → 4ch stem | 3,456 |
| 删除 time_mlp | 14,016 |
| **合计** | **17,472（0.93%）** |

**参数量只降 0.9%，但代码结构显著变干净**：
不再有"三路输入"、"时间条件"、"coherent target" 这三个在 direct 模式下无意义的部件。

> 若目标是"最小参数"，真正的杠杆是 `base_dim`（见 §3），不是这些零碎。

## 3. 需要实测的简化（正在跑）

| 简化 | 潜在收益 | 对应消融 |
|---|---|---|
| 去掉每层内容注入 | −10,752 参数（0.6%） | A1 |
| 去掉 Style-ID 条件 | **−372,480 参数（19.8%）** | A2 |
| 去掉规范化器 C | 无参数，但省一整套预处理 | A3 |
| `base_dim` 48 → 32 | **1.88M → 0.85M（−55%）** | A5 |
| `base_dim` 48 → 24 | **1.88M → 0.48M（−74%）** | A4 |
| 步数 800 → 400 | 训练时间减半 | A7 |

**最大的两个杠杆是 AdaLN（20%）与 base_dim（决定 80%）**，
所以 A2 与 A4/A5 是最关键的两个消融。

## 4. 一个可以直接给出的"最小基线"（不依赖未完成消融）

即使 A1–A7 全部未完成，当前也有一个**明确更简单**的基线可用：

```
V6 D1 Direct Operator（C³-Direct, c1_gentle, base_dim=48）
  mode      = direct                # 单步前向，无 ODE、无迭代
  参数      = 1.88M
  训练      = 800 步 / 有效 batch 240 / 572 s / 峰值 ~3.9 GB
  推理      = 1 次网络前向（~15 ms/张）
  目标      = 真实 latent（coherence_beta=0，无 target 变换）
  损失      = w_rec 1.0 + w_style_dist 0.25 + w_cross 0.35 + w_canon_inv 1.5
  评测      = ΔT +0.0323 / DINO-C 0.9167 / LPIPS 0.3658 / 4-5 风格改善
```

**它比 V6 报告里的"定型推荐"更简单**：不需要 ScoreDiff 的 12 步迭代、
不需要 2.55M / 3.27M 的大网络、不需要 ODE。
再叠加 §2 的三项无损简化，可以得到一个**结构上明显更干净**的版本。

## 5. 存疑清单（必须在报告里保留）

| # | 存疑点 | 影响 |
|---|---|---|
| 1 | **"5/5 风格改善"依赖推理强度标定 α=0.70**；原始模型是 4/5（Ukiyo −0.0078） | 宣称的口径需注明 |
| 2 | **Ukiyo-e 在每个变体里都是负的** | 唯一的系统性短板 |
| 3 | **ΔT 与 DINO-C 竞争**（T1_strong vs c1_gentle） | 无单一最优，需先定目标 |
| 4 | **内容路径从未被直接检验** | A1/A1b/A2 正在跑 |
| 5 | **800 步从未扫过** | A7 正在跑 |
| 6 | **B1 潜空间风格编码器**在分布损失里是否必要，未与原型回退对比 | 影响可移植性 |
| 7 | **同评测口径下的 identity / 平凡基线缺失**（V6 报告的 identity −0.0219 来自另一条流水线） | 基线强度不明 |
| 8 | **DINO-C 0.9167 与 LPIPS 0.3658 同时偏高** | 语义保留好但像素改动大，是否是期望的折中需明确 |
| 9 | **`base_dim` 与权重是耦合调的**（所有 1.88M 变体都用同一组权重） | 换尺寸后最优权重可能不同 |
| 10 | **训练数据只有 15,545 张**，Rococo 2,519 / Ukiyo 1,479 / ER 1,474 / Min 1,084 | 小类仍是风险 |

## 7. 解释：为什么只有 Rococo 动

**R1 critic 在真实图上的分目标 recall**：

| 目标 | R1 recall |
|---|---:|
| Early_Renaissance | 0.814 |
| Impressionism | 0.900 |
| Minimalism | 0.891 |
| **Rococo** | **0.834** |
| **Ukiyo_e** | **0.937** |

**R1 对 Ukiyo 的 recall 最高（0.937），但 Ukiyo 的 Top-1 一点没动（0.000）。
所以"critic 分得开"不等于"生成器能学会"。**

**可能原因（未验证）**：
1. Ukiyo 在 DWT 统计空间里与 ER 只差 0.60，V6 主损失在把输出拉向 ER，与 ranking 对抗
2. Rococo 的 DWT 特征与其他风格距离较远（ER–Rococo 1.47），主损失与 ranking 不冲突
3. 4 个任务的变化可能是噪声

**第 3 点必须用 seed-43 复现来排除 —— 正在进行。**

# Local Style Reader / Gate R：最终报告（Gate R 失败）

**日期**：2026-11-11
**代码**：`tools/local_reader/`（`readers.py`、`data.py`、`run.py`、`diagnose.py`、`selftest.py`、`run_serial.sh`）
**结论**：**Gate R 失败**。冻结 A0 Encoder 上，10K–100K 参数的可学习 Local Style Reader 未能达到方案设定的工程门槛；**不进入 Encoder 训练**。但结果同时支持「原生 latent 含可用风格信息」，并否证了「局部集合归纳偏置」这一具体假设。

---

## 0. 研究问题（方案收紧后）

> 能不能让一个极小、局部、内容不敏感的模型，从原生 latent 中稳定读取画风？

前置条件：先冻结 A0 Encoder，只训练读取器；不训练 Encoder、不改 latent 接口、不引入显式 Style Branch。

---

## 1. 实现与验证

| 项 | 结果 |
|---|---|
| Local Style Reader（Deep Sets） | `r(z)=ρ(mean_p φ(Patch_p(z)))`，3×3 unfold → 共享 MLP → mean pool → 64 维 L2；**20,848 参数** |
| 对照：浅层 CNN | 3 层 conv + 全局池化 → 64 维；**34,624 参数** |
| 缓存对齐 | latent / DINO / 负样本索引**逐元素一致**（`ELEMENT-WISE EQUAL: True`），latent 无全零行，负样本无同风格污染 |
| painter-disjoint | 留出 250 位画家（排除 30.0% 训练图，保留 41,427 张监督图），严格验证子集 **768 张**；未见流派 311 张 / 31 类 |
| 自测 | 读取器形状/参数/梯度/置换不变性、bootstrap、数据对齐、未见流派 0 正样本 —— 全 PASS |
| 可复现性 | 修复了 `build()` 在 `manual_seed` 之前执行导致权重随机的问题；两次相同 300 步运行**数字完全一致** |
| 成本 | 读取器 1500 步约 30 秒（纯缓存 latent，无 VAE 前向） |

修掉的方法学问题：
- 配对 Bootstrap 最初按「每个 positive pair」聚类，CI 伪精确；改为**按源图聚类**
- 配对量最初用原始余弦分数，会被共模抬高误导；改为**每源图的 pos−hard 判别 gap**
- few-shot 测试池随 k 变化导致 10-shot < 5-shot；改为**固定测试池**

## 2. 四项验收（冻结 2048 验证集，最终可复现结果）

| 同指标（painter-disjoint 768 张） | — | **0.4651** | 0.4788 | — | 与全量一致，无画家捷径 |
| 5-shot 检索（r(z)） | 0.0295 | **0.0353** | 0.0529 | >0.0708 | ❌ |

| 配对 Bootstrap（gap vs 固定） | — | +0.01742 `[+0.01528,+0.01965]` | +0.01813 `[+0.01597,+0.02031]` | 可信 | ✅ 排除 0 |

† 本轮 flat-latent 5-shot 为 0.0912；方案给的 0.0708 来自上一轮 `art_vae/eval.py`，其测试池是「每风格 `v[5:15]`」，而本轮为可比性固定为「每风格 `v[20:40]`」—— 两者都是全 2048 验证集，差异仅来自测试池划分，不是子集大小。**无论用哪个基准，两个读取器都未超过**（0.0353 / 0.0529 均小于 0.0708 与 0.0912）。

**Gate R：FAILED**（5 项中 3 项通过，AUROC 与 5-shot 两项未过）。按方案「若 Gate R 失败，不再对固定 Gram/协方差/中心化无休止微调，直接重新讨论 latent 的结构化风格表示」—— 本轮到此为止，**不进入两阶段 Encoder 训练**。

## 3. 三个关键发现

### 3.1 原生 latent 确实含风格信息（避免过度推断）

`diagnose.py` 区分 hard / easy 负样本：

| | hard AUROC（内容匹配异风格） | **easy AUROC（随机异风格）** |
|---|---:|---:|
| 固定读取器 | 0.4535 | 0.5375 |
| Local Reader | 0.4645 | **0.5976** |
| CNN 对照 | 0.4770 | **0.6098** |

可学习读取器把 easy AUROC 从 0.5375 提到 **~0.60**，且配对 gap 的 Bootstrap CI 排除 0 → **风格信息存在且能被小模型部分读出**。hard AUROC < 0.5 是因为内容匹配的异风格图像在 latent 上比同风格跨画家更近（`hard_mean 0.9553 > pos_mean 0.9533`），**不是 latent 无风格信息**。这印证了方案「AUROC 低于 0.5 不意味着 latent 没有风格信息」的判断。

### 3.2 局部集合归纳偏置没有带来收益（对照实验的直接答案）

CNN 对照在**每一项上都优于或持平** Local Reader：AUROC 0.4770 vs 0.4645、5-shot 0.0529 vs 0.0353、未见流派持平。配对 gap `local − cnn = −0.00071`，CI `[-0.00100,-0.00042]` 排除 0。

即：**风格收益来自「可训练非线性」本身，而非 Deep Sets / 局部统计的特定归纳偏置**。方案设置这个对照要回答的问题，答案是明确的「否」。

### 3.3 共模仍主导，简单读取器仍不如展平 latent

所有余弦挤在 0.94–0.96；`q` 输出高度共线。5-shot 检索（0.0353/0.0529）**低于直接展平 latent 的 0.0912** —— 与方案「简单读取器应优于复杂分类器」的预期相反。10-shot 不高于 5-shot 是最近质心检索的固有现象（同风格跨画家差异大，更多样本求均值反把原型拉向「平均画」），非实现 bug。

训练侧 SupCon loss 从 4.13 缓慢降到 4.08 后进入平台，说明 1500 步内优化已基本饱和，不是训练不足。

## 4. 与上一轮（固定读取器失败）的关系

| | 固定 1340 维统计读取器 | 本轮可学习读取器 |
|---|---|---|
| 是否读出风格信息 | 不能（easy 0.5375） | **能（easy ~0.60）** |
| hard AUROC | 0.4535 | 0.4645 / 0.4770 |
| 是否跨过 Gate 门槛 | 否 | **否** |
| 潜在改进来源 | — | 主要来自「可训练非线性」，非局部归纳偏置 |

结论收紧为：**问题不在「有没有风格信息」，而在「原生 latent 中风格与内容的耦合方式」** —— 内容相近的不同风格作品在表示空间里系统性地更近，使得内容匹配负样本成为硬约束下的不可分对。

## 5. 下一步（需您决策，本轮未执行）

按方案 Gate R 失败的分支：**不再微调固定 Gram / 协方差 / 中心化，直接重新讨论 latent 的结构化风格表示**。可考虑的方向：

1. **改变评测口径前先明确目标**：若 WEAVE 真正需要的是「跨内容迁移」，内容匹配 hard AUROC 是正确约束；若只需「同内容不同画风」，可改用内容固定配对。两者不应混用。
2. **显式 Style Branch**（`z=(z_c,s)` + 零初始化 FiLM）：方案此前暂缓，但本轮显示「在原生 latent 上用极小读取器无法解耦内容/风格」，这是重新讨论它的实证依据。需评估对 S10 Decoder 及已有生成模型兼容性的影响。
3. **重建教师选择**：已知 S10 重建 LPIPS 0.0831 明显差于 A0 0.0678，后续任何 Encoder 验收必须同时比较两者，不能只因 S10 推理快就当作最优重建教师。

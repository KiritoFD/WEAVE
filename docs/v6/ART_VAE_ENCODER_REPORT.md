## 3. 根因诊断（`diagnose.py`，只读）

### 3.1 r(z) 是内容主导，不是风格主导

余弦分布（a0）：

| 配对 | 平均余弦 |
|---|---:|
| 同风格 / 不同画家（正样本） | **+0.7993** |
| 不同风格 / DINO 内容匹配（hard neg） | **+0.8140** |
| 不同风格 / 随机（easy neg） | +0.7803 |

**hard neg 比正样本更相似（+0.0147）**，这直接解释了为什么 Cross-Artist Content-Matched AUROC **< 0.5**（比随机差）。固定多尺度统计量（μ/σ/Gram）捕捉的是内容/纹理共性，而非画派。

### 3.2 强共模，余弦无分辨力

所有配对余弦挤在 **0.78–0.82**，L2 归一化后样本几乎共线。做了零成本的去共模对照（减去验证池平均 r(z) 再归一化）：

| | a0 | A |
|---|---:|---|
| AUROC raw | 0.4535 | 0.4566 |
| **AUROC centered** | **0.4316** | **0.4336** |

去共模后**更差** → 失败不是「均值偏置」这类实现缺陷，而是**算子本身的归纳偏置不成立**。

### 3.3 SupCon 只制造了共模式伪进步

Stage A 把 pos 和 hard 同时抬高（0.7993→0.8118、0.8140→0.8241），pos−hard gap 仅改善 **+0.00233**；`z_rms` 4.656→4.665、`q` 每维 std 0.012315→0.011956（略降）。这正是方案明确列为失败模式的**「靠整体相似度抬高取得表面进展」**，而非有效风格分离。

## 4. 过程中修掉的、会毁掉结论的 bug

| bug | 影响 | 修法 |
|---|---|---|
| `calibrate_lam_s` 缩放公式沿用了旧代码的 `lam_s*0.15/ratio`，但 `g_s` 未乘 `lam_s` | 风格梯度只有重建的 **1.5%**（应 15%），SupCon 被压制 10 倍 | 改为 `lam_s = TARGET_SHARE/ratio`，实测 0.01882 |
| 标定用 8 张 + 两次独立 encoder 图 | upd 20 OOM | 单次 encoder forward 复用 posterior，回 4 张 |
| gate 用「per-update style loss 首尾差」判据 | 该值随 batch 构成在 4.28–4.45 波动（±0.1），有一半概率误判 | 引入**固定参考 batch** 的 `ref_style` 曲线 + 四分位均值 |
| `run_serial.sh` 的 `set -e` 下 gate 非零退出码 | 脚本直接退出而非记录判定 | `set +e` 捕获 |
| data 自测 numpy/torch 混用 | step 5 中止 | `torch.as_tensor` |
| gate 重建基线误用 A0 | 把 decoder 容量差当退化 | 改与 S10 比 |

## 5. 结论与建议

**结论**：在方案给定的约束下（原生 4×64×64、固定无参数多尺度统计读取、SupCon+VICReg、只训 Encoder 末端、S10 冻结、风格梯度 15%、500 步），**目标未能塑造出跨画家可分、简单读取器可学的风格结构**。gate A 失败是真实结论，B/C 按方案「A 通过才扩展」规则跳过，未浪费 4500 updates。

**根因**：`r(z)=[μ,logσ,G₀,G₁]` 是**内容/纹理统计**，不是风格统计。内容匹配的不同风格作品在 r(z) 上比同风格跨画家更近。这不是权重、学习率或步数问题，加大 λ_s 或延长训练只会放大共模。

**若要继续（需用户决策，本次未擅自执行）**：
1. 换读取算子：不再是固定统计，而用「同风格跨画家正样本 / 内容匹配负样本」监督出一个**轻量可学习投影**（但仍非 768 维随机投影、非分类头主出口），或改用 patch-level 高阶统计（Gram 的通道间相关性而非中心化协方差）
2. 或按方案的结构分支升级为 `z=(z_c, s)` + 零初始化 FiLM —— 但方案规定该分支的触发条件是「B 成功但 C 失败」，本次 B 未执行，**不触发**
3. 先做一个零成本的前置判据：任何候选读取算子必须先满足「content-matched hard-neg 余弦 < same-style cross-painter 余弦」（即 raw AUROC > 0.5），再投入训练预算

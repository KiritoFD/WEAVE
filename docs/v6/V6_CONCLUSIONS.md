# 结论 5：失败的本质是**方向纯度 0.30**，不是幅度

## 5.1 变换"改了很多但瞄不准"

| 量 | 值 | 含义 |
|---|---:|---|
| 潜空间变换幅度 `d_out` | **71.66** | 每维 RMS ≈ 0.56，改变量很大 |
| 跨目标差异 `d_cross` | **66.39** | 换目标风格的改变 ≈ 整个变换的 **98%** |
| **CSD 空间朝目标位移 ΔT** | **+0.03** | 小 |
| CSD 空间离源位移 ΔS | **−0.11** | 大（3.6 倍于 ΔT） |
| **方向纯度 \|ΔT\|/\|ΔS\|** | **0.30** | **只有 30% 的位移朝目标** |

> **70% 的位移是"破坏源风格而未获得目标风格"。**

**因此输出仍有 91.4% 被识别为源风格，目标风格仅 3.1%。**

**机制**：破坏源风格的判别特征便宜（低维），合成目标风格的特征昂贵（高维），
而损失只要求"余弦提高"，不要求"落在目标原型的 Voronoi 区域内"。

## 5.2 加大幅度能小幅改善，但代价不可接受

M0 的 α 扫描（α=0 → 2.0，N7_dim24，200 任务）：

| α | ΔT | **Top-1** | LPIPS |
|---:|---:|---:|---:|
| 0.00 | −0.0005 | 0.015 | 0.078 |
| 1.00 | **+0.0354** | 0.035 | 0.366 |
| 1.25 | +0.0365（ΔT 峰值） | 0.075 | 0.454 |
| 1.50 | +0.0291 | 0.100 | 0.531 |
| 1.75 | +0.0188 | 0.105 | 0.598 |
| 2.00 | +0.0074 | **0.130** | **0.655** |

**三条曲线的方向完全不同**：Top-1 单调上升（0.015→0.130）、LPIPS 单调上升（0.078→0.655）、
**ΔT 在 α=1.25 达峰后下降**。**这就是 ΔT 与 Top-1 秩相关只有 0.214 的机制。**

**即使 α=2.0（训练幅度的 2 倍）：Top-1 0.130 仍低于随机 0.20，LPIPS 0.655 接近翻倍，
margin 仍为 −0.157（目标原型仍不是 argmax）。**

**外推：达到 Top-1=0.20 需要 α≈3.0，此时 LPIPS 约 0.85+，图像基本被破坏。**

## 5.3 每目标强度标定（计划 §7 的 r_j）

| 目标 | 保真档 | 均衡档 | 风格档 |
|---|---|---|---|
| Early_Renaissance | α=1.0 | α=1.0 | α=1.0 |
| Impressionism | α=1.0 | α=1.0 | α=1.0 |
| Minimalism | **α=0.75** | α=0.75 | α=0.75 |
| Rococo | **α=0.75** | α=0.75 | α=1.0 |
| **Ukiyo_e** | **α=0.5** | α=0.5 | α=0.5 |

**Ukiyo 与 Minimalism 的最优 α 低于 1 —— 过度推动对它们有害。**

**分目标在 α>1 时的表现**：只有 Impressionism 继续改善（峰值 +0.0789 @ α=1.75）；
ER、Rococo、Ukiyo 全部退化；Minimalism 持平。
**视觉能量强的风格从"改得更多"获益，结构性学院派风格则被过度推动破坏。**

# 结论 7：结构性解释 —— 训练空间与评测空间失配

> **V6 在 DWT 子带统计空间监督风格，而"是否画成目标风格"在 CSD 语义空间度量。
> 两空间弱耦合 → DWT 空间优化饱和，CSD 空间可识别性保持平坦。**

**四条汇聚证据**：

| # | 证据 | 内容 |
|---|---|---|
| 1 | **S5 预实验** | DWT 空间里 Ukiyo 与 ER 只差 0.60；HF 特征与现有 DWT 矩冗余 **0.921**；HF 区分力更低（0.503 vs 0.555）；对困难目标更差（1.22 vs 2.58） |

| 3 | **24 臂** | ΔT 变化 2.6 倍，Top-1 恒定 0.02–0.05，秩相关仅 **0.214** |
| 4 | **V11 d2** | 直接在 CSD 空间监督，L_dist 降 **65%** 但 CSD-SWD 仍平坦 |

**"幅度不足"是现象，不是解释；失配解释了为什么幅度上不去。**

# 结论 9：下一步（按推荐度）

## 路径 A（推荐）：提高方向纯度

**理由**：幅度已经很大（跨目标差异达变换的 98%），但方向纯度只有 0.30。
**继续放大幅度只会同时放大错误分量** —— M0 的 α 曲线已经证明这条路的上限。

**具体做法**：
1. **人工盲评**（计划 §1 要求，**唯一未做项**）
   网格图已就绪：`runs/v6_24h/grid/grid_*.png`
   每张含 源图 / VAE 往返 / 五个目标输出，附 `manifest.json`（含每图的 target cosine、argmax、margin）
2. **在损失中显式约束方向**：例如要求 `ΔT ≥ κ·|ΔS|`，惩罚"只降 ΔS 不升 ΔT"的位移
3. 若确认需要换机制，再考虑在 CSD 空间直接监督可识别性（须先解决 V11 d2 的传导失败）

## 路径 B：换特征空间（针对 Minimalism / Ukiyo 天花板）

DWT 统计空间无法区分这两个目标，**必须换空间**。
但 V11 的教训是 latent 与 CSD 空间失配，需先解决传导问题。

## 明确不该做的事

| 不该做 | 原因 |
|---|---|
| 继续调 λ_s / λ_c | λ_c 已饱和；2×2 因子设计完整，交互项 −0.0029 已量化（近似可分离） |

| 加 DWT 统计类损失 | S5 预实验证明该空间无法区分困难目标 |
| 用 ΔT 单指标排名 | 秩相关仅 0.214；α>1 后两者方向相反 |
| 把 ΔT +0.008 当显著进展 | 小于 VAE 往返漂移 0.0113 |
| 宣称"5/5 风格改善" | 依赖 Ukiyo 的 +0.0006（噪声内），且 Heldout400 上为负 |
| 单层消融推断"该层不重要" | 三层内容注入是冗余通路（单层 ≤0.0018，全关 +0.0151） |

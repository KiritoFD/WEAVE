## 评测结果（750 任务 × 3 编辑水平，配对噪声）

**dino_s @ t0=0（纯风格生成）**：

| 臂 | conv base | att base | conv where | att where |
|---|---|---|---|---|
| dim96 | **0.563** | 0.561 | 0.561 | 0.559 |
| dim64 | 0.551 | 0.532 | 0.540 | 0.519 |
| dim32 | 0.501 | 0.482 | 0.493 | 0.472 |
| dim16 | 0.472 | 0.459 | 0.468 | 0.476 |

- **style_top1（NCM 最近风格分类）**：全部 16 臂 × 3 水平 = **48/48 落在 0.190–0.208 ≈ 随机（0.20）**。
- **度量校准**：真画（z_src 解码）同一读数 **top1 = 0.827**、self-sim 0.611 → 度量上限充足，臂的随机 top1 是真实的生成风格无关，不是读数弱。
- **dino_c（内容保留）** 完全按设计工作：t0=0/0.4/0.7 → 0.25 / 0.35–0.44 / 0.71–0.75。编辑算子健康。
- **dino_s_cross < dino_s**（每个水平，如 t0=0.7：0.461 vs 0.496）→ cross 任务输出没有被拉向目标风格，停留在源风格区。
- t0=0.7 的 dino_s（0.49）与 V10 E4 管线（0.4415）同量级——本读数体系下 probe 臂与成熟管线相当，但 top1 都是随机的 → **dino_s 绝对值主要反映"像一幅画"，不反映"像目标画派"**。

## 判决（V15 主矩阵三轴全部排除）

1. **容量**：0.13M→3.16M（24×）只买 +0.10 dino_s（"更像画"的通用成分），top1 恒随机。
2. **上下文（attention）**：生成层零效果（训练层仅 dim16 有效）。
3. **Where 自监督**：生成层零效果（每格内 where ≈ base ±0.02）。→ 候选方法论第五定律：**Where self-supervision ≠ generation style specificity**。

**结论**：风格 one-hot 全局条件（AdaLN）在本文献探针族里不能把生成分布拉向目标画派；风格特异性瓶颈不在生成容量/上下文/where 监督，与 V10–V15 全线"表示层 > 感受野 > 内容保护"结论一致。内容轴（dino_c）则完全健康——局部编辑的内容来源已经解决，**未解决的是风格轴的注入机制**。

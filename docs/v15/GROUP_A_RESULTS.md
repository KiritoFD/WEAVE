## 3. 横向发现

1. **style_top1：48/48 格全部 0.190–0.208 ≈ 随机（0.20）**。真画 0.827 锚定下，这是生成端风格无关的实锤，容量/上下文/where 任何组合都无效。
2. **dino_s 容量梯度**：0.46 → 0.50 → 0.53 → 0.56（dim16→96，t0=0），+0.10 且在 dim64→96 饱和；**但 top1 不动** → 增量是"更像画"的通用成分，不是"更像目标画派"。
3. **dino_s_cross < dino_s** 在每个水平成立（如 t0=0.7：0.461 vs 0.496）→ cross 任务输出未被拉向目标风格，停留在源风格区。
4. **dino_c 内容轴完全健康**：0.25 → 0.35–0.44 → 0.71–0.75 随 τ0 按设计变化；where/att/容量都不扰动内容轴。
5. **where 自监督零效果**：每格内 where ≈ base（dino_s ±0.02，top1 不动）。→ 候选方法论第五定律：**Where self-supervision ≠ generation style specificity**。
6. **attention 生成层零效果**（att 在同格内甚至普遍略低于 conv，如 dim64: 0.532 vs 0.551）。
7. t0=0.7 的 dino_s（~0.49）与 V10 E4 管线（0.4415，同读数体系）量级相当 → dino_s 绝对值主要由"像一幅画"驱动；**跨臂比较必须用 top1 / cross 分量**。

## 4. 判决（V15 主矩阵三轴全部排除）

| 轴 | 证据 | 结论 |
|---|---|---|
| 容量 0.13M→3.16M（24×） | dino_s +0.10 饱和；top1 恒随机 | 排除 |

**V15 P0 回答**：风格 one-hot 全局条件（AdaLN）在探针族里不能把生成分布拉向目标画派。内容轴已解决，未解决的是风格轴的注入机制——与 V10–V15 全线"瓶颈在表示/注入，不在生成容量"闭环。

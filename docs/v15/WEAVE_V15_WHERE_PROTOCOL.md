# **V15：WEAVE 局部内容识别与条件化风格生成的完整实验方案**

## **一、研究目标与基本原则**

这次不设置任何中途判停门槛。所有预注册实验臂均完成训练、诊断和统一评测；无论中间结果好坏，都不改变后续实验的执行范围。

**核心问题：在现有约 15k 训练图像的条件下，重新训练并扩大 WEAVE 的 U-Net，能否让模型根据局部内容选择不同的风格编辑操作？这种能力由模型容量、感受野、空间条件机制还是训练目标决定？**

这需要区分四件事：

1. **信息可获得性**：输入 latent 是否保留了识别局部内容所需的信息？
2. **内容表示能力**：U-Net 中间特征是否能够区分局部结构和语义区域？
3. **条件化编辑能力**：相同目标画派下，不同内容区域是否产生不同的编辑操作？
4. **实际生成收益**：这种空间条件化是否提升目标风格忠实度，同时保持内容？

前两项成立不意味着后两项成立。整图画派分类准确率高，也不能证明模型具有区域识别能力。

### **1.1 已有事实**

仓库中已确认：

- V6 使用包含 **15,545 张真实画作 latent** 的五画派数据池；旧 V6 训练代码还按每类前 100 张划分验证数据，实际训练数量需按具体实验清单计算。
- 现有 `C3UNet` 具有 64×64、32×32、16×16 多尺度结构，使用 StyleAdaLN 和 Content Injection。
- B4 约 218K 参数。扩大到数百万乃至千万级参数，可以作为正式实验变量，而不是预先排除。
- V14 的 S8 多尺度表示在 painting-level NCM 上达到 0.7965，说明其具有较强的**整图画派判别能力**，但不能证明局部内容可识别。
- V11b-H2 已表现出中频细节生成能力，不过目标风格条件的独立贡献仍然不足。

这次实验不预设“latent 信息不足”“必须使用 RGB”或者“必须使用大型预训练模型”。

这些都应该成为被测假说。

### **1.2 数学上能确定什么、不能确定什么**

必须明确无配对风格迁移的可识别性限制。

设源内容分布为 \\(P_C\\)，目标画派图像分布为 \\(P_s\\)。即使学到了一个映射 \\(T_s\\)，使得：

\\[ (T_s)\_\\#P_C=P_s \\]

也无法仅凭目标边缘分布证明该映射正确保留了内容对应。

因为对任意保持 \\(P_s\\) 不变的变换 \\(\pi\\)，映射

\\[ \widetilde T_s=\pi\circ T_s \\]

仍然满足：

\\[ (\widetilde T_s)\_\\#P_C=P_s \\]

因此，**只有画派标签和无配对图像分布，不足以唯一确定正确的局部风格转换。**

这是一个可识别性问题，不是网络参数量不足的猜测。

它意味着我们必须额外研究内容结构、空间对应与局部编辑的一致性。

但它不意味着模型无法学习有用的局部风格转换。实际目标应当是验证特定架构和监督条件下，哪些可观测能力能够被稳定学到。

## **二、给 Where 一个可计算的定义**

我建议不再用“模型理解了局部”这种模糊描述，而是研究三个相互关联但不同的量。

### **2.1 Where-A：内容是否编码在局部特征中？**

设 U-Net 第 \\(l\\) 层的空间特征为：

\\[ F_l(x)\in\mathbb R^{C_l\times H_l\times W_l} \\]

定义区域标签 \\(R_i\\)，例如天空、建筑、人物、植被，或者几何结构意义上的平坦区、边界区、纹理区。

通过统一的冻结特征 Probe：

\\[ \hat R_i=P\_\phi(F_l(x)\_i) \\]

检验不同层、不同容量、不同上下文模型的区域可分性。

需要测量：

- 语义区域 Macro-F1、mIoU；
- 几何边界 F1、区域连通性；
- 跨画派和跨画家泛化；
- 仅使用局部 Token 与加入全局上下文后的差异；
- 输入 RGB、VAE latent、Canonical latent 的差异。

这些指标测的是**表征中有多少可供指定 Probe 使用的区域信息**，不是直接证明生成器使用了这些信息。

### **2.2 Where-B：风格编辑是否依赖局部内容？**

这是整个实验最核心的对象。

定义一个生成器：

\\[ G\_\theta(c,s) \\]

其中 \\(c\\) 为规范化内容，\\(s\\) 为目标 Style-ID。

比较两个目标风格的输出：

\\[ \Delta\_{s,t}(c)=G\_\theta(c,s)-G\_\theta(c,t) \\]

它表示在相同内容下，切换目标画派产生的变化。

现在对内容做局部干预 \\(I_R\\)，只修改指定区域 \\(R\\)，得到：

\\[ \boxed{ D_R^{s,t} = \Delta\_{s,t}(I_R(c)) - \Delta\_{s,t}(c) } \\]

这个量有明确的解释。

如果生成器的目标风格差异完全不依赖内容，即：

\\[ G(c,s)=A(c)+B(s) \\]

那么严格有：

\\[ D_R^{s,t}=0 \\]

反过来，\\(D_R^{s,t}\neq0\\) 只能证明存在内容—风格交互，**不能单独证明这种交互符合语义或画派规律**。

因此还必须测量响应的位置、结构一致性，以及正确与错误风格条件下的区别。

局部干预包括：

- 替换区域内部的纹理，但尽量保持几何；
- 修改区域的结构，同时控制纹理统计；
- 将相似局部结构放入不同的全局上下文；
- 平移或翻转整个内容，并对齐比较风格响应；
- 保留局部特征，改变其周围区域。

通过这些干预，可以把局部纹理敏感性、区域结构敏感性和全局上下文敏感性分开。

### **2.3 Where-C：编辑在空间上如何传播？**

还要测量生成器的局部响应。

令 \\(\Delta\_{s,t}(c)\_i\\) 是输出位置 \\(i\\) 的风格差异，则：

\\[ J\_{ij}^{s,t} = \frac{\partial \Delta\_{s,t}(c)\_i} {\partial c_j} \\]

这是风格条件差异对输入内容的 Jacobian。

我们不需要显式构造完整 Jacobian。可以用 JVP、VJP 或有限差分估计。

根据空间距离、区域关系和干预类型聚合：

\\[ K\_{s,t}(d)= \mathbb E\_{\\,\operatorname{dist}(i,j)=d} \left[\\|J\_{ij}^{s,t}\\|\right] \\]

得到不同距离上的响应曲线。

但这里不能简单认为远距离响应一定不好：天空的画法可能需要整幅画的上下文。正确分析应同时报告：

- 空间距离；
- 是否属于同一结构区域；
- 是否处于同一语义对象；
- 响应是否有助于目标风格；
- 是否损害无关内容。

**这三个 Where 量共同回答：模型能否识别局部、是否利用局部信息、是否把局部信息转换成合理的画法。**

## **三、数据、监督和可识别性实验**

### **3.1 数据组织**

统一以现有五画派真实训练池为基础。历史记录中 V6 为 15,545 张，部分 V10 缓存为 15,539 张。实验前需要以实际图片 ID、文件哈希和 latent manifest 核对有效样本，不能把不同缓存的数量直接视为一致。

数据划分采用：

| 数据         | 用途                 | 约束                           |
| ---------- | ------------------ | ---------------------------- |
| 真实画作训练集    | U-Net、H2、Where 自监督 | 五画派均衡采样                      |
| 画作级验证集     | 训练曲线、重建能力、条件预测     | 不参与梯度更新                      |
| 艺术家级留出集    | 检验未见画家泛化           | 尽可能按 artist ID 分组            |
| 现有 Test750 | 所有正式生成比较           | 600 Cross + 150 Same，全部臂完整评测 |
| 新建区域标注集    | 独立测量 Where         | 不参与模型选择                      |
| 合成可控内容集    | 验证模型空间表达能力         | 有解析的局部区域与目标操作                |

全部数据划分固定，所有实验臂共享。

Test750 已经反复用于研发，所以仍应明确称作统一研发评测集，而非独立盲测。

### **3.2 建立独立的 Where 标注集**

**这是必要的测量工具，不是下一轮大型标注训练任务。**

建议在训练池的独立留出部分抽取 300 幅画作，每画派 60 幅。

分别标注两类信息：

- **几何结构区域**：平坦区、边界、纹理区、连续结构区域。
- **可辨认的语义区域**：人物、天空、植被、建筑、其他；抽象作品允许“不适用”。

将其中 200 幅用于训练和交叉验证统一 Probe，100 幅作独立报告集。按艺术家分组，部分样本采用双人标注以量化标注歧义。

这样可以区分两个问题：

**Q1：** 模型是否能识别视觉结构？

**Q2：** 模型是否能识别语义区域？

二者不应该被混为一谈。对于 Minimalism 等抽象画派，Q1 可能比 Q2 更有意义。

### **3.3 还需要一个有解析真值的受控实验**

单靠真实艺术数据，无法唯一确定正确的跨画派局部变换。

因此增加合成场景测试。

随机生成包含多种几何对象、区域遮挡和不同局部纹理的画面，并定义明确的空间条件变换，例如：

\\[ T_s(x)\_i= \begin{cases} T\_{s,1}(x)\_i,&i\in R_1\\\ T\_{s,2}(x)\_i,&i\in R_2\\\ T\_{s,3}(x)\_i,&i\in R_3 \end{cases} \\]

区域类型和正确变换均由生成程序确定。

训练相同架构完成这些受控任务，直接测量：

\\[ L\_{\mathrm{oracle}}= \\|G\_\theta(x,s)-T_s(x)\\|^2 \\]

在这里，正确答案是已知的。

这个实验能回答：某个大小的 U-Net 是否有能力表示和学习空间条件化操作。

但它不能证明模型已经学会真实艺术画派。两套实验必须分别报告。

## **四、完整 U-Net 重训：主因子实验**

不采用先扩容、成功后才加 Attention 的路线。

**所有容量、上下文和监督组合一起预注册，全部执行。**

### **4.1 三个独立实验因子**

| 因子          | 水平                          | 要回答的问题        |
| ----------- | --------------------------- | ------------- |
| 容量 \\(P\\)  | `base_dim=16/32/64/96`      | 表示能力是否随模型规模改善 |
| 上下文 \\(C\\) | 原始多尺度卷积 / 增强跨区域 Attention   | 是否需要显式长程信息交互  |
| 监督 \\(W\\)  | 原始 V6 目标 / 原始目标 + Where 自监督 | 空间表示是否需要独立监督  |

构成：

\\[ 4\times2\times2=\boxed{16\text{ 个主实验臂}} \\]

每个臂训练两个固定 Seed，共 32 次训练。

模型实际参数量、FLOPs、显存和速度通过 profiling 记录，不使用文档中的估算参数量代替实测。

### **4.2 上下文因子的具体实现**

原始架构：

```
64×64 Conv
    ↓
32×32 Conv
    ↓
16×16 Conv
    ↓
32×32 Conv
    ↓
64×64 Conv
```

增强上下文架构：

```
64×64 Conv
    ↓
32×32 Window Attention
    ↓
16×16 Global Attention
    ↓
32×32 Window Attention
    ↓
64×64 Conv
```

16×16 只有 256 个空间 Token，因此可以直接进行全局注意力。

但不能因为 Attention 有更大的理论感受野，就认为它一定能够更好地识别内容。

必须比较实际的空间响应、特征可解码性和生成效果。

为隔离架构影响，还需要控制参数量和计算量。纯卷积对照允许调整宽度或深度，使同一档位尽量接近 Attention 模型的参数与计算规模；所有无法完全匹配的差异均记录。

### **4.3 Where 自监督的具体内容**

这一组实验仍保留 V6 原有的真实画作重建、跨画派分布和内容约束目标。

新增损失为：

\\[ L\_{\mathrm{train}} = L\_{\mathrm{V6}} +\lambda_mL\_{\mathrm{masked}} +\lambda_aL\_{\mathrm{affinity}} +\lambda_iL\_{\mathrm{invariance}} \\]

其中：

**Masked Context Reconstruction**

随机遮挡部分内容特征，要求网络利用其他区域恢复缺失结构：

\\[ L\_{\mathrm{masked}} = \frac{\\|M\odot(\hat c-c)\\|\_1} {\sum_iM_i+\epsilon} \\]

**Region Affinity**

使用原图构造的弱结构区域标签，监督空间特征预测局部区域关系：

\\[ L\_{\mathrm{affinity}} = \mathcal L(A\_\theta,A\_{\mathrm{weak}}) \\]

这里的 \\(A\_{\mathrm{weak}}\\) 来自边缘和区域连续性等算法，明确不把它当成真实语义标注。

**Content Invariance**

对几何不变的颜色和纹理扰动，约束结构表示一致：

\\[ L\_{\mathrm{invariance}} = \\|E_c(T_1x)-E_c(T_2x)\\|^2 \\]

配合方差或协方差正则防止表示塌缩。

损失权重不是性能判停阈值。采用固定的梯度尺度标定规则，并在代表性架构上执行预注册的权重敏感性扫描，报告完整响应曲线，而不是挑一个看起来效果最好的配置。

## **五、独立研究空间路由：Where 是否真正参与风格生成？**

即使 U-Net 特征具有区域信息，也可能没有把它用于编辑。

因此需要第二组机制实验。

固定 `base_dim=64`，使用增强上下文架构和同一套 Where 自监督，比较：

| 实验 | 风格条件机制                     | 研究目的                   |
| -- | -------------------------- | ---------------------- |
| R0 | 原始全局 AdaLN                 | 空间共享条件基线               |
| R1 | Spatial FiLM               | 允许不同位置有不同风格调制          |
| R2 | 4 个局部操作专家 + Spatial Router | 检验内容相关的局部操作选择          |
| R3 | 空间条件随机打乱的 Router           | 检验真实位置对应是否重要           |
| R4 | 等容量卷积式 Spatial Modulation  | 区分空间调制收益与 Attention 收益 |

R0 可以复用主矩阵相同配置，其余四臂额外训练。

### **5.1 Spatial FiLM**

原始全局调制：

\\[ F'\_i=\gamma(s)F_i+\beta(s) \\]

改为：

\\[ \boxed{ F'\_i=\gamma(F_i,F_g,s)F_i+ \beta(F_i,F_g,s) } \\]

其中 \\(F_g\\) 是全局内容表示。

这样架构上允许相同目标画派对不同空间位置采用不同操作。

### **5.2 Spatial Router**

\\[ \Delta F_i= \sum\_{k=1}^{K} \pi_k(F_i,F_g,s)E_k(F_i) \\]

这里 \\(E_k\\) 是可学习的局部操作。

不人为指定某个专家负责天空或人物，也不假定专家最终一定会形成语义分工。

需要研究的是：区域信息是否真的影响 \\(\pi_k\\)，以及改变 \\(\pi_k\\) 是否导致对应局部的输出变化。

### **5.3 不能只看 Attention 图**

设置三类固定干预：

1. 保持内容不变，仅交换不同区域的 Router 输出。
2. 保持位置不变，交换当前区域的内容特征。
3. 保持局部特征不变，替换全局上下文。

分别记录输出中的局部变化。

这些实验可以把**绝对位置依赖、局部内容依赖和全局上下文依赖**区分开。

不过，某个 Router 的输出变化不一定具有艺术意义。最终仍需与区域结构、独立风格指标和视觉评价对应。

## **六、第三组：latent 是否足以支持 Where？**

这一组不能省略，否则模型扩容失败时，我们仍然无法确定问题来自架构还是输入表示。

固定同一个 `base_dim=64`、增强上下文及 Where 自监督配置，对比：

| 实验 | 内容输入                               | 研究问题              |
| -- | ---------------------------------- | ----------------- |
| I0 | Canonical latent                   | 原有输入的能力           |
| I1 | Canonical latent + 原始 RGB 灰度/边缘金字塔 | 显式结构信息是否有帮助       |
| I2 | Canonical latent + 轻量 RGB 特征编码器    | RGB 中的其他内容信息是否有帮助 |

I0 复用主矩阵，其余两臂新增训练。

RGB 分支仅使用输入图像，输出 16×16、32×32 或 64×64 内容特征，不在推理时引入大型预训练模型。

这里要特别注意：

**V14 的 79.65% 是整图画派识别能力，不能据此断言 latent 已经完整保留了 Where 需要的区域信息。**

而 V11 的 S10 重建风格指标保留率，也不等价于局部语义信息无损。

I0/I1/I2 可以直接检验这些差异。

## **七、第四组：重新训练 H2，检验内容条件如何改善中频生成**

这部分不再作为前面训练结果的后续分支。

**H2 所有实验预先固定使用同一个 Backbone 配置：**`base_dim=64 + Global Attention + Where 自监督`**，无论该配置在前面的主实验中排名如何，都完整执行。**

这样避免根据中间结果临时选择条件模型，引入额外的选择偏差。

### **7.1 为什么 H2 要重新训练？**

原始 V11b：

\\[ v\_\theta(h\_\tau,LL_2,e,s,\tau) \\]

主要依赖 LL2、边缘和当前含噪 H2。

下一版：

\\[ \boxed{ v\_\theta( h\_\tau, LL_2, F\_{\mathrm{local}}, F\_{\mathrm{global}}, s,\tau) } \\]

显式引入新 U-Net 的局部和全局内容表示。

但不能预设这样就有效，因此需要独立比较。

### **7.2 H2 的完整实验序列**

| 实验 | 配置                           | 隔离的变量               |
| -- | ---------------------------- | ------------------- |
| H0 | 原 V11b checkpoint            | 历史基准                |
| H1 | 原架构，15k 数据重新训练               | 数据规模与训练修复           |
| H2 | H1 + 全尺寸 512px 训练上下文         | 训练感受野               |
| H3 | H2 + 新 U-Net 内容特征            | 学习式内容条件             |
| H4 | H3 + Masked H2 Flow Matching | 监督目标                |
| H5 | H4 + Spatial Style Router    | 内容条件化局部笔触选择         |
| H6 | H4 + 连续 GCL                  | 内容结构约束              |
| H7 | H4 + 旧 Self-sim 连续约束         | 学习式 GCL 与手工关系的区别    |
| H8 | H4 + 允许小幅 LL2 残差编辑           | H2-only 自由度是否限制风格变化 |

H1–H8 均完整训练，H0 只复评。

所有模型保留正确/错误/无条件 Style-ID 的统一推理控制，并使用逐任务固定噪声。

### **7.3 重新设计 H2 监督**

我认为这里应该重点借鉴真实画作终点监督，而不是简单延长原版 Flow 的训练。

原始训练使用：

\\[ h\_\tau=(1-\tau)\epsilon+\tau h\_{\mathrm{real}} \\]

网络可以从当前 \\(h\_\tau\\) 获得相当多的目标细节，因此 Style-ID 的额外预测价值可能很小。

增加区域遮挡：

\\[ \widetilde h\_\tau = (1-M)\odot h\_\tau+ M\odot\epsilon \\]

只在已知真实画作上构造这种退化。

重点预测被遮挡部分：

\\[ L\_{\mathrm{H2-mask}} = \frac{ \\|M\odot(v\_\theta-v^\*)\\|^2 }{ \sum_iM_i+\epsilon } \\]

这样模型必须更多依赖附近结构、全局上下文与目标画派条件。

但即使预测性能改善，也不能直接证明它学会了跨画派笔触生成。

因此同时评价正确、错误、无条件 Style-ID 下的预测误差及其空间差异。

### **7.4 对 Style-ID 的预测价值进行数学分解**

对于平方误差，设 \\(H\\) 为待预测 H2，\\(C\\) 为可见内容条件，\\(S\\) 为画派。

Bayes 最优预测器分别为：

\\[ f_C^\*=\mathbb E[H\mid C] \\]

\\[ f\_{C,S}^\*=\mathbb E[H\mid C,S] \\]

则存在严格恒等式：

\\[ \boxed{ R^\*(H\mid C)-R^\*(H\mid C,S) = \mathbb E \left[ \left\\| f\_{C,S}^\*-f_C^\* \right\\|^2 \right]\geq0 } \\]

这给了我们一个有明确数学意义的研究目标：

**在已知内容条件之后，画派标签究竟还能提供多少关于局部 H2 的可预测信息？**

实际通过相同容量的条件与无条件模型近似估计这项差异，并报告有限样本不确定性。

如果经验差异很小，不能立即断言风格条件分布相同：平方误差主要考察条件均值，多模态分布的差异还可能存在于方差和高阶结构。因此还要比较条件采样分布、局部纹理统计及视觉效果。

这是比简单训练一个局部画派分类器更直接的监督分析。

## **八、统一诊断：所有实验都要回答 Where**

以上实验不能只交付一张总排行榜。

每个模型都必须交付四类分析。

### **8.1 空间表示能力**

在相同 Probe 训练协议下，逐层测量：

- 16×16、32×32、64×64 特征的区域可分性；
- 几何区域和语义区域的区别；
- 对颜色、纹理扰动的稳定性；
- 跨画派、跨艺术家的泛化；
- 局部特征与加入全局上下文后的性能差异。

同时进行冻结特征的线性 Probe 和小容量非线性 Probe，区分线性可解码性与更一般的可解码性。

### **8.2 内容—风格交互**

使用前面定义的：

\\[ D_R^{s,t} = \Delta\_{s,t}(I_R(c))-\Delta\_{s,t}(c) \\]

分别统计：

- 对局部结构变化的响应；
- 对无关局部纹理变化的响应；
- 对远程上下文变化的响应；
- 在不同目标画派下的响应差异。

对于具有区域标注的样本，还可以拟合区域类型与目标风格的交互项：

\\[ Y\_{i,r,s} = \mu+\alpha_s+\beta_r+\gamma\_{s,r} +u_i+\varepsilon \\]

其中 \\(Y\\) 是区域编辑特征，\\(u_i\\) 表示画作效应。

\\(\gamma\_{s,r}\\) 可以量化画派与区域之间的交互，但不将其非零直接解释成正确画法。

### **8.3 空间响应与内容损坏**

测量生成器的 Jacobian 或有限差分响应，按照空间距离和区域归属聚合。

再将这些响应与真实的边界保持、区域连通性、DINO-C、LPIPS 联系起来。

需要特别避免把“响应越局部越好”当成先验。合理的风格迁移可能需要跨区域协调。

### **8.4 实际风格生成**

所有生成实验统一使用：

- S10 解码；
- Test750 全量；
- Cross600 / Same150 分开；
- DINO-S、DINO-C、LPIPS；
- CSD Target Top-1、Margin；
- Style Affinity、G；
- 五画派逐类和 5×5 目标转换矩阵；
- 端到端延迟、峰值显存和 GPU 计算开销。

另外选取固定图像集合，进行盲法区域级视觉比较，分别评价内容保真和局部画法是否符合目标风格。

不能只用训练时使用过的同一风格分类器评价生成结果。

## **九、统计设计：估计作用大小，不设人为成功阈值**

### **9.1 主因子分析**

对主矩阵，分析：

\\[ Y= \beta_0+ \beta_P\log P+ \beta_CC+ \beta_WW+ \beta\_{PC}(\log P)C+ \beta\_{PW}(\log P)W+ \beta\_{CW}CW+ \beta\_{PCW}(\log P)CW+ \varepsilon \\]

这里：

- \\(P\\)：模型参数规模；
- \\(C\\)：上下文机制；
- \\(W\\)：Where 自监督；
- \\(Y\\)：某项具体性能指标。

由于容量是四个离散实验水平，主报告还应直接列出各水平的均值和交互效应，不强制假定结果对 \\(\log P\\) 呈线性。

分析会回答：

- 容量增加产生多少边际收益？
- 上下文增强是否独立有效？
- Where 自监督是否独立有效？
- 它们之间是否存在交互？
- 收益是否来自更高的计算预算，而非具体机制？

### **9.2 重复训练与计算预算**

预注册统一训练规则：

| 项目              | 规则                               |
| --------------- | -------------------------------- |
| 主模型训练           | 每臂 12,000 次真实 optimizer updates  |
| Checkpoint      | 2k、6k、12k 全部保留                   |
| Effective batch | 128，显存不足采用梯度累积                   |
| 随机种子            | 主矩阵两个固定 Seed                     |
| 画派采样            | 五类等概率，记录每幅画作实际采样次数               |
| 优化器             | 同一类优化器与预注册学习率日程                  |
| 质量评测            | 所有最终模型均执行 Test750                |
| 计算分析            | 同时按 updates、见过的样本数和实测 GPU 时间绘制曲线 |

不同网络的收敛速度可能不同，所以只比较第 12k 步不够；还需要完整学习曲线。

相同 updates 不代表相同算力成本，因此必须同时报告计算量。

### **9.3 统计推断**

对 Test750，按 150 幅源图聚类进行配对 bootstrap，避免将同一源图的五个目标当成独立样本。

报告效应量、置信区间、各 Seed 的结果及多重比较调整结果。

**不设置“提升 5pp 才算成功”等任意门槛。**

即使某项变化很小、置信区间覆盖零，也如实报告其估计精度和可兼容的效应范围，而不直接宣布数学意义上的“无效”。

对于模型规模与性能，还应提供完整的 Pareto 曲线，而不是挑出单个赢家。

## **十一、这套实验最终能回答什么？**

我认为研究问题应当被准确地表述成以下四个可回答的问题。

| 问题                       | 主要证据                               | 可支持的结论                 |
| ------------------------ | ---------------------------------- | ---------------------- |
| **Q1：当前 latent 是否足够？**   | I0/I1/I2 + 区域 Probe                | RGB 补充信息能否提升区域识别和编辑    |
| **Q2：当前 U-Net 是否太小？**    | 四档容量的完整性能曲线                        | 容量对 Where 和风格迁移的实际边际收益 |
| **Q3：是否需要显式区域建模？**       | Conv/Attention/Router/Where 监督因子实验 | 上下文、路由与监督各自的贡献         |
| **Q4：Where 是否真正帮助画派迁移？** | 局部干预 + H2 重训 + Test750             | 区域内容理解能否转化为目标风格收益      |

其中 Q4 最重要。

如果一个模型具有很好的语义 Probe，却不能据此产生有效的风格编辑，那么问题就不再是区域识别能力本身，而是区域信息如何进入生成目标。

反过来，如果模型在没有明确语义分割能力的情况下，也能稳定产生内容相关且符合画派规律的笔触，那就说明**显式语义识别并不是实现实用 Where 的必要条件**。

这两种结果都具有研究价值，不能通过中间门槛预先排除。

## **最终建议**

**重新训练 U-Net 是这次实验的主体，而不是附加选项。**

我建议正式将 V15 定义为：

**Where Does Local Style Editing Come From? — A Controlled Study of Capacity, Context, Spatial Conditioning and Supervision in Lightweight WEAVE**

研究不预设小网络一定足够，也不预设必须依赖 StyleGallery 的大型预训练特征。

2026 年 StyleGallery 和 CoCoDiff 的共同启示，是语义对应及区域一致性对风格迁移具有重要作用；但它们使用了预训练扩散特征，不能据此推断轻量模型无法学到相同类型的操作。

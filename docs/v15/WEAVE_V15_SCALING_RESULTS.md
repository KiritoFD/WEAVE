## 结论

1. **容量扩展改善的是"像画"，不是"像目标画派"**。t0=0 各项生成指标全面变好（S6 margin ≈ 0 为全场唯一）；但 t0=0.4/0.7 编辑点上，dino_c/lpips 显著改善的同时 target Top1/margin 反而略降——更强的源内容保持意味着轻编辑下输出更贴近源风格。
2. **t0=0.7 dino_s 下降不是测量错误**：同一 eval/measure 管线、同一裁判、配对噪声；GROUP_A 的 dim16→96 在 t0=0.7 本来就是平的（.449–.461），容量→dino_s 的上升趋势只在 t0=0 成立。S6 的 .4445 略低于该区间，与"8000 updates + 4×容量 → 更强内容保持"的机制一致。
3. 混杂说明：S 系为 8000 updates（W96 为 4000），dino_c/lpips 优势部分可能来自训练量而非纯容量；若要干净归因需补 dim96×8000 对照。
4. 对 Style-Bridge PT 的意义：**底座选择应权衡**——S6 生成质量/内容保持更好，但跨画派条件判别（本轮核心问题）并未因容量改善；P2–P4 仍以 W_dim96_conv_base 为基线保持可比性，S6 可作为后续验证底座。

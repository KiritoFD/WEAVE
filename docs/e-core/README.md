# E-Core｜高保真单步编辑与目标流形路由

> 11,131,268 参数 · 1-NFE · 当前权重 ECore_NoDINO，非历史 V28/DINO 版本。生成路径不依赖 P-Core。系统调度见 [System](../system/README.md)，内容条件见 [Conditioning](../conditioning/README.md)。

## 1. 职责与接口

E 不是 P 的廉价近似，而是学习明确的跨画派编辑映射。它同时承担两项任务：高内容区直接生成；在中强风格区为 P 提供已经包含目标画法的起点。P 不应直接从保留大量源画法的源 latent 恢复。

| 输入/输出 | 规格 |
|---|---|
| 源 latent z_s | B×4×64×64，SD-VAE scaled（×0.18215） |
| 局部结构 c64 | B×4×64×64，按真实生产预处理；不得从测速脚本的临时拼接推断训练契约 |
| 语义 q16 | B×32×16×16 ConvNeXt Stiefel |
| 目标条件 | tid、raw_stats、priors |
| 控制 | lambda、noise |
| 输出 z_E | B×4×64×64，仍在同一 scaled latent 空间 |

原始 UnifiedHybridUNet：64→32→16→32→64 残差 U-Net；16×16 只接粗布局条件，高分辨率保留受控源结构 skip，空间 AdaGN 调制而非参考 Value 注入。输出参数化为 z_E=z_0(lambda)+lambda*Delta_theta；lambda=0 的 latent 恒等由结构保证。A3 是 P 起点校准，不得无条件写进 E.forward 改变原生单步基线。E+A3 作为独立实验变体单列。

## 2. 训练血缘：单步学生需要一致映射

历史关键配方由 V28 形成：V22 Peak1500+P1 锚生成单一教师双档终点，连续 lambda 采样（含约20%同画派恒等），Smooth L1、Haar 高频及亮度约束，加 S10 像素桥 VGG/ConvNeXt Patch-SWD 与 Oklab 统计。历史 Adv1NFE 在放松高强度 L1、保持结构约束的同时加入 Projected GAN（adv_w=.06，2600步）。这是一组联合后训练，不能把所有收益独立归因 GAN。V32 从随机初始化重训 Zero-DINO E（2800步）；不得直接套用 V28 的训练时长作为 V32 的精确复现配置。

| 历史对照 | 结果 | 结论 |
|---|---|---|
| 多专家逐图择优 Pool A | 教师70.7%，学生40.17% Top-1 | 单图高分≠统一可学映射 |
| 单图优化 Pool B | 学生14.67% | 不一致监督导致高方差 |
| 单一旧教师 | 51.33% | 映射一致性重要 |
| V22 clean + 连续2tier | 58.67% | 强且一致的目标优于异构冠军 |
| 联合 Adv1NFE | 66.83%，+8.17pp [5.50,10.83]；S +.0287，C +.0087 | 训练阶段可缓解单步回归折中 |
| 离散3tier | l060 回落至约1% | 强度覆盖空洞产生恒等捷径 |

以上是历史 V28 工作点，不能混作现役 E 的同构消融。来源：[原始报告](../archive/historical/v28/PROGRESS.md)。

## 4. 最强因果证据：E 决定 P 从哪里开始

固定现役44M P、同一调度/噪声，仅替换草稿（V35 P1）：

| 草稿 | s085 Top-1 / source-lock | s100 Top-1 / source-lock |
|---|---:|---:|
| 原源 latent | 2.50% / 91.50% | 10.17% / 74.67% |
| 解析色度匹配 | 4.50% / 88.17% | 17.17% / 65.50% |
| E | 51.67% / 40.00% | 66.17% / 24.17% |
| E+A3 | 55.00% / 35.33% | 69.00% / 20.33% |

E 相对色度匹配：s085 Top-1 +47.17pp [42.33,51.83]，s100 +49.00pp [45.50,52.33]。改变草稿同时改变内容工作点，因此该表证明目标路由/解除源锁定，而非等内容质量增益。

s100 的正误目标 2×2：

| E+A3 目标 | P 正确 | P 错误 |
|---|---:|---:|
| 正确 | 69.00% | 53.00% |
| 错误 | 3.67% | 2.17% |

固定 P 正确条件，纠正草稿 +65.33pp；固定正确草稿，纠正 P 条件 +16.00pp。两者为不同简单效应，不可相加为总收益。证明当前半噪调度下草稿主导目标流形选择，P 仍有独立作用。纯噪端另属不同调度。

## 5. 已关闭的路线与边界

单步 TTO 裸推或穿透学生优化未能突破前沿（V28 TTO2 S=.5072 @ C=.6395；穿透学生产生撤销编辑捷径）；多教师择优、离散强度锚、无约束残差回归不再重试。E 的极限风格分仍约 .508；Uki 在 P7 l100 仅15.8%，需要 P 补足，而非把 E 强行扩容成全谱单步模型。P9 的 E/P 交界 latent RMSE=.1935，连续旋钮的视觉过渡尚未闭合。

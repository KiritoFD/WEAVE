## 二、统一等效判定与剪枝规则（验收铁律）

对每一项组件的**保留/删除**，均须在 `cross600`（源图聚类 `n_clusters=150`, `n_boot=4000`）上跑配对 Bootstrap 95% CI（`src/eval/metrics.py::bootstrap_source_ci`）：

- **等效容忍区间**：`ΔDINO-C ∈ [-0.010, +0.010]`，`ΔDINO-S ∈ [-0.005, +0.005]`，`ΔLPIPS ∈ [-0.010, +0.010]`（同时核查五画派最差类别不发生单类坍缩、`same_blind` 不退化）。
- **剪枝优先原则**：若更简单配置相对复杂配置在两项核心内容/风格指标上的损失不突破上述容忍区间（或 95% CI 显著不劣），**强制删除复杂组件**；某组件若不能形成明确的 Pareto 增益，一律删除。
- **主目标参考线**：`DINO-C ≥ 0.70–0.73`，`DINO-S ≥ 0.49–0.51`，`LPIPS ≤ 0.51`，端到端延迟 `< 100 ms/img`。

### Round 1：无训练推理结构消融（4090，共 22 臂：复用 6 臂 + 实跑 16 臂）

#### 1. P0-1：单模型强度扫描 vs Hybrid 必要性（`exp/v25/r1_p0_hybrid_vs_single.py`）
回答：**`M1_lin`（PRISM-1 + V20 D6 双模型混合）是否真的不可替代？**

- **曲线 A（`PRISM-1` 单模型，仅调 $\lambda$）**：
  - `A_p1_l075`（**复用 `V24 M0_prism1_l075`**：`D-C=0.7715, D-S=0.4371, LPIPS=0.4848`）
  - `A_p1_l100`（**复用 `V24 M0_prism1_l100`**：`D-C=0.7440, D-S=0.4430, LPIPS=0.5057`）
  - `A_p1_l130`（**实跑**，`λ=1.30, α=min(0.45, 0.20λ)=0.26`）
  - `A_p1_l160`（**实跑**，`λ=1.60, α=0.32`）
- **曲线 B（`V20 D6` 单模型 `slf_core_v2.pt` + T4 锚点，固定权重与分支，仅移起点区间 $\tau$）**：
  - `B_d6_orig`（`[0.40, 0.74]`，**复用 `V24 M0_v20_d6`**：`D-C=0.6688, D-S=0.5107, LPIPS=0.5374`）
  - `B_d6_tau50`（**实跑**，`tau_min=0.50, tau_hi=0.80`）
  - `B_d6_tau58`（**实跑**，`tau_min=0.58, tau_hi=0.86`）
  - `B_d6_tau66`（**实跑**，`tau_min=0.66, tau_hi=0.90`）
  - *(附跑 1 组同机制 `B_dswd_tau58` 使用 `slf_DualSWD_pure.pt` 作高内容参考对照)*
- **曲线 C（`PRISM-1 + D6` 线性 Hybrid，仅调 $\gamma$）**：
  - `C_hyb_g25`（**复用 `V24 M1_lin_g25`**：`D-C=0.7527, D-S=0.4482`）
  - `C_hyb_g40`（**复用 `V24 M1_lin_g40`**：`D-C=0.7467, D-S=0.4600`）
  - `C_hyb_g55`（**复用 `V24 M1_lin_g55`**：`D-C=0.7321, D-S=0.4745`）
  - `C_hyb_g70`（**实跑**，`0.30 P1 + 0.70 D6`）
  - `C_hyb_g85`（**实跑**，`0.15 P1 + 0.85 D6`）
- **决策点**：在 `DINO-C ≈ 0.70 / 0.73 / 0.75` 处插值比较 A/B/C 的 `(DINO-S, LPIPS, Latency)` + 配对 Bootstrap。若单模型 B 在同 `DINO-C` 下追平 C，直接淘汰 Hybrid；若 C 显著占优（`ΔDINO-S > +0.008` 且 CI 排除 0），保留 Hybrid 作为双模型参考上限或后期蒸馏目标。

#### 2. P0-2：相同权重下 `sc_only` vs `cs_j` vs `full` CFG（`exp/v25/r1_p0_cfg_branches.py`）
回答：**四分支 `full`（40 NFE）能否精简为内容条件双分支 `cs_j`（20 NFE）或无 CFG `sc_only`（10 NFE）？**

- **严格同权重对照**：固定 `slf_core_v2.pt`（唯一完整训过四分支与双分支的 V20 原主权重）+ `T4` 锚点 + `original` Gate（确保 `v_s0/v_00/v_0c/v_sc` 全分支都在训练分布内）：
  - 档位 1（`DINO-C ≈ 0.65`）：`D5_SOLVER` (`tau ∈ [0.28, 0.66]`, `ws_fig=4.2` / `cs_j` 另附一档匹配 `ws_fig=5.5` 防止仅因默认权重偏低误杀) × `{sc_only, cs_j, full}` → `3` 组实跑。
  - 档位 2（`DINO-C ≈ 0.70`）：`D6`-high (`tau ∈ [0.48, 0.80]`) × `{sc_only, cs_j, full}` → `3` 组实跑。
- **决策点**：在匹配 `DINO-C` 水平下对比 `cs_j` 与 `full`。若 `cs_j` 满足等效区间，正式将主模型 CFG 砍半为双分支 `cs_j`（NFE 40→20）。

#### 3. P1-3：`T4` vs `PRISM-1` vs `Source` 锚点在等 `DINO-C` 下对比（`exp/v25/r1_p1_anchor_and_gate.py`）
回答：**昂贵的 `T4` 迭代优化锚点能否被 `PRISM-1`（17ms）或直接 `z_src` 替代？**

- 固定 Round 1 胜出主权重与 CFG 模式，在 **`DINO-C ≈ 0.70`**（调各锚点专属 `tau_min/tau_hi` 对齐内容水位）下对比：
  - `Anc_T4`、`Anc_PRISM1`、`Anc_Source`（另附 `Anc_PRISM1 @ D-C≈0.65` 共 `4` 组实跑）。
- 同步测 **完整端到端单图延迟（ms/img，含锚点准备 + Flow + S10）与峰值显存**。

#### 4. P1-4：`original` 自适应 Gate vs `fixed_g=0.5`（同脚本 `r1_p1_anchor_and_gate.py`）
回答：**密度估计与 `sigmoid((dsd-mid)*550)` 门控能否删除？**

- 在选定最终主权重 + 锚点上，分别在 **`DINO-C ≈ 0.65`** 与 **`≈ 0.70`** 下对比 `original` vs `fixed_g=0.5`（各自允许采用预先给定的匹配 `tau` 偏移，共 `4` 组实跑）。

### Round 2：最小受控训练消融矩阵（4090，4–5 组训练）

**前置规则**：待 Round 1 定下推理结构（单/双分支、锚点、Gate）后，从同一个 **`slf_final.pt`**（V20 5000-step 预训练起点）出发，严格控制 **单变量**：
- 固定：`1500 updates`（V22 确认的峰值甜点）、有效 `batch=120`、`AdamW 1.2e-4→1.5e-5`、`EMA=0.996`、80% Core 采样、`layout=1.0` 固定、Coarse `LCN16 (0.10)`、同 `seed=20263500` 共享数据顺序与噪声。
- 矩阵定义（`exp/v25/r2_train_ablation.py`）：

| 训练臂 | `Content Dropout` (`drop_c`) | `Anchor-Bridge` (`AB`) | `MultiScalePatchSWD` | 备注 |
|---|---:|---:|---:|---|
| `Tr_T0` | `0%` | `0%` | `0` | 纯净双分支/基础对照组 |
| `Tr_T1` | `30%` | `0%` | `0` | 单独验证 `Content Dropout` 增量 |
| `Tr_T2` | `0%` | `25%` (`PRISM-1` 真 `z0_tr` 起点) | `0` | 单独验证 `Anchor-Bridge` 增量 |
| `Tr_T3` | `30%` | `25%` | `0` | 检验两机制可加性/协同 |
| `Tr_T4_swd` | 取 `T0–T3` 最优 | 取 `T0–T3` 最优 | **`w_swd=0.12`** | **条件追加**：仅在 `T0–T3` 完成后对胜出者开启 `SWD` |

- **重要修复点**：`Anchor-Bridge` 训练集锚点提前用 `B4 + canonicalizer` 为 4400 张训练图算好真实 `z0_tr`（~1 min），消除此前 `avg_pool` 引起的 `z0` train-test gap。
- 每条训练臂在统一的 **两个强度工作点**（`DINO-C ≈ 0.65` 与 `≈ 0.70`）完成完整 `test750` 评测并跑 Bootstrap CI 决定最终入库成分。

## 四、3060 One-Shot 详细实施方案（Round 3，与 4090 完全并行）

以已验证全胜的 **`O3_rgb_cnx_gated`**（`Q/K` 灰度 DINO + `V` RGB ConvNeXt + 全局 Oklab 门控）为唯一候选，脚本 `exp/v25/r3_oneshot_minimal.py`（共补 3 项对照）：

1. **标签依赖对照（`O3` vs `O3_label_free`）**：
   - `test750` 数据 **已跑完复用**（`O3`: `0.5845/0.5245/35.3%` @ t45, `0.6783/0.5025/24.0%` @ t55；`O3_label_free`: `0.6769/0.4666/11.3%` @ t45, `0.7300/0.4575/8.8%` @ t55）；
   - **需补跑**：`O3_label_free` 的 **§8.4 参考更换敏感度 (`swap_dist`)** + **SG-25 OOD 125-pair 评测**，直接对比 `O3` (`0.5867 D-C / ΔS +0.157 / swap 0.442`)。
2. **跨风格监督必要性对照（`O3_self_only` vs `O3_cross50`）**：
   - 在完全相同的 `O3_rgb_cnx_gated` 结构与 1200 updates 下，将训练数据改为 **100% 自配对重建 (`O3_self_only`)**，对比已有 50% 跨风格版 `O3_rgb_cnx_gated`，在 `t45/t55` 两档 + `swap_dist` 上定量证明跨风格监督是否不可或缺。
3. **单一 `strength (τ)` 接口标定（`O3_rgb_cnx_gated` @ `τ ∈ {0.40, 0.45*, 0.50, 0.55*, 0.60}`）**：
   - `t45/t55` **已测复用**，在同一 `O3_rgb_cnx_gated.pt` 上补跑 `τ=0.40` 与 `τ=0.60` 两档 + 实测端到端延迟，验证能否暴露单一 `strength` 滑块给 `PRISM-Ref` 接口。

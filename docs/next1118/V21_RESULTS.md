## 一、核心实验结论（科学事实与诚实诊断）

1. **Stiefel 极分解正交商彻底消除二阶 Gram 源风格泄漏（`92.33% → 20.00%`）**：
   - 在 `300` 幅留出画作上实测，旧对角白化 $\tilde{P}_{16}$ 的一阶均值泄漏虽仅为 `18.33%`，但其通道协方差（二阶 Gram 矩阵）仍泄漏 **`92.33%`** 源画派身份；
   - 替换为此轮提出的 Stiefel 极分解正交商 $Q_{32}(x) = \sqrt{256}\,U V^\top$ 后，严格满足 $\frac{1}{256}Q_{32}Q_{32}^\top \equiv I_{32}$（最大误差 $2.21\times 10^{-4}$），**二阶 Gram 5 分类泄漏直接降至精确均匀随机水平 `20.00%`**。
2. **任意单图 1-Shot 直出（`PRISMAttnUNet`，`24.78M`，`100%` 零类别 ID）**：
   - **同 `StyleGallery` 5 张参考图严苛 1-Shot 对决（`V21_1Shot_SG_exact_hiS`）**：在 `135.4 ms/img`（较 `StyleGallery` `30,400 ms` 提速 **`224×`**）下取得 **`DINO-S = 0.6006`**（超 `StyleGallery` `0.5604` **`+4.02pp`**，超过 `StyleShot` `0.5750`）、**`CLIP-S = 0.7517`**、**`Style Affinity = 0.6761`**（超 `StyleGallery` `0.6432` **`+3.29pp`**）、**`CSD Top-1 = 52.83%`**（`Minimalism = 100.0%`、`Impressionism = 100.0%`、`ER = 62.5%`）。
   - **未见留出集单张参考图直出（`V21_1Shot_Holdout_single`）**：在从未见过的单张留出参考图上维持 **`DINO-S = 0.5656`**、**`Affinity = 0.6524`**、**`DINO-C = 0.4976`**（`LPIPS = 0.5129`），而错标签控制 `V21_1Shot_Holdout_wrong` 的 Top-1 跌至 **`6.00%`**（因果差 **`+32.33pp`**）。
   - **4-Shot 画廊模式（`V21_4Shot_Gallery_hiS` / `hiC`）**：`DINO-S` 最高达 **`0.6016`**（`Affinity = 0.6744`、`Top-1 = 53.50%`）；高保真档 `hiC` 达 `DINO-C = 0.5415, Affinity = 0.6544`（`106.8 ms`）。
3. **诚实短板记录（为什么 `V20_D2` 仍保留为多类旗舰，而 `V21` 定位为 1-Shot 任意图拓展）**：
   - `V21` 在完全移除类别嵌入与 VGG 均衡边际教师监督后，在 `Ukiyo-e`（`0.0%–5.0%`）与单张参考 `Rococo`（`0.8%–8.3%`）上的 `CSD Top-1` 显著低于 `V20_D2`（`Ukiyo-e = 41.7%`, `Rococo = 53.3%`, 总 Top-1 `60.50%`），且 1-Shot 高风格档 `DINO-C`（`0.3970`）低于 `V20_D2`（`0.5335`）。
   - 因此论文与主表严格采用 **`PRISM`（1-Step，`17.0 ms`）** 与 **`PRISM-Flow`（`V20_D2`，`134.1 ms`）** 作为双代表主线，并将 `V21` 1-Shot 结果作为零样本任意参考图能力的真实实证纳入报告。

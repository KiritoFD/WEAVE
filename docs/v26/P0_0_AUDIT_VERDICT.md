**门控判定: FAIL** (Top-1 21.67% < 45%/38%), 但 **DINO-C 门 PASS** (0.575–0.615 ≥ 0.55,
较 V21 的 0.397–0.498 提升 +0.18) — **V26 Exp 1 的"加性 RefAttn 污染内容"诊断被删除实验直接证实**:
删掉 mid/dec32 两个加性 cross-attention 后, 内容保持跃升至历史最佳区间。

**新科学事实 — 风格容量与内容纯净的权衡被精确定位**:
纯全局 128d 向量条件 (无论 VGG 描述子迭代 / 11 维统计 / 423d E_ref) 的免标签能力
全部落在 20–37% 区间且 **ER/Roc/Uki 坍缩 (第五次同模式)**; 而 V21 的 52.83% (ER 62.5%)
依赖空间 cross-attention tokens。结论: **ER/Roc/Uki 级笔触需要空间级参考信息,
纯全局向量在原理上不够; 但空间加性注入 (现有形态) 摧毁内容**。

**下一阶段唯一正确的问题**: 如何**非加性**地把参考的空间笔触信息注入 — 候选:
(a) 解码高分辨层零初始化**乘性** AdaGN (参考 token 统计调制 P_C, 双向瓶颈纯净合规);
(b) cross-attention 输出经零初始化门控并限幅 (先验上界 0.1×);
(c) Q32 token 作为 cross-attention 的 Query (商空间纯净) 而 K/V 仅调制的混合形态。
此为 P0-1' 的核心实验设计问题, 需用户裁决后实施。

## 二、根因裁决（修正用户原始假设）

1. **"教师缓存是隐藏元凶" — 成立且比预期更严重**：教师直测 11.67%，不仅远低于 V20_D2 的
   60.5%，甚至低于学生（16%）。所谓"教师→学生信号流失 60%→16%"的真相是：
   **教师源头从来没有 60%** —— `build_teacher` 使用的教师配方 =
   `DUAL_CKPT`（**V24 单步模型家族**）+ core exemplar 纤维条件 + 源锚 SDEdit，
   该组合的原生上限就是 ~12–16%。
2. **锚点为次级因素**：τ0=0（纯噪声）消除了源锚后教师仍仅 15.6% — 源锚贡献了
   ~3pp 的压制（15.6→12.5），但天花板本身来自模型家族。
3. **条件侧无救**：闭集原型纤维 ≈ 单参考纤维（Δ1pp）— 换任何 795d 纤维条件都救不动；
   Style Dropout / CFG 修复属于锦上添花，不改变家族上限。
4. **V24 家族 ≈ V20 家族的 1/4 能力**：V20_D2 60.5%（分段视界流 + 原型条件 + 原生锚）
   vs V24 OneShot ~16%（单步 + 纤维条件）。L1/L3/L4/L5 全部实验都在 V24 家族内进行 —
   **16% 天花板是家族属性，与 SWD/数据/步数/注意力等所有受控变量无关**（这解释了
   为什么 7.5× 步数、4× 数据、换损失全部无效）。

## 三、结论与行动指向

- **撤回口径确认**（与用户 2026-11-22 分析一致）："Global-only 足够 / SWD 原理无效" 降级为
  "在 V24 家族 16% 天花板下无净收益"；"SG-25 未触瓶颈" 降级为 "swap=0.154 仅为 C2nt 的
  1/3，响应幅度弱"；"len9000 收敛" 降级为 "家族天花板"。
- **确立口径**：双向瓶颈纯净原则、解码器流形回拉效应（L2 负迁移）、速度场末端坍缩 (K1-C)、
  4 步少步化跨家族稳健（C2nt 43.17% 与 S0 15.83% 双验证）——全部升级进主线。
- **唯一有希望的方向 = 用户 P0（同空间条件对齐）**：不再在 V24 家族内修复，而是对
  **V20_D2（60.5% 原生条件空间）** 训练轻量参考投影器 E_ref（多尺度 Oklab + Haar + DINO
  风格统计 → PRISM-Flow 原生条件嵌入），以跨画派教师 + Style Dropout 联合微调，
  直接继承 60% 级笔触合成力。16% 家族的全部修复项（dropout/去锚定/原型条件）在
  V24 家族内已证无效，不应再投入。
- **Locality 重开门槛**（维持用户判定）：等任意参考主干进入 45–50% 强风格区后，
  路径 A（多步真实 Rollout 重测 Bary-SWD）/ 路径 B（解码层零初始化 AdaGN / 2 步无训练
  UOT 局部引导）才有资格重开。

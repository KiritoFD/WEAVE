## 一、Exp 1 — RefAttn 根因复核 (零训练)

### 1.1 实验设计

在 C2nt 权重上, 对 `RefAttnV24` 施加四组**零训练**干预 (150 cross 任务, in-process DINO 评分), 与 K1 已有 R0/R3/R4 串联成完整因果链:

| 臂 | 干预 | 预期 |
|---|---|---|
| X1 | V_ref 空间去化 (per-image mean → 逐 token 常量) | 若几何泄露 → DINO-C 应反弹至 R3 (0.589) |
| X2a | 温度 T=4 (更平滑) | 若尖锐度是因 → 内容改善 |
| X2b | 温度 T=48 (更尖锐) | 若平滑是因 → 内容恶化 |
| X3 | UOT Γ̄ 替换 Dense Softmax (零参数, 冻结 DINO 代价) | 软对齐保留内容 |

### 1.2 实测结果

| 臂 | dino_c vs 内容 | dino_s vs 目标参考 | Δc vs R0 |
|---|---:|---:|---:|
| **R0** 原模型 (基线) | **0.5392** | 0.3958 | — |
| R1 gate=0 (纯全局) | 0.4767 | 0.4057 | −0.063 |
| **R3** V=0 (局部置零) | **0.5892** | 0.3897 | **+0.050** |
| R4 V 打乱 | 0.5886 | 0.3851 | +0.049 |
| **X1** V 去空间化 | 0.4858 | 0.3992 | **−0.053** |
| X2a T=4 | 0.4879 | 0.4007 | −0.051 |
| X2b T=48 | 0.4931 | 0.4067 | −0.046 |
| **X3** UOT Γ̄ | 0.4949 | 0.4044 | **−0.044** |

### 1.3 判读 (修正后的根因)

**去空间化 V (X1) 并未使 DINO-C 反弹至 R3 (0.589)**——它甚至比基线更低 (0.486)。温度扫描与 UOT Γ̄ 也均未恢复内容。这意味着:

1. **内容损害不是纯粹的"空间几何泄露"**: 即使 V 变为逐图常量 (零空间方向), out_proj 仍然把它注入 h16 并改变内容特征——**损害的根源是 V 通路本身的激活值幅度**, 而非其空间结构。
2. **V=0 是唯一有效修复**: 完全移除局部 Value → R = (1−g)·global → 内容最高 (0.589)。打乱 V ≈ V=0 (0.589 vs 0.589) 一致, 因为打乱后注意力加权平均在后退化为噪声常量, 对内容无额外方向性干扰。
3. **温度/UOT 不改变结局**: 它们只改变注意力的空间分配权重, 不改变 V 的通路存在性——所以内容分始终在 0.486–0.495 区间, 远低于 R3 的 0.589。
4. **门控 (gate≈0.53) 无法提供保护**: R2 gate=1 (纯局部) 的 dino_s 仅 0.370, 甚至低于 R1 gate=0 的 0.406——门控关闭时全局反而更强, 确认局部 Value 通路没有学到有用的纹理信息。

### 1.4 对 PRISM-Flow 任意参考化设计的最终指导

- **当前 C2nt 的 RefAttnV24 局部 Value 通路不值得原样继承**；下一版先做不含该通路的 Global-only 控制，未来新局部机制必须过受控的内容—风格双指标验收;
- 任意参考的**优先基线**只走全局弦通路 (adapter(u_ref, u_src) + fib_n[ref])，不是宣称局部条件永远不应存在;
- 局部纹理信息应留在**训练损失** (Bary-SWD) 而非推理结构注入。

## 六、关键结论汇总

1. **RefAttnV24 局部 Value 通路 = 内容净损害**: V=0 是唯一有效修复 (+0.050 DINO-C), 去空间化/温度/UOT 均无效 (Exp 1)。
2. **跨画派参考采样不是 C2nt 根因**: A1/A2 无收益 (L0)。
3. **教师条件反置**: 修复前 F2 读数作废; 跨画派教师 (目标画派条件) 重建后待重评。
4. **SWD 判别力与 mean-VGG 相当** (AUC 口径), 但梯度方向近正交 (cos 0.179) — Bary-SWD 训练对比待 Exp 2。
5. **设计指导**: 任意参考化走全局弦通路; 局部纹理信息留训练损失 (Bary-SWD), 推理端移除局部注入。

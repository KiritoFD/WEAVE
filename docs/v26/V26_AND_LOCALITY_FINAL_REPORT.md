## 一、V26 是什么：一条"闭集 → 任意参考"的归因链

**起点问题**: PRISM-Flow (V20_D2, 闭集五画派原型条件) 想变成 One-Shot 任意参考模型，
但 C2nt 训练配方在此路线上失败 (Top-1 ~11%，困难画派 0%)。V26 用三层归因回答"为什么失败、
什么才是最小有效配方"：

```
K0–K2 诊断 (C2nt 权重, 零训练)          → 病灶定位
   K0 Q32 结构审计 / K1 RefAttn 因果干预 / K2 风格损失判别力+题材偏置
L0–L6 36h 长队列 (受控训练实验)          → 七问裁决
   L0 采样因果 / L1 监督因果 / L2 Decoder 归因 / L3 SWD×分支 / L4 Rollout / L5 少步+Q32 / L6 验收
最终验收补齐                             → 交付完备性
   SG-25×候选臂 / 20 路线矩阵 / 聚类配对 CI / 双种子 / 难例图
```

**核心背景结论 (K 阶段)**:
- **K1**: RefAttnV24 局部 Value 通路对内容保持是净损害 (V=0 → DINO-C +0.050)；轨迹末端参考身份消失；训练参考 ~100% 同画派 (nbr_idx 结构)。
- **K2-C 正对照**: CSD 裁判在真 Rococo 图上 90% Top-1 → 裁判不盲，模型 0% 是真实失败。
- **K2-A 修正**: "SWD 判别力 13×" 系尺度伪象 — AUC 口径 mean-VGG .673 / Gram .649 / SWD .661 同档；SWD 梯度幅度 82× (校准后归一)。

## 三、Locality 专题：从根因到终判

### 3.1 Exp 1 — RefAttn 根因复核 (零训练, C2nt 权重, 150 cross 任务)

| 干预 | DINO-C | Δ vs R0 | 判定 |
|---|---:|---:|---|
| R0 原模型 | 0.5392 | — | 基线 |
| **R3 V=0 (局部通路移除)** | **0.5892** | **+0.050** | **唯一有效修复** |
| R4 V 打乱 | 0.5886 | +0.049 | ≈V=0 (非相干扰动被自然衰减) |
| X1 V 去空间化 | 0.4858 | −0.053 | **几何泄露理论被证伪** |
| X2a/b 温度 4/48 | 0.488/0.493 | −0.051/−0.046 | 注意力尖锐度不是因 |
| X3 UOT Γ̄ 替换 | 0.4949 | −0.044 | 零参数软对齐也不救 |

**理论重构 — 商空间加性污染 (Additive Quotient Pollution)**: 内容损害的根源不是
"参考几何搬运"，而是局部 Value 通路**加性残差** `h + W_out·R` 的激活幅度本身。
即使 R 完全去空间化 (X1)，W_out·R 仍是空间相干 **DC 偏移**，把 16×16 瓶颈全部 256 个
token 向同一方向拉拢 → token 间夹角对比度 (布局商空间的核心编码) 单调坍缩 → DINO-C 必然暴跌。
**V 打乱 ≈ V=0** 因为打乱破坏 V 与 W_out 主奇异方向的相干性，扰动落入小奇异值子空间被衰减；
去空间化的常量却**完整穿透**主奇异方向。完整推导见 `docs/locality/quotient_uot_fiber_bundle.md` §一。

### 3.2 理论升级 (由 Exp 1 驱动)

| 原则 | 内容 |
|---|---|
| **双向瓶颈纯净** | 原理论只有源侧防御 (Π⊥ 商投影防 Source-Style Lock)；Exp 1 补上**参考侧镜像** — 参考特征只能以**规范调制** (AdaGN γ·h+β，方向保持) 进入商流形，禁止加性向量偏移 |
| **摊销式局部性** | 局部性留在**训练损失**而非推理结构：网络内部学习 (区域语义 Q_i, 全局弦 e) → 区域专属笔触的条件映射先验，推理零注意力开销 |
| **Quotient-UOT Fiber Bundle** | 替代 StyleGallery 五步启发式的三个零聚类算子：log-domain 非平衡 Sinkhorn (跨题材熵正则自适应退化) / 1D W2 重心闭式 Bary-SWD (Agueh-Carlier) / 去几何纤维统计 (Oklab+Haar，无边缘方向)。代码 `exp/v26/uot_fiber_bundle.py`，23 项合同测试 |
| **信息论分界线** | 全局弦 e∈S^127 对**极端 OOD** 实例级区域绑定 (红天空+蓝海面 vs 反转) 有硬上限；触界时才启用阶段 II (解码端高分辨层零初始化 AdaGN，仅调制 P_C，16×16 瓶颈永不受污染) |

### 3.5 终判：兑现判决框架的第三分支

判决框架 (理论文档 §5.2) 的四个分支中，实测落在第三支：

> **V2 ≈ V0 → Bary-SWD 无额外增益 → 回退最简 VGG 均值 + Global-only。**

- **"模型局部能力够用，缺训练期外部局部监督"** — 被否定 (Bary 分化度 ≤ VGG 基线，Top-1 反降 2pp)；
- **"摊销上限被训练损失解锁"** — 被否定 (同上)；
- **"SG-25 OOD 触及全局弦信息瓶颈"** — 未触发 (δs=+0.171/+0.174 正常外推) → **阶段 II (解码端 AdaGN) 无必要**；
- **摊销式局部性成立，但载体是模型内部条件化 + 教师监督质量** (F2 +5.17pp)，不是外部局部损失机制。

**对设计指导的修正**: Exp 1 时代的指导"局部纹理信息留训练损失 (Bary-SWD)"被 Exp 2 修正为
"局部纹理**不需要**显式监督机制 — VGG 均值 + 教师监督已足够，显式局部化反而有害 (−2pp)"。
UOT/Bary 算子作为**负结果**归档 (数学正确、测试齐全、无 Top-1 收益)。

**L2 的旁证**: 真图域 FT (含逐格匹配目标) 对生成 latent 解码负迁移 (−5pp)，进一步说明
"加强 decoder/损失侧的域适配"不是当前瓶颈方向。

## 四、一句话总结

> **C2nt 败于监督而非采样；任意参考化的第一杠杆是把教师条件修对 (+5.17pp，三种子稳定)；
> 推理端要极简 (全局弦、无局部注入、4 步即可)；SWD/UOT/Bary-SWD 及一切外部局部监督
> 机制在当前规模均无净收益；S10 解码器不是瓶颈；16×16 商瓶颈的双向纯净原则 (禁加性注入)
> 与摊销式局部性成立 — 最终配方 GLOBAL_REF_ONLY。**

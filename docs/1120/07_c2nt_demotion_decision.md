# V26 决策记录：C2nt 从主线降级为探索分支（2026-11-21）

> **决策人**：用户｜**生效**：立即｜**基线**：`main @ 632d94c`
> **一句话**：C2nt 是**成功的概念验证，不是成功的最终模型**——保留其科学结论，冻结其训练配方，把"统一任意参考 Flow"的 North Star 改为 **让 PRISM-Flow 获得可靠的任意参考能力**。

---

## 一、C2nt 是什么（定义澄清）

`C2nt = C2 No-Teacher`：无伪目标教师的参考条件风格迁移。约 22M 参数 `SLFUNetV24OneShot` 继承 V22 预训练权重（并非从零训练），以三种损失训练：

$$\mathcal{L} = \underbrace{\mathcal{L}_{\mathrm{self\text{-}FM}}}_{\text{恢复源图}} + \lambda_s\underbrace{\mathcal{L}_{\mathrm{VGG\text{-}style}}}_{\text{靠近参考}} + \lambda_c\underbrace{\mathcal{L}_{\mathrm{content}}}_{\text{保留内容}}$$

不需要新的跨风格伪目标教师，但仍依赖预训练 Flow。

## 二、性能证据（为什么降级）

最新完整 Cross600 结果：

| 模型 | DINO-C ↑ | DINO-S ↑ | Top-1 ↑ |
|---|---:|---:|---:|
| StyleGallery | 0.6113 | **0.5604** | 52.50% |
| O3 t45 | 0.5845 | 0.5245 | 35.33% |
| C2nt t45 | 0.5448 | 0.5235 | 42.17% |
| **C2nt t55** | **0.6647** | 0.5027 | 28.33% |
| PRISM-HC | 0.7723 | 0.4564 | 42.50% |

- `t45`：StyleGallery 的内容、风格、Top-1 **全部更高**（但 C2nt t45 LPIPS `0.5205` < SG `≈0.5576`，未被全指标严格支配）。
- `t55`：内容超过 StyleGallery，但风格明显偏弱。
- 相对旧 O3 的提升主要体现在 Top-1，**不是 DINO-S 的实质突破**。

**根本问题——训练目标相互冲突**：Self-FM 恒教网络还原源图，风格损失只要求一次 Euler 预览的 VGG **均值**特征接近参考，内容损失又要求不破坏原图——没有任何一项直接教"如何把源图变成目标风格"。网络学到最便宜的捷径：改变整体颜色/明暗/留白，而非生成目标画派局部纹理。分画派结果高度一致（C2nt t45 Top-1：Impressionism 93.3% / Minimalism 90.8% / Ukiyo-e 20.8% / ER 5.8% / **Rococo 0%**；其中部分受 CSD 题材偏置影响，`K2-C` 直接量化该混杂）。

## 三、为什么不直接砍掉

C2nt 至少证明了一件重要的事：**不需要新的伪目标教师，模型也能真实响应参考图**——正确参考相对错误参考的 `DINO-S` 差距 `+0.0732` 且内容水平相同。这是有价值的科学结果，但不是足以支撑主线的模型。它还缺第二训练种子与独立 SG-25 OOD 完整验证（本次 V26 补齐）。

## 四、路线取舍表（执行依据）

| 路线 | 决策 |
|---|---|
| PRISM-1 / PRISM-HC / Flow | 继续作为核心模型，保留已建立的 Pareto 优势 |
| C2nt 原始训练配方 | **冻结，不再长时间直接续训** |
| Source-Repulsive CFG | 保留零训练验证（4090） |
| RefAttn 门控与 Value 消融 | 保留，查明参考瓶颈（4090 K1） |
| 动态 SWD | 只保留一轮受控试验（3060） |
| C2nt 多尺度参考 / 完整 Rollout / Reflow | 暂缓，不同时投入 |
| 统一任意参考 Flow | 保留为长期目标（North Star） |

## 五、执行预算与停机条件

- **4090（2–3h C2nt 诊断）**：SR-CFG（`SR0–SR7` + 自参考恒等审计）、RefAttn 干预（`K1` `R0–R6`）、题材偏置（`K2-C`）、Q32 审计（`K0`）；SG-25 OOD 因 StyleGallery 资产仅在 3060 而移至 3060 队列。
- **3060（≤4–6h C2nt 收尾）**：只测试**修复采样后的动态 SWD 与原基线**（`S1fix_vgg` vs `S1fix_swd`，各 1200 updates + 全量 t45），外加零训练少步扫描与 SG-25 OOD。
- **停机条件**：若两臂均无法在**相近内容水平**形成新 Pareto 工作点、也无法改善 Rococo/ER 的参考响应 → **正式停止 C2nt 训练配方**，剩余 GPU 时间转向 **Flow 少步化、Q32 消融、解码器研究**。

## 六、最终判断

保留 C2nt 的实验结论，停止把它当成唯一的未来主干；**优先研究如何把 PRISM-Flow 的强迁移能力转化为任意参考能力**。`K1`（参考条件是否真被利用）与 `K2`（SWD 是否补足纹理监督）的报告将直接构成 PRISM-Flow 任意参考化设计的证据基础。

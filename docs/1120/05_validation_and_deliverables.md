## 一、P5 强制验证清单（必须全部完成）

### 1.1 最佳候选的第二独立训练种子复验
- 对 V26 胜出的最佳路线（至少 1 条主力候选），使用**完全相同的训练预算与超参、不同的独立 RNG 种子**从头复训一遍；
- 校验两颗种子在 `test750` 与 `SG-25` 上的主要指标改善方向是否一致（若方向冲突则按铁律追加第三颗种子或降级为 `INCONCLUSIVE`）。

### 1.2 全维度完整测试矩阵
1. **标准全量测试**：`test750`（`Cross600` 主读数 + `Same150` 对照）；
2. **无 Bypass 真实自参考测试**：强制关闭 `Same150` bypass，检验模型在 `ref = src` 时是否发生过度漂移、偏色或锐化伪影；
3. **20 条有向迁移路线 & $5\times 5$ 预测混淆矩阵**：专门检查困难路线（`ER / Rococo / Minimalism→Ukiyo-e`）及源风格锁定率；
4. **`SG-25 OOD` 严格盲测**：在 `StyleGallery` 完全相同的 5 类 OOD 参考与源图协议下正面对比，验证 5 类是否均有稳定正迁移；
5. **参考特异性四元对照**：`正确参考` vs. `错误风格参考` vs. `同画派不同参考` vs. `源图内容与参考语义跨度大的难例`；
6. **单模型连续 Strength 曲线**：在**同一个最终 checkpoint** 上扫描同一个连续风格强度参数（例如 $w$ 或注入强度），绘制真实单模型曲线（严禁跨模型拼接）。

### 1.3 多目标聚类配对统计判决
- 对 `(DINO-C, DINO-S, LPIPS, CSD Top-1, RTX 3060 E2E Latency)` 五维同时做 **150 源图聚类配对 Bootstrap 95% CI**（`n_boot = 4000`）；
- 不得以单项 `DINO-S` 上升掩盖 `LPIPS` 恶化、`DINO-C` 崩塌或困难路线退化。

### 1.4 Decoder 因果对照联动（对接 4090 `K4`）
- 完整的同域同预算 Decoder 对照（`Full SD-VAE` vs. `Full FT Decoder` vs. `S10 Decoder`）由 **4090 独立队列 `K4`**（详见 [`06_4090_diagnostic_queue.md`](06_4090_diagnostic_queue.md)）在 14–19h 窗口承担，并**绝不挤占 3060 One-Shot 主实验复验**；
- 若因故未在 4090 完成 `K4`，3060 仅在 P5 尚余 1–2h 预算时运行轻量判伪 Pilot，且 `1000–2000` 步微调不自动构成严格匹配的剪枝因果消融结论（未收敛则登记为未决）。

### 1.5 论文级视觉对比拼图（强制包含失败路线）
固定生成并盲审以下 **4 条高难度/易失败路线**（每条均并排展示：`Source`、`Reference`、`V25 C2nt`、`V26 Best` 及 `StyleGallery` 参照）：
1. `Minimalism → Ukiyo-e`
2. `Impressionism → Early Renaissance`
3. `Rococo → Early Renaissance`
4. `Impressionism → Minimalism`
同时配齐成功高光样例，防止只针对失败样例过拟合调参。

## 二、正式三态决策标准

每个机制（SR-CFG / Q32 / 采样修复 / SWD / SWD-Hinge / Ref-MultiScale / Rollout / Reflow）在收官时只允许落入以下三种状态之一：

| 判定状态 | 严格定义 |
|---|---|
| **`PASS`** | 在相近 `DINO-C` 内容保持水位下，取得可跨种子重复的风格（`DINO-S` / `Affinity` / `Top-1`）、失真（`LPIPS`）或 RTX 3060 端到端速度的 Pareto 净收益（配对 CI 支持），且无明显新的视觉退化。 |
| **`FAIL`** | 受控实验无净收益，或新增参数/计算/工程复杂度超过收益（如仅因 2× NFE 获益而不如等算力原 CFG，或引起严重灰化/失真）。 |
| **`INCONCLUSIVE`** | 双种子方向不一致、对照条件未拉齐、样本不足、或仅有聚合平均指标而缺失分路线/自参考验证。 |

## 四、终极验收：必须正面回答的六个核心科学问题

整个 V26 计划的成败**不以"跑完多少步训练"为准**，而以是否给出有据可查的明确答案为准：

1. **`Q32` 在统一适配器下究竟是否真有必要？**（是保留还是从最简主线彻底删掉？）
2. **`Source-Repulsive CFG` 能否在零训练或训练耦合下显著克服源锁定？**（比等算力原 CFG 强多少？）
3. **`C2nt` 在 `ER / Rococo` 等困难画派上的短板主要来自风格监督目标（均值 vs SWD），还是来自参考条件瓶颈（`RefAttnV24`）？**
4. **能否只用一个免类别输入的任意参考模型覆盖主要质量 Pareto 前沿？**（单个 checkpoint 随 strength 变化能否同时达标？）
5. **在保证视觉与指标不崩塌的前提下，推理步数真正能压缩到多少步？**（2 步、4 步还是 6 步？RTX 3060 端到端能否逼近 `250 ms`？）
6. **在完全相同的严格 1-Shot 协议（`SG-25` + `test750`）下，能否正面挑战并打平/超越 `StyleGallery`？**

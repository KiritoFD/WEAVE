## 三、P0 零训练诊断详规（`K0–K2`，0–8h）

### 3.1 `K0`：Q32 是否真有必要？（0–2h，纯诊断）

- **科学问题**：V25 主线使用 384 通道 `dino_16`，而理论文档中的 `Q32` 为 32 通道。现有 `dino_16` 究竟保留了多少源风格？硬极分解是否以损坏有用结构为代价换取线性探针下降？
- **对照对象**（同批训练图提取，**不直接喂给预期 384 通道的旧模型**）：
  1. 原始 `dino_16`（384 维）；2. `PCA32`；3. 硬 `Q32`；4. Tikhonov 软 `Q32`（$\eta$ 仅由训练集奇异值分位数设定，禁用 `test750` 搜 $\eta$）。
- **必测维度**：奇异值谱与有效秩、低秩样本（尤其 `Minimalism` 高背景占比图）数值稳定性、独立风格线性探针分类率、语义布局可分性、空间自相关、输入微扰稳定性、画派间谱差异。
- **关键规范**：**不能只报告 Gram 恒等式**；需明确 `92.33%` 是二阶统计线性探针分类率而非信息论泄露比例。必须绘制核心二维权衡图：**`Style Leakage ↓` vs. `Content Structure Retention ↑`**。
- **交付与闸门**：`docs/v26/4090/K0_Q32_FEATURE_AUDIT.md`。若 `Q32` 未表现出内容—风格解耦潜力，**直接取消 `K3`** 释放 6 小时 4090 算力。

### 3.2 `K1`：`RefAttnV24` 为什么未能有效迁移 Rococo / ER？（2–5h，最优先推荐）

基于 `exp/v24/p0_o1_o3_value.py::RefAttnV24`，**严禁盲目堆叠新注意力模块**，先做完整 Hook 遥测 + 因果干预 + 速度场解剖：

1. **K1-A Hook 遥测（全量 `test750`，按 $5\times 5$ 来源/目标画派分别统计）**：
   - Attention entropy / $\log(256)$（是否退化为均匀匹配）；
   - `max(QK)` 分布（是否跨画派匹配失效）；
   - Gate $g_i$ 均值与分位数（是否关闭局部参考）；
   - Local $\lVert gV\rVert$ vs. Global $\lVert (1-g)\text{Global}\rVert$ 注入范数比 & `out_proj(R)` 范数；
   - 同源同配置下更换不同参考图时输出的局部变化幅度。
2. **K1-B 7 组受控因果干预（同 `C2nt` ckpt，固定噪声/内容/strength）**：
   - `R0` 原模型基线；`R1` 强制 `Gate=0`（纯全局）；`R2` 强制 `Gate=1`（纯局部）；
   - `R3` 置零 `Local Value=0`；`R4` 跨参考随机打乱 `Value`；
   - `R5` 仅替换 `Key` 不换 `Value`；`R6` 仅替换 `Value` 不换 `Key`。
   *(注：上述为分布外因果压力测试，干预后退化不等同于重训后表现。)*
3. **K1-C 源参考速度场几何诊断**：
   直接比较 $v_{\mathrm{target}}$、$v_{\mathrm{source}}$ 与 $v_{\mathrm{target}} - v_{\mathrm{source}}$ 的范数、与原速度夹角、时间演化、目标画派差异、色度/亮度分量，以及经 `S10` 解码后的真实图像空间梯度方向（明确该差分**不是**严格数学正交分量）。
- **交付**：`docs/v26/4090/K1_REFATTN_CAUSAL_AUDIT.md`——直接裁决 `3060 P3-A` 与 `4090 K6` 是否启动。

### 3.3 `K2`：SWD 判别力、梯度数值与 CSD 题材偏置诊断（5–8h，3060 长训前交付）

1. **K2-A 风格判别力（冻结 VGG）**：对比 `mean-VGG 余弦`、`VGG Gram`、`动态多尺度 SWD`、高频/对比度统计在 5 画派与不同参考上的同/异画派间隔、`ER vs Rococo` 可分性、`Ukiyo-e` 独立性，以及对色移、模糊、局部纹理打乱的敏感性——重点辨别 **SWD 提升的是笔触判别，还是仅仅对颜色/内容更敏感**。
2. **K2-B 梯度数值诊断**：固定 128 张训练内部生成样本（不训生成器），比较 `mean-VGG / Gram / dynamic-SWD` 对生成 latent 的梯度范数、方向稳定性、对比度/结构扰动，以及投影数 $K\in\{32,64,128\}$ 与 `BF16 vs FP32` 数值稳定性。
3. **K2-C CSD 题材偏置审计**：为源图补充题材分类标签（人物/风景/建筑/静物，视觉模型生成候选 + 人工核验），同一目标风格下按题材拆分 `CSD Top-1`、分类 `margin`、独立风格距离、`DINO-C` 与盲视觉评分，防止把 `ER / Roc` 的题材混杂误判为风格迁移失败。
- **交付**：`docs/v26/4090/K2_STYLE_LOSS_AND_SUBJECT_AUDIT.md`。

## 四、P1 严格消融与公平对照（`K3–K4`，8–19h）

### 4.1 `K3`：Q32 同维度适配器匹配训练消融（8–14h，仅 `K0` 过闸后执行）

| 臂 | 内容特征 | 条件接口 | 训练控制 |
|---|---|---|---|
| `Q0` | 原始 `dino_16` (384) | 原始模型 | 同初始化、同有效 batch、同学习率与解冻范围、**1200 updates** |
| `Q1` | `PCA32` | `32 → 384` 同规格适配器 | 同上（**控制降维压缩效应**） |
| `Q2` | 硬 `Q32` | 完全同规格适配器 | 同上（**检验极分解去 Gram 独立收益**） |
| `Q3` | Tikhonov 软 `Q32` | 完全同规格适配器 | 同上（**检验谱收缩稳健性**） |

- **全量 `test750` 评测**：重点关注 `Minimalism` 源、`Ukiyo-e` 目标与 `ER` 目标；若 `Q2/Q3` 未能超越 `Q0/Q1`，最简 PRISM 主线正式永久剔除 `Q32`。

### 4.2 `K4`：Full Decoder 同域微调公平对照（14–19h）

- **回答核心审稿质疑**：`S10` 相对原版 SD-VAE Decoder 的质量优势，究竟源于 **剪枝导致的频谱瓶颈**、**WikiArt 绘画域微调**、还是 **训练预算**？
- **三臂公平对比**（若难以完全复原当年 `S10` 训练预算，**必须另行训练一对预算、数据、损失完全一致的 `Full FT` vs. `S10-match` 控制组**，禁止把跨预算差异归因于剪枝）：
  1. `Full SD-VAE Decoder`（未剪枝，未域微调）
  2. `Full FT Decoder`（未剪枝，WikiArt 同域同配方微调）
  3. `S10 Decoder`（78.5% 剪枝 + 同域训练）
- **评测指标**：用**完全相同的生成 latent** 分别解码，测定重建 `PSNR/LPIPS`、生成图 `DINO-C / DINO-S / CSD Top-1`、径向/局部频谱、边缘纹理保留及延迟（仅使用 Decoder 重建配方，严禁改动主 Flow 目标）。
- **结论落地**：若 `Full FT` 追平 `S10`，论文将其准确表述为**高效域适配解码器**；若 `S10` 仍有独立超额增益，则实证支撑“频谱瓶颈剪枝正则化”命题。

## 五、P2 高成本上界探索与少步曲率诊断（`K5–K8`，19–36h）

### 5.1 `K5`：四步完整可微 Rollout 上界（19–24h，高风险）

先跑 100-step 显存/吞吐探针（启用 BF16 + activation checkpointing + 梯度累积），随后固定同一 ckpt、同一配对、同损失、同有效 batch 与更新数跑三组对照：
- `T0`：1 步 Euler 清洁端预览（1 步反传）
- `T1`：4 步 Rollout 终态监督（仅随机中间 1 步可微）
- `T2`：4 步 Rollout 终态监督（**完整 4 步 BPTT 可微**）
- **决策**：`T2 >> T1` → 完整轨迹梯度有效，3060 应改进近似 BPTT；`T1 ≈ T2` → 保留廉价截断方案；两者均不优 `T0` → 叫停 Rollout。

### 5.2 `K6`：高分辨率参考 Value 上界（24–29h，条件触发：仅当 `K1` 证明缺高频细节）

保持源内容严格在 `16×16` 不动，逐步验证更多参考高频信息的质量天花板（不与 3060 轻量化版本重复）：
- `V0`：原 `16×16` ConvNeXt Value；
- `V1`：`32×32` 参考局部纹理统计；
- `V2`：`V1 + 64×64` 多尺度纹理统计；
- `V3`：`V2 + 语义对应位置注入`。
*(若 `V1` 无增益，直接取消 `V2/V3`。)*

### 5.3 `K7`：Flow 轨迹曲率与少步误差归因（29–33h，无训练＋条件缓存）

- 沿 10/16 步 ODE 轨迹测量：逐步速度范数、相邻步余弦曲率、Euler/RK2 局部截断误差、分画派误差分布、分段 CFG 贡献；
- 仅基于**训练集内部轨迹**构造并对比均匀、前加密、中加密、后加密及误差自适应非均匀时间网格，随后在完整 `test750` 校验；
- **条件教师轨迹缓存**：若 3060 确定启动 `P4-B Reflow`，由 4090 生成训练集内部配对的 `(z_start, 中间状态, 教师终态, 参考特征, config_hash)` 缓存供 3060 蒸馏（**严禁混入 `test750` 或 `SG-25` 数据**）。

### 5.4 `K8`：最终复验与全量资产归档（33–36h）

不新增任何模块，按优先级收束：`K3` 胜出变体第二种子 → `K4` 匹配微调复验 → `K5` 胜出 Rollout 复验 → `K1` 关键干预聚类配对 CI → 困难路线视觉/频谱剖析 → **确认所有 `runs/v26/gpu4090/` 资产已完整拉回本地并校验 SHA256**。

## 六、4090 → 3060 信息流与跨卡依赖契约（4090 绝不阻塞 3060）

## 一、全局核心结论与跨代突破（Executive Findings）

### 1.1 最新的历史性突破（V18 Track A，2026-11-18 实测）
将 V17 发现的 **DINOv2 上下文 + 无压缩 `u_tgt − u_src` 差分学生**（`V17 P2_S4`）与 **独立留出集校准 R1 + RMS 归一化 Target−Source 方向 + 适度预算扩展 `LD4+`** 迁移回 **去风格基底（`B4 / N2C`）** 后，一次性击穿了此前停滞半年的两个关键天花板：

1. **刷新全仓最高风格转移精度（超越外部 Seedream 4.5 与历史 Q2a+Oracle1）**：
   - **`V18.A1b_LD4plus_e18`**：Cross600 **CSD Top-1 = `38.00%`**（Margin `-0.0368`，DINO-S `0.4470`，Style Affinity `0.5674`，DINO-C `0.7428`，LPIPS `0.5018`）。
   - 相比同轮复现基线 `V18.A0_LD4_repro`（`34.67%`）提升 **`+3.33pp`**，首次在 **S10 同裁判协议** 下正面超越商业标杆 **Seedream 4.5（`37.30%`）** 与 **Q2a + R1 Oracle1（`36.30%`）**，且在 DINO-S（`0.447` vs `0.389`）、Style Affinity（`0.567` vs `0.531`）、DINO-C（`0.743` vs `0.734`）与 LPIPS（`0.502` vs `0.520`）上 **全面同时支配 Seedream 4.5**。
2. **首次实现纯前馈单步高特异摊销（零测试期梯度、~95 ms/img）**：
   - **`V18.A2_FastStudent`**（`0.44M` 参数单步 Adapter，输入 `B4 + c_canon + C_64 + 空间白化灰度 DINO layout`）：Cross600 **CSD Top-1 = `33.83%`**（Margin `-0.0542`，DINO-C `0.7793`，LPIPS `0.4806`，750 张全量推理仅 `71.1s`）。
   - 相比历史最优纯前馈单步模型 `P1_B4_distill50`（`22.20%`）暴涨 **`+11.63pp`**，且比测试期运行 2 步梯度搜索的 `V8 N2C`（`32.83%`）还高出 `+1.00pp`（同时 DINO-C 更高、LPIPS 更低）。
   - **铁证级控制对比**：固定同一输入、同一 `B4` 基底与同一噪声，仅把目标标签错移（`V18.A2_FastStudent_wrong`），Cross600 Top-1 立刻跌至 **`1.33%`**（`correct − wrong = +32.50pp`），证实模型几乎 100% 依据目标标签执行跨画派变换，彻底告别了 V15–V17 时代的伪增益陷阱。

### 1.2 全仓库六条已验证方法论铁律

1. **Law 1 — Reference Retrieval $\neq$ Style Distribution Gradient（V10.1）**：内容条件近邻检索目标会混入供体内容布局，在恢复代理上与真实方向呈负相关（$-0.25\sim -0.53$ vs KDE $+0.30$）。
2. **Law 2 — Recovery Alignment $\neq$ Style Specificity（V10.2）**：低维统计空间（DWT 矩/协方差）KDE 梯度的恢复收益中 **95% 属于通用“像画”先验，仅 5% 具有画派特异性**。
3. **Law 3 — Separation Margin $\neq$ Generative Direction（V11–V12 / V15 PT_C）**：无强信任域约束直接优化风格判别器奖励会立即走“摧毁内容刷分”捷径（DINO-C `0.75→0.26`）；固定类别常数 logit 偏置在不含 max-other 切换的线性差分中梯度精确为零。
4. **Law 4 — Local DWT Token $\neq$ Semantic Style Carrier（V13–V14）**：小感受野局部小波 token 无法承载语义画派判别（DWT 对比学习 NCM 仅 `0.425–0.544`，而 224px DINOv2 16×16 patch 达 **`0.793`**）。
5. **Law 5 — Self-Paired Generative Capacity $\neq$ Cross-Style Editing（V15–V17）**：在无显式去风格内容通道的自配对 Flow 中，将容量从 `0.13M` 扩至 `34.19M`（260×）能把 $\tau_0=0$ 纯生成 Top-1 推至 `49.3%`，但在 $\tau_0=0.7$ SDEdit 工作点反而因源统计保真增强使 Cross600 Top-1 从 `10.67%` 跌至 `6.67%`（59% 输出被 CSD 判回源画派）；57.8% Impressionism 不平衡进一步使底座在 `ER` 与 `Ukiyo-e` 上先验坍缩为 `0.0%`。
6. **Law 6 — Residual Distillation Requires Content-Style Decoupled Anchor & Context（V16–V18）**：加入 DINO 空间语义上下文 + `u_tgt − u_src` 差分编码可将局部残差拟合度从 `0.256` 提至 `0.744`，且效果严格受限于起点锚盆——在源锁定的 `V15@0.7` 上只能拿到 `13.33%`（`V17 P2_S4`），一旦锚定在去风格基底 `B4 / N2C` 上立即解锁至 **`33.83%`**（`V18 A2`）。

## 五、跨指标相关性核心发现（基于 `figures/correlation_heatmap.svg`）

- **风格判别簇与内容簇呈强负相关**：`DINO-S` vs `DINO-C` 的 Spearman $\rho = -0.62$（$n=143$），解释了为什么所有“单向拉升 DINO-S”的方案必须同步审计 `DINO-C` 与 `LPIPS`。
- **ArtFID 与风格特异性几乎脱钩**：`ArtFID` 与 `KID` 强相关（$\rho = 0.90$），与 `DINO-C` 强相关（$\rho = 0.77$），但与 `DINO-S` 呈微弱负相关（$\rho = -0.16$）——ArtFID 主要度量整体域分布与内容保真，**绝不能替代 CSD Target Top-1 / Margin 与错标签控制来判定风格迁移成败**。
- **V18 Track B（`CCF-UNet` 纯噪声去风格结构流）**：已在 `RTX 4090 (24GB)` 完成代码、15,545 规范化池及全部 4 裁判权重迁移并全绿通过（`V18_CANARY_ALL_OK`），即将在 4090 上以全速验证 **$\tau_0=0.0$ 纯噪声结构条件生成** 能否正面打通 `ER / Ukiyo-e` 的最后壁垒。

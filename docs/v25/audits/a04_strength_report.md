## 六、科学结论

### confirmed（实测支持）

1. **四条旋钮在 (DINO-C, DINO-S) 平面均严格单调**，各自族内全部臂都在本族 C-S 前沿上 —— 每个旋钮都是合格的强度拨盘（无回摆）。唯一的单调性异常在 **D6 Top-1**（τ_min=0.66→0.70 段 +0.00167 反向），幅度仅 1 个任务（0.167pp），在计数噪声内。
2. **D6 τ_min 响应在保守端饱和，0.73 内容水位不可达**。τ_min 0.66→0.70→0.72 的 ΔC 分别 +0.00345 / +0.00132（后者低于 0.002 阈值，饱和段），D6 曲线渐近 DINO-C≈0.7055。`B_d6_t072` 正是 A01 要求的 'τ_min≈0.72 补臂'，实测只到 0.7055 —— **A01 未决项 'D6 vs Hybrid @0.73' 无法靠 τ_min 平移解决**（tau_hi=0.78 固定下），需换杠杆（Hybrid γ≈0.55 水位 0.7321 / PRISM-1 λ≈1.0 水位 0.7440 均已有实测臂覆盖 0.73）。
3. **D6 存在死区 τ_min∈[0.50,0.58]**: ΔS=−0.0008（低于 0.002 饱和阈值）而 ΔC=+0.0084 —— 纯内容代价、无风格收益；调 τ_min 应避开该带。最有效区间 τ_min∈[0.66,0.70]（效率 0.606）。
4. **全局 C-S 前沿 13/19 臂**: D6 全族占据中段（DINO-C 0.669–0.706），Hybrid {g25, g40, g55} 占 0.733–0.753，PRISM-1 仅 l075（0.7715 最高内容），O3 三臂（t40/t45/t60）占 0.546–0.727 低内容带；被支配 6 臂: l100（g25）、l130/l160（g40）、C_hyb_g85 与 o3_t55（t066/t057）、**C_hyb_g70（被 o3_t60 双维度反超：C +0.0145 实在、S +0.00009 属亚噪声贴平**，见 JSON dominated_details 的 sub_noise_margin 标注——点估计口径下 O3 保守端已覆盖 Hybrid g70 的生态位）。
5. **LPIPS≤0.51 约束下格局反转**: D6 全族 LPIPS 0.518–0.537 **全部违约**，可行前沿 = {l075, g25, g40, g55, o3_t40/t45/t55/t60}。D6 的 C-S 支配性以 LPIPS≥0.518 为代价 —— 04 文档 'B≳C、可删 Hybrid' 的初步读法（点估计+插值）在 LPIPS 约束口径下不成立，且 A01 第 2 组 CI 已证明密度门控必须保留；删除 Hybrid 的决策必须等 τ 对齐的配对 CI，且需明确是否接受 LPIPS 包络外扩。
6. **C-Top1 前沿由 Hybrid 主导**: 全局前沿 = {l075, g25, g40, g55, g70, g85, t070, t072}（8 臂）；PRISM-1 族仅 l075（最大内容端）存活，O3 全族被支配（Top-1 天花板 40.83% 且随编辑增强反而下降）。D6 仅在最保守端（t070/t072）存活 —— 其 Top-1 平台期（≈0.55）使中段被同水位 Hybrid 臂支配。注意 t070/t072 与 g70 之间的 Top-1 差分（≤0.0067 = 4 任务）接近计数噪声，该段前沿成员资格对噪声敏感（top1 噪声阈值 0.005）。
7. **各旋钮最有效区间（ΔS/|ΔC| 最大）**: PRISM-1 λ∈[0.75,1.00]（0.216）；D6 τ_min∈[0.66,0.70]（0.606，反向旋钮）；Hybrid γ∈[0.25,0.40]（1.97）；O3 τ0∈[0.55,0.60]（0.290，反向旋钮）。四条曲线共同模式：**保守端效率最高、激进端递减/饱和**，即所有引擎的边际风格收益在弱编辑侧最大。
8. **strength 映射已交付**: PRISMCore 三引擎（prism1/λ、d6/τ_min、hybrid/γ）与 PRISMRef 一引擎（o3/τ0）的内容锚定分段线性映射表（每段标注实测依据臂），默认档 s=0.5 → λ≈1.218 / τ_min≈0.528 / γ≈0.630 / τ0≈0.506（descriptive 插值）。

### rejected（被本轮证据否定）

- 'D6 τ_min 继续上移可实测 DINO-C≈0.73 水位'（A01 §四.1 的解决路径）：B_d6_t070/t072 实测饱和于 0.7055，该路径关闭。
- 'O3 τ0 曲线是纯 τ0 单变量'：t40/t60 的 wj 不同（2.3 vs 1.9），曲线混杂，不能作为纯强度响应引用。

### inconclusive（未决，不做外推）

- D6 vs Hybrid @0.73 配对判定：D6 在 0.73 无任何实测臂（饱和），维持 A01 UNDECIDED；若必须对齐 0.73，需改 D6 其它参数（tau_hi 上调 / 分支结构）补臂后用 a01 工具出 CI。
- O3 保守端 s=0（τ0=0.60）仍离恒等映射很远（C=0.7274）；O3 缺少近恒等实测锚，PRISMRef 的弱编辑端行为 UNMEASURED。
- D6 τ_min=0.40 端点臂（M0_v20_d6）tau_hi=0.74 与 B 臂 0.78 不一致，τ_min=0.40 端点的映射结点带协议混杂。
- Top-1 分辨率：600 任务下单任务 = 0.167pp，所有 <0.5pp 的 Top-1 差分（含 D6 平台期内部差异）不作结论。

## 七、风险与局限

1. 全部结论为 **cross600 点估计**，无配对 CI；曲线臂之间未做源聚类 bootstrap（A01 工具可对任意两臂补算）。
2. 效率/最有效区间按分段差分计算，段间密度不均（λ 段宽 0.25–0.30 vs τ_min 段宽 0.02–0.08），跨旋钮比较效率绝对值时注意分母口径（内容水位跨度不同：D6 全程仅 0.0367，O3 0.1818）。
3. strength 映射的内容锚定基于 DINO-C；若下游更关心 Top-1 或 LPIPS 锚定，同表结构可用其它锚指标重算（脚本改 `anchor_metric` 一处）。
4. Hybrid 族跨 V24 复用臂（g25/g40/g55）与 V25 实跑臂（g70/g85）两批来源，假定同族定义一致（04 文档曲线 C 口径）；PRISM-1 λ 与 Hybrid γ 的联合空间（λ≠1.0 的 Hybrid）未实测。
5. SVG/PNG 中的连接线是实测点连线，仅描述性；面板不呈现任何插值臂读数点。

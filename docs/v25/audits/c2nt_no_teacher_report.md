## 一、从探针发现的梯度尺度病灶：`CNX` 通道均值偏置 vs `VGG` ReLU

先跑 `ConvNeXt-Tiny (s2+s3)` 空间均值池化探针（`λ_sw ∈ {0.2, 0.5, 1.0, 40.0}`，`200 updates`）暴露了关键数值现象：
- `CNX` 末层（LayerNorm+Conv 之后、无 ReLU 截断）对所有画作输出一个近乎相同的正偏置均值向量，导致跨画作池化余弦 `preview_style_cos ≈ 0.9975`、`l_style = 1 − cos ≈ 0.0022`——即使 `λ_sw = 40.0`（`40 × 0.0017 = 0.068`），`t45 Top-1` 也仅从 `12.50%` 微升至 `13.17%`。
- 切换为 **`VGG-16 (relu3_3 + relu4_3)`**（ReLU 非负激活，无共享均值偏置）后，初始 `preview_style_cos = 0.738`、**`l_style = 0.2617`（动态范围大 `105×`！）**；仅 `200 updates`（`λ_sw=5.0, λ_c=1.0`）即推动 `t45 DINO-S = 0.4909`、`Top-1 = 15.50%`，并在 `4` 条件参考敏感度上拉开正确/错误参考差距。

## 三、科学结论与诚实边界

1. **方案③ `C2nt` 正式成立**：在**零教师包、零画派标签输入**的前提下，仅通过自配对 Flow-MSE + VGG-16 参考风格正则，在 `t45` 达到 `Top-1 = 42.17% / DINO-S = 0.5235`（超越有标签教师版 `O3` `+6.84 pp`、超越 `O3_label_free` `+30.84 pp`），在 `t55` 达到 `0.6647 / 0.5027 / 28.33%`（同样全面超越有标签版 `O3` `0.6783 / 0.5025 / 24.00%`）；且相同内容水位下正确参考风格匹配高出错误参考 **`+0.0732`**。

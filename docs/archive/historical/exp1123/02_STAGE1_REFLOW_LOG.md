## 二、`v1` → `v2` 诊断与精准修复

首轮 `v1`（$\alpha=0.30$ + 无 `y32_lcn` + 1D $\gamma$）虽达 `55.67%` Top-1 / `0.567` DINO-S / `1.33%` 错标签，但 70% 噪声起点+无亮度结构约束导致 `DINO-C` 跌至 `0.4781`（`Uki=0.0%`），且 1D $\gamma$ 未拉开档位。

**`v2`（`d1_reflow_v2.pt`）三项手术修复**：
1. **$\alpha = 0.55$**：$\tilde{z}_0 = 0.45\epsilon + 0.55 z_0^\perp$，提升起点信噪比同时保留 45% 噪声重构笔触。
2. **加入 `0.25 * st_loss`**：约束 $\hat{z}_1$ 与 $z^*$ 的 `32×32` 潜亮度 `LCN_5` 结构。
3. **`16D` Sinusoidal $\gamma$ Embedding**（零初始化列扩维）：放大强度滑块条件。

训练 `3,500` updates 耗时 **`15.3 min`**，`phuber` 从 `v1` 的 `0.3457` 大幅降至 **`0.2169`**，`hf` 从 `0.1565` 降至 **`0.1084`**。

### 阶段 1 总结与向阶段 2 的交接判读
1. **轨迹已被完全拉直**：`2 步 Euler`（`53.00%`）≈ `4 步 Euler`（`53.17%`）≈ `4 步 RK2`（`52.83%`），证明 1-Reflow 已把原 6 步弯曲轨迹拉成几乎零曲率直线。
2. **DINO-C 修复 & 零泄漏因果差**：`DINO-C` 从 `v1` 的 `0.4781` 弹回 **`0.5666–0.5747`**（高于 `e2full` 教师的 `0.5464`），Minimalism 随 $\gamma$ 平滑调节（`0.552 → 0.489 DINO-C`、`89.2% → 97.5% Top-1`），错标签跌至 **`0.50%`**（$\Delta_{\text{causal}} = +52.83\text{pp}$）。
3. **遗留短板与阶段 2 使命**：纯潜空间蒸馏平滑了 `ER (9.2%)` 与 `Uki (1.7%)` 的高频墨线/细笔触，导致总 Top-1（`53.3%`）距 `6k` 教师（`56.2%–57.8%`）差 `~3pp`。这正是阶段 2 **4 步全可微 Rollout + 像素级 `VGG-SWD` + `Part-Bank` 闭环**要正面攻克的物理目标。

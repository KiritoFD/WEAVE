# PRISM-1-Unified 教师熔断验收

在 4090 上从 train_4400 按画派等量抽取 1,500 张拟用来源，并从其跨画派任务中固定种子、按目标画派各抽 30 条。仅生成这 150 条任务的两档终点。两档使用同一个 6k ICME Q32 EMA、同一个离线 T4 锚点和逐任务相同噪声。强风格档用 e2full_d5，高内容档用 cs_j_d6h。输出全部由 S10 解码并采用冻结裁判。

| 判据 | 实测 | 门槛 | 判定 |
| --- | ---: | ---: | --- |
| 强风格 CSD Top-1 | 87/150 = 58.00% | ≥54% | 通过 |
| 强风格 ER | 7/30 = 23.33% | ≥25% | 失败 |
| 强风格 Uki | 6/30 = 20.00% | ≥25% | 失败 |
| 高内容 DINO-C，对 S10 源重建 | .6474 / 150 条 | ≥.62 | 通过 |
| 高内容 DINO-C，对匹配源原图 | .5932 / 87 条 | ≥.62 | 低于门槛，覆盖 87/150 |

原始源图只匹配到 87 条。全量 .6474 和原图子集 .5932 使用两个不同的参照口径。ER 与 Uki 两项都失败，结论与内容参照口径无关。已按硬规则中止，学生更新为 0，未生成完整 7,500 对缓存。

原始 T4 工作点的历史 Cross600 给出独立旁证。e2full_d5 的 Top-1 是 335/600，ER/Uki 分别 23/120、14/120。cs_j_d6h 的总体 DINO-C 为 .6361。此前采用 P1 锚点的教师记录属于另一组工作点。

λ=0 的严格验收适合直接比较输入输出 latent，并与 S10 源重建做像素对照。当前 test750 将输出同原图相比较，历史直接返回原 latent 再经 S10 时，Same150 仍为 145/150，DINO-C 为 .9590。原图口径中的 1.000 与 100% 无法用 latent 恒等式单独保证。

## 下游训练

根据用户后续指令，保留上述验收失败记录并继续训练。完整缓存用同一个训练池和固定抽样矩阵，共 1,500 来源、6,000 跨画派、1,500 恒等任务。跨画派复用验收的 150 条原始双终点，其余 5,850 条用六步教师补齐。教师缓存按 256 条原子写盘，以便断点恢复。

学生从零初始化，实测参数量 6,699,588。使用宽度 192、八个全分辨率扩张块、Q32 自注意力与乘性空间 AdaGN。以亮度守恒的解析色度对齐作为残差起点，λ=0 的输出在 CPU 预检中已逐元素等于输入。训练采用 64 有效批及 5,000 步，融合目标严格使用 Smooth L1、Haar 高频 L1、亮度 L1 与固定频次的冻结 S10 感知梯度。FP32 主干允许 4090 在卷积和矩阵乘中使用 TF32，S10 感知桥用 BF16。最终 test750 取消 Same150 旁路并验证 λ=0 latent 恒等及 λ=1 错目标。

```bash
python -m exp.v27_single.unified.cache
python -m exp.v27_single.unified.train
```

4090 实验目录为 `runs/v27_mainline/prism1_unified/`。

## 吞吐调整

教师微批从 16 增为 24 后，通过分片恢复保留已完成任务。两种尺寸的单分片耗时都约 47–50 秒，调整未显示出稳定加速。学生在像素与 latent 共用大微批时发生显存不足，后改为普通 latent 微批 16、含 S10/VGG 图的微批 4。两类微批的梯度在同一次更新累积，有效批仍为 64，偶数步仍恰好 8 张跨画派样本使用像素项。按恢复点延续同一训练。100 步前的微批 4 约 .67 秒/步，混合微批在 450–575 步实测约 .57 秒/步。

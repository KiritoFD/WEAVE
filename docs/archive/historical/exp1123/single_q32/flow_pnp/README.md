# Flow-PnP 零训练推理

固定 `icme_q32_flagship.pt` 的 EMA 和 S10，真实 test750 每臂都运行模型，前沿读数采用 Cross600。每个样本从配对纯高斯噪声出发，做八次显式重投影。每步由冻结 Q32 的 `cs_j` 两分支估计速度，反传只作用于脱离 U-Net 计算图的洁净端点。模型保留现有 checkpoint 所需的缓存参考向量及场景路由。

每一步对潜空间亮度轴做单次结构下降。结构损失由低频亮度 MSE 与两个解析度的 LCN 一致性组成。联合版在第 4、5 步增加一次 BF16 S10 和冻结 VGG 的风格梯度，风格更新投影至亮度轴的正交补。VGG 使用四层、每层 32 条固定正交切片与 256 个空间采样。每类从训练池取 24 张图来建 SWD 及 Oklab 原型。测试参考和评测裁判仅用于独立评测。

两种梯度都逐样本归一到单位 RMS。固定结构上限 .45、风格上限 .20，随后由旋钮分别乘以 `(1-s)^2` 和 `s`。风格 CFG 从 1 线性插值至现有场景自适应的 cs_j 权重。六档共用同一组上限、同一批任务和噪声。此运行验证闭集风格引导，尚未测任意参考 1-Shot。

```bash
python -m exp.v27_single.flow_pnp
python -m exp.v27_single.plot_flow_pnp results.json
```

### 关键解读（诚实边界 + 权衡）

1. **`HC_R12_g55` 四项全面严格支配 `PRISM-1 λ=0.75`**（配对 CI `PASS`）：
   - `ΔDINO-C = +0.0008 [−0.0047, +0.0063]`（同内容水位）
   - `ΔDINO-S = +0.0193 [+0.0154, +0.0232]`（**+0.0193 显著风格提升**）
   - `ΔLPIPS = −0.0065 [−0.0113, −0.0020]`（**显著更低感知失真**）
   - `ΔTop-1 = +4.83 pp`（`42.50%` vs `37.67%`）
2. **`HC_R12_g70 / g85` 在内容、风格、LPIPS 三维上严格支配旧 Hybrid `M1_lin_g25 / g40`，但 CSD Top-1 存在真实回落（−4.17 ~ −9.33 pp）**：
   - `HC_R12_g70` vs `M1_lin_g25`：`ΔDINO-C = +0.0095 [+0.0043, +0.0149]`、`ΔDINO-S = +0.0188 [+0.0149, +0.0226]`、`ΔLPIPS = −0.0189 [−0.0227, −0.0153]`，同时 `Top-1 = −4.17 pp`（触发 `a01` 单类守卫标记 `INCONCLUSIVE`）；
   - `HC_R12_g85` vs `M1_lin_g55`：`ΔDINO-C = +0.0149 [+0.0112, +0.0186]`、`ΔDINO-S = +0.0029 [+0.0001, +0.0058]`、`ΔLPIPS = −0.0190 [−0.0216, −0.0165]`，同时 `Top-1 = −9.33 pp`。
   - **科学解释**：B4 锚显著压低了图像结构畸变（LPIPS ~0.48）并在 DINO 空间提供了高保真—高风格余弦平衡，但在极端抽象/高分类置信度方向（如 Rococo/Early_Renaissance）的 CSD 分类器边距不如 T4 各向异性优化锚锐利。因此若目标为 **高内容保真 + 低 LPIPS + DINO-S**，R12 是全仓新高；若目标为 **CSD Top-1 分类准确率**，旧 `T4` 系 Hybrid (`M1_lin_g55`, 52.67%) 仍不可替代。
3. **`HC_R12_g100` 意外解锁“单模型直达 DINO-C ≈ 0.73”**：此前 Round 1 / R1b 用 T4 锚无论如何上调 `τ_min` 都饱和在 `0.7055`；换成 B4 锚后，单模型 `slf_core_v2 (cs_j, D6H)` 无 PRISM-1 混合即直接到达 **`DINO-C = 0.7286 / DINO-S = 0.4870 / LPIPS = 0.4980`**（20 NFE + 218K 轻量 B4 锚）。

## 三、归因总结与产品化建议

1. **为什么 R12 会出现提升？** 不是因为某个未解释黑魔法，而是 **三个因素各自干净可加**：
   - `B4 锚` 提供 ~75–80% 的内容保真与 LPIPS 改善（+0.03~0.036 DINO-C，−0.021~0.026 LPIPS），并打破了 T4 锚下 `0.7055` 的单模型内容天花板；
   - `D6H_SOLVER`（τ∈[0.48,0.78]）贡献剩余 ~+0.010 DINO-C 与 −0.006 LPIPS；
   - `cs_j` 在不降 DINO-C 的前提下反而贡献了 **+0.002 DINO-S** 并将流前向 NFE 砍半（40 → 20 NFE）！
2. **双高内容分支定位**：
   - 交付资产归档至 `docs/ours/02_PRISM_HighContent_R12/`（含全部 3 个 checkpoint、750 图 `g55/g70/g85` 与完整配方）；
   - 保留 `T4` 系 Hybrid (`M1_lin_g55`, Top-1 52.67%) 作为 CSD 高判别对照，两档互补覆盖高内容段全部应用需求。

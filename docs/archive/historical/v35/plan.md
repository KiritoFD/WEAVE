# **二、最终12h实验队列**

以 **V34 C2（44.54M + Q32）+ A3** 为唯一生产基线，E-Core 和 S10B 保持冻结，不再调整网络架构。

| 顺序     | 实验阶段                | GPU预算   |
| ------ | ------------------- | ------- |
| P0     | 资产冻结、基线复现           | 0.5h    |
| P1     | E-Core 锚点及目标条件因果消融  | 0.75h   |
| P2     | 最终模型 Decoder 消融     | 0.75h   |
| P3     | Stiefel、Pool C 同构重训 | 3.5h    |
| P4     | 第二种子与核心贡献复验         | 2h      |
| P5     | 44M 训练时长与收敛诊断       | 1.5h    |
| P6     | A3、CFG、采样超参数定型      | 1.25h   |
| P7     | 大小核质量—效率对照          | 0.5h    |
| P8     | 最终评测、测速及机动          | 1.25h   |
| **合计** |                     | **12h** |

全部单卡4090串行执行。

## **P0：冻结最终基线（0.5h）**

固定 C2 checkpoint、E-Core、S10B、ConvNeXt、K8 风格银行、训练数据、评测裁判和噪声种子。

复现 `s085/s100/s150`，特别核查：

- V34 的 `s150` 与 `tau0=0` 实际配置有何区别，两者结果明显不同。
- Wrong-target 是否真正改变生成条件。
- Holdout 的源图、参考图、画家与训练集的隔离情况。
- V34 训练源码、配置及 optimizer/EMA 状态是否完整。

若基线无法复现，优先修复协议，不继续产生不可比较的实验结果。

## **P1：E-Core 到底贡献了什么？（0.75h）**

冻结44M P-Core，固定噪声、Q32、CFG、积分步数及起点时间，只改变起点。

| 实验 | 起点                      |
| -- | ----------------------- |
| A0 | 原始源图 latent             |
| A1 | 解析色度对齐 latent           |
| A2 | E-Core 草稿               |
| A3 | E-Core 草稿 + A3          |
| A4 | 正确目标草稿 + 错误 P-Core 风格条件 |
| A5 | 错误目标草稿 + 正确 P-Core 风格条件 |
| A6 | 错误目标草稿 + 错误 P-Core 风格条件 |

A4–A6 中，A3 的目标统计跟随草稿目标，确保不会形成隐蔽的正确标签通路。

需要回答三个问题：

- `A2−A1`：学习式 E-Core 相比解析预编辑增加了多少生成能力？
- `A3−A2`：A3 的独立贡献是多少？
- 正误草稿×正误条件的2×2对照：目标风格主要由初始状态还是速度场决定？

重点记录目标分类率、源风格锁定率、DINO-C/S。

**这组实验比再训练一种新的桥接 Flow 更有价值。**

## **P2：Decoder 的最终贡献（0.75h）**

缓存相同的最终 latent，分别经过三个 Decoder：

| 实验 | Decoder               |
| -- | --------------------- |
| D0 | 原始 SD-VAE 49.49M      |
| D1 | WikiArt 微调全尺寸 Decoder |
| D2 | S10B 10.66M           |

覆盖 E-Core `s075/s100`，P-Core `s085/s150`。

不重新编码、不重新生成 latent，仅替换解码器。

除常规指标外，测量编辑前后目标风格 Margin、Haar 各频带能量和局部纹理响应，验证 Texture Retraction 的解释。

如果 D1 历史权重无法恢复，则明确记录缺失，优先完成 D0/D2，不浪费时间重训 Decoder。

## **P3：Stiefel 与 Pool C 的联合消融（3.5h）**

**本轮最重要的训练实验。**

将两组问题合并，复用同一个44M共同基线。

| 实验 | 内容表示        | Pool C | 参数量    |
| -- | ----------- | ------ | ------ |
| Q0 | Stiefel Q32 | 15%    | 44.54M |
| Q1 | 普通逐通道白化     | 15%    | 44.54M |
| Q2 | Raw PCA-32  | 15%    | 44.54M |
| Q3 | Stiefel Q32 | 0%     | 44.54M |

统一使用 V34 Stage C 的真实训练配方：

- 3,500 updates，相同有效 batch、优化器、学习率、EMA。
- 同一初始化、训练数据顺序及随机种子。
- 保持原始 Flow Matching 目标，不引入失败的桥接速度目标。
- 只改变 P-Core 内容表征，E-Core 及其草稿不变。

如果原 C2 的资产和训练配置完全匹配，直接复用 Q0，只新增三个训练臂。

### **Stiefel 的关键判据**

`Q0−Q1` 才是正交化的独立贡献，而不是正确 Q32 与置零 Q32 的差值。

同时记录：

| 指标               | 说明            |
| ---------------- | ------------- |
| Gram Probe       | 二阶源风格泄漏       |
| Spatial Probe    | 空间特征中剩余的风格信息  |
| Source-Lock Rate | 泄漏是否真的导致保留源画法 |
| 等内容 DINO-S       | 去泄漏是否实际推动生成前沿 |
| Top-1 / Same150  | 目标特异性与同画派稳定性  |

再用现役44M ConvNeXt 模型复现 `correct/zero/shuffled × 两种起点` 六臂干预。

### **Pool C 的关键判据**

Q3 不是简单删掉15%的训练数据，而是将这些反向配对替换为相同真实目标画作的自配对。

保持目标画作、画派比例、目标风格条件和曝光量不变。

这样才能隔离**跨风格配对本身**的价值，而不是误把数据均衡的效果算成 Pool C 的贡献。

如果没有足够预算复现 Q0，优先砍掉 Raw PCA 的 Q2，保留最关键的 Q0/Q1/Q3。

## **P4：第二种子复验（2h）**

只训练两个模型：

| 实验 | 配置                           |
| -- | ---------------------------- |
| R0 | 44M + Stiefel + Pool C，seed1 |
| R1 | 44M + 普通白化 + Pool C，seed1    |

既验证 V34 的44M生产配方能否稳定复现，又验证论文第一项核心贡献是否依赖某一个随机种子。

如果 P3 中 Stiefel 只表现为去泄漏，而没有改善生成质量，也必须保留这一结果。

**消融的目的不是确保每个组件都有效，而是确定它们实际起了什么作用。**

## **P5：训练时长定型（1.5h）**

从 C2 的3500步恢复原 optimizer 和 EMA，继续训练。

| Checkpoint | 作用   |
| ---------- | ---- |
| 3500       | 当前基线 |
| 4500       | 短期续训 |
| 5500       | 中期收敛 |
| 7000       | 长训上限 |

重点检查三条曲线：

1. 训练速度回归损失。
2. 固定内容水平下的 DINO-S 与 Top-1。
3. Same150 与源风格锁定率。

如果训练损失继续下降，但生成前沿停滞甚至退化，就说明出现了历史 V22 的钟形性能曲线，不应继续延长训练。

不调整损失、网络或数据。如果7000步仍在提升，也先按预算停止，记录为尚未完全饱和。

## **P6：推理超参数最终定型（1.25h）**

只保留三个变量组。

### **① A3 校准幅度**

\\[ z'\_E=z_E+\alpha_Y\Delta L\_{\rm low} +\alpha_C\Delta P_C \\]

| 实验 | \\(\alpha_Y\\) | \\(\alpha_C\\) |
| -- | -------------- | -------------- |
| A0 | 0              | 0              |
| A1 | 1              | 0              |
| A2 | 0              | 1              |
| A3 | 1              | 1              |
| A4 | 0.5            | 1              |
| A5 | 1              | 0.5            |

其中 A0/A3 可复用 P1 已测结果。

### **② CFG 与起点**

| 参数           | 扫描范围                 |
| ------------ | -------------------- |
| 风格 CFG       | 原值 × 0.8 / 1.0 / 1.2 |
| 内容 CFG       | 原值 × 0.8 / 1.0 / 1.2 |
| \\(\tau_0\\) | 原调度 ±0.05            |

逐项扫描，最后只验证一次组合配置，不进行笛卡尔积搜索。

### **③ 积分步数**

比较4/6/8步。V33 已证明增加步数的收益很小，因此这里主要确定44M模型是否能够在4步下保持足够质量、恢复部分吞吐。

最终所有内部旋钮固化为单一 `s`，并保证：

- `s=0` latent 精确恒等。
- E/P 交界没有明显视觉跳变。
- A3 在纯噪声起点不产生额外影响。
- 任何调整均不使用画派特判。

## **P7：大小核必要性——大幅精简（0.5h）**

**我不建议在这12h内再训练一个55M共享主干。**

共享主干需要重新设计接口、双任务损失与采样策略，训练公平性也很难保证，学术 ROI 不如前面的严格消融。

先完成冻结权重的系统级比较：

| 系统     | 推理方式                    |
| ------ | ----------------------- |
| E-only | E-Core 单步，覆盖完整强度范围      |
| P-only | 不使用 E-Core 草稿，采用解析或源图起点 |
| CLEAVE | 完整 E/P 协作               |

绘制三者的质量—效率前沿，证明两个核心在不同工作区间的互补价值。

这能够支持“非对称任务分工有效”，但不能证明所有共享网络都不可能达到相同性能。如果论文坚持宣传专门化的架构必要性，再单独安排共享主干训练。

## **P8：最终验收（1.25h）**

固定最终 checkpoint 和全部超参数后：

- 完整 test750 强度谱评测。
- Holdout-750 复验。
- 若 P5 选择了更长训练时长，优先将 seed1 续训至相同步数；预算不足则明确长训只验证了单种子。
- RTX4090 的 batch=1/16 完整 RGB→RGB 测速。
- 最终参数量、显存、实际 NFE 与分段耗时。
- 输出统一消融表、Pareto 图和固定任务 ID 的视觉对比图。

# **三、统一评测与停机标准**

所有正式实验使用完整 test750，不采用 dev200。

超参数和训练时长选择使用训练侧固定校准任务，避免继续利用 holdout-750 调参。该 holdout 已用于 V34 验证，不能再称为从未使用过的最终盲测集。

| 判定类型 | 标准                                      |
| ---- | --------------------------------------- |
| 显著收益 | 配对95% CI 排除0                            |
| 实用收益 | ΔS≥0.005、ΔC≥0.005 或 Top-1≥2pp，并检查其它指标代价 |
| 等效   | CI 完全落在预注册等效区间                          |
| 不确定  | CI 跨零且超出等效区间                            |
| 训练收敛 | 继续训练不再推动质量前沿                            |
| 最终停机 | 12卡时到达，或全部必做验证完成                        |

训练实验按 V34 的实测约50分钟/臂估算，预算不包括源码补齐和历史权重下载。若实际耗时超出预期，优先削减 Raw PCA 对照及额外采样扫描，不缩减正式评测样本。

## 一、三大科学发现（TL;DR）

1. **训练集超平面边际离群陷阱 vs. 内部 `kNN-30` 核心流形（`+20pp~+29pp` 原型跃升）**：
   - 在 `Stage 1` 与 `Stage 2` 初期，尽管 `Early Renaissance`（`0.556`）、`Impressionism`（`0.682`）、`Rococo`（`0.562`）、`Ukiyo-e`（`0.545`）四类 `DINO-S` 已超越 `StyleGallery`，但 `Minimalism` 长期卡在 `0.245–0.331` 拉低五类均值。
   - **零泄漏内部归因**：在 `train_4400` 内部检查发现，WikiArt 原始 `Minimalism` 类近半数样本实为 **3D 展厅装置实拍照片**（日光灯管房间、地板砖块），最大化分类器超平面边际 $\ell_s - \max_{k\neq s}\ell_k$ 反而挑出位于决策边界外侧的离群实拍图（`DINO-S = 0.124`）！改用**纯 `train_4400` 内部 `kNN-30` 余弦核密度筛选（`Core-kNN`，零外部/参考集接触）**后，五类 40 个子流派原型的流形对齐度从 `[0.585, 0.490, 0.331, 0.527, 0.551]` 暴涨至 **`[0.801, 0.697, 0.619, 0.775, 0.759]`**（`Minimalism` 净增 **`+28.85pp`**！）。
2. **`GroupNorm` 尺度抵消陷阱与 Coarse-16 `SLFUNet` 分段视界流（`PRISM-Flow` 正面击败 `StyleGallery`）**：
   - 仅在 $16\times 16$ 瓶颈层注入结构语义、解放 $32\times 32$ 与 $64\times 64$ 层的 `SLFUNet`（`21.95M`）若在 `GroupNorm` 之前缩放 $\tilde{P}_{16}$，其方差重归一化会完全抹平尺度调节。将连续布局衰减 `layout_scale` 置于 `GroupNorm` 之后，并在 `Core-kNN` 2D 绘画核心集上微调 `1,800` 步（`9.9 min`），使 `Minimalism DINO-S` 从 `0.245` 跃升至 **`0.503`**（`CSD Top-1 = 100.0%`！）。
   - 旗舰档 **`V20_D1_core_slf_hiS`**（`134.1 ms/img`，比 `StyleGallery` 快 **`>134×`**）取得 **`DINO-S = 0.5789`**（超 `StyleGallery` `0.5604` **`+1.85pp`**，并超越 `StyleShot` `0.5750`！）、**`CLIP-S = 0.7576`**（`+3.17pp`）、**`Style Affinity = 0.6683`**（`+2.51pp`）、**`CSD Top-1 = 64.00%`**（`+11.50pp`）。
   - 连续调节桥接起点与视界参数（`D1 → D2 → D3 → D7 → D5 → D6`）形成从 `DINO-C = 0.501` 直抵 `0.669` 的无断层帕累托前沿墙；反事实错标签控制 `V20_D4_core_slf_wrong` 跌至 **`2.33%`**（因果特异性 **`+58.17pp`**）。
3. **多尺度 `Patch-SWD` 推进高保真 `Top-1 = 64.50%`，零 DINO `PRISM-Flash` 消融锁定单步下界**：
   - 在 `V19_T4` 基础上引入 `ConvNeXt-Tiny + RGB 3×3` 切片 Wasserstein 抛光（`V20_A1_t4_patchswd`），在保持高结构保真（`DINO-C = 0.6392`, `LPIPS = 0.5332`）的同时将 `CSD Top-1` 推至 **`64.33%–64.50%`**（`Ear = 40.8%`, `Uki = 47.5%`）。
   - 移除 `DINOv2` 与 `B4` 的纯潜空间单通网络 `PRISMFlashNet`（`1.75M` 参数）潜空间耗时仅 **`0.59 ms/img`**（含 `S10` 端到端 `13.27 ms/img = 75.4 img/s` @ 4090；**12GB RTX 3060 实机 `2.31 ms/img` 潜推理、`4.06 GB` 训练峰值**），但其 `DINO-C` 从 `PRISM-1`（`17.0 ms/img`）的 `0.7440` 跌至 `0.4677`——定量证伪了“纯潜卷积可替代 `DINOv2` 语义布局”的假说，确立 `PRISM-1`（`17.0 ms`）为单步最优形态。

## 五、12GB RTX 3060 实机兼容性与测速记录

在 `ssh 3060`（12.0 GB RTX 3060 Windows Server，禁用 `expandable_segments`）上完成实机验证：
- `src.utils.tier_micro_accum(128, device="cuda")` 自动收敛至 `(micro=32, accum=4)`；
- `21.95M` 参数 `SLFUNet` 前向 + 反向传播峰值显存仅 **`4.06 GB`**（远低于 `<= 6 GB` 安全红线）；
- `PRISMFlashNet` 纯潜空间耗时 **`2.31 ms/img`**，推理峰值显存 **`4.05 GB`**。

# 专项分析：DINOv2 特征复用导致的评估偏差与全链路零 DINO 迁移论证

> **专项结论**：对比 `V29 (DINOv2 Q32 + DINO 417D)` 与 `V32 (ConvNeXt-Tiny Stage-3 Zero-DINO)` 在完全一致的 `test750` 协议与 150 来源聚类 Bootstrap 95% CI 下的实测数据（[v32_nodino_summary.json](../../runs/v32_nodino/v32_nodino_summary.json) · [v32_vs_v29_ci.json](../../runs/v32_nodino/v32_vs_v29_ci.json) · [q32_6arm_diag.json](../../runs/v32_nodino/q32_6arm_diag.json)）：
> 1. 历史链路中的 `DINOv2` **并未造成 `DINO-S` 全局虚高**，但在 **`DINO-C` 上存在全线约 `0.02–0.03` 的稳定同源评估偏差**，并在纯噪声生成段（`s150`, $\tau_0=0$）与语义表征容量差异叠加放大；
> 2. 彻底切换至纯卷积 `ConvNeXt-Tiny Stage-3`（`12.35M`，`0.386 ms` @ `b=16`）后，全链路实现与五大评估裁判（`DINO-C / DINO-S / CSD / CLIP / LPIPS`）的 **100% 跨架构盲测隔离**，总参数精确收敛至 `56.43M`（含提取器与 `S10` 解码器），同时主工作点仍保持显著前沿优势。

## 一、历史架构中的评估同源隐患与审稿双标风险

在 `V21–V31` 架构中，尽管优化损失从未直接反向传播经过评测裁判 `DINOv2-small`，推理与训练输入仍包含两处 `DINOv2` 特征通道：
1. **内容骨架 `Q32`**：由灰度 `DINOv2-small` 经 Stiefel 极商正交提取（尽管二阶 Gram 风格泄漏已压至随机基线 `~20%`）；
2. **风格银行 `K=8` (`417-D`) 与场景路由**：除 `27-D Oklab` 与 `6-D Haar` 外，混入了 `384-D RGB DINOv2` 空间均值与灰度 `DINOv2` 粗场景向量 `sub_scene`。

由此引发两项结构性论文硬伤：
- **审稿逻辑双标**：反驳外部基线（如 `StyleGallery` 推理期基于冻结 `DINOv2` 做梯度蒸馏与区域匹配）的“评估器特征空间亲和”时，若我方条件通道自身仍使用同一 `DINOv2` 骨干，审稿人会直接质疑我方 `DINO-C` 乃至 `DINO-S` 同享同源红利；
- **端到端轻量化口径失真**：忽略首次 RGB 编码时加载重型 ViT（`86M` ViT-B / `304M` ViT-L 或外部 `DINOv2`）的计算体积与冷启动延迟。

## 二、因果隔离证据：`Q32` 六臂诊断 + `NoDINO` 从零重训全谱对照

### 1. 现有 `PStar_seed0` 上的 `Q32` 六臂因果诊断（full `test750`）
在固定 `V29` 权重下检验 $\tau_0 \in \{0.75, 0.00\} \times Q_{32} \in \{\text{correct}, \text{zero}, \text{shuffled}\}$（详见 [q32_6arm_diag.json](../../runs/v32_nodino/q32_6arm_diag.json)）：
- **`τ0 = 0.75` (`s=0.85`)**：保留 `Q32` 带来 **`ΔDINO-C = +0.0625`**（vs `zero`）与 **`+0.0742`**（vs `shuffled`），`LPIPS` 同步改善 `-0.0239 / -0.0334`（均 `excludes_zero=True`），但对 `DINO-S` 影响在噪声内（`+0.0028 / +0.0012`，`False`）；
- **`τ0 = 0.00` (`s=1.50`)**：`Q32` 置零会引发构图与风格双崩塌——`DINO-C` 跌 `-0.0853`、`DINO-S` 跌 **`-0.0877`**（其中 `Rococo` 从 `0.639` 骤降至 `0.371`）。

这证明 **内容条件不可删除，但只需强卷积中高层布局，完全不必耦合 ViT/DINOv2**。

## 三、核心机理解析：究竟证明了什么？

1. **全线显现的是 `DINO-C` 结构同源偏移（`-0.021 ~ -0.032`）**：
   从单步 `E-Core` 到 6 步 `s150`，`NoDINO` 在同推理设定下对 `DINO-C` 一致低 `0.021–0.032`；但在 `s090 vs s085` 上独立像素指标 `LPIPS` 差异为 `-0.0038`（95% CI 包含 0）。这直接实证：过去采用 `DINOv2 Q32` 时，生成的空间几何布局与 `DINOv2-C` 裁判的特征梯度天然更贴合，带来约 `0.02–0.03` 的轻微内容评估偏移；折算回等 `DINO-C` 曲线，中强段风格净差不超过 `~0.01`。
2. **`DINO-S` 未发现全局虚高，但 `s150` 揭示“轻度同源红利 + 语义容量差”叠加**：
   在主工作段 `l100 / s100 / s125`，删去 `K=8` DINO RGB 均值及 DINO `Q32` 后，`DINO-S` 分别为 `-0.0002`、`+0.0023`、`+0.0015` 级（均在统计噪音内），反证了 `WEAVE` 的主段风格性能并非依靠 DINO 捷径。仅在 `s150` ($\tau_0=0$ 纯噪声生成) 出现 `-0.0325 DINO-S` 伴随独立分类器 `CSD Top-1 -3.33pp`，且跌幅集中在 `Rococo (-0.100)`——与六臂诊断中 `Rococo` 对 `Q32` 高层语义依赖最强的现象完全一致，说明 `12.35M ConvNeXt-Stage3` 在极端纯噪声复杂构图下的语义表达容量略逊于 DINOv2。

## 四、终版切换决策与收敛收益

正式采用 **`Zero-DINO` (`V32 ConvNeXt-Stage3`) 作为终版底座**，实现四重论文闭环：
1. **100% 盲测隔离**：训练条件与五大评测裁判（`DINO-C / DINO-S / CSD / CLIP / LPIPS`）彻底跨架构解耦，无任何双标漏洞；
2. **真·全链路轻量化**：全系统 `ECore (11.13M) + PCore (22.29M) + ConvNeXt-Stage3 (12.35M) + S10 (10.66M) = 56.43M`，提取器 `4090 b=16` 仅 `0.386 ms`；
3. **前沿仍稳压外部基线**：`ECore 1-NFE` 保持 `67.17% Top-1 / 0.5077 S`，`s100/s125` 保持 `75.17%–77.33% Top-1` 与 `0.5628–0.5814 S`，`s150` `0.6054 S` 仍显著高于 `StyleShot (0.5750)`；
4. **消融价值提升**：成对提供 `V29 vs V32` 跨骨干对比，量化揭示特征同源性对评测尺度的实际影响边界。

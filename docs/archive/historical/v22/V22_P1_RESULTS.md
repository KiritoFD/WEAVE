1. **合法最优冠军 (`slf_T4Ssnap1500.pt`, 21.95M)**：
   - **固定门控推荐档 (`g=0.45, wc=1.0, τhi=0.66`)**：Cross600 **CSD Top-1 = `76.83%`**（vs `StyleGallery` `52.50%` **+24.33pp**，vs `V20 D5` `55.17%` **+21.66pp**）、**DINO-S = `0.5781`**、**Affinity = `0.6670`**、**DINO-C = `0.4779`**、**LPIPS = `0.6268`**（视觉审计通过，构图与主体群像保留完整）。
   - **零内容代价严格支配档 (`g=0.50, wc=1.5`)**：**CSD Top-1 = `69.00%`**（配对 Bootstrap vs `T0_wc14` **+8.33pp SIG**，`CI[+5.83, +11.00]`）、**DINO-C = `0.5319`**（vs `T0` Δ=+0.0012，**统计等效**）、DINO-S/Affinity/CLIP-S/LPIPS **全部显著优于基线**。
   - **标准甜点档 (`g=0.50, wc=1.0`)**：**CSD Top-1 = `73.67%`**（vs `T0_wc11` **+10.33pp SIG**）、**DINO-S = `0.5720`**、**DINO-C = `0.4992`**。
2. **极速低显存**：在 RTX 4090 上热路径（10步 RK2 Flow + S10 解码）仅 **`206.2 ms/img` (B=1, 峰值 410.8 MiB)** / **`85.2 ms/img` (B=16, 峰值 4.21 GiB)**，对比 `StyleGallery` (`30,400 ms/img`) 提速 **147×～357×**。
3. **诚实的边界披露**：`PRISM-Core-Simple` 在高风格档（`Top-1 ≥ 69%`）下内容相似度为 `DINO-C 0.478–0.532`，尚未在保持 `Top-1 ≥ 70%` 的同时追上 `StyleGallery` 的 `DINO-C = 0.6113`；`Top-1 ≥ 79%` 的激进工作点（如 `g=0.35 → 82.67%`, `g=0.42/τhi=0.55 → 81.00%`）经视觉审计处于边缘强融解状态，不作为默认推荐档发布。

## 三、P1：推理组件受控消融（25 臂核心结论）

基于冻结权重 `V20 slf_core_v2.pt` 与同噪声种子在 test750 上单因子拆解：

1. **锚点贡献（A 组）**：`A0 纯噪声 35.5%`、`A1 源图 20.5%` vs `A3 T4 55.8%` vs **`A2 PRISM-1 学生锚点 57.17%`**。结论：Flow 需要初始化锚点提供色盘与笔触先验，且 **`PRISM-1` 单步锚点以 1/27 的推理成本反超重型教师 `T4`**。
2. **四分支 CFG（B 组）**：
   - `B2 (wp=0)` 掉 `-6.3pp` → 纯风格分支 `wp(v_s0 - v_00)` 贡献显式风格拉动；
   - `B3 (wc=0)` 升 `+11.8pp` Top-1（达 `67.00%`），但视觉审计证实 **`wc ≤ 1.1` 在旧 ckpt 上会引发内容构图坍缩**（退化为风格条件生成），被视觉否决；
   - `B1 (v0c + wj(vsc-v0c))` 双分支简式风格完全崩塌（仅 `~36%`）→ **四分支线性组合必须保留**，`wc` 为核心内容-风格拨盘。
3. **复杂度密度门控（C 组，N1 判决）**：
   - 原版全自适应 `sigmoid((dsd-mid)*550)` Top-1 = `55.8%`；
   - 拆解为独立开关 `C1(tau)` / `C2(layout)` / `C3(guidance)` 与训练分布分位数 `C5(quantile)` 均不及**固定常数门控 `C0 (fixed g=0.5)` = `61.50%`（+5.7pp Top-1, +0.018 DINO-S）**；
   - 结论：**原密度门控本质是具有画派偏置的启发式，固定中位数门控全面更优且零超参**（N1 归入 `Core-Simple` 默认）。
4. **Core-kNN 原型（D 组）**：固定门控下 `K1` 类重心坍缩至 `46.0%`，而 `K4 (60.8%)`、`K8 (61.5%)`、`K8_core (61.5%)`、`random 随机训练样本 (61.0%)` 全部落在 ±0.5pp 等效区间——**有效成分是“多原型非重心采样”，无需昂贵的 Core-kNN 筛选**。

## 四、P2 & P3：同预算训练消融、曲线定位与三项低侵入改善

### 4.1 同预算训练矩阵（T0–T5，从 `slf_final.pt` 热启动 1800 updates）

| 臂 | Core 采样 | 内容 Dropout | Layout 训练 | 结构损失 | wc11 Top-1 | wc11 D-C | wc14 Top-1 | wc14 D-C |
|---|---|---|---|---|---:|---:|---:|---:|
| `T0` | 预训练锚点 | — | — | — | 63.33% | 0.5087 | 60.67% | 0.5306 |
| `T1` | 80% Core | 30% | 连续随机 | 0.10 | 61.00% | 0.5878 | 57.83% | 0.6130 |
| `T2` | 0%（全池） | 30% | 连续随机 | 0.10 | 60.67% | 0.5907 | 56.67% | 0.6159 |
| `T3` | 80% Core | 8% | 连续随机 | 0.10 | 58.33% | 0.6023 | 53.67% | 0.6275 |
| **`T4`** | **80% Core** | **30%** | **固定 1.0** | **0.10** | **69.00%** | **0.5112** | **66.00%** | **0.5295** |
| `T5` | 80% Core | 30% | 连续随机 | 0 | 61.33% | 0.5874 | 57.83% | 0.6125 |

**训练侧核心发现**：
1. **`layout_scale` 连续随机训练是内容崩溃与风格折损的训练端根源**：`T1/T2/T3/T5` 在允许 `layout_scale < 1` 后普遍掉 Top-1；而 **`T4 (layout 固定 1.0)`** 使模型从未学会"丢弃内容布局"，不仅在双档上登顶（`69.0% / 66.0%`），还让原本危险的 `wc=1.0` 低内容指导档彻底安全化并通过视觉审计（`70.67% @ wc=1.0`）。
2. **`T1` vs `T2` = `0.33pp`（Bootstrap `CI[-2.5, +1.8]`, 不显著）**：第三次证明 Core-kNN 过滤非必要。
3. **`T1` vs `T3` = `+2.67pp`**：30% 内容 dropout 显著强化无内容条件分支。
4. **`T1` vs `T5` = `±0.3pp`**：Coarse-LCN 显式结构损失对最终表现无贡献，可简化。

### 4.2 训练曲线峰值与 EMA 消融

- **T4S 3600-step 快照曲线（`wc=1.0, g=0.5`）**：  
  `600 (70.33%) → 900 (72.00%) → 1200 (73.67%) → 1500 (73.67%) → 1800 (70.67%) → 2100 (70.00%) → 2700 (68.33%) → 3300 (66.00%) → 3600 (65.67% ≈ T4L 66.00%)`
- **EMA 半衰期验证（1500 updates）**：`0.996 (73.67%) > 0.997 (72.17%) > 0.999 (70.83%)`——排除了 EMA 滞后假峰假说，确认 **`1200–1500 updates @ EMA=0.996` 为真实收敛甜点**。

### 4.3 架构与三项无训练改善（S32 & P3-N1/N2/N3）总结

| 实验 | 做法 | Cross600 结果 | 最终判决 |
|---|---|---|---|
| **S32 (`arch_s32.py`)** | 32×32 SPADE 残差结构注入 | `-17~-19pp` Top-1 暴跌 | **REJECTED**（同预算不足以训练新空间块；Coarse-16 胜出） |
| **P3-N1 (Gate)** | 解耦 `g_tau/g_layout/g_guid` vs 固定中位数 | **固定 `g=0.5` 反超原版 `+5.7pp`** | **ACCEPTED（简化保留固定门控）** |
| **P3-N2 (Trust Region)** | 粗亮度沿 `ŵ_Y` 潜空间回拉 (`beta=0.15~0.5`) | `ΔDINO-C ~ 0.000`（内容丢在中频语义） | **REJECTED** |
| **P3-N3 (Conflict Control)** | 诊断 `cos(d_s0, d_0c)=-0.110`（83.3% 冲突）；测试 `neg_proj`/`ortho`/`rms_cap` | `75.83% / DINO-C 0.4899`（等价于调 `wc=1.15` 的 `76.17% / 0.4881`） | **NEUTRAL（仅沿原 Pareto 平移，不并入）** |

## 六、3060 旁路 One-Shot 实验结论（P2-0 / P2-1 / P2-1b）

在 3060 上独立验证“能否不改动主干结构、仅以轻量全局 Adapter 赋予 V20 模型 arbitrary One-Shot 能力”：

1. **P2-0 双分支重训练 (`prism_dual_branch.pt`)**：强迫 `drop_content=False, layout_scale=1.0`，内容极强（`DINO-C=0.6649`），但单保留两分支时 `Top-1=36.2%`（风格偏弱）。
2. **P2-1 全局 `RefAdapter` (65.9K 参数) + 冻结双分支主干 + `onehot(5)=0`**：
   - `P2A_1shot_vsc` (自图重建目标)：`Top-1 = 12.17%`，`DINO-C = 0.6380`，`pred_eq_src = 55.8%`；
   - `P2A_1shot_cs_j` (双分支 CFG `wj=2.2`)：`Top-1 = 13.50%`，`DINO-C = 0.6623`，`pred_eq_src = 59.0%`；
   - **`P2B_1shot_v2_vsc` (异图重建目标 `z_target = z_ref`，强迫依赖 `u_style`)**：`Top-1 = 12.33%`，`DINO-C = 0.6284`，`pred_eq_src = 50.2%`。
3. **结论（路线判负，已关闭）**：两种监督目标均证实，冻结 V20 `SLFUNet` 主干且置零 `onehot(5)` 后，单靠 128D 全局 `StyleFiberEncoder` + 65K `RefAdapter` 无法把风格向量转化为真实风格迁移（输出大概率退回源图）。**任意参考 One-Shot 必须采用局部 Reference Attention + 主干联合训练路线（维持 V21 `PRISM-AttnFlow` 45.50% 1-Shot / 52.00% 4-Shot 为基础推进）**。

# WEAVE V6 · 24 小时加法 / 减法 / 乘法实验计划

**研究基点**：V6 D1_c1_gentle（Direct C3UNet，base_dim=48，1.88M，800 updates，有效 batch 240）。  
**算力约束**：单卡 RTX 4090，24 小时墙钟硬截止，串行 GPU 训练；当前 GPU 空闲。  
**版本依据**：用户提供的 `e153e5a` A0/A1 消融摘要，以及可访问的原始 `tools/v6/{models_v6,train_eval_v6,canonicalize,score_diff}.py`。远端连接暂未取到 `e153e5a`，因此新脚本细节须在 P0 审计。  
**目标**：不是最大化改动幅度，而是找出 V6 五风格迁移的最小有效机制，并把目标风格识别率、风格真实性和内容保真度组成可控的 Pareto 前沿。

## 0. 研究问题与已知事实

当前冻结 Val200 基线：

| 模型 | ΔT↑ | DINO-C↑ | LPIPS↓ | 改善的目标风格数 |
|---|---:|---:|---:|---:|
| A0 / D1 gentle | +0.0323 | 0.9167 | 0.3658 | 4/5 |
| T1 strong | +0.0404 | 0.8859 | 0.3984 | 4/5 |
| A1 no multi-scale injection | +0.0474 | 0.7920 | 0.4751 | 3/5 |

A1 的 ΔT 增益主要集中在 Impressionism（+0.0517→+0.1992），ER（+0.0378→−0.0291）、Ukiyo（−0.0078→−0.0849）同时恶化。它是一个**有价值的内容—风格边界实验**，而非删除内容注入的正面证据。

**必须纠正的历史因果表述：** V6 损失为
\[
L=L_{\rm rec}+\lambda_{\rm same}L_{\rm style,same}
+\lambda_sL_{\rm style,cross}+\lambda_cL_{\rm canon,inv},
\quad \lambda_c=w_{\rm cross}w_{\rm canon,inv}.
\]
A0 的 `(λ_same,λ_s,λ_c)=(0.25,0.35,0.525)`；T1 为 `(0.25,1.20,0.240)`。T1 同时增强风格和削弱内容约束，不能单独归因于某一个系数。过去的 T2/T3 也并非完全单因素。

## 1. 固定协议和验收口径

**数据/模型**：固定同一五风格训练集、同一 VAE、Core64 参考统计缓存、全局 C1 统计、训练/验证划分和模型初始种子。默认所有臂使用 800 updates、有效 batch 240、同 LR 计划、同 AMP/解码/参考集。只允许一个明示变更。每个臂保存参数、曝光量、耗时、峰值显存、完整配置 JSON 与 Git SHA。

**评测层级**：

1. `Smoke16`：前向、反向、同风格、梯度、Style-ID 交换、内容交换；不据此选模型。
2. `Screen50`：每目标 10 张，共 50 个跨风格任务，专用于大量推理旋钮粗筛；固定源图和 task-id 随机种子，不可宣称最终收益。
3. `Val200`：每目标 40 张，A0/T1/A1 与所有完整训练臂的主比较。报告每目标 Top-1、Margin、ΔT、ΔS、DINO-C、LPIPS、CSD-SWD/MMD 与可视化。
4. `Heldout400`：按独立源图拆分的 400 个任务，用于最终 2–3 个模型；`Test600` 只能作为与论文 Baseline 的统一比较口径。注意历史 V6.1 已查看过 Heldout400，**不能将其宣传为完全未参与过研究决策的盲测集**；若可快速建立全新 source-heldout，请作为补充。
5. `Same150`：实际运行网络后评测同风格重建；禁止用代码级硬 Identity 冒充模型学会自一致。

机会水平：五类均匀猜测为 20%；已知源风格且仅在四个合法非源目标中猜测为 25%。所有汇总以**五目标等权宏平均**，另给最弱目标、五类混淆矩阵与目标分布多样性。DINO-C 与 LPIPS 只能衡量源图差异，不能单独当作画质指标。

**排名使用 Pareto 而非单值**：A0、T1、A1，以及既有 ScoreDiff 16/20/24 步构成候选前沿。对新模型在相近 DINO-C（±0.02）处比较 ΔT/Top-1；若显著改善某目标却牺牲其他目标，要明确记录，不只看总体。

**Go/No-Go**：继续开发需满足：① 相对同内容档位 ΔT 至少 +0.008，或 Top-1 至少 +5pp；② 不出现 2/5 以上目标的 ΔT 显著退化；③ 内容和 LPIPS 在声明的档位内；④ CSD 以外至少一种独立风格评价/人工盲图不否认收益。Val200 的 40 张/目标不足以支持小幅 Top-1 变化的强断言，应使用按源图聚类的配对 bootstrap，最终以 Heldout400 复核。

## 3. P0（第 0–1 小时）：基点与缺陷核验

- A0 `model/eval200` 的指标与用户报告一致；A1 的 `no_content` 确实只断开额外多尺度注入，Stem `c` 与 `out=c+Δ` 仍在。
- A2 的 `no_style` 必须同时关掉 **StyleAdaLN 条件与 PaletteHead Style-ID**，但评测/风格损失仍按真实目标 `j` 计算；否则不是合法 Style-ID 消融。
- A3 必须仅将 `c_in=C(z)` 改为 `c_in=z`，不要偷偷更改 `L_canon,inv` 的定义；若规范化及损失同时移除，需要另列变体。
- 原始 `canonicalize.py` 的 `c1_soft` 路径存在 `hl_full=hl_n*hl_std+lh_mean` 的均值引用错误。修正后记录版本差异，**不把历史 soft/gentle 差异直接当作干净的规范化消融**。A0/gentle 不受该行影响。
- 确认 V5 B1 checkpoint 是否确实被 A0 加载，并打印 B1 分支加权 Loss 与真实 Batch 梯度；缺失则该分支原本无效，N6 自动跳过。
- 确认完整参考缓存不读取 eval/test 图，不重建测试参考统计；训练期间目标随机分配覆盖每类。
- 做 `A0`, `T1`, `A1` 三组旧权重的统一 Val200 复评分和 5×5 混淆矩阵；如缓存已有可复用输出，不必重解码。
- 任何新增损失均须在真实 Batch 检查 `grad_norm>0`、梯度方向、有限差分（合理扰动尺度）和数值稳定；不能再用 Loss 非零证明有梯度。
- 编写串行队列，单 GPU 进程排他锁，单臂超时与自动失败标记；禁止 watcher 抢占 GPU。状态 JSON 实时落盘，不依赖后台人工轮询。

## 4. 减法Ⅰ（第 1–6 小时）：最多 7 臂

除特殊标注外，全部使用原 A0 配方、同种子和预算。只改一项。

| ID | 变量 | 必须验证什么 | 决策 |
|---|---|---|---|
| N1 `A2_no_style` | StyleAdaLN 与 PaletteHead 均固定风格 ID | 5×5 同源不同目标输出差异、Top-1、ΔT | 证明 Style-ID 作用；**不是**证明 AdaLN 参数量不能折叠 |
| N2 `A3_no_canon` | 输入 c=z，内容一致性项不变 | 风格、结构与训练自重建 | 若不劣才删 C1 |
| N3 `A5_dim32` | base_dim 48→32 | 参数约 0.85M、速度、质量 | 若不劣则选 32 |
| N4 `A7_steps400` | 训练预算 800→400、独立 LR 周期 | 低预算是否充分 | 同时比较 800-run 第400步中间权重（若有） |
| N5 `inv_off` | λ_c 0.525→0，λ_s 固定 0.35 | 内容一致性是否单独必要 | 禁止沿用 T2 推断 |
| N6 `B1_off` | 只删除 B1 监督，保留 DWT 损失 | 是否能删除额外编码器 | 若 B1 未加载，直接判定空操作并替补 |
| N7 `dim24_or_dim40` | N3 成功选 24；失败选 40 | 确定最小有效宽度 | 其他配置固定 |

用于选择**最小可训练**基点的非劣阈值（对 A0）：ΔT≥0.0273、DINO-C≥0.9017、LPIPS≤0.3858；最弱目标不额外恶化 0.01。阈值用于筛选，细微差异必须看配对 CI。

另做**零训练精确压缩**：Direct 的 12 通道 Stem 折叠至 4 通道，常量 time 条件合并进按 Style-ID 预计算的 AdaLN 表，`coherence_beta=0` 的无效目标变换删除。先只做 inference checkpoint conversion，逐图验证输出一致（fp32 最大差异、bf16/AMP 容差），不得把等价部署压缩混称为“从零训练也无损”。

`A1b_content_none` 不进入这 7 臂：Direct 没有随机输入，完全删除 c 后每目标只能输出同一张确定性图，因此可做 16 样本输入不变性负控；它不能与正常风格迁移候选公平比较。

## 5. 减法Ⅱ（第 6–9.5 小时）：最多 5 臂

首先把当前乘积形式的权重**解耦**：
\[
L=L_{\rm rec}+0.25L_{\rm same}+\lambda_sL_{\rm cross}+\lambda_cL_{\rm inv}.
\]
固定训练代码，保证 `λ_c` 不再随 `λ_s` 自动变化。

| ID | λ_s | λ_c | 其他变化 | 研究问题 |
|---|---:|---:|---|---|
| L1 `factor_lowC` | 0.35 | 0.240 | 无 | 单独减轻内容约束（与 A0 比） |
| L2 `factor_highS` | 1.20 | 0.525 | 无 | 单独增强风格监督（与 A0 比） |
| L3 `core_sampler_off` | 0.35 | 0.525 | Core64 采样由 50% 改为 0%，参考统计仍 Core64 | 典型画作重复曝光是否造成偏置 |
| L4 `ref_full` | 0.35 | 0.525 | 风格参考统计改为全训练集或画家均衡子集；采样仍原样 | Core64 目标统计是否偏向题材/少数画家 |
| L5 `same_style_off` | 0.35 | 0.525 | λ_same=0，L_rec 不变 | 同风格分布监督是否必要 |

原 A0 = `(0.35,0.525)`；原 T1 = `(1.20,0.240)`，它们与 L1/L2 共同构成解释风格/内容影响的 **2×2 因子设计**。必要时只在最后挑一组中间配方（非本阶段默认臂），不要无界调参。

**判断标准**：保留模块/损失只因为其有独立、可复现的正贡献；如果删除后训练更快、性能非劣，标记 Remove。如果删掉后 ΔT 变好但 DINO-C 降低，归类为 Pareto trade-off，不标记 Remove。Core64 采样与 Core64 参考统计必须分别判断，不能一起改。

## 6. 加法（第 9.5–14.5 小时）：最多 6 臂

**先完成最有机制解释力的三个尺度实验，剩余三个有条件执行。** 每臂使用筛选出的最小有效 D1；但为保证与 A0 的可比性，至少对同一宽度做一个参考重训/使用已匹配 checkpoint。若宽度改变产生明显性能漂移，则先统一退回 48，不允许“宽度变化 + 新机制”同时作为结论。

| ID | 加/减项 | 最小实现 | 假说 |
|---|---|---|---|
| S1 `no_inject_64` | 关闭 64×64 编解码内容注入，保留 Stem 和其他尺度 | 高频内容约束是否压制目标笔触 |
| S2 `no_inject_32` | 关闭 32×32 内容注入 | 中尺度形状/纹理约束是否过强 |
| S3 `no_inject_16` | 关闭 16×16 内容注入 | 粗结构条件是否是保持内容的关键 |
| S4 `target_scale_gate` | 每目标×每尺度仅 15 个可学习门控，初值 1；范围约 [0,1.5]，轻微正则到1 | 统一尺度开关是否能改成按目标适配 |
| S5 `HF_structure_loss` | 额外匹配真实目标风格的 HF 方向共现/跨尺度局部自相关统计；冻结真实参考统计 | 提供原始 DWT 均值/协方差/4×4 PatchSWD 缺少的长程笔触关系 |
| S6 `style_key_residual`（条件） | 在 16×16 bottleneck 添加每风格 K=8 个可学习 style keys 的低秩残差 cross-attention；输出初始化为零，其他损失不变 | 通过内容位置选择目标风格原型，而不是只加全局 Style-ID |

**S4 工程约束**：不要先通过单纯 inference gate=0 的结果声称一个连续门控已经被训练。门控参数按照五目标分别学习；如果 S1–S3 没有揭示稳定、可理解的尺度差异，取消 S4。

**S5 预实验（≤30分钟）**：从目标训练真图提取多尺度 Haar HF 的定向邻域相关（位移1/2/4像素）、二阶方向共现；用独立画家、题材匹配的真实样本检验其区分风格的能力，同时计算与当前 PatchSWD 的相关性。若近乎完全冗余、无法区分困难目标，则取消 S5，不能只为了“新 Loss”而添加。真图统计只在训练集离线缓存。新 Loss 在真实训练 Batch 的加权梯度范数相对 `L_rec+L_cross` 控制在约 0.1–0.4，不能靠随意放大系数直接压倒原目标。

**S6 预实验**：Style key 是**类别条件原型**，而非任意 style-reference 图像注意力。只在 S1–S5 已完成、剩余开发/训练窗口足够且 30 分钟内实现和通过 shape/grad/memory 测试时运行；否则将该臂替换为 S1–S3 中最佳尺度配置的二种子复现。不要在同一臂同时引入 Style Key 和新 Style Loss，以免丧失归因。

**保留条件**：新机制在匹配内容水平上改善 ΔT/Top-1，并且至少 ER、Rococo、Ukiyo 中一个困难目标获得明确收益；A1 所见“仅 Imp 暴涨、其他退化”不能作为加法成功。

文献动机：AdaAttN（ICCV 2021）指出全局统计不足以捕获局部风格，StyA2K（ICCV 2023）说明选择性 style keys 可减小注意力匹配中的结构失真；本实验只是**轻量受控借鉴**，并非复现它们的完整算法。

## 7. 乘法（第 14.5–19 小时）：不训练的风格—内容控制

乘法阶段只使用冻结的 A0、T1、最小有效 D1、最佳结构候选和现有 V6 ScoreDiff 权重。目标是测**可控性**，不是再次通过过度编辑制造单点高分。

### M0：最简单的 Direct 插值控制

\[
T_{\alpha}(z,s)=z+\alpha[G(C(z),s)-z],\quad \alpha\in[0,1].
\]

先取 α={0,0.25,0.5,0.75,1}。禁止把 α>1 当主线；历史已有 `α=1.8/2.2` 出现 Top-1 上升却 ΔT 下降、LPIPS 激增。对每个模型、每目标，绘制 `(ΔT,Top1,DINO-C,LPIPS)` 曲线并检查是否单调。α=0 必须复现 Identity。

### M1：ScoreDiff 的强度/保护旋钮

\[
z_{k+1}=z_k+\eta_{j}\,\mathcal{P}_{\beta}
\left[g_{s\to j}(z_k)\right],
\]
其中基础版 \(\mathcal P_0\) 为恒等，\(\eta_j=\eta\cdot r_j\) 为每目标强度，另有结构锚定 \(a\)。

先在 `Screen50` 用固定 task-id 噪声粗筛：步数 N={8,12,16,20,24}、基本步长 η={0.055,0.10,0.16}、锚定 a={0,0.08}。**不是盲跑 30×200 次完整 CPU 评测**：一次加载 CSD/DINO，缓存真实源特征和各阶段生成图；在初筛挑每种内容档位最多 2 个候选进入 Val200。

在 `Val200` 上再做**目标专属标定** `r_j`：不让 Minimalism 的高 Top-1 抵消 Ukiyo/Rococo 失效。选参只使用验证集，五风格所有结果完整保存。

### M2：D1→ScoreDiff 与单独 ScoreDiff 的对照

对相同源图和风格条件比较：
- D1 only；
- ScoreDiff(source) only；
- D1→ScoreDiff（ScoreDiff 从 D1 输出初始化，N={4,8,12}）。

注意 D1 输出已经具有部分目标风格，继续施加原 `source→target` 分数差会过冲，不能事先宣称两个模块互补。若组合没有优于同内容档位的 ScoreDiff only，立刻删除组合路线。

### M3：内容切向保护（可选，优先于额外多步 Bridge）

令 \(C\) 为现有 canonicalizer，\(q=\nabla_z\|C(z)-C(z_{\rm src})\|_2^2\)，\(g\) 为 ScoreDiff 更新。定义：
\[
g_{\rm safe}=g-\beta\,\frac{\max(0,\langle g,q\rangle)}
{\|q\|_2^2+\epsilon}\,q,\quad \beta\in\{0,0.5,1\}.
\]
它在局部一阶近似下去除**增加内容规范化距离**的更新分量，不需要 VAE 解码或外部教师；但 canonicalizer 不能完全代表内容，仍需独立 DINO/目视确认。设置梯度范数下界、阻止 NaN，并记录每步投影比例。只在 Screen50 出现 Pareto 改善后扩大评测。

### 旋钮最终输出

建立三档**自动可复现**预设：保真（DINO-C≥0.90）、均衡（≥0.80）、风格优先（≥0.65），每档均记录每目标最优参数、CSD ΔT、Top-1、Margin、SWD、DINO-C、LPIPS。门槛是选择约束，不是高画质保证；每档仍需人工检查高清图。

## 8. P5（19–22 小时）：最终评测

固定候选，不在 Heldout400 上继续调参，默认选：
1. 最小有效 Direct 版本；
2. 训练或结构上真正改善 Pareto 的一个候选；
3. 最好的乘法风格增强配方（ScoreDiff 或 D1→ScoreDiff）。

每种跑独立源图 Heldout400 与 Same150，必要时 2 seed；同一任务固定噪声和相同参考，计算按源图聚类的配对 bootstrap 95% CI。对论文 13 个 Baseline 使用统一 `paper_rgb_v1` 进行排名，但要报告**风格榜与内容榜分别排名**，不得混称 SOTA。

额外保存至少 5 类×4 源风格×3 内容档位的可视化格图；人工盲评至少覆盖 ER/Rococo/Ukiyo 三个难目标，逐项标出缺失笔触、色块、轮廓、边缘崩坏与语义替换。风格真实性与分类器可攻击性须分开。

## 9. 自动化停止规则

- **时间**：24h 为墙钟上限；单臂超预算 1.5×即终止并记为 incomplete，不篡改曝光量；每阶段结束检查剩余时间，先保留 P5 的 3h 与 2h 缓冲。
- **工程**：发现无梯度、错目标分组、数据泄漏、随机种子漂移或 Style-ID 未完全固定，当前臂标 INVALID；修复后重跑，而非解释异常指标。
- **统计**：微小的 Val200 Top-1 (+1–2pp) 不作为突破；提高 ΔT 却造成困难目标退化、内容显著下降，只记 Pareto trade-off。
- **机制**：Style Key、HF 新 Loss、内容投影各自只有在**独立模块/独立指标**成立后才保留；未有效则归档 Negative_Results，禁止继续堆叠成组合大模型。
- **工作量**：如果 S5/S6 的实现与验证超时，优先完成已有三尺度消融与乘法阶段，**不牺牲最终评测**。

## 11. 预期能得到的科学结论（不是预设实验结果）

- 若删掉某尺度注入后对 ER/Ukiyo 不再有害且提高 Imp，说明不是“内容与风格必然冲突”，而是**内容注入的空间频率配置不适合所有风格**。
- 若损失 2×2 发现只增风格不降内容也能提高 ΔT，说明 T1 的核心收益来自风格学习，而非单纯“放松内容”。
- 若删除 B1 / Core64 不掉点，则 V6 的有效性更多来自自重建、跨风格正则和局部统计，而非辅助风格判别器/少量核心作品。
- 若结构/损失加法都失败，但 ScoreDiff 旋钮能有效提升真实画风且保留一定内容，则优先研究**可标定的推理控制**，而非加大网络。
- 若分类器 ΔT 明显改善但独立评价和盲图不支持，应判为指标偏移，不能作为模型改进。

**最终原则：减法要因果可解释，加法要改善真实风格的 Pareto 前沿，乘法要在固定模型上连续可控；三者均以 V6 D1 作为唯一稳定基点。**
